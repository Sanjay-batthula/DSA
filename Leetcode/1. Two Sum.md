# 1. Two Sum 

## Problem Statement
Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

 
## Sample Test Cases 
Example 1:
```
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].  

Example 2:
```
Input: nums = [3,2,4], target = 6
Output: [1,2]
```
Example 3:
```
Input: nums = [3,3], target = 6
Output: [0,1]
```

## Brute force approach

| Section              | Details                                                   |
| -------------------- | --------------------------------------------------------- |
| **Intuition**        | Try every pair to find the target sum.                    |
| **Approach**         | Use nested loops and check if any pair equals the target. |
| **Time Complexity**  | `O(n^2)`                                                  |
| **Space Complexity** | `O(1)`                                                    |


```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for(int i=0;i<nums.length;i++){
            for(int j=i+1;j<nums.length;j++){
                if(nums[i]+nums[j]==target){
                    return new int[]{i,j};
                }
            }
        }
        return new int[]{};
    }
}
```

## Hash Map Approach ✅

| Section              | Details                                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Intuition**        | Store numbers in a map while scanning; check if the complement already exists.                                            |
| **Approach**         | Iterate once, compute `target - nums[i]`, look it up in the map, return indices if found; otherwise store current number. |
| **Time Complexity**  | `O(n)`                                                                                                                    |
| **Space Complexity** | `O(n)`                                                                                                                    |

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> d = new HashMap<>();
        for (int i = 0;; ++i) {
            int x = nums[i];
            int y = target - x;
            if (d.containsKey(y)) {
                return new int[] {d.get(y), i};
            }
            d.put(x, i);
        }
    }
}
```

## Two-pass HashMap

| Section              | Details                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Intuition**        | First map all values to indices, then scan again to check if the complement exists.                                            |
| **Approach**         | Pass 1: build a hash map of value → index. Pass 2: for each value, check if `target - value` exists and is not the same index. |
| **Time Complexity**  | `O(n)`                                                                                                                         |
| **Space Complexity** | `O(n)`                                                                                                                         |

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) map.put(nums[i], i);
        for (int i = 0; i < nums.length; i++) {
            int y = target - nums[i];
            if (map.containsKey(y) && map.get(y) != i) return new int[]{i, map.get(y)};
        }
        return new int[]{};
    }
}
```

## Two-pointer Approach (after sorting)

| Section              | Details                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Intuition**        | Sort the array and use two pointers from both ends to move toward the target sum.                               |
| **Approach**         | Store value–index pairs, sort by value, use left/right pointers to find the pair, then return original indices. |
| **Time Complexity**  | `O(n log n)`                                                                                                    |
| **Space Complexity** | `O(n)`                                                                                                          |

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int[][] arr = new int[nums.length][2];
        for (int i = 0; i < nums.length; i++) arr[i] = new int[]{nums[i], i};
        Arrays.sort(arr, Comparator.comparingInt(a -> a[0]));
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int sum = arr[left][0] + arr[right][0];
            if (sum == target) return new int[]{arr[left][1], arr[right][1]};
            else if (sum < target) left++;
            else right--;
        }
        return new int[]{};
    }
}
```

## Binary Search (for sorted arrays) - Wrong Answer
| Section               | Details                                                                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition**         | Fix one element, binary search for its complement in the remaining array.                                                                 |
| **Approach**          | For each index, compute `target - nums[i]` and binary search the rest of the array; returns wrong results on unsorted input.              |
| **Reason It's Wrong** | Binary search requires the array to be sorted, but sorting breaks original indices, and using the unsorted array gives incorrect results. |
| **Time Complexity**   | `O(n log n)`                                                                                                                              |
| **Space Complexity**  | `O(1)`                                                                                                                                    |

```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            int idx = Arrays.binarySearch(nums, i + 1, nums.length, complement);
            if (idx > i) return new int[]{i, idx};
        }
        return new int[]{};
    }
}
```


## Approach Comparison

| Approach | Time Complexity | Space Complexity | Works on Unsorted? | Keeps Indices? | Notes |
|---------|-----------------|------------------|---------------------|----------------|-------|
| Brute Force | `O(n^2)` | `O(1)` | ✔️ | ✔️ | Slowest |
| Hash Map (One-pass) | `O(n)` | `O(n)` | ✔️ | ✔️ | ⭐ Optimal |
| Two-pass Hash Map | `O(n)` | `O(n)` | ✔️ | ✔️ | Slightly redundant vs one-pass |
| Two-pointer (Sorted) | `O(n log n)` | `O(n)` | ❌ | ✔️ | Good only when sorting allowed |
| Binary Search (Wrong) | `O(n log n)` | `O(1)` | ❌ | ❌ | Fails for unsorted input |



## Summary
- Optimal approach: HashMap (O(n))
- Sorting + Two-pointer works but slower (O(n log n))
- Brute force is simplest but slowest (O(n²))
