# 102. Binary Tree Level Order Traversal

## Problem Statement
Given the root of a binary tree, return its nodes in level-order traversal, meaning from left to right, level by level.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `root = [3,9,20,null,null,15,7]` | `[[3],[9,20],[15,7]]` |
| `root = [1]` | `[[1]]` |
| `root = []` | `[]` |

## Constraints
- The number of nodes in the tree is in the range `[0, 2000]`.
- `-1000 <= Node.val <= 1000`

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| BFS with queue | Breadth-First Search | `O(n)` | `O(w)` |
| DFS with level index | Depth-First Search | `O(n)` | `O(h)` |

## Code
### Pattern
- BFS
- DFS

### Intuition
A level-order traversal naturally suggests breadth-first search. We process nodes level by level by keeping a queue of nodes to visit. For each level, we know exactly how many nodes are currently in the queue, so we can collect that level’s values together.

A recursive DFS approach is also possible. The idea is to add each node to the list corresponding to its depth. This avoids explicit queue usage and still produces the same structure.

### Algorithm
1. If the tree is empty, return an empty list.
2. Initialize a queue with the root node.
3. While the queue is not empty:
   - Determine the number of nodes in the current level.
   - Process that many nodes, adding their values to a temporary list.
   - Enqueue their children.
   - Append the temporary list to the result.
4. Return the result.

### Code
```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        Queue<TreeNode> queue = new LinkedList<>();
        List<List<Integer>> result = new ArrayList<>();

        if (root == null) return result;
        queue.add(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> currentLevel = new ArrayList<>();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                currentLevel.add(node.val);

                if (node.left != null) queue.add(node.left);
                if (node.right != null) queue.add(node.right);
            }

            result.add(currentLevel);
        }

        return result;
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(w)`

## Other Approaches
### DFS with Level Index
#### Pattern
- DFS
- Recursion

#### Intuition
In a recursive DFS, each node knows its depth. We can place the node value into the corresponding list for that level. If the level does not exist yet, we create a new list.

#### Algorithm
1. Start DFS from the root at depth `0`.
2. If the current level is beyond the size of the result, create a new list.
3. Add the node value to that level’s list.
4. Recurse into the left and right children with `level + 1`.

#### Code
```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, 0, result);
        return result;
    }

    private void dfs(TreeNode node, int level, List<List<Integer>> result) {
        if (node == null) return;

        if (level == result.size()) {
            result.add(new ArrayList<>());
        }

        result.get(level).add(node.val);
        dfs(node.left, level + 1, result);
        dfs(node.right, level + 1, result);
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(h)`

## Approach Comparison
| Approach | Pattern | Time | Space | Pros | Cons |
| --- | --- | --- | --- | --- | --- |
| BFS with queue | BFS | `O(n)` | `O(w)` | Naturally matches level-order traversal | Uses extra queue space |
| DFS with level index | DFS | `O(n)` | `O(h)` | Elegant recursive solution | Slightly less intuitive for level-based ordering |

## Key Observations
- Level-order traversal is the standard output of BFS.
- The queue size at the start of each loop equals the number of nodes in the current level.
- DFS can also solve the problem by assigning each node to its correct depth.

## Common Mistakes
- Forgetting to process exactly one level at a time.
- Not adding child nodes after popping the current node.
- Using the wrong level index in the recursive DFS version.

## Related Patterns
- BFS
- DFS
- Tree Traversal

## Summary
- The optimal solution uses BFS with a queue to process the tree level by level.
- The pattern is breadth-first traversal.
- Time complexity is `O(n)`, and space complexity is `O(w)`, where $w$ is the maximum width of the tree.
- Interview takeaway: level-order traversal is one of the most common applications of BFS on trees.
