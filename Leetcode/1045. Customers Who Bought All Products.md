# 1045. Customers Who Bought All Products

## Problem Statement

Return the IDs of customers who bought every product listed in `Product`. The `Customer` table may contain duplicate rows; `customer_id` is not `NULL`.

## Sample Test Case

```text
Customer:
+-------------+-------------+
| customer_id | product_key |
+-------------+-------------+
| 1           | 5           |
| 2           | 6           |
| 3           | 5           |
| 3           | 6           |
| 1           | 6           |
+-------------+-------------+

Product:
+-------------+
| product_key |
+-------------+
| 5           |
| 6           |
+-------------+

Output:
+-------------+
| customer_id |
+-------------+
| 1           |
| 3           |
+-------------+
```

Customers `1` and `3` each bought both products, `5` and `6`.

## Group By + Count Comparison ✅

```sql
SELECT a.customer_id
FROM (
    SELECT customer_id, COUNT(DISTINCT product_key) AS num
    FROM Customer
    GROUP BY customer_id
) AS a
WHERE a.num = (
    SELECT COUNT(DISTINCT product_key)
    FROM Product
);
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | A customer has all products when their number of distinct purchased products equals the number of products available. |
| **Approach** | Count each customer's distinct `product_key` values, then compare that count with the product count from `Product`. `DISTINCT` prevents duplicate purchase rows from inflating a customer's count. |
| **Key Concepts** | `GROUP BY`, `COUNT(DISTINCT)`, scalar subquery |

## Alternative Approach: Relational Division with `NOT EXISTS`

```sql
SELECT DISTINCT c1.customer_id
FROM Customer c1
WHERE NOT EXISTS (
    SELECT product_key
    FROM Product p
    WHERE NOT EXISTS (
        SELECT 1
        FROM Customer c2
        WHERE c2.customer_id = c1.customer_id
          AND c2.product_key = p.product_key
    )
);
```

For each customer, the nested `NOT EXISTS` checks that there is no product for which that customer lacks a matching purchase. The original note labels this approach TLE; its actual performance depends on the database and data size.

## Summary

- Compare each customer's count of distinct products with the total number of products.
- Use `COUNT(DISTINCT product_key)` so duplicate rows do not affect the result.
- Nested `NOT EXISTS` expresses the same requirement as “there is no product this customer did not buy.”
