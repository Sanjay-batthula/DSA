# 1061. Lexicographically Smallest Equivalent String

## Problem Statement

Given equal-length strings `s1` and `s2`, each corresponding pair of characters defines an equivalence. Equivalence is reflexive, symmetric, and transitive. Replace each character in `baseStr` with the lexicographically smallest character in its equivalence class, and return the resulting string.

The strings contain lowercase English letters; `s1` and `s2` have equal lengths, and each input string has length from 1 to 1000.

## Sample Test Cases

### Example 1

```text
Input: s1 = "parker", s2 = "morris", baseStr = "parser"
Output: "makkek"
```

The equivalence classes include `[m,p]`, `[a,o]`, `[k,r,s]`, and `[e,i]`.

### Example 2

```text
Input: s1 = "hello", s2 = "world", baseStr = "hold"
Output: "hdld"
```

### Example 3

```text
Input: s1 = "leetcode", s2 = "programs", baseStr = "sourcecode"
Output: "aauaaaaada"
```

## Union-Find with Lexicographically Smallest Root ✅

| Section | Details |
|---|---|
| **Intuition** | Equivalent characters form connected groups. If each group's representative is its smallest letter, every character can be replaced directly by that representative. |
| **Approach** | Initialize each of the 26 letters as its own parent. For every pair in `s1` and `s2`, find the roots and attach the larger root to the smaller one. Then map each character of `baseStr` to its root. |
| **Time Complexity** | `O(|s1| + |baseStr|)` amortized, with near-constant union-find operations over a fixed 26-letter alphabet. |
| **Space Complexity** | `O(26 + |baseStr|)` including the parent array and output; `O(26)` auxiliary space excluding the result. |

```java
class Solution {
    private final int[] p = new int[26];

    public String smallestEquivalentString(String s1, String s2, String baseStr) {
        for (int i = 0; i < p.length; ++i) {
            p[i] = i;
        }
        for (int i = 0; i < s1.length(); ++i) {
            int x = s1.charAt(i) - 'a';
            int y = s2.charAt(i) - 'a';
            int px = find(x), py = find(y);
            if (px < py) {
                p[py] = px;
            } else {
                p[px] = py;
            }
        }
        char[] s = baseStr.toCharArray();
        for (int i = 0; i < s.length; ++i) {
            s[i] = (char) ('a' + find(s[i] - 'a'));
        }
        return String.valueOf(s);
    }

    private int find(int x) {
        if (p[x] != x) {
            p[x] = find(p[x]);
        }
        return p[x];
    }
}
```

## Graph + DFS: Connected Components

| Section | Details |
|---|---|
| **Intuition** | Each equivalence pair creates an undirected edge. All mutually reachable letters belong to the same equivalence class. |
| **Approach** | Build a graph from corresponding character pairs. DFS each component, find its smallest letter, then use that minimum as the replacement for every character in the component. |
| **Time Complexity** | `O(26 + |s1| + |baseStr|)`; each letter and equivalence edge is traversed a bounded number of times. |
| **Space Complexity** | `O(26 + |s1| + |baseStr|)` including graph, traversal structures, and output; `O(26 + |s1|)` auxiliary space excluding the result. |

```java
class Solution {
    public String smallestEquivalentString(String s1, String s2, String baseStr) {
        List<Integer>[] graph = new ArrayList[26];
        for(int i = 0; i < 26; i++) graph[i] = new ArrayList<>();

        for(int i = 0; i < s1.length(); i++){
            int a = s1.charAt(i) - 'a';
            int b = s2.charAt(i) - 'a';
            graph[a].add(b);
            graph[b].add(a);
        }

        int[] smallest = new int[26];
        Arrays.fill(smallest, -1);

        for(int i = 0; i < 26; i++){
            if(smallest[i] == -1){
                List<Integer> comp = new ArrayList<>();
                dfs(i, graph, comp, smallest);

                int min = 26;
                for(int x : comp) min = Math.min(min, x);

                for(int x : comp) smallest[x] = min;
            }
        }

        StringBuilder res = new StringBuilder();
        for(char c : baseStr.toCharArray()){
            res.append((char)(smallest[c - 'a'] + 'a'));
        }

        return res.toString();
    }

    void dfs(int node, List<Integer>[] graph, List<Integer> comp, int[] smallest){
        if(smallest[node] != -1) return;

        smallest[node] = -2;
        comp.add(node);

        for(int nei : graph[node]){
            dfs(nei, graph, comp, smallest);
        }
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Auxiliary Space | Notes |
|---|---|---|---|
| Union-find | `O(|s1| + |baseStr|)` amortized | `O(26)` | Keeps the smallest letter as each component's root. |
| Graph + DFS | `O(26 + |s1| + |baseStr|)` | `O(26 + |s1|)` | Builds connected components, then finds each component's minimum. |

## Summary

- Corresponding characters in `s1` and `s2` define equivalence relations that combine transitively.
- The smallest character in each connected group is the replacement for every letter in that group.
- Union-find stores that minimum as the root; DFS discovers components and computes their minima explicitly.
