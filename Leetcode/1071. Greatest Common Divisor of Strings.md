# 1071. Greatest Common Divisor of Strings

## Problem Statement

For two strings $s$ and $t$, we say "t divides s" if and only if $s = t + t + \ldots + t$ (i.e., $t$ is concatenated with itself one or more times).

Given two strings $str1$ and $str2$, return the largest string $x$ such that $x$ divides both $str1$ and $str2$.

---

## Sample Test Cases

| Input | Output |
|-------|--------|
| str1 = "ABCABC", str2 = "ABC" | "ABC" |
| str1 = "ABABAB", str2 = "ABAB" | "AB" |
| str1 = "LEET", str2 = "CODE" | "" |
| str1 = "AAAAAB", str2 = "AAA" | "" |

---

## Constraints

- $1 \leq str1.length,\ str2.length \leq 1000$
- $str1$ and $str2$ consist of English uppercase letters.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Math | Euclidean algorithm for string GCD | $O(m+n)$ | $O(m+n)$ |
| Brute Force | Try all prefixes | $O((m+n)\cdot min(m,n))$ | $O(m+n)$ |

---

## Code: String GCD using the Euclidean Algorithm

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Euclidean algorithm for string GCD | $O(m+n)$ | $O(m+n)$ |

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        if (!(str1 + str2).equals(str2 + str1)) {
            return "";
        }
        int gcdLength = gcd(str1.length(), str2.length());
        return str1.substring(0, gcdLength);
    }
    
    private int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
}
```

## Code: Brute Force Prefix Enumeration with Repetition Check

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Try all prefixes | $O((m+n)\cdot min(m,n))$ | $O(m+n)$ |

```java
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        int n = Math.min(str1.length(), str2.length());
        String ans = "";
        for (int i = 1; i <= n; i++) {
            if (str1.length() % i == 0 && str2.length() % i == 0) {
                String sub = str1.substring(0, i);
                if (check(str1, sub) && check(str2, sub)) {
                    ans = sub;
                }
            }
        }
        return ans;
    }

    private boolean check(String s, String sub) {
        int k = s.length() / sub.length();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < k; i++) sb.append(sub);
        return sb.toString().equals(s);
    }
}
```

## Summary
- Use the Euclidean algorithm for an efficient solution.
- Brute force checks all possible prefix divisors.
