# 1071. Greatest Common Divisor of Strings

## String GCD using the Euclidean Algorithm
```
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        if (!(str1 + str2).equals(str2 + str1)) {
            return "";
        }
        int gcdLength = gcd(str1.length(), str2.length());
        return str1.substring(0, gcdLength);
    }
    
    private int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
}
```

## Brute Force Prefix Enumeration with Repetition Check
```
class Solution {
    public String gcdOfStrings(String str1, String str2) {
        int n = Math.min(str1.length(), str2.length());
        String ans = "";
        for (int i = 1; i <= n; i++) {
            if (str1.length() % i == 0 && str2.length() % i == 0) {
                String sub = str1.substring(0, i);
                if (check(str1, sub) && check(str2, sub)) {
                    ans = sub;
                }
            }
        }
        return ans;
    }

    private boolean check(String s, String sub) {
        int k = s.length() / sub.length();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < k; i++) sb.append(sub);
        return sb.toString().equals(s);
    }
}
```
