# 1128. Number of Equivalent Domino Pairs

## Problem Statement

Given a list of dominoes, $dominoes[i] = [a, b]$ is equivalent to $dominoes[j] = [c, d]$ if and only if either $(a == c \ \text{and}\ b == d)$, or $(a == d \ \text{and}\ b == c)$ — that is, one domino can be rotated to be equal to another domino.

Return the number of pairs $(i, j)$ for which $0 \leq i < j < dominoes.length$, and $dominoes[i]$ is equivalent to $dominoes[j]$.

---

## Sample Test Cases

| Input | Output |
|-------|--------|
| dominoes = [[1,2],[2,1],[3,4],[5,6]] | 1 |
| dominoes = [[1,2],[1,2],[1,1],[1,2],[2,2]] | 3 |

---

## Constraints

- $1 \leq dominoes.length \leq 4 \times 10^4$
- $dominoes[i].length == 2$
- $1 \leq dominoes[i][j] \leq 9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Compare all pairs | $O(n^2)$ | $O(1)$ |
| Normalization | Encode dominoes, count pairs | $O(n)$ | $O(1)$ |

---

## Code: Brute Force (TLE)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Compare all pairs | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int numEquivDominoPairs(int[][] dominoes) {
        int n = dominoes.length;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if ((dominoes[i][0] == dominoes[j][0] && dominoes[i][1] == dominoes[j][1]) ||
                    (dominoes[i][0] == dominoes[j][1] && dominoes[i][1] == dominoes[j][0])) {
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

---

## Code: Normalization

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Encode dominoes, count pairs | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int numEquivDominoPairs(int[][] dominoes) {
        int[] cnt = new int[100];
        int ans = 0;
        for (var e : dominoes) {
            int x = e[0] < e[1] ? e[0] * 10 + e[1] : e[1] * 10 + e[0];
            ans += cnt[x]++;
        }
        return ans;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Too slow for large $n$ |
| Normalization | $O(n)$ | $O(1)$ | Efficient, uses encoding |

---

## Summary
- Normalize dominoes to a unique encoding for fast counting.
- Brute force is too slow for large input sizes.
