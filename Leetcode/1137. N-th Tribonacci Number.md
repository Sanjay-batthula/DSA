# 1137. N-th Tribonacci Number

## Dynamic Programming with Space Optimization
```
class Solution {
    public int tribonacci(int n) {
        int a = 0, b = 1, c = 1;
        while (n-- > 0) {
            int d = a + b + c;
            a = b;
            b = c;
            c = d;
        }
        return a;
    }
}
```

## Recursion + Memoization
```
class Solution {
    int[] memo = new int[38];
    public int tribonacci(int n) {
        return trib(n);
    }
    int trib(int n) {
        if (n == 0) return 0;
        if (n <= 2) return 1;
        if (memo[n] != 0) return memo[n];
        return memo[n] = trib(n - 1) + trib(n - 2) + trib(n - 3);
    }
}
```
