# 1137. N-th Tribonacci Number

## Problem Statement

The Tribonacci sequence $T_n$ is defined as follows:

$T_0 = 0$, $T_1 = 1$, $T_2 = 1$, and $T_{n+3} = T_n + T_{n+1} + T_{n+2}$ for $n \geq 0$.

Given $n$, return the value of $T_n$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| n = 4 | 4 | $T_3 = 0 + 1 + 1 = 2$, $T_4 = 1 + 1 + 2 = 4$ |
| n = 25 | 1389537 |  |

---

## Constraints

- $0 \leq n \leq 37$
- The answer is guaranteed to fit within a 32-bit integer, i.e., $answer \leq 2^{31} - 1$.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| DP | Bottom-up, space optimized | $O(n)$ | $O(1)$ |
| Recursion + Memo | Top-down with memoization | $O(n)$ | $O(n)$ |

---

## Code: Dynamic Programming with Space Optimization

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Bottom-up, space optimized | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int tribonacci(int n) {
        int a = 0, b = 1, c = 1;
        while (n-- > 0) {
            int d = a + b + c;
            a = b;
            b = c;
            c = d;
        }
        return a;
    }
}
```

---

## Code: Recursion + Memoization

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Top-down with memoization | $O(n)$ | $O(n)$ |

```java
class Solution {
    int[] memo = new int[38];
    public int tribonacci(int n) {
        return trib(n);
    }
    int trib(int n) {
        if (n == 0) return 0;
        if (n <= 2) return 1;
        if (memo[n] != 0) return memo[n];
        return memo[n] = trib(n - 1) + trib(n - 2) + trib(n - 3);
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| DP | $O(n)$ | $O(1)$ | Most efficient |
| Recursion + Memo | $O(n)$ | $O(n)$ | Simpler, but uses more space |

---

## Summary
- Tribonacci is a simple DP recurrence.
- Bottom-up DP is most efficient for this problem.
