
# 118. Pascal's Triangle

## Problem Statement

Given an integer $\text{numRows}$, return the first $\text{numRows}$ of Pascal's triangle.

In Pascal's triangle, each number is the sum of the two numbers directly above it as shown:

| numRows = 1 | [[1]] | Single row |

## Constraints

- $1 \leq \text{numRows} \leq 30$

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Use binomial coefficients | $O(n^2)$ | $O(n^2)$ |
| Dynamic Programming | Build triangle row by row | $O(n^2)$ | $O(n^2)$ |
| Space-Optimized DP | Update row in-place | $O(n^2)$ | $O(n)$ |
| Pure Math | Binomial formula | $O(n^2)$ | $O(n^2)$ |
| Symmetry Optimization | Use symmetry for efficiency | $O(n^2)$ | $O(n^2)$ |

## Code: Brute Force

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>();
            long val = 1;
            for (int j = 0; j <= i; j++) {
                row.add((int) val);
                val = val * (i - j) / (j + 1);
            }
            res.add(row);
        }
        return res;
    }
}
```

## Code: Dynamic Programming

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();
        triangle.add(List.of(1));
        for (int rowIndex = 1; rowIndex < numRows; ++rowIndex) {
            List<Integer> row = new ArrayList<>();
            row.add(1);
            for (int j = 0; j < triangle.get(rowIndex - 1).size() - 1; ++j) {
                row.add(triangle.get(rowIndex - 1).get(j) + triangle.get(rowIndex - 1).get(j + 1));
            }
            row.add(1);
            triangle.add(row);
        }
        return triangle;
    }
}
```

## Code: Space-Optimized DP

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        List<Integer> row = new ArrayList<>();
        row.add(1);
        res.add(new ArrayList<>(row));

        for (int i = 1; i < numRows; i++) {
            row.add(1);
            for (int j = i - 1; j > 0; j--) {
                row.set(j, row.get(j) + row.get(j - 1));
            }
            res.add(new ArrayList<>(row));
        }
        return res;
    }
}
```

## Code: Symmetry Optimization

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        for (int n = 0; n < numRows; n++) {
            List<Integer> row = new ArrayList<>();
            long val = 1;

            for (int r = 0; r <= n / 2; r++) {
                row.add((int) val);
                val = val * (n - r) / (r + 1);
            }

            for (int r = n / 2 - 1; r >= 0; r--) {
                row.add(row.get(r));
            }

            res.add(row);
        }
        return res;
    }
}
```
