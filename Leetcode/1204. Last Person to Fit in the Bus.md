# 1204. Last Person to Fit in the Bus

## Correlated Subquery
```
select person_name 
from queue a
where (select sum(weight) 
       from queue 
       where a.turn >= turn) <= 1000
order by turn desc 
limit 1
```

## Window Function (Running Total)
```
with cte as (
    select *,
           sum(weight) over (
               order by turn
           ) as total_weight
    from queue
)

select person_name
from cte
where total_weight <= 1000
order by turn desc
limit 1;
```
