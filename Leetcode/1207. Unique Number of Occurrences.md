# 1207. Unique Number of Occurrences

## Problem Statement

Given an array of integers $arr$, return true if the number of occurrences of each value in the array is unique or false otherwise.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| arr = [1,2,2,1,1,3] | true | 1 occurs 3 times, 2 occurs 2 times, 3 occurs 1 time. All unique. |
| arr = [1,2] | false | 1 and 2 both occur once. Not unique. |
| arr = [-3,0,1,-3,1,1,1,-3,10,0] | true | All counts unique. |

---

## Constraints

- $1 \leq arr.length \leq 1000$
- $-1000 \leq arr[i] \leq 1000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Count and compare | $O(n^2)$ | $O(n)$ |
| Hashing | Frequency counting with map/set | $O(n)$ | $O(n)$ |
| Sorting | Sort and count | $O(n \log n)$ | $O(n)$ |
| Array | Use array for frequency | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count and compare | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        int n = arr.length;
        int[] counts = new int[n];
        int countIndex = 0;
        boolean[] visited = new boolean[n];
        for (int i = 0; i < n; i++) {
            if (visited[i]) continue;
            int count = 1;
            for (int j = i + 1; j < n; j++) {
                if (arr[i] == arr[j]) {
                    count++;
                    visited[j] = true;
                }
            }
            counts[countIndex++] = count;
        }
        for (int i = 0; i < countIndex; i++) {
            for (int j = i + 1; j < countIndex; j++) {
                if (counts[i] == counts[j]) return false;
            }
        }
        return true;
    }
}
```

## Code: Frequency Counting using Hashing

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Frequency counting with map/set | $O(n)$ | $O(n)$ |

```java
import java.util.*;

class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Map<Integer, Integer> countMap = new HashMap<>();
        // Count occurrences of each number
        for (int num : arr) {
            countMap.put(num, countMap.getOrDefault(num, 0) + 1);
        }
        // Check if all occurrences are unique
        Set<Integer> occurrences = new HashSet<>(countMap.values());
        return occurrences.size() == countMap.size();
    }
}
```

## Code: Sorting-Based Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and count | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Arrays.sort(arr);
        List<Integer> counts = new ArrayList<>();
        int i = 0, n = arr.length;
        while (i < n) {
            int count = 1;
            while (i + 1 < n && arr[i] == arr[i + 1]) {
                count++;
                i++;
            }
            counts.add(count);
            i++;
        }
        Collections.sort(counts);
        for (int j = 1; j < counts.size(); j++) {
            if (counts.get(j).equals(counts.get(j - 1))) return false;
        }
        return true;
    }
}
```

## Code: Array-Based Frequency Counting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use array for frequency | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        int[] freq = new int[2001];
        for (int num : arr) freq[num + 1000]++;
        boolean[] seen = new boolean[1001];
        for (int f : freq) {
            if (f > 0) {
                if (seen[f]) return false;
                seen[f] = true;
            }
        }
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(n)$ | Not efficient |
| Hashing | $O(n)$ | $O(n)$ | Most common, simple |
| Sorting | $O(n \log n)$ | $O(n)$ | Alternative, but slower |
| Array | $O(n)$ | $O(1)$ | Fastest, but only for small range |

---

## Summary
- Use hashing or array-based counting for best performance.
- Brute force and sorting are less efficient.
