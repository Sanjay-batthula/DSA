# 1251. Average Selling Price

## Weighted Average with JOIN Aggregation
```
SELECT 
    p.product_id,
    ROUND(IFNULL(SUM(u.units * p.price) / SUM(u.units), 0), 2) AS average_price
FROM Prices p
LEFT JOIN UnitsSold u 
    ON p.product_id = u.product_id 
    AND u.purchase_date BETWEEN p.start_date AND p.end_date
GROUP BY p.product_id;
```

## CTE (Common Table Expression) + Weighted Average
```
WITH sales AS (
    SELECT
        p.product_id,
        p.price,
        u.units
    FROM Prices p
    LEFT JOIN UnitsSold u
        ON p.product_id = u.product_id
        AND u.purchase_date BETWEEN p.start_date AND p.end_date
)
SELECT
    product_id,
    ROUND(
        IFNULL(SUM(price * units) / SUM(units), 0),
        2
    ) AS average_price
FROM sales
GROUP BY product_id;
```
