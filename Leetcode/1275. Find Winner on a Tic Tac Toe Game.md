# 1275. Find Winner on a Tic Tac Toe Game


## Line Counting with Turn-Scoped Backward Traversal
```
class Solution {
    public String tictactoe(int[][] moves) {
        int n = moves.length;
        int[] cnt = new int[8];
        for (int k = n - 1; k >= 0; k -= 2) {
            int i = moves[k][0], j = moves[k][1];
            cnt[i]++;
            cnt[j + 3]++;
            if (i == j) {
                cnt[6]++;
            }
            if (i + j == 2) {
                cnt[7]++;
            }
            if (cnt[i] == 3 || cnt[j + 3] == 3 || cnt[6] == 3 || cnt[7] == 3) {
                return k % 2 == 0 ? "A" : "B";
            }
        }
        return n == 9 ? "Draw" : "Pending";
    }
}
```

## Bitmask Pattern Matching
```
class Solution {
    public String tictactoe(int[][] moves) {
        int[] win = {
            0b111000000,
            0b000111000,
            0b000000111,
            0b100100100,
            0b010010010,
            0b001001001,
            0b100010001,
            0b001010100
        };
        int a = 0, b = 0;
        for (int i = 0; i < moves.length; i++) {
            int bit = 1 << (moves[i][0] * 3 + moves[i][1]);
            if (i % 2 == 0) {
                a |= bit;
                for (int w : win) if ((a & w) == w) return "A";
            } else {
                b |= bit;
                for (int w : win) if ((b & w) == w) return "B";
            }
        }
        return moves.length == 9 ? "Draw" : "Pending";
    }
}
```
