# 1275. Find Winner on a Tic Tac Toe Game

## Problem Statement

Tic-tac-toe is played by two players A and B on a $3 \times 3$ grid. The rules of Tic-Tac-Toe are:

- Players take turns placing characters into empty squares.
- The first player A always places 'X', while the second player B always places 'O'.
- The game ends when there are three of the same (non-empty) character filling any row, column, or diagonal.
- The game also ends if all squares are non-empty.

Given a 2D integer array $moves$ where $moves[i] = [row_i, col_i]$ indicates that the $i$th move will be played on $grid[row_i][col_i]$, return the winner of the game if it exists ("A" or "B"). In case the game ends in a draw return "Draw". If there are still movements to play return "Pending".

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| moves = [[0,0],[2,0],[1,1],[2,1],[2,2]] | "A" | A wins, they always play first. |
| moves = [[0,0],[1,1],[0,1],[0,2],[1,0],[2,0]] | "B" | B wins. |
| moves = [[0,0],[1,1],[2,0],[1,0],[1,2],[2,1],[0,1],[0,2],[2,2]] | "Draw" | No moves left, no winner. |

---

## Constraints

- $1 \leq moves.length \leq 9$
- $moves[i].length == 2$
- $0 \leq row_i, col_i \leq 2$
- No repeated elements in moves; moves follow the rules of tic tac toe.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Line Counting | Count rows, cols, diags for each player | $O(n)$ | $O(1)$ |
| Bitmask | Encode board as bits, check win patterns | $O(n)$ | $O(1)$ |

---

## Code: Line Counting with Turn-Scoped Backward Traversal

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count rows, cols, diags for each player | $O(n)$ | $O(1)$ |

```java
class Solution {
    public String tictactoe(int[][] moves) {
        int n = moves.length;
        int[] cnt = new int[8];
        for (int k = n - 1; k >= 0; k -= 2) {
            int i = moves[k][0], j = moves[k][1];
            cnt[i]++;
            cnt[j + 3]++;
            if (i == j) {
                cnt[6]++;
            }
            if (i + j == 2) {
                cnt[7]++;
            }
            if (cnt[i] == 3 || cnt[j + 3] == 3 || cnt[6] == 3 || cnt[7] == 3) {
                return k % 2 == 0 ? "A" : "B";
            }
        }
        return n == 9 ? "Draw" : "Pending";
    }
}
```

## Code: Bitmask Pattern Matching

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Encode board as bits, check win patterns | $O(n)$ | $O(1)$ |

```java
class Solution {
    public String tictactoe(int[][] moves) {
        int[] win = {
            0b111000000,
            0b000111000,
            0b000000111,
            0b100100100,
            0b010010010,
            0b001001001,
            0b100010001,
            0b001010100
        };
        int a = 0, b = 0;
        for (int i = 0; i < moves.length; i++) {
            int bit = 1 << (moves[i][0] * 3 + moves[i][1]);
            if (i % 2 == 0) {
                a |= bit;
                for (int w : win) if ((a & w) == w) return "A";
            } else {
                b |= bit;
                for (int w : win) if ((b & w) == w) return "B";
            }
        }
        return moves.length == 9 ? "Draw" : "Pending";
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Line Counting | $O(n)$ | $O(1)$ | Simple, easy to implement |
| Bitmask | $O(n)$ | $O(1)$ | Elegant, bitwise tricks |

---

## Summary
- Both approaches efficiently determine the winner or game state.
- Bitmasking is elegant but line counting is easier to understand.
