# 1290. Convert Binary Number in a Linked List to Integer

## Problem Statement

Given $head$ which is a reference node to a singly-linked list. The value of each node in the linked list is either 0 or 1. The linked list holds the binary representation of a number.

Return the decimal value of the number in the linked list.

The most significant bit is at the head of the linked list.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| head = [1,0,1] | 5 | (101) in base 2 = (5) in base 10 |
| head = [0] | 0 | |

---

## Constraints

- The Linked List is not empty.
- Number of nodes will not exceed 30.
- Each node's value is either 0 or 1.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Bitwise | Left shift and OR | $O(n)$ | $O(1)$ |
| Arithmetic | Multiply by 2 and add | $O(n)$ | $O(1)$ |

---

## Code: Bitwise Accumulation (Left Shift) / Iterative Binary to Decimal Conversion

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Left shift and OR | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int getDecimalValue(ListNode head) {
        int ans = 0;
        while (head != null) {
            ans = (ans << 1) | head.val;
            head = head.next;
        }
        return ans;
    }
}
```

---

## Code: Arithmetic Binary Accumulation

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Multiply by 2 and add | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int getDecimalValue(ListNode head) {
        int ans = 0;
        while(head!=null){
            ans = ans * 2 + head.val;
            head = head.next;
        }
        return ans;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Bitwise | $O(n)$ | $O(1)$ | Efficient, idiomatic |
| Arithmetic | $O(n)$ | $O(1)$ | Equivalent, more explicit |

---

## Summary
- Both approaches convert binary linked list to decimal in $O(n)$ time.
- Bitwise is concise; arithmetic is explicit.
