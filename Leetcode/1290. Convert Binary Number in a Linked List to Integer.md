# 1290. Convert Binary Number in a Linked List to Integer


## Bitwise Accumulation (Left Shift) / Iterative Binary to Decimal Conversion
```
class Solution {
    public int getDecimalValue(ListNode head) {
        int ans = 0;
        while (head != null) {
            ans = (ans << 1) | head.val;
            head = head.next;
        }
        return ans;
    }
}
```

## Arithmetic Binary Accumulation
```
class Solution {
    public int getDecimalValue(ListNode head) {
        int ans = 0;
        while(head!=null){
            ans = ans * 2 + head.val;
            head = head.next;
        }
        return ans;
    }
}
```
