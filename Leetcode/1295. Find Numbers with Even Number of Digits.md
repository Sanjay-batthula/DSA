# 1295. Find Numbers with Even Number of Digits

## Problem Statement

Given an array $nums$ of integers, return how many of them contain an even number of digits.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [12,345,2,6,7896] | 2 | 12 and 7896 have even number of digits |
| nums = [555,901,482,1771] | 1 | Only 1771 has even number of digits |

---

## Constraints

- $1 \leq nums.length \leq 500$
- $1 \leq nums[i] \leq 10^5$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| String Conversion | Convert to string, count length | $O(nk)$ | $O(1)$ |
| Math | Count digits with division | $O(nk)$ | $O(1)$ |

---

## Code: String Conversion–Based Digit Counting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Convert to string, count length | $O(nk)$ | $O(1)$ |

```java
class Solution {
    public int findNumbers(int[] nums) {
        int ans = 0;
        for (int x : nums) {
            if (String.valueOf(x).length() % 2 == 0) {
                ++ans;
            }
        }
        return ans;
    }
}
```

---

## Code: Math-based Digit Counting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count digits with division | $O(nk)$ | $O(1)$ |

```java
class Solution {
    public int findNumbers(int[] nums) {
        int count = 0;
        for (int n : nums) {
            int digits = 0;
            while (n > 0) {
                digits++;
                n /= 10;
            }
            if (digits % 2 == 0) count++;
        }
        return count;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| String Conversion | $O(nk)$ | $O(1)$ | Simple, uses library |
| Math | $O(nk)$ | $O(1)$ | No string conversion |

---

## Summary
- Both approaches count digits for each number.
- Math avoids string conversion, but both are $O(nk)$.
