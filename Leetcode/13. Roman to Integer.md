# 13. Roman to Integer

## Problem Description
Roman numerals are represented by seven different symbols: I, V, X, L, C, D and M.
```
Symbol       Value
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```
For example, 2 is written as II in Roman numeral, just two ones added together. 12 is written as XII, which is simply X + II. The number 27 is written as XXVII, which is XX + V + II.

Roman numerals are usually written largest to smallest from left to right. However, the numeral for four is not IIII. Instead, the number four is written as IV. Because the one is before the five we subtract it making four. The same principle applies to the number nine, which is written as IX. There are six instances where subtraction is used:

- I can be placed before V (5) and X (10) to make 4 and 9. 
- X can be placed before L (50) and C (100) to make 40 and 90. 
- C can be placed before D (500) and M (1000) to make 400 and 900.
Given a roman numeral, convert it to an integer.

## Sample Test Cases
```
Example 1:
Input: s = "III"
Output: 3
Explanation: III = 3.

Example 2:
Input: s = "LVIII"
Output: 58
Explanation: L = 50, V= 5, III = 3.

Example 3:
Input: s = "MCMXCIV"
Output: 1994
Explanation: M = 1000, CM = 900, XC = 90 and IV = 4.
```


## Brute force
| Section              | Details                                             |
| -------------------- | --------------------------------------------------- |
| **Intuition**        | Explicitly match subtractive pairs                  |
| **Approach**         | Check 2-character substrings, else single character |
| **Time Complexity**  | `O(n)`                                              |
| **Space Complexity** | `O(1)`                                              |
| **Issue**            | Verbose, hard to scale                              |

```
class Solution {
    public int romanToInt(String s) {
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            if (i + 1 < s.length()) {
                String two = s.substring(i, i + 2);
                if (two.equals("IV")) { ans += 4; i++; continue; }
                if (two.equals("IX")) { ans += 9; i++; continue; }
                if (two.equals("XL")) { ans += 40; i++; continue; }
                if (two.equals("XC")) { ans += 90; i++; continue; }
                if (two.equals("CD")) { ans += 400; i++; continue; }
                if (two.equals("CM")) { ans += 900; i++; continue; }
            }
            char c = s.charAt(i);
            if (c == 'I') ans += 1;
            else if (c == 'V') ans += 5;
            else if (c == 'X') ans += 10;
            else if (c == 'L') ans += 50;
            else if (c == 'C') ans += 100;
            else if (c == 'D') ans += 500;
            else if (c == 'M') ans += 1000;
        }
        return ans;
    }
}
```


## right to left approach
| Section              | Details                                                 |
| -------------------- | ------------------------------------------------------- |
| **Intuition**        | Subtract if a smaller value appears before a larger one |
| **Approach**         | Traverse from right, compare current with previous      |
| **Time Complexity**  | `O(n)`                                                  |
| **Space Complexity** | `O(1)`                                                  |
| **Status**           | ⭐ Interview favorite                                    |

```
class Solution {
    private int value(char c) {
        switch (c) {
            case 'I': return 1;
            case 'V': return 5;
            case 'X': return 10;
            case 'L': return 50;
            case 'C': return 100;
            case 'D': return 500;
            case 'M': return 1000;
        }
        return 0;
    }

    public int romanToInt(String s) {
        int n = s.length();
        int ans = value(s.charAt(n - 1));
        for (int i = n - 2; i >= 0; i--) {
            if (value(s.charAt(i)) < value(s.charAt(i + 1))) {
                ans -= value(s.charAt(i));
            } else {
                ans += value(s.charAt(i));
            }
        }
        return ans;
    }
}
```

## left to right approach
| Section              | Details                       |
| -------------------- | ----------------------------- |
| **Intuition**        | Same rule, forward comparison |
| **Approach**         | Subtract when current < next  |
| **Time Complexity**  | `O(n)`                        |
| **Space Complexity** | `O(1)`                        |
| **Note**             | Slightly less intuitive       |

```
class Solution {
    private int value(char c) {
        switch (c) {
            case 'I': return 1;
            case 'V': return 5;
            case 'X': return 10;
            case 'L': return 50;
            case 'C': return 100;
            case 'D': return 500;
            case 'M': return 1000;
        }
        return 0;
    }

    public int romanToInt(String s) {
        int ans = 0;
        for (int i = 0; i < s.length() - 1; i++) {
            if (value(s.charAt(i)) < value(s.charAt(i + 1))) {
                ans -= value(s.charAt(i));
            } else {
                ans += value(s.charAt(i));
            }
        }
        ans += value(s.charAt(s.length() - 1));
        return ans;
    }
}
```


## using hashmap
| Section              | Details                            |
| -------------------- | ---------------------------------- |
| **Intuition**        | Map symbols to values              |
| **Approach**         | Compare adjacent values            |
| **Time Complexity**  | `O(n)`                             |
| **Space Complexity** | `O(1)`                             |
| **Issue**            | Extra structure for fixed alphabet |

```
class Solution {
    public int romanToInt(String s) {
        String cs = "IVXLCDM";
        int[] vs = {1, 5, 10, 50, 100, 500, 1000};
        Map<Character, Integer> d = new HashMap<>();
        for (int i = 0; i < vs.length; ++i) {
            d.put(cs.charAt(i), vs[i]);
        }
        int n = s.length();
        int ans = d.get(s.charAt(n - 1));
        for (int i = 0; i < n - 1; ++i) {
            int sign = d.get(s.charAt(i)) < d.get(s.charAt(i + 1)) ? -1 : 1;
            ans += sign * d.get(s.charAt(i));
        }
        return ans;
    }
}
```



## Using an Array + Index Trick (Constant Lookup Table)
| Section              | Details                   |
| -------------------- | ------------------------- |
| **Intuition**        | Direct ASCII lookup       |
| **Approach**         | Use array indexed by char |
| **Time Complexity**  | `O(n)`                    |
| **Space Complexity** | `O(1)`                    |
| **Status**           | ⭐ Clean and fast          |

```
class Solution {
    public int romanToInt(String s) {
        int[] val = new int[128];
        val['I'] = 1; val['V'] = 5; val['X'] = 10;
        val['L'] = 50; val['C'] = 100; val['D'] = 500; val['M'] = 1000;
        int ans = 0;
        for (int i = 0; i < s.length() - 1; i++) {
            if (val[s.charAt(i)] < val[s.charAt(i + 1)]) ans -= val[s.charAt(i)];
            else ans += val[s.charAt(i)];
        }
        ans += val[s.charAt(s.length() - 1)];
        return ans;
    }
}
```

## Stack-Based Approach
| Section              | Details                              |
| -------------------- | ------------------------------------ |
| **Intuition**        | Handle subtractive cases using stack |
| **Approach**         | Push and pop values                  |
| **Time Complexity**  | `O(n)`                               |
| **Space Complexity** | `O(n)`                               |
| **Issue**            | No benefit over linear scan          |

```
class Solution {
    public int romanToInt(String s) {
        Map<Character, Integer> val = Map.of(
            'I', 1, 'V', 5, 'X', 10, 'L', 50,
            'C', 100, 'D', 500, 'M', 1000
        );
        Stack<Integer> st = new Stack<>();
        int ans = 0;
        for (char c : s.toCharArray()) {
            int v = val.get(c);
            if (!st.isEmpty() && st.peek() < v) ans += v - st.pop();
            else st.push(v);
        }
        while (!st.isEmpty()) ans += st.pop();
        return ans;
    }
}
```

## Recursive Approach
| Section              | Details                      |
| -------------------- | ---------------------------- |
| **Intuition**        | Recursive subtraction logic  |
| **Approach**         | Compare first two characters |
| **Time Complexity**  | `O(n²)`                      |
| **Space Complexity** | `O(n)`                       |
| **Issue**            | Substring overhead           |

```
class Solution {
    int val(char c) {
        return switch(c) {
            case 'I' -> 1;
            case 'V' -> 5;
            case 'X' -> 10;
            case 'L' -> 50;
            case 'C' -> 100;
            case 'D' -> 500;
            case 'M' -> 1000;
            default -> 0;
        };
    }
    public int romanToInt(String s) {
        if (s.length() == 1) return val(s.charAt(0));
        int first = val(s.charAt(0)), second = val(s.charAt(1));
        return first < second 
            ? romanToInt(s.substring(1)) - first 
            : romanToInt(s.substring(1)) + first;
    }
}
```

## Approach Comparison
| Approach      | Time    | Space  | Status | Notes       |
| ------------- | ------- | ------ | ------ | ----------- |
| Brute Force   | `O(n)`  | `O(1)` | ❌      | Verbose     |
| Right-to-Left | `O(n)`  | `O(1)` | ⭐ Best | Clean logic |
| Left-to-Right | `O(n)`  | `O(1)` | ✅      | Acceptable  |
| HashMap       | `O(n)`  | `O(1)` | ❌      | Redundant   |
| Array Lookup  | `O(n)`  | `O(1)` | ⭐ Best | Fastest     |
| Stack         | `O(n)`  | `O(n)` | ❌      | Overkill    |
| Recursive     | `O(n²)` | `O(n)` | ❌      | Inefficient |


## Summary
- Core rule: subtract if current < next
- Array lookup or right-to-left scan is ideal
- Avoid stacks and recursion
