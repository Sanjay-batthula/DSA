# 1317. Convert Integer to the Sum of Two No-Zero Integers

## Problem Statement

No-Zero integer is a positive integer that does not contain any 0 in its decimal representation.

Given an integer $n$, return a list of two integers $[a, b]$ where:
- $a$ and $b$ are No-Zero integers.
- $a + b = n$

The test cases are generated so that there is at least one valid solution. If there are many valid solutions, you can return any of them.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| n = 2 | [1,1] | Both 1 and 1 are no-zero, 1+1=2 |
| n = 11 | [2,9] | Both 2 and 9 are no-zero, 2+9=11 (other answers possible) |

---

## Constraints

- $2 \leq n \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Try all pairs | $O(n \cdot d)$ | $O(1)$ |
| Validation | Only up to $n/2$ | $O(n \cdot d)$ | $O(1)$ |
| Greedy | Increment $a$, check both | $O(n \cdot d)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Try all pairs | $O(n \cdot d)$ | $O(1)$ |

```java
class Solution {
    public int[] getNoZeroIntegers(int n) {
        for (int a = 1; a < n; a++) {
            int b = n - a;
            if (isNoZero(a) && isNoZero(b)) {
                return new int[]{a, b};
            }
        }
        return new int[]{};
    }

    private boolean isNoZero(int x) {
        while (x > 0) {
            if (x % 10 == 0) return false;
            x /= 10;
        }
        return true;
    }
}
```

## Code: Constructive Greedy

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Increment $a$, check both | $O(n \cdot d)$ | $O(1)$ |

```java
class Solution {
    public int[] getNoZeroIntegers(int n) {
        int a = 1, b = n - 1;
        while (!isNoZero(a) || !isNoZero(b)) {
            a++;
            b = n - a;
        }
        return new int[]{a, b};
    }
    private boolean isNoZero(int x) {
        while (x > 0) {
            if (x % 10 == 0) return false;
            x /= 10;
        }
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n \cdot d)$ | $O(1)$ | Tries all pairs |
| Validation | $O(n \cdot d)$ | $O(1)$ | Slightly fewer checks |
| Greedy | $O(n \cdot d)$ | $O(1)$ | Fast in practice |

---

## Summary
- All approaches check pairs for no-zero property.
- Greedy and validation are practical for small $n$.
