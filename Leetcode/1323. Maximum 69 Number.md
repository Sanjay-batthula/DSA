# 1323. Maximum 69 Number

## Problem Statement

You are given a positive integer $num$ consisting only of digits 6 and 9.

Return the maximum number you can get by changing at most one digit (6 becomes 9, and 9 becomes 6).

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| num = 9669 | 9969 | Change second digit to 9 for max |
| num = 9996 | 9999 | Change last digit to 9 |
| num = 9999 | 9999 | No change needed |

---

## Constraints

- $1 \leq num \leq 10^4$
- $num$ consists of only 6 and 9 digits.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Try all single-digit changes | $O(k)$ | $O(k)$ |
| Greedy | Change first 6 to 9 | $O(k)$ | $O(k)$ |
| Replace | Use string replace | $O(k)$ | $O(k)$ |
| Recursive | Simulate recursively | $O(k)$ | $O(k)$ |

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Try all single-digit changes | $O(k)$ | $O(k)$ |

```java
class Solution {
    public int maximum69Number (int num) {
        String s = String.valueOf(num);
        int max = num;
        for (int i = 0; i < s.length(); i++) {
            char[] chars = s.toCharArray();
            if (chars[i] == '6') {
                chars[i] = '9';
                int newNum = Integer.parseInt(new String(chars));
                if (newNum > max) max = newNum;
            } else if (chars[i] == '9') {
                chars[i] = '6';
                int newNum = Integer.parseInt(new String(chars));
                if (newNum > max) max = newNum;
            }
        }
        return max;
    }
}
```

class Solution {
    public int maximum69Number (int num) {
        List<Integer> nums= new ArrayList<>();
        nums.add(num);
        char[] chars= String.valueOf(num).toCharArray();

        for (int i = 0; i < chars.length; i++) {
            if(chars[i]=='6'){
                chars[i]='9';
                nums.add(Integer.valueOf(String.valueOf(chars)));
                chars[i]='6';
            }
        }
        for (int i = 0; i < chars.length; i++) {
            if(chars[i]=='9'){
                chars[i]='6';
                nums.add(Integer.valueOf(String.valueOf(chars)));
                chars[i]='9';
            }
        }
       return nums.stream().distinct().max(Integer::compare).get();
    }
}

## Code: Greedy Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Change first 6 to 9 | $O(k)$ | $O(k)$ |

```java
class Solution {
    public int maximum69Number (int num) {
        char[] chars = String.valueOf(num).toCharArray();
        for (int i = 0; i < chars.length; i++) {
            if (chars[i] == '6') {
                chars[i] = '9';
                break;
            }
        }
        return Integer.parseInt(new String(chars));
    }
}
```

## Code: Replace-based String Method

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use string replace | $O(k)$ | $O(k)$ |

```java
class Solution {
    public int maximum69Number (int num) {
        return Integer.parseInt(String.valueOf(num).replaceFirst("6", "9"));
    }
}
```

## Code: Recursive Simulation

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Simulate recursively | $O(k)$ | $O(k)$ |

```java
class Solution {
    public int maximum69Number (int num) {
        return helper(String.valueOf(num), 0);
    }
    private int helper(String s, int i) {
        if (i == s.length()) return Integer.parseInt(s);
        if (s.charAt(i) == '6') 
            return Integer.parseInt(s.substring(0, i) + '9' + s.substring(i + 1));
        return helper(s, i + 1);
    }
}
```

- Greedy and replace-based methods are most concise.
