# 1346. Check If N and Its Double Exist

## Problem Statement

Given an array $arr$ of integers, check if there exist two indices $i$ and $j$ such that:
- $i \neq j$
- $0 \leq i, j < arr.length$
- $arr[i] = 2 \times arr[j]$

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| arr = [10,2,5,3] | true | 10 == 2 * 5 |
| arr = [3,1,7,11] | false | No such pair |

---

## Constraints

- $2 \leq arr.length \leq 500$
- $-10^3 \leq arr[i] \leq 10^3$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Check all pairs | $O(n^2)$ | $O(1)$ |
| HashSet | Store seen, check double/half | $O(n)$ | $O(n)$ |
| Sorting + Binary Search | Sort and search for double | $O(n \log n)$ | $O(1)$ |
| Bitmask | Use array for fast lookup | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check all pairs | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public boolean checkIfExist(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i != j && arr[i] == 2 * arr[j]) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

## Code: HashSet Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Store seen, check double/half | $O(n)$ | $O(n)$ |

```java
class Solution {
    public boolean checkIfExist(int[] arr) {
        Set<Integer> s = new HashSet<>();
        for (int x : arr) {
            if (s.contains(x * 2) || ((x % 2 == 0 && s.contains(x / 2)))) {
                return true;
            }
            s.add(x);
        }
        return false;
    }
}
```

## Code: Sorting + Binary Search

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and search for double | $O(n \log n)$ | $O(1)$ |

```java
class Solution {
    public boolean checkIfExist(int[] arr) {
        java.util.Arrays.sort(arr);
        for (int i = 0; i < arr.length; i++) {
            int target = arr[i] * 2;
            int idx = java.util.Arrays.binarySearch(arr, target);
            if (idx >= 0) {
                if (idx != i) return true;
                if (idx + 1 < arr.length && arr[idx + 1] == target) return true;
                if (idx - 1 >= 0 && arr[idx - 1] == target) return true;
            }
        }
        return false;
    }
}
```

## Code: Bitmask Frequency Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use array for fast lookup | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean checkIfExist(int[] arr) {
        int offset = 1000;
        boolean[] seen = new boolean[2001];
        for (int x : arr) {
            int d = x << 1;
            if (d >= -1000 && d <= 1000 && seen[d + offset]) return true;
            if ((x & 1) == 0) {
                int h = x >> 1;
                if (h >= -1000 && h <= 1000 && seen[h + offset]) return true;
            }
            seen[x + offset] = true;
        }
        return false;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, slow |
| HashSet | $O(n)$ | $O(n)$ | Efficient, recommended |
| Sorting + Binary Search | $O(n \log n)$ | $O(1)$ | Alternative |
| Bitmask | $O(n)$ | $O(1)$ | Fast, but less common |

---

## Summary
- HashSet and bitmask approaches are most efficient.
- Brute force is simple but slow for large arrays.
