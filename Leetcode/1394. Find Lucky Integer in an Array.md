# 1394. Find Lucky Integer in an Array

## Problem Statement

Given an array $arr$ of integers, a lucky integer is an integer that has a frequency in the array equal to its value.

Return the largest lucky integer in the array. If there is no lucky integer, return -1.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| arr = [2,2,3,4] | 2 | 2 occurs twice |
| arr = [1,2,2,3,3,3] | 3 | 3 occurs three times |
| arr = [2,2,2,3,3] | -1 | No lucky integer |

---

## Constraints

- $1 \leq arr.length \leq 500$
- $1 \leq arr[i] \leq 500$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Count frequency for each | $O(n^2)$ | $O(1)$ |
| Frequency Array | Count with array | $O(n)$ | $O(1)$ |
| HashMap | Count with map | $O(n)$ | $O(n)$ |
| Sorting | Sort and count | $O(n \log n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count frequency for each | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int findLucky(int[] arr) {
        int ans = -1;
        for (int i = 0; i < arr.length; i++) {
            int count = 0;
            for (int j = 0; j < arr.length; j++) {
                if (arr[i] == arr[j]) count++;
            }
            if (arr[i] == count) ans = Math.max(ans, arr[i]);
        }
        return ans;
    }
}
```

## Code: Frequency Array / Counting Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count with array | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int findLucky(int[] arr) {
        int[] cnt=new int[501];
        for(int x:arr)++cnt[x];
        for(int x=500;x>0;--x)if(x==cnt[x])return x;
        return -1;
    }
}
```

## Code: HashMap Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count with map | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int findLucky(int[] arr) {
        Map<Integer,Integer> map = new HashMap<>();
        for(int x : arr)
            map.put(x, map.getOrDefault(x, 0) + 1);
        
        int ans = -1;
        for(int key : map.keySet())
            if(key == map.get(key))
                ans = Math.max(ans, key);
        
        return ans;
    }
}
```

## Code: Sorting + Frequency Count

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and count | $O(n \log n)$ | $O(1)$ |

```java
class Solution {
    public int findLucky(int[] arr) {
        Arrays.sort(arr);
        int ans = -1;
        int i = 0;
        while (i < arr.length) {
            int num = arr[i];
            int count = 0;
            while (i < arr.length && arr[i] == num) {
                count++;
                i++;
            }
            if (num == count) ans = num;
        }
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, slow |
| Frequency Array | $O(n)$ | $O(1)$ | Fastest for small range |
| HashMap | $O(n)$ | $O(n)$ | General, flexible |
| Sorting | $O(n \log n)$ | $O(1)$ | Alternative |

---

## Summary
- Frequency array is fastest for small value ranges.
- HashMap is general for any value range.
