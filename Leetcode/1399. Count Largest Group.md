# 1399. Count Largest Group

## Problem Statement

You are given an integer $n$.

Group the numbers from $1$ to $n$ according to the sum of their digits. Return the number of groups that have the largest size (i.e., the maximum number of elements).

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| n = 13 | 4 | Groups: [1,10], [2,11], [3,12], [4,13], [5], [6], [7], [8], [9]. 4 groups have the largest size. |
| n = 2 | 2 | Groups: [1], [2] |

---

## Constraints

- $1 \leq n \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Use HashMap to count group sizes | $O(n \cdot d)$ | $O(n)$ |
| Array Counting | Use array for digit sums | $O(n \cdot d)$ | $O(1)$ |
| On-the-fly Counting | Count and track max as you go | $O(n \cdot d)$ | $O(1)$ |

## Code: Brute Force (HashMap)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use HashMap to count group sizes | $O(n \cdot d)$ | $O(n)$ |

```java
class Solution {
    public int countLargestGroup(int n) {
        HashMap<Integer, Integer> map = new HashMap<>();
        // Loop through 1 to n and calculate digit sum
        for (int i = 1; i <= n; i++) {
            int sum = 0;
            int num = i;
            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }
        // Find the largest group size
        int maxSize = 0;
        for (int val : map.values()) {
            if (val > maxSize) maxSize = val;
        }
        // Count how many groups have that size
        int count = 0;
        for (int val : map.values()) {
            if (val == maxSize) count++;
        }
        return count;
    }
}
```

## Code: On-the-fly Counting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count and track max as you go | $O(n \cdot d)$ | $O(1)$ |

```java
class Solution {
    public int countLargestGroup(int n) {
        int[] cnt = new int[40];
        int ans = 0, mx = 0;
        for (int i = 1; i <= n; ++i) {
            int s = 0;
            for (int x = i; x > 0; x /= 10) {
                s += x % 10;
            }
            ++cnt[s];
            if (mx < cnt[s]) {
                mx = cnt[s];
                ans = 1;
            } else if (mx == cnt[s]) {
                ++ans;
            }
        }
        return ans;
    }
}
```

## Code: Array - Optimized Counting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use array for digit sums | $O(n \cdot d)$ | $O(1)$ |

```java
class Solution {
    public int countLargestGroup(int n) {
        int[] cnt = new int[37];
        for (int i = 1; i <= n; i++) {
            int sum = 0, x = i;
            while (x > 0) {
                sum += x % 10;
                x /= 10;
            }
            cnt[sum]++;
        }
        int mx = 0;
        for (int c : cnt) mx = Math.max(mx, c);
        int ans = 0;
        for (int c : cnt) if (c == mx) ans++;
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force (HashMap) | $O(n \cdot d)$ | $O(n)$ | Simple, flexible |

---

## Summary
- All approaches rely on digit sum grouping.
- Array-based counting is fastest for small $n$.
