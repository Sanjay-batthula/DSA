# 14. Longest Common Prefix

## Problem Description
Write a function to find the longest common prefix string amongst an array of strings.  
If there is no common prefix, return an empty string "".  


## Sample Test Cases
```
Example 1:
Input: strs = ["flower","flow","flight"]
Output: "fl"
Example 2:
Input: strs = ["dog","racecar","car"]
Output: ""
Explanation: There is no common prefix among the input strings.
```


## Brute Force/Vertical Scanning
| Section              | Details                                 |
| -------------------- | --------------------------------------- |
| **Intuition**        | Compare characters column by column     |
| **Approach**         | Fix index `i`, check all strings at `i` |
| **Time Complexity**  | `O(n * m)`                              |
| **Space Complexity** | `O(1)`                                  |
| **Status**           | ⭐ Simple and effective                  |

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        int n = strs.length;
        for (int i = 0; i < strs[0].length(); ++i) {
            for (int j = 1; j < n; ++j) {
                if (strs[j].length() <= i || strs[j].charAt(i) != strs[0].charAt(i)) {
                    return strs[0].substring(0, i);
                }
            }
        }
        return strs[0];
    }
}
```

## Horizontal Scanning
| Section              | Details                                       |
| -------------------- | --------------------------------------------- |
| **Intuition**        | Reduce prefix by comparing with each string   |
| **Approach**         | Shrink prefix until it matches current string |
| **Time Complexity**  | `O(n * m)`                                    |
| **Space Complexity** | `O(1)`                                        |
| **Note**             | Easy to reason                                |

```
class Solution {
    public String longestCommonPrefix(String[] strs) {
        String prefix = strs[0];
        for (int i = 1; i < strs.length; i++) {
            while (!strs[i].startsWith(prefix)) {
                prefix = prefix.substring(0, prefix.length() - 1);
                if (prefix.isEmpty()) return "";
            }
        }
        return prefix;
    }
}
```

## Divide and Conquer
| Section              | Details                          |
| -------------------- | -------------------------------- |
| **Intuition**        | LCP(left half) + LCP(right half) |
| **Approach**         | Recursively split array          |
| **Time Complexity**  | `O(n * m)`                       |
| **Space Complexity** | `O(log n)`                       |
| **Issue**            | Overkill for simple problem      |

```
class Solution {
    public String longestCommonPrefix(String[] strs) {
        return lcp(strs, 0, strs.length - 1);
    }
    private String lcp(String[] strs, int l, int r) {
        if (l == r) return strs[l];
        int mid = (l + r) / 2;
        String left = lcp(strs, l, mid);
        String right = lcp(strs, mid + 1, r);
        return commonPrefix(left, right);
    }
    private String commonPrefix(String left, String right) {
        int min = Math.min(left.length(), right.length());
        for (int i = 0; i < min; i++) {
            if (left.charAt(i) != right.charAt(i))
                return left.substring(0, i);
        }
        return left.substring(0, min);
    }
}
```

## Binary Search on Prefix Length
| Section              | Details                                  |
| -------------------- | ---------------------------------------- |
| **Intuition**        | Binary search the length of prefix       |
| **Approach**         | Check if prefix of length `mid` is valid |
| **Time Complexity**  | `O(n * m log m)`                         |
| **Space Complexity** | `O(1)`                                   |
| **Issue**            | Worse than linear scans                  |

```
class Solution {
    public String longestCommonPrefix(String[] strs) {
        int minLen = Integer.MAX_VALUE;
        for (String s : strs) minLen = Math.min(minLen, s.length());
        int low = 1, high = minLen;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (isCommon(strs, mid)) low = mid + 1;
            else high = mid - 1;
        }
        return strs[0].substring(0, (low + high) / 2);
    }
    private boolean isCommon(String[] strs, int len) {
        String prefix = strs[0].substring(0, len);
        for (int i = 1; i < strs.length; i++)
            if (!strs[i].startsWith(prefix)) return false;
        return true;
    }
}
```

## Approach Comparison
| Approach            | Time           | Space      | Status | Notes          |
| ------------------- | -------------- | ---------- | ------ | -------------- |
| Vertical Scanning   | `O(n*m)`       | `O(1)`     | ⭐ Best | Most intuitive |
| Horizontal Scanning | `O(n*m)`       | `O(1)`     | ✅      | Clean          |
| Divide & Conquer    | `O(n*m)`       | `O(log n)` | ❌      | Overkill       |
| Binary Search       | `O(n*m log m)` | `O(1)`     | ❌      | Unnecessary    |


## Summary
- Vertical scanning is the cleanest and safest
- Horizontal scan is equally valid
