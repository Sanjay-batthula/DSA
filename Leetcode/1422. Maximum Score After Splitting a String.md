# 1422. Maximum Score After Splitting a String

## Problem Statement

Given a string $s$ of zeros and ones, return the maximum score after splitting the string into two non-empty substrings (left and right).

The score after splitting is the number of zeros in the left substring plus the number of ones in the right substring.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| s = "011101" | 5 | Split as "0" and "11101": 1 zero + 4 ones = 5 |
| s = "00111" | 5 | Split as "00" and "111": 2 zeros + 3 ones = 5 |
| s = "1111" | 3 | Split as "111" and "1": 0 zeros + 3 ones = 3 |

---

## Constraints

- $2 \leq s.length \leq 500$
- $s$ consists of '0' and '1' only

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Try all splits, count zeros/ones | $O(n^2)$ | $O(1)$ |
| Prefix/Suffix | Precompute prefix zeros and suffix ones | $O(n)$ | $O(n)$ |
| Optimized Linear | Single pass, running counts | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Try all splits, count zeros/ones | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int maxScore(String s) {
        int max = 0;
        for (int i = 1; i < s.length(); i++) {
            String left = s.substring(0, i);
            String right = s.substring(i);
            int zeros = 0, ones = 0;
            for (char c : left.toCharArray()) if (c == '0') zeros++;
            for (char c : right.toCharArray()) if (c == '1') ones++;
            max = Math.max(max, zeros + ones);
        }
        return max;
    }
}
```

## Code: Prefix–Suffix Count Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Precompute prefix zeros and suffix ones | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int maxScore(String s) {
        int n = s.length();
        int[] prefixZero = new int[n];
        int[] suffixOne = new int[n];

        prefixZero[0] = (s.charAt(0) == '0') ? 1 : 0;
        for (int i = 1; i < n; i++) {
            prefixZero[i] = prefixZero[i - 1] + (s.charAt(i) == '0' ? 1 : 0);
        }
        suffixOne[n - 1] = (s.charAt(n - 1) == '1') ? 1 : 0;
        for (int i = n - 2; i >= 0; i--) {
            suffixOne[i] = suffixOne[i + 1] + (s.charAt(i) == '1' ? 1 : 0);
        }
        int max = 0;
        for (int i = 0; i < n - 1; i++) {
            max = Math.max(max, prefixZero[i] + suffixOne[i + 1]);
        }
        return max;
    }
}
```

## Code: Optimized Linear (Single-Pass)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Single pass, running counts | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int maxScore(String s) {
        int l = 0, r = 0;
        int n = s.length();
        for (int i = 0; i < n; ++i) {
            if (s.charAt(i) == '1') {
                ++r;
            }
        }
        int ans = 0;
        for (int i = 0; i < n - 1; ++i) {
            l += (s.charAt(i) - '0') ^ 1;
            r -= s.charAt(i) - '0';
            ans = Math.max(ans, l + r);
        }
        return ans;
    }
}
```

## Code: Single-Pass Running Sum (Alternative)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Single pass, running sum | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int maxScore(String s) {
        int totalOnes = 0, leftZeros = 0, best = 0;
        for (char c : s.toCharArray()) if (c == '1') totalOnes++;
        int rightOnes = totalOnes;
        for (int i = 0; i < s.length() - 1; i++) {
            if (s.charAt(i) == '0') leftZeros++;
            else rightOnes--;
            best = Math.max(best, leftZeros + rightOnes);
        }
        return best;
    }
}
```

## Summary
- Optimized linear approaches are best for both time and space.
- Prefix–suffix is useful for clarity and debugging.
