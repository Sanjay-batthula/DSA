# 1431. Kids With the Greatest Number of Candies

## Problem Statement

There are $n$ kids with candies. You are given an integer array $candies$, where $candies[i]$ represents the number of candies the $i$th kid has, and an integer $extraCandies$, denoting the number of extra candies that you have.

Return a boolean array $result$ of length $n$, where $result[i]$ is true if, after giving the $i$th kid all the $extraCandies$, they will have the greatest number of candies among all the kids, or false otherwise.

Note that multiple kids can have the greatest number of candies.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| candies = [2,3,5,1,3], extraCandies = 3 | [true,true,true,false,true] | Kids 1,2,3,5 can have the greatest number |
| candies = [4,2,1,1,2], extraCandies = 1 | [true,false,false,false,false] | Only kid 1 can have the greatest |
| candies = [12,1,12], extraCandies = 10 | [true,false,true] | Kids 1 and 3 can have the greatest |

---

## Constraints

- $n = candies.length$
- $2 \leq n \leq 100$
- $1 \leq candies[i] \leq 100$
- $1 \leq extraCandies \leq 50$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | For each kid, check if giving all extraCandies makes them greatest | $O(n^2)$ | $O(n)$ |
| Single Pass | Find max, then check each kid | $O(n)$ | $O(n)$ |
| Two-Pass | Find max in one pass, check in another | $O(n)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| For each kid, check if giving all extraCandies makes them greatest | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        List<Boolean> res = new ArrayList<>();
        for (int i = 0; i < candies.length; i++) {
            int total = candies[i] + extraCandies;
            boolean flag = true;
            for (int j = 0; j < candies.length; j++) {
                if (total < candies[j]) {
                    flag = false;
                    break;
                }
            }
            res.add(flag);
        }
        return res;
    }
}
```

---

## Code: Single Pass

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Find max, then check each kid | $O(n)$ | $O(n)$ |

```java
class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int max = Arrays.stream(candies).max().getAsInt();
        List<Boolean> result = new ArrayList<>();
        for (int c : candies) result.add(c + extraCandies >= max);
        return result;
    }
}
```

---

## Code: Two-Pass (Manual Max)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Find max in one pass, check in another | $O(n)$ | $O(n)$ |

```java
class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int max = 0;
        for (int c : candies) if (c > max) max = c;
        List<Boolean> result = new ArrayList<>();
        for (int c : candies) result.add(c + extraCandies >= max);
        return result;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(n)$ | Simple, slow |
| Single Pass | $O(n)$ | $O(n)$ | Uses built-in max |
| Two-Pass | $O(n)$ | $O(n)$ | Manual max, clear logic |

---

## Summary
- Single pass or two-pass approaches are optimal for this problem.
- Brute force is only for illustration or very small $n$.
