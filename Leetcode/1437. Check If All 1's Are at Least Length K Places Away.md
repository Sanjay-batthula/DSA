## Brute Force
```
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        for(int i=0;i<nums.length;i++){
            if(nums[i]==1){
                for(int j=i+1;j<nums.length;j++){
                    if(nums[j]==1){
                        if(j-i-1<k) return false;
                        break;
                    }
                }
            }
        }
        return true;
    }
}
```

## Optimal Approach (Greedy / Single Scan)
```
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        int prev = -1;
        for(int i=0;i<nums.length;i++){
            if(nums[i]==1){
                if(prev!=-1 && i-prev-1<k) return false;
                prev = i;
            }
        }
        return true;
    }
}
```

## Counting Zeros Between Ones
```
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        int count = nums.length;
        for(int n: nums){
            if(n==1){
                if(count<k) return false;
                count=0;
            }else count++;
        }
        return true;
    }
}
```

## Regex approach 
```
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        if (k == 0) return true;
        StringBuilder s = new StringBuilder();
        for (int n: nums) s.append(n);
        return !s.toString().matches(".*10{0,"+(k-1)+"}1.*");
    }
}
```
