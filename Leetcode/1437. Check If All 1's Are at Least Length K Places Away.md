# 1437. Check If All 1's Are at Least Length K Places Away

## Problem Statement

Given a binary array $nums$ and an integer $k$, return true if all 1's are at least $k$ places away from each other, otherwise return false.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,0,0,0,1,0,0,1], k = 2 | true | Each 1 is at least 2 places away |
| nums = [1,0,0,1,0,1], k = 2 | false | Second and third 1 are only one apart |

---

## Constraints

- $1 \leq nums.length \leq 10^5$
- $0 \leq k \leq nums.length$
- $nums[i]$ is 0 or 1

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Check all pairs of 1's | $O(n^2)$ | $O(1)$ |
| Greedy / Single Scan | Track previous 1's index | $O(n)$ | $O(1)$ |
| Counting Zeros | Count zeros between 1's | $O(n)$ | $O(1)$ |
| Regex | Convert to string, use regex | $O(n)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check all pairs of 1's | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        for(int i=0;i<nums.length;i++){
            if(nums[i]==1){
                for(int j=i+1;j<nums.length;j++){
                    if(nums[j]==1){
                        if(j-i-1<k) return false;
                        break;
                    }
                }
            }
        }
        return true;
    }
}
```

---

## Code: Greedy / Single Scan

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track previous 1's index | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        int prev = -1;
        for(int i=0;i<nums.length;i++){
            if(nums[i]==1){
                if(prev!=-1 && i-prev-1<k) return false;
                prev = i;
            }
        }
        return true;
    }
}
```

---

## Code: Counting Zeros Between Ones

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count zeros between 1's | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        int count = nums.length;
        for(int n: nums){
            if(n==1){
                if(count<k) return false;
                count=0;
            }else count++;
        }
        return true;
    }
}
```

## Code: Regex Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Convert to string, use regex | $O(n)$ | $O(n)$ |

```java
class Solution {
    public boolean kLengthApart(int[] nums, int k) {
        if (k == 0) return true;
        StringBuilder s = new StringBuilder();
        for (int n: nums) s.append(n);
        return !s.toString().matches(".*10{0,"+(k-1)+"}1.*");
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, slow |
| Greedy / Single Scan | $O(n)$ | $O(1)$ | Efficient, tracks previous index |
| Counting Zeros | $O(n)$ | $O(1)$ | Alternative, clear logic |
| Regex | $O(n)$ | $O(n)$ | Elegant, but less efficient |

---

## Summary
- Greedy and counting approaches are optimal for this problem.
- Regex is elegant but less efficient for large arrays.
