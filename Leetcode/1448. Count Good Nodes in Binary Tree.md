# 1448. Count Good Nodes in Binary Tree

## Depth First Search with Prefix Maximum
```
class Solution {
    private int ans = 0;
    public int goodNodes(TreeNode root) {
        dfs(root, -100000); /*dfs(root, root.val);*/
        return ans;
    }
    private void dfs(TreeNode root, int mx) {
        if (root == null) {
            return;
        }
        if (mx <= root.val) {
            ++ans;
            mx = root.val;
        }
        dfs(root.left, mx);
        dfs(root.right, mx);
    }
}
```
