# 1455. Check If a Word Occurs As a Prefix of Any Word in a Sentence

## Problem Statement

Given a sentence that consists of some words separated by a single space, and a $searchWord$, check if $searchWord$ is a prefix of any word in $sentence$.

Return the index of the word in $sentence$ (1-indexed) where $searchWord$ is a prefix of this word. If $searchWord$ is a prefix of more than one word, return the index of the first word (minimum index). If there is no such word return $-1$.

A prefix of a string $s$ is any leading contiguous substring of $s$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| sentence = "i love eating burger", searchWord = "burg" | 4 | "burg" is prefix of "burger" (4th word) |
| sentence = "this problem is an easy problem", searchWord = "pro" | 2 | "pro" is prefix of "problem" (2nd word) |
| sentence = "i am tired", searchWord = "you" | -1 | "you" is not a prefix of any word |

---

## Constraints

- $1 \leq sentence.length \leq 100$
- $1 \leq searchWord.length \leq 10$
- $sentence$ consists of lowercase English letters and spaces
- $searchWord$ consists of lowercase English letters

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Split and check each word | $O(n \cdot m)$ | $O(n)$ |
| Index Traversal | Traverse without split | $O(n \cdot m)$ | $O(1)$ |
| String Built-ins | Use built-in string methods | $O(n \cdot m)$ | $O(1)$ |
| Regex | Use regex for prefix match | $O(n \cdot m)$ | $O(n)$ |

---

## Code: Brute Force / Direct String Traversal

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Split and check each word | $O(n \cdot m)$ | $O(n)$ |

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        String[] words = sentence.split(" ");
        for (int i = 0; i < words.length; ++i) {
            if (words[i].startsWith(searchWord)) {
                return i + 1;
            }
        }
        return -1;
    }
}
```

---

## Code: Index Traversal (Without Split)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Traverse without split | $O(n \cdot m)$ | $O(1)$ |

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        int index = 1, i = 0, n = sentence.length(), m = searchWord.length();
        while (i < n) {
            int j = 0, k = i;
            while (k < n && j < m && sentence.charAt(k) == searchWord.charAt(j)) {
                k++;
                j++;
            }
            if (j == m) return index;
            while (k < n && sentence.charAt(k) != ' ') k++;
            i = k + 1;
            index++;
        }
        return -1;        
    }
}
```

## Code: String Built-ins Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use built-in string methods | $O(n \cdot m)$ | $O(1)$ |

```java
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        int index = 1;
        int start = 0;
        while (start < sentence.length()) {
            int end = sentence.indexOf(' ', start);
            if (end == -1) end = sentence.length();
            if (sentence.startsWith(searchWord, start)) return index;
            start = end + 1;
            index++;
        }
        return -1;       
    }
}
```

## Code: Regex Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use regex for prefix match | $O(n \cdot m)$ | $O(n)$ |

```java
import java.util.regex.*;
class Solution {
    public int isPrefixOfWord(String sentence, String searchWord) {
        Matcher m = Pattern.compile("\\b" + searchWord).matcher(sentence);
        int index = 1, pos = 0;
        for (String word : sentence.split(" ")) {
            if (m.find(pos) && m.start() == sentence.indexOf(word, pos)) return index;
            pos += word.length() + 1;
            index++;
        }
        return -1;      
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n \cdot m)$ | $O(n)$ | Simple, clear |
| Index Traversal | $O(n \cdot m)$ | $O(1)$ | No split, efficient |
| String Built-ins | $O(n \cdot m)$ | $O(1)$ | Uses built-in methods |
| Regex | $O(n \cdot m)$ | $O(n)$ | Elegant, but overkill |

---

## Summary
- Brute force and index traversal are optimal for this problem.
- Regex is elegant but not necessary for small input sizes.
