# 1491. Average Salary Excluding the Minimum and Maximum Salary

## Problem Statement

You are given an array of unique integers $salary$ where $salary[i]$ is the salary of the $i$th employee.

Return the average salary of employees excluding the minimum and maximum salary. Answers within $10^{-5}$ of the actual answer will be accepted.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| salary = [4000,3000,1000,2000] | 2500.00000 | Exclude 1000 and 4000, average is (2000+3000)/2 |
| salary = [1000,2000,3000] | 2000.00000 | Exclude 1000 and 3000, average is (2000)/1 |

---

## Constraints

- $3 \leq salary.length \leq 100$
- $1000 \leq salary[i] \leq 10^6$
- All the integers of $salary$ are unique

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Sort and sum middle values | $O(n \log n)$ | $O(1)$ |
| One-pass | Track min, max, sum in one pass | $O(n)$ | $O(1)$ |
| ArrayList Removal | Remove min/max, sum rest | $O(n)$ | $O(n)$ |
| PriorityQueue | Use heap to remove min/max | $O(n \log n)$ | $O(n)$ |
| Computing | Track min, max, sum in one pass | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and sum middle values | $O(n \log n)$ | $O(1)$ |

```java
class Solution {
    public double average(int[] salary) {
        Arrays.sort(salary);
        int sum = 0;
        for (int i = 1; i < salary.length - 1; i++) {
            sum += salary[i];
        }
        return (double) sum / (salary.length - 2);
    }
}
```

---

## Code: One-pass (Optimized)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track min, max, sum in one pass | $O(n)$ | $O(1)$ |

```java
class Solution {
    public double average(int[] salary) {
        int s = 0;
        int mi = 10000000, mx = 0;
        for (int v : salary) {
            mi = Math.min(mi, v);
            mx = Math.max(mx, v);
            s += v;
        }
        s -= (mi + mx);
        return s * 1.0 / (salary.length - 2);
    }
}
```

---

## Code: ArrayList-based (Removal)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Remove min/max, sum rest | $O(n)$ | $O(n)$ |

```java
class Solution {
    public double average(int[] salary) {
        ArrayList<Integer> list = new ArrayList<>();
        for (int s : salary) list.add(s);
        list.remove(Collections.min(list));
        list.remove(Collections.max(list));
        int sum = 0;
        for (int x : list) sum += x;
        return (double) sum / list.size();
    }
}
```

---

## Code: PriorityQueue (Heap)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use heap to remove min/max | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public double average(int[] salary) {
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for (int s : salary) pq.offer(s);
        pq.poll(); // remove min
        PriorityQueue<Integer> maxQ = new PriorityQueue<>(Collections.reverseOrder());
        maxQ.addAll(pq);
        maxQ.poll(); // remove max
        int sum = 0;
        for (int v : maxQ) sum += v;
        return (double) sum / maxQ.size();
    }
}
```

---

## Code: Computing Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track min, max, sum in one pass | $O(n)$ | $O(1)$ |

```java
class Solution {
    public double average(int[] salary) {
        int sum = 0, min = salary[0], max = salary[0];
        for (int s : salary) {
            sum += s;
            if (s < min) min = s;
            if (s > max) max = s;
        }
        return (sum - min - max) / (double)(salary.length - 2);
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n \log n)$ | $O(1)$ | Simple, slow |
| One-pass | $O(n)$ | $O(1)$ | Efficient, tracks min/max/sum |
| ArrayList Removal | $O(n)$ | $O(n)$ | Easy, but not optimal |
| PriorityQueue | $O(n \log n)$ | $O(n)$ | Overkill for small $n$ |
| Computing | $O(n)$ | $O(1)$ | Best for clarity and speed |

---

## Summary
- One-pass and computing approaches are optimal for this problem.
- Brute force and heap are only for illustration or very small $n$.
