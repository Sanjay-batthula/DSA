# 15. 3Sum

## Problem Description
Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.  

Notice that the solution set must not contain duplicate triplets.  

## Sample Test Cases
```
Example 1:
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: 
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
The distinct triplets are [-1,0,1] and [-1,-1,2].
Notice that the order of the output and the order of the triplets does not matter.
Example 2:

Input: nums = [0,1,1]
Output: []
Explanation: The only possible triplet does not sum up to 0.
Example 3:

Input: nums = [0,0,0]
Output: [[0,0,0]]
Explanation: The only possible triplet sums up to 0.
```

## Brute force Approach
| Section              | Details                        |
| -------------------- | ------------------------------ |
| **Intuition**        | Try all possible triplets      |
| **Approach**         | 3 nested loops + set for dedup |
| **Time Complexity**  | `O(n³)`                        |
| **Space Complexity** | `O(k)`                         |
| **Issue**            | TLE guaranteed                 |

```
import java.util.*;
class Solution { 
    public List<List<Integer>> threeSum(int[] nums) {
        Set<List<Integer>> set = new HashSet<>();
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                for (int k = j + 1; k < n; k++) {
                    if (nums[i] + nums[j] + nums[k] == 0) {
                        List<Integer> triplet = Arrays.asList(nums[i], nums[j], nums[k]);
                        Collections.sort(triplet); // to handle duplicates like [2,-1,-1]
                        set.add(triplet);
                    }
                }
            }
        }
        return new ArrayList<>(set);
    }
}
```


## Sorting + Two Pointers (ArrayList Approach)
| Section              | Details                        |
| -------------------- | ------------------------------ |
| **Intuition**        | Fix one number, reduce to 2Sum |
| **Approach**         | Sort array, two-pointer scan   |
| **Time Complexity**  | `O(n²)`                        |
| **Space Complexity** | `O(1)`                         |
| **Status**           | ⭐ Industry standard            |

```
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;

                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return result;
    }
}
```

## HashSet / HashMap Approach
| Section              | Details                          |
| -------------------- | -------------------------------- |
| **Intuition**        | Fix one, solve 2Sum with hashing |
| **Approach**         | HashSet for complements          |
| **Time Complexity**  | `O(n²)`                          |
| **Space Complexity** | `O(n)`                           |
| **Issue**            | Dedup is messy                   |

```
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Set<List<Integer>> result = new HashSet<>();
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            Set<Integer> seen = new HashSet<>();
            for (int j = i + 1; j < n; j++) {
                int complement = -nums[i] - nums[j];
                if (seen.contains(complement)) {
                    List<Integer> triplet = Arrays.asList(nums[i], nums[j], complement);
                    Collections.sort(triplet);
                    result.add(triplet);
                }
                seen.add(nums[j]);
            }
        }
        return new ArrayList<>(result);
    }
}
```

## Binary Search Approach
| Section              | Details                          |
| -------------------- | -------------------------------- |
| **Intuition**        | Fix two, binary search the third |
| **Approach**         | Sorted array + binary search     |
| **Time Complexity**  | `O(n² log n)`                    |
| **Space Complexity** | `O(1)`                           |
| **Issue**            | Slower than two pointers         |

```
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            for (int j = i + 1; j < n - 1; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                int target = -(nums[i] + nums[j]);
                int k = Arrays.binarySearch(nums, j + 1, n, target);
                if (k > j) result.add(Arrays.asList(nums[i], nums[j], nums[k]));
            }
        }
        return result;
    }
}
```

## Counting / Frequency Map
| Section              | Details                            |
| -------------------- | ---------------------------------- |
| **Intuition**        | Work with unique values only       |
| **Approach**         | Frequency counting + combinatorics |
| **Time Complexity**  | `O(n²)`                            |
| **Space Complexity** | `O(n)`                             |
| **Issue**            | Complex edge handling              |

```
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int num : nums) freq.put(num, freq.getOrDefault(num, 0) + 1);

        List<Integer> unique = new ArrayList<>(freq.keySet());
        Collections.sort(unique);

        List<List<Integer>> result = new ArrayList<>();

        for (int i = 0; i < unique.size(); i++) {
            int a = unique.get(i);
            for (int j = i; j < unique.size(); j++) {
                int b = unique.get(j);
                int c = -a - b;

                if (!freq.containsKey(c)) continue;

                if (c < b) continue; // keep sorted order a ≤ b ≤ c

                if (a == b && b == c) {
                    if (freq.get(a) >= 3) result.add(Arrays.asList(a, b, c));
                } else if (a == b) {
                    if (freq.get(a) >= 2) result.add(Arrays.asList(a, b, c));
                } else if (b == c) {
                    if (freq.get(b) >= 2) result.add(Arrays.asList(a, b, c));
                } else {
                    result.add(Arrays.asList(a, b, c));
                }
            }
        }

        return result;
    }
}
```

## Approach Comparison
| Approach      | Time          | Space  | Status | Notes           |
| ------------- | ------------- | ------ | ------ | --------------- |
| Brute Force   | `O(n³)`       | `O(n)` | ❌      | TLE             |
| Two Pointer   | `O(n²)`       | `O(1)` | ⭐ Best | Must-know       |
| Hashing       | `O(n²)`       | `O(n)` | ❌      | Dedup pain      |
| Binary Search | `O(n² log n)` | `O(1)` | ❌      | Slower          |
| Frequency Map | `O(n²)`       | `O(n)` | ❌      | Overcomplicated |


## Summary

- Sorting + two pointers is the only correct answer in interviews
- Duplicate skipping is the core difficulty
- Any solution slower than O(n²) is unacceptable
