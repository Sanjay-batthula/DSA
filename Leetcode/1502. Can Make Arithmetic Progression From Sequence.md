# 1502. Can Make Arithmetic Progression From Sequence

## Problem Statement

A sequence of numbers is called an arithmetic progression if the difference between any two consecutive elements is the same.

Given an array of numbers $arr$, return true if the array can be rearranged to form an arithmetic progression. Otherwise, return false.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| arr = [3,5,1] | true | Can reorder as [1,3,5] with difference 2 |
| arr = [1,2,4] | false | No way to reorder to form arithmetic progression |

---

## Constraints

- $2 \leq arr.length \leq 1000$
- $-10^6 \leq arr[i] \leq 10^6$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Sorting | Sort and check differences | $O(n \log n)$ | $O(1)$ |
| Min-Max Formula | Use min, max, and index mapping | $O(n)$ | $O(n)$ |

---

## Code: Sorting based difference check

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and check differences | $O(n \log n)$ | $O(1)$ |

```java
class Solution {
    public boolean canMakeArithmeticProgression(int[] arr) {
        Arrays.sort(arr);
        int d = arr[1] - arr[0];
        for (int i = 2; i < arr.length; ++i) {
            if (arr[i] - arr[i - 1] != d) {
                return false;
            }
        }
        return true;
    }
}
```

---

## Code: Min-Max formula check

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use min, max, and index mapping | $O(n)$ | $O(n)$ |

```java
class Solution {
    public boolean canMakeArithmeticProgression(int[] arr) {
        int min = Integer.MAX_VALUE;
        int max = Integer.MIN_VALUE;
        int n = arr.length;
        for(int x : arr){
            min = Math.min(min, x);
            max = Math.max(max, x);
        }
        if((max - min) % (n - 1) != 0) return false;
        int d = (max - min) / (n - 1);
        boolean[] seen = new boolean[n];
        for(int x : arr){
            int idx = (x - min) / d;
            if(idx < 0 || idx >= n || seen[idx] || min + idx*d != x){
                return false;
            }
            seen[idx] = true;
        }
        return true;
    }
}
```

| Approach | Time Complexity | Space Complexity | Notes |

| Min-Max Formula | $O(n)$ | $O(n)$ | Fastest, but edge cases |

## Summary
- Sorting is simple and reliable for this problem.
- Min-max formula is faster but can be tricky with edge cases.
