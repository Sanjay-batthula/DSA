# 151. Reverse Words in a String

## Problem Statement
Given a string containing words separated by spaces, reverse the order of the words and return them as a single-space-separated string. Extra spaces, leading spaces, and trailing spaces must be ignored.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `s = "the sky is blue"` | `"blue is sky the"` |
| `s = "  hello world  "` | `"world hello"` |
| `s = "a good   example"` | `"example good a"` |

## Constraints
- `1 <= s.length <= 10^4`
- `s` contains English letters, digits, and spaces.
- There is at least one word in `s`.

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Split and reverse | String Parsing | `O(n)` | `O(n)` |
| Two-pointer scan | Two Pointers | `O(n)` | `O(n)` |

## Code
### Pattern
- String Parsing
- Two Pointers

### Intuition
The problem is really about extracting the words in their original order and then emitting them in reverse order. Since the input may contain repeated spaces, the solution must ignore empty tokens and produce a single separator between words.

The split-based approach is simple and direct: trim the string, split on whitespace, reverse the array of words, and join them. The two-pointer approach is more manual and avoids relying on regex or extra tokenization utilities.

### Algorithm
1. Trim the string to remove leading and trailing spaces.
2. Split the string by whitespace into words.
3. Traverse the words from the end to the beginning.
4. Append them to a result string with a single space between words.
5. Return the final string.

### Code
```java
class Solution {
    public String reverseWords(String s) {
        String[] words = s.trim().split("\\s+");
        StringBuilder result = new StringBuilder();

        for (int i = words.length - 1; i >= 0; i--) {
            result.append(words[i]);
            if (i != 0) {
                result.append(" ");
            }
        }

        return result.toString();
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## Other Approaches
### Two-Pointer Scan
#### Pattern
- Two Pointers
- String Traversal

#### Intuition
Instead of splitting the input into tokens first, we can scan the string from right to left. We identify each word by moving to the left until the previous space. Each extracted word is appended to the output, and we skip extra spaces.

#### Algorithm
1. Start from the end of the string.
2. Skip trailing spaces.
3. Find the start and end of the next word.
4. Append that word to the result.
5. Continue until the whole string is processed.
6. Trim the final output.

#### Code
```java
class Solution {
    public String reverseWords(String s) {
        StringBuilder result = new StringBuilder();
        int i = s.length() - 1;

        while (i >= 0) {
            while (i >= 0 && s.charAt(i) == ' ') i--;
            if (i < 0) break;

            int j = i;
            while (j >= 0 && s.charAt(j) != ' ') j--;

            result.append(s.substring(j + 1, i + 1));
            result.append(" ");
            i = j - 1;
        }

        return result.toString().trim();
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## Key Observations
- The problem is primarily about handling whitespace correctly.
- Multiple spaces should be treated as a single separator in the output.
- The words must appear in reverse order, but each word’s characters should remain unchanged.

## Common Mistakes
- Leaving leading or trailing spaces in the final answer.
- Producing multiple spaces between words.
- Reversing characters within each word instead of reversing word order.

## Related Patterns
- String Parsing
- Two Pointers
- Input Cleanup

## Summary
- The optimal solution is to extract the words and output them in reverse order with a single space between them.
- The pattern is string parsing with whitespace handling.
- Time complexity is `O(n)`, and space complexity is `O(n)`.
- Interview takeaway: problems with whitespace often require careful normalization of the input before processing.
