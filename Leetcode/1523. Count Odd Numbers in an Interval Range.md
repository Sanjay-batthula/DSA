# 1523. Count Odd Numbers in an Interval Range

## Problem Statement

Given two non-negative integers $low$ and $high$. Return the count of odd numbers between $low$ and $high$ (inclusive).

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| low = 3, high = 7 | 3 | Odd numbers: [3,5,7] |
| low = 8, high = 10 | 1 | Odd numbers: [9] |

---

## Constraints

- $0 \leq low \leq high \leq 10^9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Bit Manipulation | Use parity formula | $O(1)$ | $O(1)$ |
| Arithmetic | Check range and parity | $O(1)$ | $O(1)$ |

---

## Code: Bit manipulation parity formula

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use parity formula | $O(1)$ | $O(1)$ |

```java
class Solution {
    public int countOdds(int low, int high) {
        return ((high + 1) >> 1) - (low >> 1);
    }
}
```

---

## Code: Arithmetic range parity check

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check range and parity | $O(1)$ | $O(1)$ |

```java
class Solution {
    public int countOdds(int low, int high) {
        int total = high - low + 1;
        if(total % 2 == 0){
            return total / 2;
        }
        if(low % 2 == 1 || high % 2 == 1){
            return total / 2 + 1;
        }
        return total / 2;
    }
}
```
