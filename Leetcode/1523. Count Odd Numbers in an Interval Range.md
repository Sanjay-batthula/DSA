# 1523. Count Odd Numbers in an Interval Range

## Bit manipulation parity formula
```
class Solution {
    public int countOdds(int low, int high) {
        return ((high + 1) >> 1) - (low >> 1);
    }
}
```

## Arithmetic range parity check
```
class Solution {
    public int countOdds(int low, int high) {
        int total = high - low + 1;
        if(total % 2 == 0){
            return total / 2;
        }
        if(low % 2 == 1 || high % 2 == 1){
            return total / 2 + 1;
        }
        return total / 2;
    }
}
```
