# 1550. Three Consecutive Odds

## Problem Statement

Given an integer array $arr$, return true if there are three consecutive odd numbers in the array. Otherwise, return false.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| arr = [2,6,4,1] | false | No three consecutive odds |
| arr = [1,2,34,3,4,5,7,23,12] | true | [5,7,23] are three consecutive odds |

---

## Constraints

- $1 \leq arr.length \leq 1000$
- $1 \leq arr[i] \leq 1000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Greedy Scan | Single-pass, count odds | $O(n)$ | $O(1)$ |
| Sliding Window | Fixed-size window of 3 | $O(n)$ | $O(1)$ |

---

## Code: Single-pass greedy scan

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Single-pass, count odds | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        int cnt = 0;
        for (int x : arr) {
            if (x % 2 == 1) {
                if (++cnt == 3) {
                    return true;
                }
            } else {
                cnt = 0;
            }
        }
        return false;
    }
}
```

---

## Code: Fixed-Size Sliding Window (Window Size = 3)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Fixed-size window of 3 | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        for (int i = 0; i + 2 < arr.length; i++) {
            if ((arr[i] & 1) == 1 &&
                (arr[i + 1] & 1) == 1 &&
                (arr[i + 2] & 1) == 1) {
                return true;
            }
        }
        return false;
    }
}
```

---

| Approach | Time Complexity | Space Complexity | Notes |

## Summary
- Both approaches are optimal for this problem.
- Greedy scan is slightly more general.
