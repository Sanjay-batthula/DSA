# 1550. Three Consecutive Odds

## Single-pass greedy scan
```
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        int cnt = 0;
        for (int x : arr) {
            if (x % 2 == 1) {
                if (++cnt == 3) {
                    return true;
                }
            } else {
                cnt = 0;
            }
        }
        return false;
    }
}
```

## Fixed-Size Sliding Window (Window Size = 3)
```
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        for (int i = 0; i + 2 < arr.length; i++) {
            if ((arr[i] & 1) == 1 &&
                (arr[i + 1] & 1) == 1 &&
                (arr[i + 2] & 1) == 1) {
                return true;
            }
        }
        return false;
    }
}
```
