# 1572. Matrix Diagonal Sum

## single-pass diagonal traversal
```
class Solution {
    public int diagonalSum(int[][] mat) {
        int ans = 0;
        int n = mat.length;
        for (int i = 0; i < n; ++i) {
            int j = n - i - 1;
            ans += mat[i][i] + (i == j ? 0 : mat[i][j]);
        }
        return ans;
    }
}
```

## Single loop with center subtraction
```
class Solution {
    public int diagonalSum(int[][] mat) {
        int n = mat.length;
        int sum = 0;
        for(int i=0;i<n;i++){
            sum += mat[i][i];
            sum += mat[i][n-1-i];
        }
        if(n%2==1){
            sum -= mat[n/2][n/2];
        }
        return sum;
    }
}
```
