## 3Sum Closest Problem
# Intuition
We need to find three numbers in the array whose sum is closest to a given target.
A brute-force approach would check all triplets in O(n³) time, but that’s inefficient.
By sorting the array and using the two-pointer technique, we can reduce it to O(n²) while keeping track of the closest sum seen so far.

# Approach
Sort the array so that we can apply the two-pointer method efficiently.

Iterate through the array with index i:

Set two pointers:

j at i + 1

k at n - 1

Calculate the current sum t = nums[i] + nums[j] + nums[k].

If the sum equals the target, return it immediately (perfect match).

If the absolute difference between t and the target is smaller than the difference between our best answer ans and the target, update ans.

Move pointers:

If t is greater than the target, decrement k to try smaller sums.

If t is less than the target, increment j to try larger sums.

Return ans after all iterations.


# Complexity
- Time complexity:
O(n²) — Sorting takes O(n log n) and for each element we use a two-pointer search in O(n).

- Space complexity:
O(1) — Only a few extra variables are used.

# Code
```java
class Solution {
    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        int ans = 1 << 30;
        int n = nums.length;
        for (int i = 0; i < n; ++i) {
            int j = i + 1, k = n - 1;
            while (j < k) {
                int t = nums[i] + nums[j] + nums[k];
                if (t == target) {
                    return t;
                }
                if (Math.abs(t - target) < Math.abs(ans - target)) {
                    ans = t;
                }
                if (t > target) {
                    --k;
                } else {
                    ++j;
                }
            }
        }
        return ans;
    }
}
```
