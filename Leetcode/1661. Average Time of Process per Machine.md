## 1661. Average Time of Process per Machine

## Self JOIN with conditional filtering
| Section       | Details                                                                                                                                                                                                                          |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | Each process generates two rows in the same table, one for `start` and one for `end`. To compute the process duration, these two rows must be paired together before aggregation.                                                |
| **Approach**  | Perform a self join on the `Activity` table by matching `machine_id` and `process_id`. Filter one side of the join to `start` events and the other to `end` events, then compute the time difference and average it per machine. |

```
SELECT a1.machine_id,
       ROUND(AVG(a2.timestamp - a1.timestamp), 3) AS processing_time
FROM Activity a1
JOIN Activity a2
  ON a1.machine_id = a2.machine_id
 AND a1.process_id = a2.process_id
 AND a1.activity_type = 'start'
 AND a2.activity_type = 'end'
GROUP BY a1.machine_id;

```
