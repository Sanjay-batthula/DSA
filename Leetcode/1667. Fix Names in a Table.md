# 1667. Fix Names in a Table

## String Manipulation using LEFT() and SUBSTRING()
```
SELECT user_id, CONCAT(UPPER(LEFT(name, 1)), LOWER(SUBSTRING(name, 2))) AS name
FROM Users
ORDER BY user_id;
```

## String Manipulation using SUBSTR()
```
SELECT user_id,
       CONCAT(UPPER(SUBSTR(name,1,1)),
              LOWER(SUBSTR(name,2))) AS name
FROM Users
ORDER BY user_id;
```


## (Regex) Based Transformation - Wrong Answer
```
SELECT user_id,
       REGEXP_REPLACE(
           LOWER(name),
           '^[a-z]',
           UPPER(LEFT(name,1))
       ) AS name
FROM Users;
```
