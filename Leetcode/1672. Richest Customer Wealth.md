# 1672. Richest Customer Wealth

## Problem Statement

You are given an $m \times n$ integer grid $accounts$ where $accounts[i][j]$ is the amount of money the $i$th customer has in the $j$th bank. Return the wealth that the richest customer has.

A customer's wealth is the amount of money they have in all their bank accounts. The richest customer is the customer that has the maximum wealth.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| accounts = [[1,2,3],[3,2,1]] | 6 | Both customers have wealth 6 |
| accounts = [[1,5],[7,3],[3,5]] | 10 | 2nd customer has wealth 10 |
| accounts = [[2,8,7],[7,1,3],[1,9,5]] | 17 | 1st customer has wealth 17 |

---

## Constraints

- $m == accounts.length$
- $n == accounts[i].length$
- $1 \leq m, n \leq 50$
- $1 \leq accounts[i][j] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Greedy Maximum Tracking | Aggregate row sums, track max | $O(mn)$ | $O(1)$ |
| Brute Force Traversal | Nested loops, track max | $O(mn)$ | $O(1)$ |

---

## Code: Iterative Row Aggregation using Greedy Maximum Tracking

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Aggregate row sums, track max | $O(mn)$ | $O(1)$ |

```java
class Solution {
    public int maximumWealth(int[][] accounts) {
        int ans = 0;
        for (var e : accounts) {
            int s = 0;
            for (int v : e) {
                s += v;
            }
            ans = Math.max(ans, s);
        }
        return ans;
    }
}
```

---

## Code: Brute Force Traversal with Incremental Maximum Tracking

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Nested loops, track max | $O(mn)$ | $O(1)$ |

```java
class Solution {
    public int maximumWealth(int[][] accounts) {
        int max = 0;
        for (int i = 0; i < accounts.length; i++) {
            int sum = 0;
            for (int j = 0; j < accounts[i].length; j++) {
                sum += accounts[i][j];
            }
            if (sum > max) max = sum;
        }
        return max;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Greedy Maximum Tracking | $O(mn)$ | $O(1)$ | Simple, clear |
| Brute Force Traversal | $O(mn)$ | $O(1)$ | Equivalent, easy to debug |

---

## Summary
- Both approaches are optimal for this problem.
- Greedy maximum tracking is slightly more concise.
