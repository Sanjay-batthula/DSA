
# 17. Letter Combinations of a Phone Number

## Problem Description
Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent. Return the answer in any order.

A mapping of digits to letters (just like on the telephone buttons) is given below. Note that 1 does not map to any letters.

## Sample Test Cases
Example 1:  
Input: digits = "23"  
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]

Example 2:  
Input: digits = "2"  
Output: ["a","b","c"]

**Constraints:**
- 1 <= digits.length <= 4
- digits[i] is a digit in the range ['2', '9']

---

## Brute Force (Iterative Expansion)
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Build all combinations by expanding iteratively |
| **Approach**         | For each digit, append all possible letters     |
| **Time Complexity**  | `O(4^n)` (n = digits.length)                    |
| **Space Complexity** | `O(4^n)`                                       |

```java
class Solution {
    public List<String> letterCombinations(String digits) {
        List<String> ans = new ArrayList<>();
        if (digits.length() == 0) {
            return ans;
        }
        ans.add("");
        String[] d = new String[] {"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        for (char i : digits.toCharArray()) {
            String s = d[i - '2'];
            List<String> t = new ArrayList<>();
            for (String a : ans) {
                for (String b : s.split("")) {
                    t.add(a + b);
                }
            }
            ans = t;
        }
        return ans;
    }
}
```

## Recursive Backtracking
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use recursion to build combinations             |
| **Approach**         | Backtrack for each digit and letter             |
| **Time Complexity**  | `O(4^n)`                                       |
| **Space Complexity** | `O(4^n)`                                       |

```java
class Solution {
    public List<String> letterCombinations(String digits) {
        List<String> ans = new ArrayList<>();
        if (digits.isEmpty()) return ans;
        String[] d = {"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        backtrack(ans, d, digits, 0, new StringBuilder());
        return ans;
    }

    private void backtrack(List<String> ans, String[] d, String digits, int idx, StringBuilder cur) {
        if (idx == digits.length()) {
            ans.add(cur.toString());
            return;
        }
        String letters = d[digits.charAt(idx) - '2'];
        for (char c : letters.toCharArray()) {
            cur.append(c);
            backtrack(ans, d, digits, idx + 1, cur);
            cur.deleteCharAt(cur.length() - 1); // backtrack
        }
    }
}
```

## Queue-Based BFS
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use a queue to build combinations level by level|
| **Approach**         | BFS: expand all current strings for each digit  |
| **Time Complexity**  | `O(4^n)`                                       |
| **Space Complexity** | `O(4^n)`                                       |

```java
class Solution {
    public List<String> letterCombinations(String digits) {
        if (digits.isEmpty()) return new ArrayList<>();
        String[] d = {"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        Queue<String> q = new LinkedList<>();
        q.add("");

        for (char c : digits.toCharArray()) {
            String letters = d[c - '2'];
            int size = q.size();
            while (size-- > 0) {
                String base = q.poll();
                for (char ch : letters.toCharArray()) {
                    q.add(base + ch);
                }
            }
        }
        return new ArrayList<>(q);
    }
}
```

## Approach Comparison
| Approach         | Time      | Space   | Status    | Notes                |
| ---------------- | --------- | ------- | --------- | -------------------- |
| Brute Force      | `O(4^n)`  | `O(4^n)`| ✅         | Simple, iterative    |
| Backtracking     | `O(4^n)`  | `O(4^n)`| ✅ Optimal | Standard recursion   |
| BFS (Queue)      | `O(4^n)`  | `O(4^n)`| ✅         | Level-wise expansion |

## Summary

- All approaches have similar time/space due to output size
- Backtracking is the most common interview solution
- BFS and iterative are also valid and easy to implement
- Key insight: treat as a cartesian product problem
