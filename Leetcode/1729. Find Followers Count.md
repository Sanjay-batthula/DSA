# 1729. Find Followers Count

## GROUP BY Aggregation
```
SELECT
    user_id,
    COUNT(DISTINCT follower_id) AS followers_count
FROM
    Followers
GROUP BY
    user_id
ORDER BY
    user_id;
```

## Correlated Subquery
```
SELECT DISTINCT f1.user_id,
       (
           SELECT COUNT(*)
           FROM Followers f2
           WHERE f2.user_id = f1.user_id
       ) AS followers_count
FROM Followers f1
ORDER BY f1.user_id;
```
