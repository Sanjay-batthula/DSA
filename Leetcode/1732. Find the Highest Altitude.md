# 1732. Find the Highest Altitude

## Problem Statement

There is a biker going on a road trip. The road trip consists of $n + 1$ points at different altitudes. The biker starts his trip on point 0 with altitude equal 0.

You are given an integer array $gain$ of length $n$ where $gain[i]$ is the net gain in altitude between points $i$ and $i + 1$ for all $0 \leq i < n$. Return the highest altitude of a point.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| gain = [-5,1,5,0,-7] | 1 | Altitudes: [0,-5,-4,1,1,-6], highest is 1 |
| gain = [-4,-3,-2,-1,4,3,2] | 0 | Altitudes: [0,-4,-7,-9,-10,-6,-3,-1], highest is 0 |

---

## Constraints

- $n == gain.length$
- $1 \leq n \leq 100$
- $-100 \leq gain[i] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Prefix Sum | Track running sum and max | $O(n)$ | $O(1)$ |
| Explicit Prefix Array | Build prefix array, find max | $O(n)$ | $O(n)$ |

---

## Code: Prefix Sum with Running Maximum

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track running sum and max | $O(n)$ | $O(1)$ |

```java
public class Solution {
    public int largestAltitude(int[] gain) {
        int maxAltitude = 0;
        int currentAltitude = 0;
        for (int g : gain) {
            currentAltitude += g;
            maxAltitude = Math.max(maxAltitude, currentAltitude);
        }
        return maxAltitude;
    }
}
```

---

## Code: Explicit Prefix Sum Array

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Build prefix array, find max | $O(n)$ | $O(n)$ |

```java
public class Solution {
    public int largestAltitude(int[] gain) {
        int n = gain.length;
        int[] alt = new int[n + 1];
        alt[0] = 0;
        for (int i = 0; i < n; i++) {
            alt[i + 1] = alt[i] + gain[i];
        }
        int max = alt[0];
        for (int i = 1; i <= n; i++) {
            if (alt[i] > max) max = alt[i];
        }
        return max;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Prefix Sum | $O(n)$ | $O(1)$ | Concise, optimal |
| Explicit Prefix Array | $O(n)$ | $O(n)$ | Useful for debugging |

---

## Summary
- Prefix sum with running maximum is optimal for this problem.
- Explicit prefix array is useful for clarity and debugging.
