# 1732. Find the Highest Altitude.md

## Prefix Sum with Running Maximum
```
public class Solution {
    public int largestAltitude(int[] gain) {
        int maxAltitude = 0;
        int currentAltitude = 0;
        for (int g : gain) {
            currentAltitude += g;
            maxAltitude = Math.max(maxAltitude, currentAltitude);
        }
        return maxAltitude;
    }
}
```

## Explicit Prefix Sum Array
```
public class Solution {
    public int largestAltitude(int[] gain) {
        int n = gain.length;
        int[] alt = new int[n + 1];
        alt[0] = 0;
        for (int i = 0; i < n; i++) {
            alt[i + 1] = alt[i] + gain[i];
        }
        int max = alt[0];
        for (int i = 1; i <= n; i++) {
            if (alt[i] > max) max = alt[i];
        }
        return max;
    }
}
```
