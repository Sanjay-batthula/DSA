# 1752. Check if Array Is Sorted and Rotated

## Problem Statement

Given an array $nums$, return true if the array was originally sorted in non-decreasing order, then rotated some number of positions (including zero). Otherwise, return false.

There may be duplicates in the original array.

Note: An array $A$ rotated by $x$ positions results in an array $B$ of the same length such that $B[i] == A[(i+x) \% A.length]$ for every valid index $i$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [3,4,5,1,2] | true | [1,2,3,4,5] rotated by 2 positions |
| nums = [2,1,3,4] | false | No sorted array once rotated can make nums |
| nums = [1,2,3] | true | [1,2,3] is sorted, no rotation needed |

---

## Constraints

- $1 \leq nums.length \leq 100$
- $1 \leq nums[i] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Inversion Count | Count places where order breaks | $O(n)$ | $O(1)$ |
| Pivot-based | Find pivot, check sortedness | $O(n)$ | $O(1)$ |

---

## Code: Single-pass inversion count

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count places where order breaks | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean check(int[] nums) {
        int cnt = 0;
        for (int i = 0, n = nums.length; i < n; ++i) {
            if (nums[i] > nums[(i + 1) % n]) {
                ++cnt;
            }
        }
        return cnt <= 1;
    }
}
```

---

## Code: Pivot-based check

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Find pivot, check sortedness | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean check(int[] nums) {
        int n = nums.length;
        int pivot = -1;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] > nums[i + 1]) {
                pivot = i;
                break;
            }
        }
        if (pivot == -1) return true;
        for (int i = 1; i < n; i++) {
            int prev = nums[(pivot + i - 1) % n];
            int curr = nums[(pivot + i) % n];
            if (prev > curr) return false;
        }
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Inversion Count | $O(n)$ | $O(1)$ | Simple, clear |
| Pivot-based | $O(n)$ | $O(1)$ | Useful for debugging |

## Summary
- Both approaches are optimal for this problem.
- Inversion count is concise and efficient.
