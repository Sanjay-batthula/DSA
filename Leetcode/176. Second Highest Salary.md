# 176. Second Highest Salary

## Problem Statement
Find the second highest distinct salary from the Employee table. If no such salary exists, return null.

## Table Schema
| Column | Type | Description |
| --- | --- | --- |
| id | int | Primary key |
| salary | int | Salary of the employee |

## Sample Data
### Employee
| id | salary |
| --- | --- |
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

### Expected Output
| SecondHighestSalary |
| --- |
| 200 |

## SQL Pattern
- SELECT
- DISTINCT
- WHERE
- Scalar Subquery
- Aggregate Functions
- ORDER BY
- LIMIT / OFFSET
- Window Functions

Alternative patterns:
- Aggregate Function with subquery
- Window Function with ranking

## Solution 1 (Recommended)

### Technique
Scalar Subquery + Aggregate Function

### Why it Works
The highest salary is removed by using a subquery, and then the largest remaining distinct salary is selected. This directly matches the requirement for the second highest distinct value.

### Query
```sql
SELECT MAX(salary) AS SecondHighestSalary
FROM Employee
WHERE salary < (
    SELECT MAX(salary) FROM Employee
);
```

### Query Breakdown
- SELECT: chooses the final result column.
- MAX(salary): returns the largest salary that still satisfies the condition.
- FROM Employee: reads from the Employee table.
- WHERE salary < (...): keeps only salaries smaller than the maximum salary.
- Scalar Subquery: finds the current maximum salary in the table.

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(1)`

## Other Solutions

### Solution 2

### Technique
ORDER BY + LIMIT / OFFSET

### Why it Works
If distinct salaries are sorted in descending order, the second value in that ordered list is the second highest distinct salary.

### Query
```sql
SELECT (
    SELECT DISTINCT salary
    FROM Employee
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1
) AS SecondHighestSalary;
```

### Complexity
- Time Complexity: `O(n log n)`
- Space Complexity: `O(1)`

### Solution 3

### Technique
Window Function with DENSE_RANK

### Why it Works
Ranking the salaries makes it easy to identify the second rank directly.

### Query
```sql
SELECT MAX(salary) AS SecondHighestSalary
FROM (
    SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
    FROM Employee
) t
WHERE rnk = 2;
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## Solution Comparison
| Technique | SQL Features | Readability | Performance | Best Use Case |
| --- | --- | --- | --- | --- |
| Scalar subquery | Subquery, MAX | High | Good | Simple and concise solution |
| ORDER BY + LIMIT/OFFSET | DISTINCT, ORDER BY, LIMIT | High | Moderate | Easy to read when sorting is acceptable |
| Window function | DENSE_RANK, OVER | Moderate | Good | When ranking logic is already needed |

## Pattern Recognition
This pattern should come to mind when the problem asks for:
- second highest value
- top-k ranking
- distinct ranking from a single column

## Common Mistakes
- Forgetting to use `DISTINCT` and accidentally counting duplicates.
- Using `<=` instead of `<` in the comparison.
- Not handling the case where no second salary exists.

## Interview Tips
- Mention that the problem is about distinct values, not row positions.
- If asked, explain that the subquery solution is usually the most interview-friendly.
- Be aware of database-specific behavior for `NULL` and `LIMIT`.

## Revision Summary
- Main SQL pattern: scalar subquery with aggregate function
- Best solution: use `MAX` after filtering salaries below the highest value
- Alternative techniques: sorting with `LIMIT/OFFSET` or ranking with window functions
- Common pitfalls: duplicates and missing second value
- Key takeaway: the second highest distinct salary is the highest salary smaller than the maximum
