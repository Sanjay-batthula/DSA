# 1768. Merge Strings Alternately

## Problem Statement

You are given two strings $word1$ and $word2$. Merge the strings by adding letters in alternating order, starting with $word1$. If a string is longer than the other, append the additional letters onto the end of the merged string.

Return the merged string.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| word1 = "abc", word2 = "pqr" | "apbqcr" | Alternating merge |
| word1 = "ab", word2 = "pqrs" | "apbqrs" | Append extra from word2 |
| word1 = "abcd", word2 = "pq" | "apbqcd" | Append extra from word1 |

---

## Constraints

- $1 \leq word1.length, word2.length \leq 100$
- $word1$ and $word2$ consist of lowercase English letters

## Code: Two Pointer traversal (index-based) with parallel iteration

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Traverse both strings, alternate | $O(n)$ | $O(n)$ |

```java
class Solution {
    public String mergeAlternately(String word1, String word2) {
        StringBuilder mergedString = new StringBuilder();
        int len1 = word1.length();
        int len2 = word2.length();
        int maxLen = Math.max(len1, len2);
        for (int i = 0; i < maxLen; i++) {
            if (i < len1) {
                mergedString.append(word1.charAt(i));
            }
            if (i < len2) {
                mergedString.append(word2.charAt(i));
            }
        }
        return mergedString.toString();
    }
}
```
