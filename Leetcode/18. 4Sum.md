
# 18. 4Sum

## Problem Description
Given an array `nums` of n integers, return an array of all the unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:

- 0 <= a, b, c, d < n
- a, b, c, and d are distinct.
- nums[a] + nums[b] + nums[c] + nums[d] == target

You may return the answer in any order.

## Sample Test Cases
Example 1:  
Input: nums = [1,0,-1,0,-2,2], target = 0  
Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

Example 2:  
Input: nums = [2,2,2,2,2], target = 8  
Output: [[2,2,2,2]]

**Constraints:**
- 1 <= nums.length <= 200
- -10⁹ <= nums[i] <= 10⁹
- -10⁹ <= target <= 10⁹

---

## Brute Force
| Section              | Details                                 |
| -------------------- | --------------------------------------- |
| **Intuition**        | Try all quadruplets                     |
| **Approach**         | Four nested loops, check all (i,j,k,l)  |
| **Time Complexity**  | `O(n⁴)`                                 |
| **Space Complexity** | `O(1)`                                  |

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;
        Arrays.sort(nums);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    for (int l = k + 1; l < n; l++) {
                        long sum = (long) nums[i] + nums[j] + nums[k] + nums[l];
                        if (sum == target) {
                            List<Integer> temp = Arrays.asList(nums[i], nums[j], nums[k], nums[l]);
                            if (!ans.contains(temp)) ans.add(temp);
                        }
                    }
                }
            }
        }
        return ans;
    }
}
```

## Optimized Two-Pointer Approach
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Sort, fix two, use two pointers for the rest                 |
| **Approach**         | For each i, j, use k/l to find quadruplets                   |
| **Time Complexity**  | `O(n³)`                                                      |
| **Space Complexity** | `O(1)`                                                       |

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < n; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int k = j + 1, l = n - 1;

                while (k < l) {
                    long sum = (long) nums[i] + nums[j] + nums[k] + nums[l];

                    if (sum == target) {
                        ans.add(Arrays.asList(nums[i], nums[j], nums[k], nums[l]));

                        while (k < l && nums[k] == nums[k + 1]) k++;
                        while (k < l && nums[l] == nums[l - 1]) l--;

                        k++;
                        l--;
                    } else if (sum < target) {
                        k++;
                    } else {
                        l--;
                    }
                }
            }
        }
        return ans;
    }
}
```

## HashSet + ThreeSum Reduction
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Reduce to 3Sum with hashset for complements                  |
| **Approach**         | For each i, j, use set to find complement for quadruplet     |
| **Time Complexity**  | `O(n³)`                                                      |
| **Space Complexity** | `O(n)`                                                       |

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            for (int j = i + 1; j < n; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                Set<Integer> seen = new HashSet<>();
                for (int k = j + 1; k < n; k++) {
                    int complement = target - nums[i] - nums[j] - nums[k];
                    if (seen.contains(complement)) {
                        List<Integer> quad = Arrays.asList(nums[i], nums[j], complement, nums[k]);
                        Collections.sort(quad);
                        if (!ans.contains(quad)) ans.add(quad);
                    }
                    seen.add(nums[k]);
                }
            }
        }
        return ans;
    }
}
```

## HashMap of Pair Sums
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Store all pair sums, look for complement pairs               |
| **Approach**         | Use map to store pairs, combine to form quadruplets          |
| **Time Complexity**  | `O(n²)` for map, `O(n²)` for search, but high constant       |
| **Space Complexity** | `O(n²)`                                                      |

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        Map<Long, List<int[]>> map = new HashMap<>();
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                long sum = (long) nums[i] + nums[j];
                map.computeIfAbsent(sum, k -> new ArrayList<>()).add(new int[]{i, j});
            }
        }

        Set<List<Integer>> set = new HashSet<>();
        for (long sum1 : map.keySet()) {
            long sum2 = (long) target - sum1;
            if (map.containsKey(sum2)) {
                for (int[] p1 : map.get(sum1)) {
                    for (int[] p2 : map.get(sum2)) {
                        if (p1[1] < p2[0]) {
                            List<Integer> quad = Arrays.asList(
                                nums[p1[0]], nums[p1[1]], nums[p2[0]], nums[p2[1]]
                            );
                            Collections.sort(quad);
                            set.add(quad);
                        }
                    }
                }
            }
        }

        ans.addAll(set);
        return ans;
    }
}
```

## K-Sum Recursive Approach
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Generalize to k-sum, recursively reduce                      |
| **Approach**         | Recursively reduce k, use two-pointer for k=2                |
| **Time Complexity**  | `O(n^{k-1})` for k-sum, here `O(n³)`                         |
| **Space Complexity** | `O(n)` (recursion stack)                                     |

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        return kSum(nums, target, 4, 0);
    }
    private List<List<Integer>> kSum(int[] nums, long target, int k, int start) {
        List<List<Integer>> res = new ArrayList<>();
        if (k == 2) {
            int l = start, r = nums.length - 1;
            while (l < r) {
                long sum = nums[l] + nums[r];
                if (sum == target) {
                    res.add(Arrays.asList(nums[l++], nums[r--]));
                    while (l < r && nums[l] == nums[l - 1]) l++;
                    while (l < r && nums[r] == nums[r + 1]) r--;
                } else if (sum < target) l++;
                else r--;
            }
            return res;
        }
        for (int i = start; i < nums.length; i++) {
            if (i > start && nums[i] == nums[i - 1]) continue;
            for (List<Integer> subset : kSum(nums, target - nums[i], k - 1, i + 1)) {
                List<Integer> temp = new ArrayList<>();
                temp.add(nums[i]);
                temp.addAll(subset);
                res.add(temp);
            }
        }
        return res;
    }
}
```

## Approach Comparison
| Approach                | Time         | Space   | Status    | Notes                |
| ----------------------- | ------------ | ------- | --------- | -------------------- |
| Brute Force             | `O(n⁴)`      | `O(1)`  | ❌ TLE     | Baseline only        |
| Two-Pointer             | `O(n³)`      | `O(1)`  | ✅ Optimal | Standard interview   |
| HashSet/3Sum            | `O(n³)`      | `O(n)`  | ❌         | Not always correct   |
| HashMap of Pair Sums    | `O(n²)`      | `O(n²)` | ❌ TLE     | High constant, slow  |
| K-Sum Recursive         | `O(n³)`      | `O(n)`  | ✅         | Generalizes to k-sum |

## Summary

- Two-pointer and k-sum recursive are optimal and practical
- Brute force and hash-based methods are too slow for large n
- Key insight: sort, fix two, use two pointers for the rest
- ⭐ Classic problem for array and k-sum mastery
