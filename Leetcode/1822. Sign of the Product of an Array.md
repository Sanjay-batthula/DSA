# 1822. Sign of the Product of an Array

## Sign-tracking (or parity-based sign tracking) approach
```
class Solution {
    public int arraySign(int[] nums) {
        int ans = 1;
        for (int v : nums) {
            if (v == 0) {
                return 0;
            }
            if (v < 0) {
                ans *= -1;
            }
        }
        return ans;
    }
}
```

## Negative-count (parity) approach
```
class Solution {
    public int arraySign(int[] nums) {
        int neg = 0;
        for (int v : nums) {
            if (v == 0) return 0;
            if (v < 0) neg++;
        }
        return (neg & 1) == 0 ? 1 : -1;
    }
}
```
