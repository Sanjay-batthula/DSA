# 1822. Sign of the Product of an Array

## Problem Statement

Implement a function $signFunc(x)$ that returns:
- 1 if $x$ is positive.
- -1 if $x$ is negative.
- 0 if $x$ is equal to 0.

You are given an integer array $nums$. Let $product$ be the product of all values in the array $nums$.

Return $signFunc(product)$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [-1,-2,-3,-4,3,2,1] | 1 | Product is 144, signFunc(144) = 1 |
| nums = [1,5,0,2,-3] | 0 | Product is 0, signFunc(0) = 0 |
| nums = [-1,1,-1,1,-1] | -1 | Product is -1, signFunc(-1) = -1 |

---

## Constraints

- $1 \leq nums.length \leq 1000$
- $-100 \leq nums[i] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Sign Tracking | Track sign as you iterate | $O(n)$ | $O(1)$ |
| Negative Count | Count negatives, check parity | $O(n)$ | $O(1)$ |

---

## Code: Sign-tracking (parity-based sign tracking) approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track sign as you iterate | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int arraySign(int[] nums) {
        int ans = 1;
        for (int v : nums) {
            if (v == 0) {
                return 0;
            }
            if (v < 0) {
                ans *= -1;
            }
        }
        return ans;
    }
}
```

---

## Code: Negative-count (parity) approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Count negatives, check parity | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int arraySign(int[] nums) {
        int neg = 0;
        for (int v : nums) {
            if (v == 0) return 0;
            if (v < 0) neg++;
        }
        return (neg & 1) == 0 ? 1 : -1;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Sign Tracking | $O(n)$ | $O(1)$ | Concise, clear |
| Negative Count | $O(n)$ | $O(1)$ | Alternative, easy to debug |

---

## Summary
- Both approaches are optimal for this problem.
- Sign tracking is concise and efficient.
