# 185. Department Top Three Salaries

## Problem Statement
Find the employees whose salary is within the top three distinct salaries in their department. Return the department name, employee name, and salary for each qualifying employee.

## Table Schema
### Employee
| Column | Type | Description |
| --- | --- | --- |
| id | int | Primary key |
| name | varchar | Employee name |
| salary | int | Salary of the employee |
| departmentId | int | Department reference |

### Department
| Column | Type | Description |
| --- | --- | --- |
| id | int | Primary key |
| name | varchar | Department name |

## Sample Data

| id | name | salary | departmentId |
| --- | --- | --- | --- |

## Solution 1 (Recommended)

### Technique
Window Function with DENSE_RANK

### Why it Works
The query ranks employees within each department by salary in descending order. Employees whose rank is 1, 2, or 3 are the top three distinct earners in that department.

### Query
```sql
SELECT Department, Employee, Salary
FROM (
    SELECT 
        d.name AS Department,
        e.name AS Employee,
        e.salary AS Salary,
        DENSE_RANK() OVER (
            PARTITION BY d.name
            ORDER BY e.salary DESC
        ) AS rnk
    FROM Employee e
    JOIN Department d
        ON e.departmentId = d.id
) AS t
WHERE rnk <= 3;
```

### Query Breakdown
- SELECT: chooses the final columns to return.
- JOIN: combines employee and department information.
- DENSE_RANK(): assigns a rank to each employee within the same department.
- PARTITION BY d.name: restarts the ranking for each department.
- ORDER BY e.salary DESC: ranks the highest salary first.
- WHERE rnk <= 3: keeps only the top three distinct salary earners.

### Complexity
- Time Complexity: `O(n log n)` due to ranking
- Space Complexity: `O(n)`

## Other Solutions

### Solution 2

### Technique
Correlated Subquery

### Why it Works
For each employee, the subquery counts how many distinct salaries in the same department are greater than that employee’s salary. If the count is less than 3, the employee is in the top three distinct salaries.

### Query
```sql
SELECT d.name AS Department, e.name AS Employee, e.salary AS Salary
FROM Employee e
JOIN Department d
ON e.departmentId = d.id
WHERE (
    SELECT COUNT(DISTINCT e2.salary)
    FROM Employee e2
    WHERE e2.departmentId = e.departmentId
      AND e2.salary > e.salary
) < 3;
```

### Complexity
- Time Complexity: `O(n^2)` in the worst case
- Space Complexity: `O(1)` extra space

| --- | --- | --- | --- | --- |
| Window Function | DENSE_RANK, PARTITION BY | High | Good | Best overall solution |
| Correlated Subquery | Correlated Subquery, COUNT(DISTINCT) | Moderate | Slower on larger data | Useful when ranking functions are unavailable |

## Pattern Recognition
This pattern should come to mind when the problem asks for:
- top-k within groups
- ranking inside partitions
- department-wise leader boards

## Common Mistakes
- Using `RANK` instead of `DENSE_RANK` and accidentally skipping ranks when salaries tie.
- Forgetting to partition by department.
- Not using `DISTINCT` when counting salaries.

## Interview Tips
- Mention that the requirement is “top three distinct salaries,” so ties should not create extra ranks.
- The window function approach is usually the clearest interview answer.
- If asked about database compatibility, note that window functions are supported in most modern SQL engines.

## Revision Summary
- Main SQL pattern: ranking within groups using window functions
- Best solution: use `DENSE_RANK` partitioned by department
- Alternative technique: correlated subquery with distinct salary comparison
- Common pitfalls: incorrect ranking and duplicate salary handling
- Key takeaway: employees in the top three distinct salaries per department are selected by ranking within each department
