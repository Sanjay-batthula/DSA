# 1863. Sum of All Subset XOR Totals

## Bitwise Contribution / Mathematical Optimization
```
class Solution {
    public int subsetXORSum(int[] nums) {
        int or = 0;
        for (int x : nums) or |= x;
        return or << (nums.length - 1);
    }
}
```

## Bitmask Enumeration
```
class Solution {
    public int subsetXORSum(int[] nums) {
        int n = nums.length;
        int ans = 0;
        for (int i = 0; i < 1 << n; ++i) {
            int s = 0;
            for (int j = 0; j < n; ++j) {
                if ((i >> j & 1) == 1) {
                    s ^= nums[j];
                }
            }
            ans += s;
        }
        return ans;
    }
}
```

## Brute Force Subset Enumeration (Python)
```
class Solution(object):
    def subsetXORSum(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n=len(nums)
        t=0
        for m in range(1 << n):
            xt=0
            for i in range(n):
                if m &(1<< i):
                    xt^=nums[i]
            t+=xt
        return t
```
