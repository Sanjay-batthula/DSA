# 1863. Sum of All Subset XOR Totals

## Problem Statement

The XOR total of an array is defined as the bitwise XOR of all its elements, or 0 if the array is empty.

Given an array $nums$, return the sum of all XOR totals for every subset of $nums$.

Note: Subsets with the same elements should be counted multiple times.

An array $a$ is a subset of an array $b$ if $a$ can be obtained from $b$ by deleting some (possibly zero) elements of $b$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,3] | 6 | Subsets: [], [1], [3], [1,3]; XOR totals: 0+1+3+2=6 |
| nums = [5,1,6] | 28 | Subsets: 8 subsets, sum of XOR totals is 28 |
| nums = [3,4,5,6,7,8] | 480 | Sum of all XOR totals is 480 |

---

## Constraints

- $1 \leq nums.length \leq 12$
- $1 \leq nums[i] \leq 20$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Bitwise Contribution | Mathematical optimization | $O(n)$ | $O(1)$ |
| Bitmask Enumeration | Enumerate all subsets | $O(n2^n)$ | $O(1)$ |
| Brute Force | Enumerate all subsets (Python) | $O(n2^n)$ | $O(1)$ |

---

## Code: Bitwise Contribution / Mathematical Optimization

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Mathematical optimization | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int subsetXORSum(int[] nums) {
        int or = 0;
        for (int x : nums) or |= x;
        return or << (nums.length - 1);
    }
}
```

---

## Code: Bitmask Enumeration

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Enumerate all subsets | $O(n2^n)$ | $O(1)$ |

```java
class Solution {
    public int subsetXORSum(int[] nums) {
        int n = nums.length;
        int ans = 0;
        for (int i = 0; i < 1 << n; ++i) {
            int s = 0;
            for (int j = 0; j < n; ++j) {
                if ((i >> j & 1) == 1) {
                    s ^= nums[j];
                }
            }
            ans += s;
        }
        return ans;
    }
}
```

## Code: Brute Force Subset Enumeration (Python)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Enumerate all subsets (Python) | $O(n2^n)$ | $O(1)$ |

```python
class Solution(object):
    def subsetXORSum(self, nums):
        n=len(nums)
        t=0
        for m in range(1 << n):
            xt=0
            for i in range(n):
                if m &(1<< i):
                    xt^=nums[i]
            t+=xt
        return t

s=Solution()
print(s.subsetXORSum([1,3]))
print(s.subsetXORSum([5,1,6]))
print(s.subsetXORSum([3,4,5,6,7,8]))
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Bitwise Contribution | $O(n)$ | $O(1)$ | Fastest, mathematical insight |
| Bitmask Enumeration | $O(n2^n)$ | $O(1)$ | General, easy to implement |
| Brute Force | $O(n2^n)$ | $O(1)$ | Python version, same as bitmask |

---

## Summary
- Bitwise contribution is optimal for this problem.
- Bitmask enumeration is general and easy to implement.
