# 1920. Build Array from Permutation

## Problem Statement

Given a zero-based permutation $nums$ (0-indexed), build an array $ans$ of the same length where $ans[i] = nums[nums[i]]$ for each $0 \leq i < nums.length$ and return it.

A zero-based permutation $nums$ is an array of distinct integers from $0$ to $nums.length - 1$ (inclusive).

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [0,2,1,5,3,4] | [0,1,2,4,5,3] | $ans = [nums[nums[0]], nums[nums[1]], ...]$ |
| nums = [5,0,1,2,3,4] | [4,5,0,1,2,3] | $ans = [nums[nums[0]], nums[nums[1]], ...]$ |

---

## Constraints

- $1 \leq nums.length \leq 1000$
- $0 \leq nums[i] < nums.length$
- The elements in $nums$ are distinct

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Direct Index Mapping | Build new array using index mapping | $O(n)$ | $O(n)$ |
| In-Place Encoding | Encode both old and new values in one array | $O(n)$ | $O(1)$ |

---

## Code: Direct Index Mapping (Simulation)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Build new array using index mapping | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int[] buildArray(int[] nums) {
        int[] ans = new int[nums.length];
        for (int i = 0; i < nums.length; ++i) {
            ans[i] = nums[nums[i]];
        }
        return ans;
    }
}
```

---

## Code: In-Place Encoding

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Encode both old and new values in one array | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int[] buildArray(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            nums[i] = nums[i] + n * (nums[nums[i]] % n);
        }
        for (int i = 0; i < n; i++) {
            nums[i] = nums[i] / n;
        }
        return nums;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Direct Index Mapping | $O(n)$ | $O(n)$ | Simple, clear |
| In-Place Encoding | $O(n)$ | $O(1)$ | Space efficient, clever |

---

## Summary
- In-place encoding is optimal for space.
- Direct index mapping is simple and clear.
