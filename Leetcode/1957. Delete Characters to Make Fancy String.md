# 1957. Delete Characters to Make Fancy String

## Problem Statement

A fancy string is a string where no three consecutive characters are equal.

Given a string $s$, delete the minimum possible number of characters from $s$ to make it fancy.

Return the final string after the deletion. It can be shown that the answer will always be unique.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| s = "leeetcode" | "leetcode" | Remove an 'e' from the first group of 'e's |
| s = "aaabaaaa" | "aabaa" | Remove an 'a' from the first group, then two 'a's from the second group |
| s = "aab" | "aab" | No three consecutive characters are equal |

---

## Constraints

- $1 \leq s.length \leq 10^5$
- $s$ consists only of lowercase English letters.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Run-Length Encoding | Greedy truncation of consecutive characters | $O(n)$ | $O(n)$ |
| Single-Pass Greedy | Track frequency and skip extra characters | $O(n)$ | $O(n)$ |

---

## Code: Run-Length Encoding (RLE) with Greedy Truncation

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Greedy truncation of consecutive characters | $O(n)$ | $O(n)$ |

```cpp
class Solution {
public:
    string makeFancyString(string s) {
        string ans;
        for (int i=0, j=0; i<s.size(); i=j) {
            for (j=i; j<s.size() && s[j]==s[i]; ++j);
            ans += string(min(2, j-i), s[i]);
        }
        return ans;
    }
};
```

---

## Code: Single-Pass Greedy with Frequency Counter

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track frequency and skip extra characters | $O(n)$ | $O(n)$ |

```java
class Solution {
    public String makeFancyString(String s) {
        StringBuilder result= new StringBuilder();
        int count=1;
        result.append(s.charAt(0));
        for(int i=1;i<s.length();i++){
            if(s.charAt(i) == s.charAt(i-1)) {
                count++;
            }
            else{
                count=1;
            }
            if(count<3){
                result.append(s.charAt(i));
            }
        }
        return result.toString();
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| RLE Greedy | $O(n)$ | $O(n)$ | Works for C++ |
| Single-Pass Greedy | $O(n)$ | $O(n)$ | Works for Java, easy to implement |

---

## Summary
- Both approaches efficiently remove extra characters to ensure no three consecutive are equal.
- Single-pass greedy is easy to implement and works well for Java.
