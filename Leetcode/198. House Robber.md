
# 198. House Robber

## Problem Statement

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed, the only constraint stopping you from robbing each of them is that adjacent houses have security systems connected and it will automatically contact the police if two adjacent houses were broken into on the same night.

Given an integer array $\text{nums}$ representing the amount of money of each house, return the maximum amount of money you can rob tonight without alerting the police.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,2,3,1] | 4 | Rob house 1 (1) and house 3 (3): 1+3=4 |
| nums = [2,7,9,3,1] | 12 | Rob house 1 (2), house 3 (9), house 5 (1): 2+9+1=12 |

---

## Constraints

- $1 \leq \text{nums.length} \leq 100$
- $0 \leq \text{nums}[i] \leq 400$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Recursion, try all options | $O(2^n)$ | $O(n)$ |
| Memoization | Top-down DP | $O(n)$ | $O(n)$ |
| DP | Bottom-up DP | $O(n)$ | $O(n)$ or $O(1)$ |

---

## Code: Brute Force - TLE

```java
class Solution {
    public int rob(int[] nums) {
        return rob(nums, 0);
    }
    private int rob(int[] nums, int i) {
        if (i >= nums.length) return 0;
        return Math.max(nums[i] + rob(nums, i + 2), rob(nums, i + 1));
    }
}
```

---

## Code: Recursion + Memoization

```java
class Solution {
    public int rob(int[] nums) {
        int[] dp = new int[nums.length];
        Arrays.fill(dp, -1);
        return robHelper(nums, 0, dp);
    }

    private int robHelper(int[] nums, int i, int[] dp) {
        if (i >= nums.length) return 0;
        if (dp[i] != -1) return dp[i];
        int robCurrent = nums[i] + robHelper(nums, i + 2, dp);
        int skipCurrent = robHelper(nums, i + 1, dp);
        dp[i] = Math.max(robCurrent, skipCurrent);
        return dp[i];
    }
}
```

---

## Code: Memoized Recursion

```java
class Solution {
    private Integer[] f;
    private int[] nums;

    public int rob(int[] nums) {
        this.nums = nums;
        f = new Integer[nums.length];
        return dfs(0);
    }

    private int dfs(int i) {
        if (i >= nums.length) {
            return 0;
        }
        if (f[i] == null) {
            f[i] = Math.max(nums[i] + dfs(i + 2), dfs(i + 1));
        }
        return f[i];
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(2^n)$ | $O(n)$ | TLE for large $n$ |
| Memoization | $O(n)$ | $O(n)$ | Top-down DP |
| DP | $O(n)$ | $O(n)$ or $O(1)$ | Bottom-up, most efficient |

---

## Summary

- Use DP or memoization for efficient solution.
- Brute force is not practical for large $n$.
