# 199. Binary Tree Right Side View

## Problem Statement
Given the root of a binary tree, return the values visible from the right side of the tree, ordered from top to bottom.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `root = [1,2,3,null,5,null,4]` | `[1,3,4]` |
| `root = [1,2,3,4,null,null,null,5]` | `[1,3,4,5]` |
| `root = []` | `[]` |

## Constraints
- The number of nodes in the tree is in the range `[0, 100]`.
- `-100 <= Node.val <= 100`

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| BFS level traversal | Breadth-First Search | `O(n)` | `O(w)` |
| DFS with level overwrite | Depth-First Search | `O(n)` | `O(h)` |

## Code
### Pattern
- BFS
- DFS

### Intuition
The right-side view consists of the rightmost node at each level. A level-order traversal is a natural fit because each level can be processed independently. The last node seen at each level is the visible node from the right.

A DFS solution also works by storing the latest node seen at each depth. When the recursion reaches a node, it overwrites the value for that level, ensuring that the last node visited at that depth is the one that remains.

### Algorithm
1. If the tree is empty, return an empty list.
2. Use a queue for BFS.
3. For each level, process all nodes in that level.
4. Record the last node of the level as the visible value from the right.
5. Return the collected values.

### Code
```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (i == size - 1) {
                    result.add(node.val);
                }
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }

        return result;
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(w)`

## Other Approaches
### DFS with Level Overwrite
#### Pattern
- DFS
- Recursion

#### Intuition
In a depth-first traversal, the last node encountered at a given depth is the one that appears on the right side of that level. By overwriting the stored value for each depth as we traverse, we can build the answer in one pass.

#### Algorithm
1. Start DFS from the root at depth `0`.
2. If the current depth is beyond the size of the result, add a placeholder.
3. Overwrite the value at that depth with the current node’s value.
4. Recurse into the right child first, then the left child.

#### Code
```java
class Solution {
    List<Integer> ans = new ArrayList<>();

    public List<Integer> rightSideView(TreeNode root) {
        dfs(root, 0);
        return ans;
    }

    void dfs(TreeNode node, int level) {
        if (node == null) return;
        if (ans.size() == level) ans.add(0);
        ans.set(level, node.val);
        dfs(node.right, level + 1);
        dfs(node.left, level + 1);
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(h)`

## Approach Comparison
| Approach | Pattern | Time | Space | Pros | Cons |
| --- | --- | --- | --- | --- | --- |
| BFS level traversal | BFS | `O(n)` | `O(w)` | Very intuitive and directly matches levels | Uses queue space |
| DFS with level overwrite | DFS | `O(n)` | `O(h)` | Elegant recursive solution | Slightly less straightforward |

## Key Observations
- The right-side view is determined by the rightmost node at each level.
- A level-order traversal naturally exposes the last node from each level.
- In DFS, visiting the right child first ensures that right-side values are recorded before left-side values.

## Common Mistakes
- Forgetting that the last node of each level is the visible one.
- Traversing left before right in DFS and accidentally overwriting the wrong value.
- Not handling the empty tree case.

## Related Patterns
- BFS
- DFS
- Tree Traversal

## Summary
- The optimal solution uses a breadth-first traversal and records the last node of each level.
- The pattern is tree traversal with level-based processing.
- Time complexity is `O(n)`, and space complexity is `O(w)` for BFS and `O(h)` for DFS.
- Interview takeaway: this is a classic example of using level-order traversal or depth-first overwrite to capture one value per depth.
