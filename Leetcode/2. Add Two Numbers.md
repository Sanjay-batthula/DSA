## 2. Add Two Numbers

## Problem Statement
You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.

## Sample Test Cases
Example 1:
```
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
```
Explanation: 342 + 465 = 807.  

Example 2:
```
Input: l1 = [0], l2 = [0]
Output: [0]
```
Example 3:
```
Input: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Output: [8,9,9,9,0,0,0,1]
```


## Brute Force Approach

| Section              | Details                                                              |
| -------------------- | -------------------------------------------------------------------- |
| **Intuition**        | Add digits one-by-one while carrying overflow.                       |
| **Approach**         | Use a dummy node, iterate both lists, compute sum + carry each step. |
| **Time Complexity**  | `O(max(n,m))`                                                        |
| **Space Complexity** | `O(max(n,m))`                                                        |

```
public class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int x = (l1 != null) ? l1.val : 0;
            int y = (l2 != null) ? l2.val : 0;
            int sum = x + y + carry;

            carry = sum / 10;
            curr.next = new ListNode(sum % 10);
            curr = curr.next;

            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }

        return dummy.next;
    }
}
```




## recursive approach

| Section              | Details                                                                     |
| -------------------- | --------------------------------------------------------------------------- |
| **Intuition**        | Solve one digit at a time through recursion, carrying overflow forward.     |
| **Approach**         | Recursively add digits and propagate carry. Base case: no nodes & no carry. |
| **Time Complexity**  | `O(max(n,m))`                                                               |
| **Space Complexity** | `O(max(n,m))` (recursion stack)                                             |

```
public class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        return calculate(l1, l2, 0); 
    }
        ListNode calculate(ListNode l1, ListNode l2, int carry)
       {
        if(l1==null&&l2==null&&carry==0) return null; 
        if(l1==null&&l2==null&&carry!=0) return new ListNode(1); 
	int temp=(l1==null? 0: l1.val)+ (l2==null? 0: l2.val)+ carry; 
	ListNode result=new ListNode(temp%10); 
	result.next=calculate(l1==null? null: l1.next, l2==null? null: l2.next, temp/10); 
        return result;
	 }
}
```


## Iterative with Dummy Head (Optimized Version)

| Section              | Details                                                               |
| -------------------- | --------------------------------------------------------------------- |
| **Intuition**        | A clean iterative solution using a dummy node to simplify edge cases. |
| **Approach**         | Traverse lists, compute digit sum, attach new node, maintain carry.   |
| **Time Complexity**  | `O(max(n,m))`                                                         |
| **Space Complexity** | `O(max(n,m))`                                                         |

```
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode head = new ListNode(0);
        ListNode current = head;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) { sum += l1.val; l1 = l1.next; }
            if (l2 != null) { sum += l2.val; l2 = l2.next; }
            carry = sum / 10;
            current.next = new ListNode(sum % 10);
            current = current.next;
        }
        return head.next;
    }
}
```

## Stack-Based Approach - Wrong Answer
| Section              | Details                                                                                       |
| -------------------- | --------------------------------------------------------------------------------------------- |
| **Intuition**        | Reverse order using stacks to simulate normal addition.                                       |
| **Approach**         | Push digits onto stacks, pop & add. But order mismatch makes this incorrect for this problem. |
| **Reason It's Wrong** | The input lists already store digits in reverse (least-significant first). Using stacks reverses them and treats digits as if they were stored most-significant-first, causing digit misalignment and incorrect sums. Also adds unnecessary O(n) extra space. |
| **Time Complexity**  | `O(n + m)`                                                                                    |
| **Space Complexity** | `O(n + m)`                                                                                    |

```
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        Stack<Integer> s1 = new Stack<>();
        Stack<Integer> s2 = new Stack<>();
        while (l1 != null) { s1.push(l1.val); l1 = l1.next; }
        while (l2 != null) { s2.push(l2.val); l2 = l2.next; }
        int carry = 0;
        ListNode result = null;
        while (!s1.isEmpty() || !s2.isEmpty() || carry != 0) {
            int sum = carry;
            if (!s1.isEmpty()) sum += s1.pop();
            if (!s2.isEmpty()) sum += s2.pop();
            ListNode node = new ListNode(sum % 10);
            node.next = result;
            result = node;
            carry = sum / 10;
        }
        return result;
    }
}
```

## Reverse-List Approach
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Reverse lists to make addition like normal arithmetic.       |
| **Approach**         | Reverse both lists, add digits head-first, then form result. |
| **Time Complexity**  | `O(n + m)`                                                   |
| **Space Complexity** | `O(n + m)`                                                   |

```
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        l1 = reverse(l1);
        l2 = reverse(l2);
        ListNode res = null;
        int carry = 0;
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) { sum += l1.val; l1 = l1.next; }
            if (l2 != null) { sum += l2.val; l2 = l2.next; }
            ListNode node = new ListNode(sum % 10);
            node.next = res;
            res = node;
            carry = sum / 10;
        }
        return res;
    }
}
```

## Digit-by-Digit Linked Addition
| Section              | Details                                                    |
| -------------------- | ---------------------------------------------------------- |
| **Intuition**        | Identical to brute force but builds tail pointer manually. |
| **Approach**         | Maintain head/tail pointers while adding digits.           |
| **Time Complexity**  | `O(max(n,m))`                                              |
| **Space Complexity** | `O(max(n,m))`                                              |

```
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        int carry = 0;
        ListNode head = null, tail = null;
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            if (l1 != null) { sum += l1.val; l1 = l1.next; }
            if (l2 != null) { sum += l2.val; l2 = l2.next; }
            ListNode node = new ListNode(sum % 10);
            carry = sum / 10;
            if (head == null) head = tail = node;
            else { tail.next = node; tail = node; }
        }
        return head;
    }
}
```

## Approach Comparision
| Approach                  | Time Complexity | Space Complexity | Notes                              |
| ------------------------- | --------------- | ---------------- | ---------------------------------- |
| Brute Force               | O(max(n,m))     | O(max(n,m))      | Classic and reliable               |
| Recursive                 | O(max(n,m))     | O(max(n,m))      | Clean but uses stack               |
| Iterative Dummy Optimized | O(max(n,m))     | O(max(n,m))      | Cleanest and safest choice         |
| Stack-Based               | O(n+m)          | O(n+m)           | Incorrect due to reversed order    |
| Reverse-List              | O(n+m)          | O(n+m)           | Works but mutates input lists      |
| Digit-by-Digit            | O(max(n,m))     | O(max(n,m))      | Same as brute but slightly cleaner |


## Summary
- Best Approach: Iterative with Dummy Head.
- Doesn't mutate input, no recursion overhead, cleanest logic.
- Minimal chances of edge-case bugs.
