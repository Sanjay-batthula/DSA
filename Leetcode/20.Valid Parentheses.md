
# 20. Valid Parentheses

## Problem Description
Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:
- Open brackets must be closed by the same type of brackets.
- Open brackets must be closed in the correct order.
- Every close bracket has a corresponding open bracket of the same type.

## Sample Test Cases
Example 1:  
Input: s = "()"  
Output: true

Example 2:  
Input: s = "()[]{}"  
Output: true

Example 3:  
Input: s = "(]"  
Output: false

Example 4:  
Input: s = "([])"  
Output: true

Example 5:  
Input: s = "([)]"  
Output: false

**Constraints:**
- 1 <= s.length <= 10⁴
- s consists of parentheses only '()[]{}'

---

## Brute Force
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Remove pairs until none left                    |
| **Approach**         | Repeatedly replace pairs with empty string      |
| **Time Complexity**  | `O(n²)`                                         |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        while (s.contains("()") || s.contains("{}") || s.contains("[]")) {
            s = s.replace("()", "").replace("{}", "").replace("[]", "");
        }
        return s.isEmpty();
    }
}
```

## Stack-based Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use stack to match open/close brackets          |
| **Approach**         | Push open, pop and check for close              |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        char[] arr = new char[s.length()];
        int top = -1;
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                arr[++top] = c;
            } else {
                if (top == -1) return false;
                if (c == ')' && arr[top] != '(') return false;
                if (c == ']' && arr[top] != '[') return false;
                if (c == '}' && arr[top] != '{') return false;
                top--;
            }
        }
        return top == -1;
    }
}
```

## Deque Stack Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use Deque for stack operations                  |
| **Approach**         | Push open, pop and match for close              |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stk = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '{' || c == '[') {
                stk.push(c);
            } else if (stk.isEmpty() || !match(stk.pop(), c)) {
                return false;
            }
        }
        return stk.isEmpty();
    }
    private boolean match(char l, char r) {
        return (l == '(' && r == ')') || (l == '{' && r == '}') || (l == '[' && r == ']');
    }
}
```

## Expected Bracket Stack Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Push expected closing bracket                   |
| **Approach**         | Push expected, pop and check actual             |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        for (char c : s.toCharArray()) {
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            else {
                if (stack.isEmpty() || stack.pop() != c) return false;
            }
        }
        return stack.isEmpty();
    }
}
```

## Recursive Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Recursively remove valid pairs                  |
| **Approach**         | Replace pairs, recurse until no change          |
| **Time Complexity**  | `O(n²)`                                         |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        if (s.isEmpty()) return true;
        String replaced = s.replace("()", "").replace("{}", "").replace("[]", "");
        if (replaced.equals(s)) return false;
        return isValid(replaced);
    }
}
```

## HashMap for Pair Mapping
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use map for bracket pairs                       |
| **Approach**         | Map close to open, check stack                  |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        Map<Character, Character> map = Map.of(')', '(', '}', '{', ']', '[');
        Stack<Character> stack = new Stack<>();
        for (char c : s.toCharArray()) {
            if (map.containsValue(c)) stack.push(c);
            else if (stack.isEmpty() || stack.pop() != map.get(c)) return false;
        }
        return stack.isEmpty();
    }
}
```

## StringBuilder Stack Simulation
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use StringBuilder as stack                      |
| **Approach**         | Append or remove last char for each bracket     |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public boolean isValid(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            int len = sb.length();
            if (c == ')' && len > 0 && sb.charAt(len - 1) == '(') sb.deleteCharAt(len - 1);
            else if (c == '}' && len > 0 && sb.charAt(len - 1) == '{') sb.deleteCharAt(len - 1);
            else if (c == ']' && len > 0 && sb.charAt(len - 1) == '[') sb.deleteCharAt(len - 1);
            else sb.append(c);
        }
        return sb.length() == 0;
    }
}
```

## Approach Comparison
| Approach                | Time      | Space   | Status    | Notes                |
| ----------------------- | --------- | ------- | --------- | -------------------- |
| Brute Force             | `O(n²)`   | `O(n)`  | ❌         | Inefficient          |
| Stack-based             | `O(n)`    | `O(n)`  | ✅ Optimal | Standard, efficient  |
| Deque Stack             | `O(n)`    | `O(n)`  | ✅         | Same as stack        |
| Expected Bracket Stack  | `O(n)`    | `O(n)`  | ✅         | Push expected close  |
| Recursive               | `O(n²)`   | `O(n)`  | ❌         | Not recommended      |
| HashMap Pair Mapping    | `O(n)`    | `O(n)`  | ✅         | Clean, flexible      |
| StringBuilder Stack     | `O(n)`    | `O(n)`  | ✅         | Unusual, works       |

## Summary

- Stack-based approaches are optimal and standard
- Brute force and recursion are inefficient for large n
- Key insight: use stack to match open/close brackets
