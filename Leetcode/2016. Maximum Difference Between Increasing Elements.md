# 2016. Maximum Difference Between Increasing Elements


## Brute Force
```
class Solution {
    public int maximumDifference(int[] nums) {
        int ans = -1;
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] < nums[j]) {
                    ans = Math.max(ans, nums[j] - nums[i]);
                }
            }
        }
        return ans;
    }
}
```


## Single-pass greedy with prefix minimum tracking
```
class Solution {
    public int maximumDifference(int[] nums) {
        int mi = 1 << 30;
        int ans = -1;
        for (int x : nums) {
            if (x > mi) {
                ans = Math.max(ans, x - mi);
            } else {
                mi = x;
            }
        }
        return ans;
    }
}
```

## Stack Approach (Monotonic Decreasing Stack)- Wrong Answer
```
class Solution {
    public int maximumDifference(int[] nums) {
        Stack<Integer> stack = new Stack<>();
        int diff = -1;
        for (int x : nums) {
            if (stack.isEmpty() || x < stack.peek()) {
                stack.push(x);
            } else {
                diff = Math.max(diff, x - stack.peek());
            }
        }
        return diff;
    }
}
```
