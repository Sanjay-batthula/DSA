# 2016. Maximum Difference Between Increasing Elements

## Problem Statement

Given a 0-indexed integer array $nums$ of size $n$, find the maximum difference between $nums[i]$ and $nums[j]$ (i.e., $nums[j] - nums[i]$), such that $0 \leq i < j < n$ and $nums[i] < nums[j]$.

Return the maximum difference. If no such $i$ and $j$ exists, return $-1$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [7,1,5,4] | 4 | $i=1$, $j=2$, $5-1=4$ |
| nums = [9,4,3,2] | -1 | No $i,j$ with $i<j$ and $nums[i]<nums[j]$ |
| nums = [1,5,2,10] | 9 | $i=0$, $j=3$, $10-1=9$ |

---

## Constraints

- $n = nums.length$
- $2 \leq n \leq 1000$
- $1 \leq nums[i] \leq 10^9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Check all pairs $(i, j)$ | $O(n^2)$ | $O(1)$ |
| Single-pass Greedy | Track prefix minimum | $O(n)$ | $O(1)$ |
| Stack (Monotonic) | Use stack to track minimums | $O(n)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check all pairs $(i, j)$ | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int maximumDifference(int[] nums) {
        int ans = -1;
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] < nums[j]) {
                    ans = Math.max(ans, nums[j] - nums[i]);
                }
            }
        }
        return ans;
    }
}
```

---

## Code: Single-pass Greedy with Prefix Minimum Tracking

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track prefix minimum | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int maximumDifference(int[] nums) {
        int mi = 1 << 30;
        int ans = -1;
        for (int x : nums) {
            if (x > mi) {
                ans = Math.max(ans, x - mi);
            } else {
                mi = x;
            }
        }
        return ans;
    }
}
```

## Code: Stack Approach (Monotonic Decreasing Stack) - Wrong Answer

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use stack to track minimums | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int maximumDifference(int[] nums) {
        Stack<Integer> stack = new Stack<>();
        int diff = -1;
        for (int x : nums) {
            if (stack.isEmpty() || x < stack.peek()) {
                stack.push(x);
            } else {
                diff = Math.max(diff, x - stack.peek());
            }
        }
        return diff;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, slow for large $n$ |
| Single-pass Greedy | $O(n)$ | $O(1)$ | Optimal, recommended |
| Stack | $O(n)$ | $O(n)$ | Incorrect for this problem |

---

## Summary
- Single-pass greedy is optimal and correct.
- Brute force is simple but inefficient.
- Stack approach does not always work for this problem.
