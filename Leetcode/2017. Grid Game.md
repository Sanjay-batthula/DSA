# 2017. Grid Game

## Prefix Sum + Suffix Sum Optimization
```
class Solution {
    public long gridGame(int[][] grid) {
        long ans = Long.MAX_VALUE;
        long s1 = 0, s2 = 0;
        for (int v : grid[0]) {
            s1 += v;
        }
        int n = grid[0].length;
        for (int j = 0; j < n; ++j) {
            s1 -= grid[0][j];
            ans = Math.min(ans, Math.max(s1, s2));
            s2 += grid[1][j];
        }
        return ans;
    }
}
```

## Prefix Sum + Split Point Enumeration
```
class Solution {
    public long gridGame(int[][] grid) {
        int n = grid[0].length;
        long[] prefixTop = new long[n];
        long[] prefixBottom = new long[n];
        prefixTop[0] = grid[0][0];
        prefixBottom[0] = grid[1][0];
        for (int i = 1; i < n; i++) {
            prefixTop[i] = prefixTop[i - 1] + grid[0][i];
            prefixBottom[i] = prefixBottom[i - 1] + grid[1][i];
        }
        long totalTop = prefixTop[n - 1];
        long ans = Long.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            long topRemain = totalTop - prefixTop[i];
            long bottomRemain = i == 0 ? 0 : prefixBottom[i - 1];
            ans = Math.min(ans, Math.max(topRemain, bottomRemain));
        }
        return ans;
    }
}
```
