
# 206. Reverse Linked List

## Problem Statement

Given the head of a singly linked list, reverse the list, and return the reversed list.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| head = [1,2,3,4,5] | [5,4,3,2,1] | Reverse the list |
| head = [1,2] | [2,1] | Reverse the list |
| head = [] | [] | Empty list |

---

## Constraints

- The number of nodes in the list is the range $[0, 5000]$
- $-5000 \leq \text{Node.val} \leq 5000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Copy values, rebuild list | $O(n)$ | $O(n)$ |
| Recursion | Reverse pointers recursively | $O(n)$ | $O(n)$ |
| Iterative | Reverse pointers in-place | $O(n)$ | $O(1)$ |

---

## Code: Brute Force Version

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null) return null;
        List<Integer> vals = new ArrayList<>();
        ListNode curr = head;
        while (curr != null) {
            vals.add(curr.val);
            curr = curr.next;
        }
        ListNode dummy = new ListNode();
        curr = dummy;
        for (int i = vals.size() - 1; i >= 0; i--) {
            curr.next = new ListNode(vals.get(i));
            curr = curr.next;
        }
        return dummy.next;
    }
}
```

---

## Code: Recursive Method

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
```

---

## Code: Iterative Method

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode dummy = new ListNode();
        ListNode curr = head;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = dummy.next;
            dummy.next = curr;
            curr = next;
        }
        return dummy.next;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(n)$ | Copies values, rebuilds list |
| Recursion | $O(n)$ | $O(n)$ | Elegant, uses stack |
| Iterative | $O(n)$ | $O(1)$ | In-place, most efficient |

---

## Summary

- Iterative approach is most efficient and in-place.
- Recursion is elegant but uses extra stack space.
- Brute force copies values and rebuilds the list.
