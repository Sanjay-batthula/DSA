# 208. Implement Trie (Prefix Tree)

## Problem Statement
Implement a trie that supports insertion, exact word lookup, and prefix lookup. A trie stores strings by sharing common prefixes efficiently.

## Sample Test Cases
| Operation | Result |
| --- | --- |
| `insert("apple")` | `null` |
| `search("apple")` | `true` |
| `search("app")` | `false` |
| `startsWith("app")` | `true` |
| `insert("app")` | `null` |
| `search("app")` | `true` |

## Constraints
- `1 <= word.length, prefix.length <= 2000`
- Words and prefixes contain only lowercase English letters.
- At most `3 * 10^4` operations are performed.

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Array-based trie | Trie / Prefix Tree | `O(L)` | `O(total characters)` |
| HashMap-based trie | Trie / Prefix Tree | `O(L)` | `O(total characters)` |

## Code
### Pattern
- Trie
- Prefix Tree

### Intuition
A trie is a tree where each edge represents a character. All words sharing a prefix follow the same path, which makes insertion and prefix-based lookup efficient. The root represents the empty prefix, and each node may mark whether it ends a complete word.

The array-based version is faster and simpler when the alphabet is fixed and small. The HashMap-based version is more flexible and easier to generalize when the character set is larger or sparse.

### Algorithm
1. Create a root node.
2. For `insert(word)`, traverse each character and create missing child nodes.
3. Mark the final node as the end of a word.
4. For `search(word)`, traverse the word and confirm the final node is marked as an end node.
5. For `startsWith(prefix)`, traverse the prefix and confirm the path exists.

### Code
```java
class Trie {
    private Trie[] children;
    private boolean isEnd;

    public Trie() {
        children = new Trie[26];
    }

    public void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new Trie();
            }
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        Trie node = searchPrefix(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        Trie node = searchPrefix(prefix);
        return node != null;
    }

    private Trie searchPrefix(String s) {
        Trie node = this;
        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                return null;
            }
            node = node.children[idx];
        }
        return node;
    }
}
```

### Complexity
- Time Complexity: `O(L)` for each operation, where $L$ is the length of the word or prefix.
- Space Complexity: `O(total characters stored)`

## Other Approaches
### HashMap-Based Trie
#### Pattern
- Trie
- Prefix Tree

#### Intuition
A HashMap-based trie stores children in a dictionary rather than a fixed-size array. This avoids wasting space when the alphabet is sparse or when the input may contain more than 26 lowercase characters.

#### Algorithm
1. Use a node with a `Map<Character, Node>` for children.
2. Insert characters by creating missing nodes as needed.
3. Mark word-ending nodes with `isEnd`.
4. Search and prefix checks follow the same traversal pattern.

#### Code
```java
import java.util.*;

class Trie {
    class Node {
        Map<Character, Node> children = new HashMap<>();
        boolean isEnd;
    }

    Node root;

    public Trie() {
        root = new Node();
    }

    public void insert(String word) {
        Node node = root;
        for (char c : word.toCharArray()) {
            node.children.putIfAbsent(c, new Node());
            node = node.children.get(c);
        }
        node.isEnd = true;
    }

    public boolean search(String word) {
        Node node = traverse(word);
        return node != null && node.isEnd;
    }

    public boolean startsWith(String prefix) {
        return traverse(prefix) != null;
    }

    private Node traverse(String s) {
        Node node = root;
        for (char c : s.toCharArray()) {
            if (!node.children.containsKey(c)) return null;
            node = node.children.get(c);
        }
        return node;
    }
}
```

#### Complexity
- Time Complexity: `O(L)`
- Space Complexity: `O(total characters stored)`

## Key Observations
- Prefix lookups are efficient because shared prefixes reuse the same nodes.
- `search` and `startsWith` differ only in whether the final node must be marked as an end-of-word.
- The root node is the empty prefix.

## Common Mistakes
- Forgetting to mark the final node as the end of a word.
- Confusing `search` with `startsWith`.
- Not handling missing child nodes correctly.
