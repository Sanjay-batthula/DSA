# 2094. Finding 3-Digit Even Numbers

## Problem Statement

You are given an integer array $digits$, where each element is a digit. The array may contain duplicates.

You need to find all the unique integers that follow the given requirements:
- The integer consists of the concatenation of three elements from $digits$ in any arbitrary order.
- The integer does not have leading zeros.
- The integer is even.

Return a sorted array of the unique integers.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| digits = [2,1,3,0] | [102,120,130,132,210,230,302,310,312,320] | All possible valid integers |
| digits = [2,2,8,8,2] | [222,228,282,288,822,828,882] | Digits can be reused as many times as they appear |
| digits = [3,7,5] | [] | No even integers can be formed |

---

## Constraints

- $3 \leq digits.length \leq 100$
- $0 \leq digits[i] \leq 9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Permute all possible 3-digit numbers | $O(n^3)$ | $O(1)$ |
| Frequency Counting | Enumerate all 3-digit even numbers and check digit counts | $O(900)$ | $O(1)$ |

---

## Code: Brute Force Permutation with Index Tracking

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Permute all possible 3-digit numbers | $O(n^3)$ | $O(1)$ |

```java
class Solution {
    public int[] findEvenNumbers(int[] digits) {
        boolean[] used = new boolean[1000];
        int count = 0;
        for (int a = 0; a < digits.length; a++) {
            if (digits[a] == 0) continue;
            for (int b = 0; b < digits.length; b++) {
                if (b == a) continue;
                for (int c = 0; c < digits.length; c++) {
                    if (c == a || c == b) continue;
                    if ((digits[c] & 1) != 0) continue;

                    int value = digits[a] * 100 + digits[b] * 10 + digits[c];
                    if (!used[value]) {
                        used[value] = true;
                        count++;
                    }
                }
            }
        }
        int[] res = new int[count];
        int idx = 0;

        for (int i = 100; i < 1000; i++) {
            if (used[i]) res[idx++] = i;
        }
        return res;
    }
}
```

## Code: Digit Frequency Counting + Enumeration

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Enumerate all 3-digit even numbers and check digit counts | $O(900)$ | $O(1)$ |

```java
class Solution {
    public int[] findEvenNumbers(int[] digits) {
        int[] cnt = new int[10];
        for (int x : digits) {
            ++cnt[x];
        }
        List<Integer> ans = new ArrayList<>();
        for (int x = 100; x < 1000; x += 2) {
            int[] cnt1 = new int[10];
            for (int y = x; y > 0; y /= 10) {
                ++cnt1[y % 10];
            }
            boolean ok = true;
            for (int i = 0; i < 10 && ok; ++i) {
                ok = cnt[i] >= cnt1[i];
            }
            if (ok) {
                ans.add(x);
            }
        }
        return ans.stream().mapToInt(i -> i).toArray();
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^3)$ | $O(1)$ | Simple, but slow for large $n$ |
| Frequency Counting | $O(900)$ | $O(1)$ | Efficient, recommended |

## Summary
- Frequency counting is efficient and easy to implement.
- Brute force is simple but not optimal for large input.
