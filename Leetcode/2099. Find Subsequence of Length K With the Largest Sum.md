# 2099. Find Subsequence of Length K With the Largest Sum

## Sorting + Threshold Counting (Greedy Selection)
```
class Solution {
    public int[] maxSubsequence(int[] nums, int k) {
    int[] ans = new int[k];
    int[] arr = nums.clone();
    Arrays.sort(arr);
    final int threshold = arr[arr.length - k];
    final int larger = (int) Arrays.stream(nums).filter(num -> num > threshold).count();
    int equal = k - larger;

    int i = 0;
    for (final int num : nums)
      if (num > threshold) {
        ans[i++] = num;
      } else if (num == threshold && equal > 0) {
        ans[i++] = num;
        --equal;
      }

    return ans;
  }
}

## Index Tracking + Sorting by Value
```
class Solution {
    public int[] maxSubsequence(int[] nums, int k) {
        int n = nums.length;
        int[][] arr = new int[n][2];
        for (int i = 0; i < n; i++) {
            arr[i][0] = nums[i];
            arr[i][1] = i;
        }
        java.util.Arrays.sort(arr, (a, b) -> b[0] - a[0]);
        java.util.Set<Integer> idx = new java.util.HashSet<>();
        for (int i = 0; i < k; i++) idx.add(arr[i][1]);
        int[] res = new int[k];
        int p = 0;
        for (int i = 0; i < n; i++) {
            if (idx.contains(i)) res[p++] = nums[i];
        }
        return res;
    }
}
