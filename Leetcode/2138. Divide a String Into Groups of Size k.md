# 2138. Divide a String Into Groups of Size k

## Problem Statement

A string $s$ can be partitioned into groups of size $k$ using the following procedure:
- The first group consists of the first $k$ characters of the string, the second group consists of the next $k$ characters, and so on. Each element can be a part of exactly one group.
- For the last group, if the string does not have $k$ characters remaining, a character $fill$ is used to complete the group.
- After removing the $fill$ character from the last group (if it exists) and concatenating all the groups in order, the resultant string should be $s$.

Given the string $s$, the size of each group $k$ and the character $fill$, return a string array denoting the composition of every group $s$ has been divided into, using the above procedure.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| s = "abcdefghi", k = 3, fill = "x" | ["abc","def","ghi"] | All groups filled by characters from $s$ |
| s = "abcdefghij", k = 3, fill = "x" | ["abc","def","ghi","jxx"] | Last group padded with $fill$ |

---

## Constraints

- $1 \leq s.length \leq 100$
- $s$ consists of lowercase English letters only.
- $1 \leq k \leq 100$
- $fill$ is a lowercase English letter.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Padding First | Pad string then slice into groups | $O(n)$ | $O(n)$ |
| Incremental Chunking | Slice and post-fill last group | $O(n)$ | $O(n)$ |

---

## Code: Padding First + Fixed Window Substring

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Pad string then slice into groups | $O(n)$ | $O(n)$ |

```java
class Solution {
    public String[] divideString(String s, int k, char fill) {
        int n = s.length();
        String[] ans = new String[(n + k - 1) / k];
        if (n % k != 0) {
            s += String.valueOf(fill).repeat(k - n % k);
        }
        for (int i = 0; i < ans.length; ++i) {
            ans[i] = s.substring(i * k, (i + 1) * k);
        }
        return ans;
    }
}
```

---

## Code: Incremental Chunking with Post-fill

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Slice and post-fill last group | $O(n)$ | $O(n)$ |

```java
class Solution {
    public String[] divideString(String s, int k, char fill) {
        int n = s.length();
        int size = (n + k - 1) / k;
        String[] ans = new String[size];
        int idx = 0;
        for (int i = 0; i < n; i += k) {
            int end = Math.min(i + k, n);
            ans[idx++] = s.substring(i, end);
        }
        int lastLen = ans[size - 1].length();
        if (lastLen < k) {
            ans[size - 1] = ans[size - 1] + String.valueOf(fill).repeat(k - lastLen);
        }
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Padding First | $O(n)$ | $O(n)$ | Simple, pad then slice |
| Incremental Chunking | $O(n)$ | $O(n)$ | Slice, then post-fill |

---

## Summary
- Both approaches efficiently partition the string into groups of size $k$.
- Padding first is simple; incremental chunking is flexible.
