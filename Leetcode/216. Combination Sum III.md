# 216. Combination Sum III

## Problem Statement
Find all unique combinations of exactly k numbers from 1 to 9 that add up to n. Each number can be used at most once.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `k = 3, n = 7` | `[[1,2,4]]` |
| `k = 3, n = 9` | `[[1,2,6],[1,3,5],[2,3,4]]` |
| `k = 4, n = 1` | `[]` |

## Constraints
- `2 <= k <= 9`
- `1 <= n <= 60`

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Backtracking with pruning | Backtracking | `O(C(9, k))` | `O(k)` |
| Loop-based backtracking | Backtracking | `O(C(9, k))` | `O(k)` |

## Code
### Pattern
- Backtracking

### Intuition
The problem is a classic combination-generation problem. We choose numbers from 1 to 9, but each choice can only be used once and the total length of the combination must be exactly k. The search space is small because only 9 numbers exist. Backtracking is ideal here because it tries a candidate, recurses, and then removes it before trying the next option.

Pruning is essential. If the current remaining target is less than the next candidate, or if the path already has k numbers, the search can stop early.

### Algorithm
1. Start from number `1`.
2. At each step, try to pick a candidate.
3. Reduce the remaining target by that candidate.
4. Recurse deeper while the path length is less than `k` and the target remains non-negative.
5. If the path length reaches `k` and the target becomes `0`, record the combination.
6. Backtrack by removing the last selected number and trying the next option.

### Code
```java
class Solution {
    private List<List<Integer>> ans = new ArrayList<>();
    private List<Integer> path = new ArrayList<>();
    private int k;

    public List<List<Integer>> combinationSum3(int k, int n) {
        this.k = k;
        dfs(1, n);
        return ans;
    }

    private void dfs(int start, int remaining) {
        if (remaining == 0) {
            if (path.size() == k) {
                ans.add(new ArrayList<>(path));
            }
            return;
        }
        if (start > 9 || start > remaining || path.size() >= k) {
            return;
        }

        path.add(start);
        dfs(start + 1, remaining - start);
        path.remove(path.size() - 1);

        dfs(start + 1, remaining);
    }
}
```

### Complexity
- Time Complexity: `O(C(9, k))`
- Space Complexity: `O(k)`

## Other Approaches
### Loop-Based Backtracking
#### Pattern
- Backtracking

#### Intuition
This version makes the recursive structure more explicit by iterating over possible candidates from a given start position. Each branch explores one candidate and then unwinds.

#### Algorithm
1. Recursively build a path.
2. If the path size reaches `k`, check whether the target is `0`.
3. Otherwise, loop from the current start to 9 and try each candidate.
4. Prune when the candidate is bigger than the remaining target.

#### Code
```java
class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(1, k, n, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int start, int k, int target, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == k) {
            if (target == 0) res.add(new ArrayList<>(path));
            return;
        }

        for (int i = start; i <= 9; i++) {
            if (i > target) break;
            path.add(i);
            backtrack(i + 1, k, target - i, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

#### Complexity
- Time Complexity: `O(C(9, k))`
- Space Complexity: `O(k)`

## Key Observations
- Because numbers are chosen from 1 to 9 and each can be used once, the search space is small.
- Pruning on `start`, `remaining`, and `path.size()` reduces unnecessary branches.
- The combination is unique because numbers only increase and are chosen in a single order.

## Common Mistakes
- Forgetting to stop when the path already has `k` elements.
- Allowing numbers to be reused or choosing in the wrong order.
- Not pruning when the candidate exceeds the remaining target.

## Summary
- The optimal solution uses backtracking to build combinations and prune invalid branches.
- The pattern is backtracking with state exploration.
- Time complexity is `O(C(9, k))`, and space complexity is `O(k)`.
- Interview takeaway: when you need all valid combinations under small constraints, backtracking is usually the right tool.
