# 2176. Count Equal and Divisible Pairs in an Array

## Problem Statement

Given a 0-indexed integer array $nums$ of length $n$ and an integer $k$, return the number of pairs $(i, j)$ where $0 \leq i < j < n$, such that $nums[i] == nums[j]$ and $(i \times j)$ is divisible by $k$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [3,1,2,2,2,1,3], k = 2 | 4 | Four pairs meet all requirements |
| nums = [1,2,3,4], k = 1 | 0 | No repeated values, so no valid pairs |

---

## Constraints

- $1 \leq nums.length \leq 100$
- $1 \leq nums[i], k \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Enumerate all index pairs | $O(n^2)$ | $O(1)$ |
| HashMap + GCD | Group by value and GCD, count valid pairs | $O(n^2)$ | $O(n)$ |

---

## Code: Brute Force Index Pair Enumeration

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Enumerate all index pairs | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int countPairs(int[] nums, int k) {
        int ans = 0;
        for (int j = 1; j < nums.length; ++j) {
            for (int i = 0; i < j; ++i) {
                ans += nums[i] == nums[j] && (i * j % k) == 0 ? 1 : 0;
            }
        }
        return ans;
    }
}
```

---

## Code: Optimized Grouping using HashMap + GCD Logic

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Group by value and GCD, count valid pairs | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public int countPairs(int[] nums, int k) {
        Map<Integer, Map<Integer, Integer>> map = new HashMap<>();
        int res = 0;

        for (int i = 0; i < nums.length; i++) {
            int g = gcd(i, k);
            if (map.containsKey(nums[i])) {
                for (int prevG : map.get(nums[i]).keySet()) {
                    if ((long) prevG * g % k == 0) {
                        res += map.get(nums[i]).get(prevG);
                    }
                }
            }
            map.computeIfAbsent(nums[i], x -> new HashMap<>());
            map.get(nums[i]).put(g, map.get(nums[i]).getOrDefault(g, 0) + 1);
        }
        return res;
    }

    int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, but slow for large $n$ |
| HashMap + GCD | $O(n^2)$ | $O(n)$ | More efficient grouping, but same asymptotic complexity |

---

## Summary
- Brute force is simple but not optimal for large input.
- HashMap + GCD approach groups indices and values for more efficient counting.
