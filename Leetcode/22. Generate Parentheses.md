

# 22. Generate Parentheses

## Problem Description
Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

## Sample Test Cases
Example 1:  
Input: n = 3  
Output: ["((()))","(()())","(())()","()(())","()()()"]

Example 2:  
Input: n = 1  
Output: ["()"]

**Constraints:**
- 1 <= n <= 8

---

## Brute Force
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Generate all possible strings, filter valid     |
| **Approach**         | Recursively build all 2^(2n) strings, check    |
| **Time Complexity**  | `O(2^{2n} * n)`                                 |
| **Space Complexity** | `O(2^{2n} * n)`                                 |

```java
class Solution {
    private List<String> ans = new ArrayList<>();
    private int n;
    public List<String> generateParenthesis(int n) {
        this.n = n;
        char[] arr = new char[2 * n];
        generateAll(arr, 0);
        return ans;
    }
    private void generateAll(char[] arr, int pos) {
        if (pos == arr.length) {
            if (isValid(arr)) {
                ans.add(new String(arr));
            }
            return;
        }
        arr[pos] = '(';
        generateAll(arr, pos + 1);
        arr[pos] = ')';
        generateAll(arr, pos + 1);
    }
    private boolean isValid(char[] arr) {
        int balance = 0;
        for (char c : arr) {
            if (c == '(') balance++;
            else balance--;
            if (balance < 0) return false;
        }
        return balance == 0;
    }
}
```

## Dynamic Programming (DP) Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use DP to build from smaller subproblems        |
| **Approach**         | dp[i] = all combinations for i pairs            |
| **Time Complexity**  | Catalan number: `O(4^n / n^{1.5})`              |
| **Space Complexity** | `O(4^n / n^{1.5})`                              |

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<List<String>> dp = new ArrayList<>();
        dp.add(Arrays.asList(""));
        for (int i = 1; i <= n; i++) {
            List<String> current = new ArrayList<>();
            for (int j = 0; j < i; j++) {
                for (String left : dp.get(j)) {
                    for (String right : dp.get(i - 1 - j)) {
                        current.add("(" + left + ")" + right);
                    }
                }
            }
            dp.add(current);
        }
        return dp.get(n);
    }
}
```

## DFS + Backtracking Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Build only valid strings using DFS              |
| **Approach**         | Recursively add '(' or ')', track counts        |
| **Time Complexity**  | Catalan number: `O(4^n / n^{1.5})`              |
| **Space Complexity** | `O(4^n / n^{1.5})`                              |

```java
class Solution {
    private List<String> ans = new ArrayList<>();
    private int n;
    public List<String> generateParenthesis(int n) {
        this.n = n;
        dfs(0, 0, "");
        return ans;
    }
    private void dfs(int l, int r, String t) {
        if (l > n || r > n || l < r) {
            return;
        }
        if (l == n && r == n) {
            ans.add(t);
            return;
        }
        dfs(l + 1, r, t + "(");
        dfs(l, r + 1, t + ")");
    }
}
```

## Approach Comparison
| Approach         | Time         | Space   | Status    | Notes                |
| ---------------- | ------------ | ------- | --------- | -------------------- |
| Brute Force      | `O(2^{2n})`  | `O(2^{2n})` | ❌         | Generates invalid    |
| DP               | Catalan      | Catalan  | ✅         | Elegant, subproblems |
| DFS/Backtracking | Catalan      | Catalan  | ✅ Optimal | Most common, fast    |

## Summary

- DFS/backtracking is the most practical and common approach
- DP is elegant and builds from subproblems
- Brute force is not efficient for large n
- Key insight: only add '(' if l < n, only add ')' if r < l
