# 2206. Divide Array Into Equal Pairs

## Frequency Counting (Parity Check) using Counting Array
```
class Solution {
    public boolean divideArray(int[] nums) {
        int[] cnt = new int[510];
        for (int v : nums) {
            ++cnt[v];
        }
        for (int v : cnt) {
            if (v % 2 != 0) {
                return false;
            }
        }
        return true;
    }
}
```

## Frequency Counting using HashMap (Parity Check)
```
class Solution {
    public boolean divideArray(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        for (int value : nums) {
            freq.put(value, freq.getOrDefault(value, 0) + 1);
        }

        for (int occurrences : freq.values()) {
            if (occurrences % 2 != 0) {
                return false;
            }
        }
        return true;
    }
}
```
