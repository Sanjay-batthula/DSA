# 2210. Count Hills and Valleys in an Array

## single-pass state-tracking greedy approach
```
class Solution {
    public int countHillValley(int[] nums) {
        int count=0;
        for (int currentIndex=1, previousIndex=0; currentIndex<nums.length-1; ++currentIndex) {
            if (nums[currentIndex]==nums[currentIndex+1]) {
                continue;
            }
            if (nums[currentIndex]>nums[previousIndex] && nums[currentIndex]>nums[currentIndex+1]) {
                count++;
            }
            if (nums[currentIndex]<nums[previousIndex] && nums[currentIndex]<nums[currentIndex+1]) {
                count++;
            }
            previousIndex=currentIndex;
        }
        return count;
    }
}
```

## Greedy single-pass local extrema detection with duplicate compression
```
class Solution {
    public int countHillValley(int[] nums) {
        int count = 0;
        int prev = nums[0];
        for (int i = 1; i < nums.length - 1; i++) {
            if (nums[i] == prev) continue;
            int next = nums[i + 1];
            while (i + 1 < nums.length && next == nums[i]) {
                i++;
                if (i + 1 < nums.length) next = nums[i + 1];
            }
            if ((nums[i] > prev && nums[i] > next) ||
                (nums[i] < prev && nums[i] < next)) {
                count++;
            }
            prev = nums[i];
        }
        return count;
    }
}
```
