# 2226. Maximum Candies Allocated to K Children

## Binary Search on the Maximum Feasible Value
```
class Solution {
    public int maximumCandies(int[] candies, long k) {
        int left = 1, right = (int)1e7, res = 0;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            long count = 0;
            for (int c : candies) {
                count += c / mid;
            }
            if (count >= k) {
                res = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return res;
    }
}
```
