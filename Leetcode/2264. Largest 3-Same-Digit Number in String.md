# 2264. Largest 3-Same-Digit Number in String

## Problem Statement

You are given a string $num$ representing a large integer. An integer is good if it meets the following conditions:
- It is a substring of $num$ with length 3.
- It consists of only one unique digit.

Return the maximum good integer as a string or an empty string "" if no such integer exists.

Note:
- A substring is a contiguous sequence of characters within a string.
- There may be leading zeroes in $num$ or a good integer.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| num = "6777133339" | "777" | Two good integers: "777" and "333"; "777" is largest |
| num = "2300019" | "000" | "000" is the only good integer |
| num = "42352338" | "" | No substring of length 3 with one unique digit |

---

## Constraints

- $3 \leq num.length \leq 1000$
- $num$ only consists of digits.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Greedy Enumeration | Check for each digit from 9 to 0 | $O(n)$ | $O(1)$ |
| Sliding Window | Check all substrings of length 3 | $O(n)$ | $O(1)$ |

---

## Code: Greedy Digit Enumeration with Pattern Matching

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check for each digit from 9 to 0 | $O(n)$ | $O(1)$ |

```java
class Solution {
    public String largestGoodInteger(String num) {
        for (int i = 9; i >= 0; i--) {
            String check = String.valueOf(i).repeat(3);
            if (num.contains(check)) {
                return check;
            }
        }
        return "";
    }
}
```

---

## Code: Sliding Window with Lexicographical Comparison

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check all substrings of length 3 | $O(n)$ | $O(1)$ |

```java
class Solution {
    public String largestGoodInteger(String num) {
        String max = "";
        for (int i = 0; i <= num.length() - 3; i++) {
            String sub = num.substring(i, i + 3);
            if (sub.charAt(0) == sub.charAt(1) && sub.charAt(1) == sub.charAt(2)) {
                if (max.isEmpty() || sub.compareTo(max) > 0) {
                    max = sub;
                }
            }
        }
        return max;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Greedy Enumeration | $O(n)$ | $O(1)$ | Simple, checks from largest digit |
| Sliding Window | $O(n)$ | $O(1)$ | Checks all substrings, finds max |

---

## Summary
- Both approaches efficiently find the largest good integer.
- Greedy enumeration is simple and optimal for this problem.
