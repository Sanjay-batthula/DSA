# 2273. Find Resultant Array After Removing Anagrams

## Problem Statement

You are given a 0-indexed string array $words$, where $words[i]$ consists of lowercase English letters.

In one operation, select any index $i$ such that $0 < i < words.length$ and $words[i - 1]$ and $words[i]$ are anagrams, and delete $words[i]$ from $words$. Keep performing this operation as long as you can select an index that satisfies the conditions.

Return $words$ after performing all operations. Selecting indices for each operation in any arbitrary order will lead to the same result.

An Anagram is a word or phrase formed by rearranging the letters of a different word or phrase using all the original letters exactly once.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| words = ["abba","baba","bbaa","cd","cd"] | ["abba","cd"] | Remove adjacent anagrams |
| words = ["a","b","c","d","e"] | ["a","b","c","d","e"] | No adjacent anagrams |

---

## Constraints

- $1 \leq words.length \leq 100$
- $1 \leq words[i].length \leq 10$
- $words[i]$ consists of lowercase English letters.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Sort and compare adjacent words | $O(n \cdot m \log m)$ | $O(m)$ |
| Single Pass Optimized | Sort and cache previous sorted word | $O(n \cdot m \log m)$ | $O(m)$ |
| Frequency Count | Use character count as signature | $O(n \cdot m)$ | $O(m)$ |
| HashMap Signature Cache | Cache sorted signature for each word | $O(n \cdot m \log m)$ | $O(n \cdot m)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and compare adjacent words | $O(n \cdot m \log m)$ | $O(m)$ |

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> res = new ArrayList<>();
        res.add(words[0]);
        for (int i = 1; i < words.length; i++) {
            char[] a = words[i].toCharArray();
            char[] b = words[i - 1].toCharArray();
            Arrays.sort(a);
            Arrays.sort(b);
            if (!Arrays.equals(a, b)) res.add(words[i]);
        }
        return res;
    }
}
```

## Code: Single Pass Optimized Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Sort and cache previous sorted word | $O(n \cdot m \log m)$ | $O(m)$ |

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> res = new ArrayList<>();
        String prevSorted = "";
        for (String w : words) {
            char[] ch = w.toCharArray();
            Arrays.sort(ch);
            String sorted = new String(ch);
            if (!sorted.equals(prevSorted)) {
                res.add(w);
                prevSorted = sorted;
            }
        }
        return res;
    }
}
```

## Code: Frequency Count

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use character count as signature | $O(n \cdot m)$ | $O(m)$ |

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> res = new ArrayList<>();
        String prevKey = "";
        for (String w : words) {
            int[] count = new int[26];
            for (char c : w.toCharArray()) count[c - 'a']++;
            String key = Arrays.toString(count);
            if (!key.equals(prevKey)) {
                res.add(w);
                prevKey = key;
            }
        }
        return res;
    }
}
```

## Code: HashMap / Signature Cache Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Cache sorted signature for each word | $O(n \cdot m \log m)$ | $O(n \cdot m)$ |

```java
class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> res = new ArrayList<>();
        Map<String, String> cache = new HashMap<>();
        String prev = "";
        for (String w : words) {
            char[] ch = w.toCharArray();
            Arrays.sort(ch);
            String key = new String(ch);
            cache.putIfAbsent(w, key);
            if (!cache.get(w).equals(prev)) {
                res.add(w);
                prev = cache.get(w);
            }
        }
        return res;
    }
}
```
