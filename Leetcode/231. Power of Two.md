# 231. Power of Two

## Problem Statement

Given an integer n, return true if it is a power of two. Otherwise, return false.

An integer n is a power of two if there exists an integer x such that n == 2^x.

## Sample Test Cases

Example 1:
```
Input: n = 1
Output: true
```
Explanation: 2^0 = 1

Example 2:
```
Input: n = 16
Output: true
```
Explanation: 2^4 = 16

Example 3:
```
Input: n = 3
Output: false
```

---

## 1️⃣ Brute Force (Division)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Keep dividing by 2; if you reach 1, it's a power of two.                |
| **Approach**         | Divide n by 2 until n becomes 1 or not divisible by 2.                  |
| **Time Complexity**  | O(log n)                                                                |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfTwo(int n) {
        if (n <= 0) return false;
        while (n % 2 == 0) {
            n /= 2;
        }
        return n == 1;
    }
}
```

---

## 2️⃣ Bit Manipulation

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Powers of two have only one bit set in binary.                          |
| **Approach**         | n > 0 and n & (n-1) == 0 checks for single set bit.                     |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfTwo(int n) {
         return n > 0 && (n & (n - 1)) == 0;
    }
}
```

---

## 3️⃣ Logarithm / Math Approach (Not Recommended)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | If log2(n) is an integer, n is a power of two.                          |
| **Approach**         | Take log base 2 and check if result is integer.                         |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |
| **Note**             | Fails for some large values due to floating-point precision.            |

```
class Solution {
    public boolean isPowerOfTwo(int n) {
        if (n <= 0) return false;
        double log = Math.log(n) / Math.log(2);
        return log == (int) log;
    }
}
```

---

## Approach Comparison

| Approach           | Time Complexity | Space Complexity | Notes                                         |
| ------------------ | -------------- | --------------- | --------------------------------------------- |
| Brute Force        | O(log n)       | O(1)            | Simple, works for all valid inputs.           |
| Bit Manipulation   | O(1)           | O(1)            | Fastest and most elegant.                     |
| Logarithm / Math   | O(1)           | O(1)            | Not reliable due to floating-point precision. |

---

## Summary

- Optimal Approach: Bit Manipulation (O(1) time, O(1) space).
- Brute force division is also reliable and easy to understand.
- Avoid the logarithm approach due to precision issues.
