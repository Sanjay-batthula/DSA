# 2348. Number of Zero-Filled Subarrays

## Brute Force / Nested Loop Enumeration
```
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long count = 0;
        for (int i = 0; i < nums.length; i++) {
            boolean allZero = true;
            for (int j = i; j < nums.length; j++) {
                if (nums[j] != 0) {
                    allZero = false;
                }
                if (allZero) {
                    count++;
                } else {
                    break;
                }
            }
        }
        return count;
    }
}
```


## Mathematical Counting / Combinatorial Counting
```
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long ans = 0;
        long zeros = 0;
        for (int num : nums) {
            if (num == 0) {
                zeros++;
            } else {
                ans += (zeros * (zeros + 1)) / 2;
                zeros = 0;
            }
        }
        ans += (zeros * (zeros + 1)) / 2;
        return ans;
    }
}
```


## Sliding Window (Implicit) / Running Streak Counting
```
class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long total = 0;
        int count = 0;
        for (int num : nums) {
            count = (num == 0) ? count + 1 : 0;
            total += count;
        }
        return total;
    }
}
```
