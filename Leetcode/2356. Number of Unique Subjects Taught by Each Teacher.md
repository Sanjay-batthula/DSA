# 2356. Number of Unique Subjects Taught by Each Teacher

## Aggregation with GROUP BY and DISTINCT
```
SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id
ORDER BY NULL;
```

## CTE Deduplication
```
WITH temp AS (
    SELECT DISTINCT teacher_id, subject_id
    FROM Teacher
)

SELECT teacher_id,
       COUNT(*) AS cnt
FROM temp
GROUP BY teacher_id;
```
