# 236. Lowest Common Ancestor of a Binary Tree

## Problem Statement
Given a binary tree and two nodes p and q, find their lowest common ancestor. The LCA is the lowest node that has both p and q in its subtree, where a node can also be considered an ancestor of itself.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1` | `3` |
| `root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4` | `5` |
| `root = [1,2], p = 1, q = 2` | `1` |

## Constraints
- The number of nodes in the tree is in the range `[2, 10^5]`.
- `-10^9 <= Node.val <= 10^9`
- All `Node.val` values are unique.
- `p != q`
- `p` and `q` will exist in the tree.

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Recursive DFS | DFS / Postorder | `O(n)` | `O(h)` |
| Parent-pointer traversal | DFS + HashMap | `O(n)` | `O(n)` |

## Code
### Pattern
- DFS
- Tree Traversal

### Intuition
The key observation is that the LCA of two nodes is the first node where one subtree contains p and the other contains q. A postorder DFS naturally returns information upward: each subtree tells us whether it contains p or q. If both children return a non-null answer, the current node is the LCA. If only one child returns a node, that child’s result is passed upward.

### Algorithm
1. Define a DFS that returns the LCA if found, otherwise `null`.
2. If the current node is `null`, return `null`.
3. If the current node is `p` or `q`, return the current node.
4. Recurse into the left and right children.
5. If both recursive calls return non-null, the current node is the LCA.
6. Otherwise return the non-null child result.

### Code
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root;
        }

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) {
            return root;
        }

        return (left != null) ? left : right;
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(h)`

## Other Approaches
### Parent Pointer + HashSet
#### Pattern
- DFS
- HashMap / Set

#### Intuition
Another way is to build parent pointers for every node while traversing the tree. Once the paths from p and q to the root are known, the LCA is the last common node in those two ancestor chains.

#### Algorithm
1. Traverse the tree from the root and record each node’s parent.
2. Build the ancestor set for `p` by walking upward.
3. Move `q` upward until it reaches a node that is already in the set.
4. Return that node as the LCA.

#### Code
```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        Stack<TreeNode> stack = new Stack<>();
        parent.put(root, null);
        stack.push(root);

        while (!parent.containsKey(p) || !parent.containsKey(q)) {
            TreeNode node = stack.pop();
            if (node.left != null) {
                parent.put(node.left, node);
                stack.push(node.left);
            }
            if (node.right != null) {
                parent.put(node.right, node);
                stack.push(node.right);
            }
        }

        Set<TreeNode> ancestors = new HashSet<>();
        while (p != null) {
            ancestors.add(p);
            p = parent.get(p);
        }

        while (!ancestors.contains(q)) {
            q = parent.get(q);
        }
        return q;
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## Approach Comparison
| Approach | Pattern | Time | Space | Pros | Cons |
| --- | --- | --- | --- | --- | --- |
| Recursive DFS | DFS / Postorder | `O(n)` | `O(h)` | Elegant and standard | Uses recursion depth |
| Parent-pointer traversal | DFS + HashMap | `O(n)` | `O(n)` | Iterative and explicit | More bookkeeping |

## Key Observations
- The LCA is found where one subtree contributes p and the other contributes q.
- A node can be an ancestor of itself, so returning the current node when it matches p or q is correct.
- The recursive solution is the most common interview answer because it directly matches the definition.

## Common Mistakes
- Returning the wrong node when only one child finds a match.
- Forgetting that a node can be its own ancestor.
- Mishandling the base case when the current node is `null`.

## Related Patterns
- DFS
- Tree Traversal
- Parent Pointers

## Summary
- The optimal solution uses a postorder DFS to determine whether each subtree contains p or q.
- The pattern is tree traversal with recursive decomposition.
- Time complexity is `O(n)`, and space complexity is `O(h)` for the recursive version.
- Interview takeaway: the LCA problem is a classic example of bottom-up tree reasoning.
