# 2379. Minimum Recolors to Get K Consecutive Black Blocks

## Problem Statement

You are given a 0-indexed string $blocks$ of length $n$, where $blocks[i]$ is either 'W' or 'B', representing the color of the $i$th block. The characters 'W' and 'B' denote the colors white and black, respectively.

You are also given an integer $k$, which is the desired number of consecutive black blocks.

In one operation, you can recolor a white block such that it becomes a black block.

Return the minimum number of operations needed such that there is at least one occurrence of $k$ consecutive black blocks.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| blocks = "WBBWWBBWBW", k = 7 | 3 | Recolor 0th, 3rd, and 4th blocks |
| blocks = "WBWBBBW", k = 2 | 0 | Already has 2 consecutive black blocks |

---

## Constraints

- $n = blocks.length$
- $1 \leq n \leq 100$
- $blocks[i]$ is either 'W' or 'B'.
- $1 \leq k \leq n$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Check all windows of size $k$ | $O(n \cdot k)$ | $O(1)$ |
| Prefix Sum | Precompute white counts, check windows | $O(n)$ | $O(n)$ |
| Sliding Window | Maintain window count of whites | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check all windows of size $k$ | $O(n \cdot k)$ | $O(1)$ |

```java
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int n = blocks.length();
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i <= n - k; i++) {
            int cnt = 0;
            for (int j = i; j < i + k; j++) {
                if (blocks.charAt(j) == 'W') cnt++;
            }
            ans = Math.min(ans, cnt);
        }
        return ans;
    }
}
```

## Code: Prefix Sum

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Precompute white counts, check windows | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int n = blocks.length();
        int[] pref = new int[n + 1];
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] + (blocks.charAt(i) == 'W' ? 1 : 0);
        }
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i + k <= n; i++) {
            ans = Math.min(ans, pref[i + k] - pref[i]);
        }
        return ans;
    }
}
```

## Code: Sliding Window

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Maintain window count of whites | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int cnt = 0;
        for (int i = 0; i < k; ++i) {
            cnt += blocks.charAt(i) == 'W' ? 1 : 0;
        }
        int ans = cnt;
        for (int i = k; i < blocks.length(); ++i) {
            cnt += blocks.charAt(i) == 'W' ? 1 : 0;
            cnt -= blocks.charAt(i - k) == 'W' ? 1 : 0;
            ans = Math.min(ans, cnt);
        }
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n \cdot k)$ | $O(1)$ | Simple, but slow for large $k$ |
| Prefix Sum | $O(n)$ | $O(n)$ | Efficient, precomputes white counts |
| Sliding Window | $O(n)$ | $O(1)$ | Optimal, maintains window |

---

## Summary
- Sliding window is optimal for this problem.
- Prefix sum is efficient and easy to implement.
