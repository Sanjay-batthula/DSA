# 2379. Minimum Recolors to Get K Consecutive Black Blocks

## Brute Force
```
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int n = blocks.length();
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i <= n - k; i++) {
            int cnt = 0;
            for (int j = i; j < i + k; j++) {
                if (blocks.charAt(j) == 'W') cnt++;
            }
            ans = Math.min(ans, cnt);
        }
        return ans;
    }
}
```

## Prefix Sum
```
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int n = blocks.length();
        int[] pref = new int[n + 1];
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] + (blocks.charAt(i) == 'W' ? 1 : 0);
        }
        int ans = Integer.MAX_VALUE;
        for (int i = 0; i + k <= n; i++) {
            ans = Math.min(ans, pref[i + k] - pref[i]);
        }
        return ans;
    }
}
```

## Sliding Window
```
class Solution {
    public int minimumRecolors(String blocks, int k) {
        int cnt = 0;
        for (int i = 0; i < k; ++i) {
            cnt += blocks.charAt(i) == 'W' ? 1 : 0;
        }
        int ans = cnt;
        for (int i = k; i < blocks.length(); ++i) {
            cnt += blocks.charAt(i) == 'W' ? 1 : 0;
            cnt -= blocks.charAt(i - k) == 'W' ? 1 : 0;
            ans = Math.min(ans, cnt);
        }
        return ans;
    }
}
```
