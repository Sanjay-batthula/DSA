# 238. Product of Array Except Self

## Problem Statement
Given an integer array, return an array where each element is the product of all elements except the one at the current index. The solution must run in linear time and must not use division.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `nums = [1,2,3,4]` | `[24,12,8,6]` |
| `nums = [-1,1,0,-3,3]` | `[0,0,9,0,0]` |

## Constraints
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- The answer fits in a 32-bit integer.

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Prefix-suffix product | Prefix Sum / Prefix-Suffix | `O(n)` | `O(1)` extra |
| Explicit prefix and suffix arrays | Prefix-Suffix | `O(n)` | `O(n)` |

## Code
### Pattern
- Prefix Sum
- Prefix-Suffix Product

### Intuition
For each index, the desired product is the product of all values to the left and all values to the right. Instead of computing these products separately for every index, we can build them incrementally. First, we store the product of all elements to the left of each index in the output array. Then, we scan from right to left and multiply in the product of all elements to the right.

This avoids division and keeps the solution linear.

### Algorithm
1. Initialize the answer array with `1`.
2. Traverse from left to right and fill each position with the product of elements to the left.
3. Traverse from right to left and multiply each position by the product of elements to the right.
4. Return the final array.

### Code
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        int leftProduct = 1;
        for (int i = 0; i < n; i++) {
            answer[i] = leftProduct;
            leftProduct *= nums[i];
        }

        int rightProduct = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= rightProduct;
            rightProduct *= nums[i];
        }

        return answer;
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(1)` extra space

## Other Approaches
### Explicit Prefix and Suffix Arrays
#### Pattern
- Prefix-Suffix

#### Intuition
This approach builds separate prefix and suffix arrays and combines them. It is slightly more explicit but uses extra arrays.

#### Algorithm
1. Build a prefix product array.
2. Build a suffix product array.
3. Multiply the corresponding prefix and suffix values for each position.

#### Code
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] prefix = new int[n];
        int[] suffix = new int[n];
        int[] answer = new int[n];

        prefix[0] = 1;
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i - 1];
        }

        suffix[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i + 1];
        }

        for (int i = 0; i < n; i++) {
            answer[i] = prefix[i] * suffix[i];
        }
        return answer;
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(n)`

## Key Observations
- The product for each index equals the product of all left-side values times the product of all right-side values.
- The output array can be reused as the left-product array, reducing extra space.
- Zero values require special care because the product of the non-zero side becomes zero for most positions.

## Common Mistakes
- Forgetting to multiply the right-side product in the second pass.
- Using division, which is not allowed.
- Mishandling zero values when building products.

## Summary
- The optimal solution uses a two-pass prefix/suffix product approach.
- The pattern is prefix-suffix product accumulation.
- Time complexity is `O(n)`, and extra space complexity is `O(1)`.
- Interview takeaway: this problem is a classic example of turning a “product of all except self” requirement into left-right accumulation.
