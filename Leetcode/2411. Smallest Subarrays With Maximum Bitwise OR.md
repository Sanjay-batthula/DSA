# 2411. Smallest Subarrays With Maximum Bitwise OR

## Reverse Traversal + Last Occurrence of Each Bit - Java
```java
class Solution {
    public int[] smallestSubarrays(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        int[] f = new int[32];
        Arrays.fill(f, -1);
        for (int i = n - 1; i >= 0; --i) {
            int t = 1;
            for (int j = 0; j < 32; ++j) {
                if (((nums[i] >> j) & 1) == 1) {
                    f[j] = i;
                } else if (f[j] != -1) {
                    t = Math.max(t, f[j] - i + 1);
                }
            }
            ans[i] = t;
        }
        return ans;
    }
}
```

## Reverse Traversal + Last Occurrence of Each Bit-Python
```python
class Solution:
    def smallestSubarrays(self, nums: List[int]) -> List[int]:
        n = len(nums)
        last = [-1] * 31
        ans = [1] * n

        for i in range(n - 1, -1, -1):
            farthest = i

            for b in range(31):
                if nums[i] & (1 << b):
                    last[b] = i
                elif last[b] != -1:
                    farthest = max(farthest, last[b])

            ans[i] = farthest - i + 1
        return ans
```
