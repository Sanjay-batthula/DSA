# 242. Valid Anagram

## Problem Statement

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

## Sample Test Cases

Example 1:
```
Input: s = "anagram", t = "nagaram"
Output: true
```

Example 2:
```
Input: s = "rat", t = "car"
Output: false
```

---

## 1️⃣ Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Try to match each character in s with one in t, marking used characters. |
| **Approach**         | Use a visited array to avoid reusing characters.                        |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        boolean[] visited = new boolean[t.length()];
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            boolean found = false;
            for (int j = 0; j < t.length(); j++) {
                if (!visited[j] && t.charAt(j) == c) {
                    visited[j] = true;
                    found = true;
                    break;
                }
            }
            if (!found) return false;
        }
        return true;
    }
}
```

---

## 2️⃣ Character Removal Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Remove each character of s from t.                                      |
| **Approach**         | Use a StringBuilder to remove matched characters.                       |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        StringBuilder temp = new StringBuilder(t);
        for (char c : s.toCharArray()) {
            int idx = temp.indexOf(String.valueOf(c));
            if (idx == -1) {
                return false;
            }
            temp.deleteCharAt(idx);
        }
        return temp.length() == 0;
    }
}
```

---

## 3️⃣ Sorting Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Anagrams have the same sorted character order.                          |
| **Approach**         | Sort both strings and compare.                                          |
| **Time Complexity**  | O(n log n)                                                              |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        char[] a = s.toCharArray();
        char[] b = t.toCharArray();
        Arrays.sort(a);
        Arrays.sort(b);
        return Arrays.equals(a, b);
    }
}
```

---

## 4️⃣ Frequency Counting Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Count frequency of each character in both strings.                      |
| **Approach**         | Use an array to count and compare frequencies.                          |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1) (since alphabet size is constant)                                  |

```
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }
        int[] cnt = new int[26];
        for (int i = 0; i < s.length(); ++i) {
            ++cnt[s.charAt(i) - 'a'];
            --cnt[t.charAt(i) - 'a'];
        }
        for (int i = 0; i < 26; ++i) {
            if (cnt[i] != 0) {
                return false;
            }
        }
        return true;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n^2)         | O(n)            | Educational, not practical.           |
| Character Removal       | O(n^2)         | O(n)            | Simpler, but slow for large strings.  |
| Sorting                 | O(n log n)     | O(n)            | Clean and easy to implement.          |
| Frequency Counting      | O(n)           | O(1)            | Optimal for lowercase English letters.|

---

## Summary

- Optimal Approach: Frequency Counting (O(n) time, O(1) space for lowercase English).
- Sorting is a good alternative for general cases.
- For Unicode, use a HashMap for frequency counting.
