# 2460. Apply Operations to an Array

## Problem Statement

You are given a 0-indexed array $nums$ of size $n$ consisting of non-negative integers.

You need to apply $n - 1$ operations to this array where, in the $i$th operation ($0$-indexed), you will apply the following on the $i$th element of $nums$:
- If $nums[i] == nums[i + 1]$, then multiply $nums[i]$ by $2$ and set $nums[i + 1]$ to $0$. Otherwise, skip this operation.
After performing all the operations, shift all the $0$'s to the end of the array.

Return the resulting array.

Note: The operations are applied sequentially, not all at once.
    
---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,2,2,1,1,0] | [1,4,2,0,0,0] | Apply operations and shift zeros |
| nums = [0,1] | [1,0] | No operation, just shift zero |

---

## Constraints

- $2 \leq nums.length \leq 2000$
- $0 \leq nums[i] \leq 1000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Greedy Simulation | Apply operations, then compact non-zeros | $O(n)$ | $O(n)$ |
| Two-pointer | Apply operations, shift zeros in-place | $O(n)$ | $O(1)$ |

---

## Code: Greedy Simulation + Stable Compaction

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Apply operations, then compact non-zeros | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int[] applyOperations(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n - 1; ++i) {
            if (nums[i] == nums[i + 1]) {
                nums[i] <<= 1;
                nums[i + 1] = 0;
            }
        }
        int[] ans = new int[n];
        int i = 0;
        for (int x : nums) {
            if (x > 0) {
                ans[i++] = x;
            }
        }
        return ans;
    }
}
```

## Code: Two-pointer Single-pass Illusion

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Apply operations, shift zeros in-place | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int[] applyOperations(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] == nums[i + 1]) {
                nums[i] <<= 1;
                nums[i + 1] = 0;
            }
        }
        int write = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) {
                nums[write++] = nums[i];
            }
        }
        while (write < n) {
            nums[write++] = 0;
        }
        return nums;
    }
}
```
