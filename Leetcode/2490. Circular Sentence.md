# 2490. Circular Sentence

## Problem Statement

A sentence is a list of words that are separated by a single space with no leading or trailing spaces.

Words consist of only uppercase and lowercase English letters. Uppercase and lowercase English letters are considered different.

A sentence is circular if:
- The last character of each word in the sentence is equal to the first character of its next word.
- The last character of the last word is equal to the first character of the first word.

Given a string $sentence$, return true if it is circular. Otherwise, return false.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| sentence = "leetcode exercises sound delightful" | true | All word transitions and wrap-around match |
| sentence = "eetcode" | true | Single word, first and last character match |
| sentence = "Leetcode is cool" | false | Transition does not match |

---

## Constraints

- $1 \leq sentence.length \leq 500$
- $sentence$ consists of only lowercase and uppercase English letters and spaces.
- The words in $sentence$ are separated by a single space.
- No leading or trailing spaces.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Adjacency Comparison | Split words, compare last and first characters | $O(n)$ | $O(n)$ |
| Single-pass Traversal | Traverse string, check transitions | $O(n)$ | $O(1)$ |

---

## Code: String Traversal + Adjacency Comparison

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Split words, compare last and first characters | $O(n)$ | $O(n)$ |

```java
public class Solution {
    public static boolean isCircularSentence(String sentence) {
        String[] words = sentence.split(" ");
        for (int i = 0; i < words.length - 1; i++) {
            if (words[i].charAt(words[i].length() - 1) != words[i + 1].charAt(0)) {
                return false;
            }
        }
        if (words[words.length - 1].charAt(words[words.length - 1].length() - 1) != words[0].charAt(0)) {
            return false;
        }
        return true;
    }
}
```

---

## Code: Single-pass String Traversal

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Traverse string, check transitions | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean isCircularSentence(String sentence) {
        int n = sentence.length();
        if (sentence.charAt(0) != sentence.charAt(n - 1)) return false;
        for (int i = 1; i < n; i++) {
            if (sentence.charAt(i) == ' ') {
                if (sentence.charAt(i - 1) != sentence.charAt(i + 1)) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Adjacency Comparison | $O(n)$ | $O(n)$ | Splits words, compares edges |
| Single-pass Traversal | $O(n)$ | $O(1)$ | Efficient, no extra space |

---

## Summary
- Single-pass traversal is optimal for space.
- Adjacency comparison is simple and clear.
