# 2529. Maximum Count of Positive Integer and Negative Integer

## Linear Scan / Counting Approach
```
class Solution {
    public int maximumCount(int[] nums) {
        int a = 0, b = 0;
        for (int x : nums) {
            if (x > 0) {
                ++a;
            } else if (x < 0) {
                ++b;
            }
        }
        return Math.max(a, b);
    }
}
```

## Binary Search on Sorted Array
```
class Solution {
    public int maximumCount(int[] nums) {
        int n = nums.length;
        int left = 0, right = n - 1;
        int firstPos = n;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > 0) {
                firstPos = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        left = 0;
        right = n - 1;
        int lastNeg = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < 0) {
                lastNeg = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return Math.max(n - firstPos, lastNeg + 1);
    }
}
```
