# 2537. Count the Number of Good Subarrays

## Sliding Window (Two Pointers) + HashMap + Incremental Pair Counting
```
class Solution {
    public long countGood(int[] nums, int k) {
        Map<Integer, Integer> cnt = new HashMap<>();
        long ans = 0, cur = 0;
        int i = 0;
        for (int x : nums) {
            cur += cnt.merge(x, 1, Integer::sum) - 1;
            while (cur - cnt.get(nums[i]) + 1 >= k) {
                cur -= cnt.merge(nums[i++], -1, Integer::sum);
            }
            if (cur >= k) {
                ans += i + 1;
            }
        }
        return ans;
    }
}
```

## Brute Force + HashMap - TLE
```
class Solution {
    public long countGood(int[] nums, int k) {
        int n = nums.length;
        long ans = 0;
        for (int i = 0; i < n; i++) {
            Map<Integer, Integer> freq = new HashMap<>();
            long pairs = 0;
            for (int j = i; j < n; j++) {
                int count = freq.getOrDefault(nums[j], 0);
                pairs += count;
                freq.put(nums[j], count + 1);
                if (pairs >= k) {
                    ans++;
                }
            }
        }
        return ans;
    }
}
```
