# 2558. Take Gifts From the Richest Pile

## Greedy algorithm using a Max Heap (Priority Queue)
```
class Solution {
    public long pickGifts(int[] gifts, int k) {
        PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> b - a);
        for (int v : gifts) {
            pq.offer(v);
        }
        while (k-- > 0) {
            pq.offer((int) Math.sqrt(pq.poll()));
        }
        long ans = 0;
        for (int v : pq) {
            ans += v;
        }
        return ans;
    }
}
```

## Greedy using In-Place Max Heap (Array-based Heap)
```
class Solution {
    public long pickGifts(int[] gifts, int k) {
        int n = gifts.length;
        for (int i = n / 2 - 1; i >= 0; i--) heapify(gifts, n, i);
        while (k-- > 0) {
            gifts[0] = (int) Math.sqrt(gifts[0]);
            heapify(gifts, n, 0);
        }
        long sum = 0;
        for (int v : gifts) sum += v;
        return sum;
    }
    void heapify(int[] a, int n, int i) {
        int largest = i;
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest != i) {
            int t = a[i];
            a[i] = a[largest];
            a[largest] = t;
            heapify(a, n, largest);
        }
    }
}
```
