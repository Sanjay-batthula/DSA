# 2558. Take Gifts From the Richest Pile

## Problem Statement

You are given an integer array $gifts$ denoting the number of gifts in various piles. Every second, you do the following:
- Choose the pile with the maximum number of gifts.
- If there is more than one pile with the maximum number of gifts, choose any.
- Reduce the number of gifts in the pile to the floor of the square root of the original number of gifts in the pile.

Return the number of gifts remaining after $k$ seconds.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| gifts = [25,64,9,4,100], k = 4 | 29 | Gifts after 4 operations: [5,8,9,4,3] |
| gifts = [1,1,1,1], k = 4 | 4 | No pile can be reduced |

---

## Constraints

- $1 \leq gifts.length \leq 10^3$
- $1 \leq gifts[i] \leq 10^9$
- $1 \leq k \leq 10^3$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Max Heap | Use priority queue to always pick max | $O(k \log n)$ | $O(n)$ |
| In-Place Heap | Use array-based heap for max selection | $O(k \log n)$ | $O(1)$ |

---

## Code: Greedy Algorithm using a Max Heap (Priority Queue)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use priority queue to always pick max | $O(k \log n)$ | $O(n)$ |

```java
class Solution {
    public long pickGifts(int[] gifts, int k) {
        PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> b - a);
        for (int v : gifts) {
            pq.offer(v);
        }
        while (k-- > 0) {
            pq.offer((int) Math.sqrt(pq.poll()));
        }
        long ans = 0;
        for (int v : pq) {
            ans += v;
        }
        return ans;
    }
}
```

## Code: Greedy using In-Place Max Heap (Array-based Heap)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use array-based heap for max selection | $O(k \log n)$ | $O(1)$ |

```java
class Solution {
    public long pickGifts(int[] gifts, int k) {
        int n = gifts.length;
        for (int i = n / 2 - 1; i >= 0; i--) heapify(gifts, n, i);
        while (k-- > 0) {
            gifts[0] = (int) Math.sqrt(gifts[0]);
            heapify(gifts, n, 0);
        }
        long sum = 0;
        for (int v : gifts) sum += v;
        return sum;
    }
    void heapify(int[] a, int n, int i) {
        int largest = i;
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        if (l < n && a[l] > a[largest]) largest = l;
        if (r < n && a[r] > a[largest]) largest = r;
        if (largest != i) {
            int t = a[i];
            a[i] = a[largest];
            a[largest] = t;
            heapify(a, n, largest);
        }
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Max Heap | $O(k \log n)$ | $O(n)$ | Uses priority queue |
| In-Place Heap | $O(k \log n)$ | $O(1)$ | Uses array-based heap |

---

## Summary
- Both approaches efficiently reduce the richest pile each second.
- In-place heap is optimal for space.
