# 2579. Count Total Number of Colored Cells

## Mathematical Pattern Recognition
```java
class Solution {
    public long coloredCells(int n) {
        return 2L * n * (n - 1) + 1;
    }
}
```

## Iterative Layer Expansion
```java
class Solution {
    public long coloredCells(int n) {
        long ans = 1;
        for (int i = 2; i <= n; i++) {
            ans += 4L * (i - 1);
        }
        return ans;
    }
}
```
