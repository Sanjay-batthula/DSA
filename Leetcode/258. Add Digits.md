
## Brute force
```
class Solution {
    public int addDigits(int num) {
        while (num >= 10) {
            int sum = 0;
            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }
            num = sum;
        }
        return num;
    }
}
```

## recursive brute force
```
class Solution {
    public int addDigits(int num) {
        if (num < 10) return num;
        int sum = 0;
        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }
        return addDigits(sum);
    }
}
```
# digital root formula
```
class Solution {
    public int addDigits(int num) {
        if(num==0)return 0;
        return 1+(num-1)%9;
    }
}
```
