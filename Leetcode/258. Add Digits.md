# 258. Add Digits

## Problem Statement

Given an integer num, repeatedly add all its digits until the result has only one digit, and return it.

## Sample Test Cases

Example 1:
```
Input: num = 38
Output: 2
```
Explanation: The process is 38 --> 3 + 8 = 11, 11 --> 1 + 1 = 2. Since 2 has only one digit, return it.

Example 2:
```
Input: num = 0
Output: 0
```

---

## 1️⃣ Brute Force (Iterative)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Keep summing the digits until a single digit remains.                   |
| **Approach**         | Use a loop to sum digits repeatedly.                                    |
| **Time Complexity**  | O(log n) per iteration, O(1) overall (since num shrinks fast).          |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public int addDigits(int num) {
        while (num >= 10) {
            int sum = 0;
            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }
            num = sum;
        }
        return num;
    }
}
```

---

## 2️⃣ Recursive Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use recursion to sum digits until a single digit remains.               |
| **Approach**         | Base case: num < 10. Otherwise, recurse on the sum of digits.           |
| **Time Complexity**  | O(log n) per call, O(1) overall.                                        |
| **Space Complexity** | O(log n) (recursion stack).                                             |

```
class Solution {
    public int addDigits(int num) {
        if (num < 10) return num;
        int sum = 0;
        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }
        return addDigits(sum);
    }
}
```

---

## 3️⃣ Digital Root Formula (O(1) Solution)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | The result follows a mathematical pattern (digital root).               |
| **Approach**         | Use the formula: 1 + (num - 1) % 9, except for num = 0.                 |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public int addDigits(int num) {
        if(num==0)return 0;
        return 1+(num-1)%9;
    }
}
```

---

## Approach Comparison

| Approach           | Time Complexity | Space Complexity | Notes                                 |
| ------------------ | -------------- | --------------- | ------------------------------------- |
| Brute Force        | O(1)           | O(1)            | Simple, works for all valid inputs.   |
| Recursive          | O(1)           | O(log n)        | Elegant, but uses stack space.        |
| Digital Root       | O(1)           | O(1)            | Most efficient, uses math trick.      |

---

## Summary

- Optimal Approach: Digital Root Formula (O(1) time, O(1) space).
- Brute force and recursion are easy to understand and implement.
- Digital root is best for interviews if you know the trick.
