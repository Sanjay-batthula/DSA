
# 26. Remove Duplicates from Sorted Array

## Problem Description
Given an integer array nums sorted in non-decreasing order, remove the duplicates in-place such that each unique element appears only once. The relative order of the elements should be kept the same.

Consider the number of unique elements in nums to be k. After removing duplicates, return the number of unique elements k.

The first k elements of nums should contain the unique numbers in sorted order. The remaining elements beyond index k - 1 can be ignored.

## Sample Test Cases
Example 1:  
Input: nums = [1,1,2]  
Output: 2, nums = [1,2,_]

Example 2:  
Input: nums = [0,0,1,1,1,2,2,3,3,4]  
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]

**Constraints:**
- 1 <= nums.length <= 3 * 10⁴
- -100 <= nums[i] <= 100
- nums is sorted in non-decreasing order.

---

## Brute Force
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use set to filter unique values                 |
| **Approach**         | Copy to set, then back to array                 |
| **Time Complexity**  | `O(n log n)`                                    |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        Set<Integer> set = new LinkedHashSet<>();
        for (int n : nums) set.add(n);
        int k = 0;
        for (int n : set) nums[k++] = n;
        return k;
    }
}
```

## Two-Pointer Technique
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use two pointers to overwrite duplicates        |
| **Approach**         | Write unique values to front of array           |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(1)`                                          |

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 0;
        for (int x : nums) {
            if (k == 0 || x != nums[k - 1]) {
                nums[k++] = x;
            }
        }
        return k;
    }
}
```

## Single-Pointer
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Track last unique, overwrite duplicates         |
| **Approach**         | Use one pointer to write unique values          |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(1)`                                          |

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 1;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) {
                nums[k++] = nums[i];
            }
        }
        return k;
    }
}
```

## HashMap Counting Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use map to count and filter unique values       |
| **Approach**         | Store counts, write unique keys to array        |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)`                                          |

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        Map<Integer, Integer> map = new LinkedHashMap<>();
        for (int n : nums) map.put(n, map.getOrDefault(n, 0) + 1);
        int k = 0;
        for (int key : map.keySet()) nums[k++] = key;
        return k;
    }
}
```

## Recursive Approach
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Recursively write unique values                 |
| **Approach**         | Helper function with index and write pointer    |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(n)` (call stack)                             |

```java
class Solution {
    private int helper(int[] nums, int i, int k) {
        if (i == nums.length) return k;
        if (k == 0 || nums[i] != nums[k - 1]) nums[k++] = nums[i];
        return helper(nums, i + 1, k);
    }
    public int removeDuplicates(int[] nums) {
        return helper(nums, 0, 0);
    }
}
```

## Approach Comparison
| Approach         | Time         | Space   | Status    | Notes                |
| ---------------- | ------------ | ------- | --------- | -------------------- |
| Brute Force      | `O(n log n)` | `O(n)`  | ❌         | Not in-place         |
| Two-Pointer      | `O(n)`       | `O(1)`  | ✅ Optimal | Standard, efficient  |
| Single-Pointer   | `O(n)`       | `O(1)`  | ✅         | Variant, works       |
| HashMap          | `O(n)`       | `O(n)`  | ❌         | Not in-place         |
| Recursive        | `O(n)`       | `O(n)`  | ✅         | Elegant, uses stack  |

## Summary

- Two-pointer and single-pointer are optimal and in-place
- Brute force and hash-based methods use extra space
- Key insight: overwrite duplicates as you scan
