# 2619. Array Prototype Last

## Problem Statement

Write code that enhances all arrays such that you can call the `array.last()` method on any array and it will return the last element. If there are no elements in the array, it should return -1.

You may assume the array is the output of JSON.parse.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [null, {}, 3] | 3 | Returns last element |
| nums = [] | -1 | No elements, returns -1 |

---

## Constraints

- arr is a valid JSON array
- $0 \leq arr.length \leq 1000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Prototype Extension | Add last() to Array.prototype | $O(1)$ | $O(1)$ |
| TypeScript Interface | Extend Array interface | $O(1)$ | $O(1)$ |

---

## Code: JavaScript Prototype Extension

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Add last() to Array.prototype | $O(1)$ | $O(1)$ |

```javascript
/**
 * @return {null|boolean|number|string|Array|Object}
 */
Array.prototype.last = function() {
    if (this.length === 0) {
        return -1;
    }
    return this[this.length - 1];
};

// Example:
const arr = [1, 2, 3];
arr.last(); // 3
```

## Code: TypeScript Interface Extension

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Extend Array interface | $O(1)$ | $O(1)$ |

```typescript
interface Array<T> {
    last(): T | -1;
}

Array.prototype.last = function() {
    if (this.length === 0) {

arr.last(); // 3
```
