# 2620. Counter

## Problem Statement

Given an integer $n$, return a counter function. This counter function initially returns $n$ and then returns 1 more than the previous value every subsequent time it is called ($n$, $n + 1$, $n + 2$, etc).

---

## Sample Test Cases

| Input | Calls | Output | Explanation |
|-------|-------|--------|-------------|
| n = 10 | ["call","call","call"] | [10,11,12] | Returns n, then increments |
| n = -2 | ["call","call","call","call","call"] | [-2,-1,0,1,2] | Starts at -2, increments |

---

## Constraints

- $-1000 \leq n \leq 1000$
- $0 \leq calls.length \leq 1000$
- $calls[i]$ is always "call"

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Closure | Use closure to maintain state | $O(1)$ per call | $O(1)$ |

---

## Code: JavaScript Closure

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Closure | $O(1)$ per call | $O(1)$ |

```javascript
var createCounter = function(n) {
    let i = n;
    return function() {
        return i++;
    };
};
```

---

## Code: TypeScript Closure

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Closure | $O(1)$ per call | $O(1)$ |

```typescript
function createCounter(n: number): () => number {
    let i = n;
    return function(): number {
        return i++;
    };
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Closure | $O(1)$ per call | $O(1)$ | Simple, uses function scope |

---

## Summary
- Using closures allows the counter to maintain its state across calls.
