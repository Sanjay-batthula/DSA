# 2621. Sleep

## Problem Statement

Given a positive integer $millis$, write an asynchronous function that sleeps for $millis$ milliseconds. It can resolve any value.

Note that minor deviation from $millis$ in the actual sleep duration is acceptable.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| millis = 100 | 100 | Resolves after 100ms |
| millis = 200 | 200 | Resolves after 200ms |

---

## Constraints

- $1 \leq millis \leq 1000$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Promise | Use setTimeout in Promise | $O(1)$ | $O(1)$ |

---

## Code: JavaScript Promise

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use setTimeout in Promise | $O(1)$ | $O(1)$ |

```javascript
async function sleep(millis) {
    return new Promise(r => setTimeout(r, millis));
}
```

---

## Code: TypeScript Promise

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use setTimeout in Promise | $O(1)$ | $O(1)$ |

```typescript
async function sleep(millis: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, millis));
}
```

---

## Summary
- Using Promise and setTimeout allows for easy async sleep.
