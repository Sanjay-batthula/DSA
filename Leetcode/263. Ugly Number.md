# 263. Ugly Number

## Problem Statement

An ugly number is a positive integer which does not have a prime factor other than 2, 3, and 5.

Given an integer n, return true if n is an ugly number.

## Sample Test Cases

Example 1:
```
Input: n = 6
Output: true
```
Explanation: 6 = 2 × 3

Example 2:
```
Input: n = 1
Output: true
```
Explanation: 1 has no prime factors.

Example 3:
```
Input: n = 14
Output: false
```
Explanation: 14 is not ugly since it includes the prime factor 7.

---

## 1️⃣ Brute Force (TLE)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Try dividing by every integer and check for non-ugly prime factors.     |
| **Approach**         | For each i from 2 to n, divide n and check if i is not 2, 3, or 5.      |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isUgly(int n) {
        if (n <= 0) return false;
        for (int i = 2; i <= n; i++) {
            while (n % i == 0) {
                n /= i;
                if (i != 2 && i != 3 && i != 5) {
                    return false;
                }
            }
        }
        return true;
    }
}
```

---

## 2️⃣ Prime Factorization Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Remove all 2s, 3s, and 5s from n; if 1 remains, it's ugly.              |
| **Approach**         | Divide n by 2, 3, and 5 as much as possible, then check if n == 1.      |
| **Time Complexity**  | O(log n)                                                                |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isUgly(int n) {
        if (n <= 0) return false;
        for (int factor : new int[]{2, 3, 5}) {
            while (n % factor == 0) {
                n /= factor;
            }
        }
        return n == 1;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n)           | O(1)            | TLE for large n.                      |
| Prime Factorization     | O(log n)       | O(1)            | Optimal and clean.                    |

---

## Summary

- Optimal Approach: Prime Factorization (O(log n) time, O(1) space).
- Brute force is educational but not practical for large n.
