# 283. Move Zeroes

## Problem Statement

Given an integer array nums, move all 0's to the end of it while maintaining the relative order of the non-zero elements.

Note that you must do this in-place without making a copy of the array.

## Sample Test Cases

Example 1:
```
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

Example 2:
```
Input: nums = [0]
Output: [0]
```

---

## 1️⃣ Brute Force (Extra Array)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Copy non-zero elements to a new array, then fill with zeros.            |
| **Approach**         | Use a temp array, then copy back.                                       |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        int[] temp = new int[n];
        int k = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) temp[k++] = nums[i];
        }
        while (k < n) temp[k++] = 0;
        for (int i = 0; i < n; i++) nums[i] = temp[i];
    }
}
```

---

## 2️⃣ In-Place Shifting Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Shift elements left when a zero is found, then put zero at the end.      |
| **Approach**         | For each zero, shift left and set last to zero.                         |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] == 0) {
                for (int j = i; j < n - 1; j++) {
                    nums[j] = nums[j + 1];
                }
                nums[n - 1] = 0;
                i--; 
                n--; 
            }
        }
    }
}
```

---

## 3️⃣ Two-Pointer Approach (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use two pointers to swap non-zero elements forward.                     |
| **Approach**         | Place non-zeros at the front, fill rest with zeros.                     |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public void moveZeroes(int[] nums) {
        int i = 0;
        for (int j = 0; j < nums.length; j++) {
            if (nums[j] != 0) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
                i++;
            }
        }
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n)           | O(n)            | Not in-place.                         |
| In-Place Shifting       | O(n^2)         | O(1)            | Inefficient for large arrays.         |
| Two-Pointer             | O(n)           | O(1)            | Optimal and in-place.                 |

---

## Summary

- Optimal Approach: Two-Pointer (O(n) time, O(1) space, in-place).
- Brute force is simple but not in-place.
- In-place shifting is inefficient for large arrays.
