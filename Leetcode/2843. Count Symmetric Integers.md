# 2843. Count Symmetric Integers

## Problem Statement

You are given two positive integers $low$ and $high$.

An integer $x$ consisting of $2n$ digits is symmetric if the sum of the first $n$ digits of $x$ is equal to the sum of the last $n$ digits of $x$. Numbers with an odd number of digits are never symmetric.

Return the number of symmetric integers in the range $[low, high]$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| low = 1, high = 100 | 9 | 11, 22, ..., 99 are symmetric |
| low = 1200, high = 1230 | 4 | 1203, 1212, 1221, 1230 |

---

## Constraints

- $1 \leq low \leq high \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Enumeration | Check each number, process digits | $O(N \cdot D)$ | $O(1)$ |
| Arithmetic | Extract digits arithmetically | $O(N \cdot D)$ | $O(1)$ |

---

## Code: Enumeration with Digit Processing

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check each number, process digits | $O(N \cdot D)$ | $O(1)$ |

```java
class Solution {
    public int countSymmetricIntegers(int low, int high) {
        int ans = 0;
        for (int x = low; x <= high; ++x) {
            ans += f(x);
        }
        return ans;
    }
    private int f(int x) {
        String s = "" + x;
        int n = s.length();
        if (n % 2 == 1) {
            return 0;
        }
        int a = 0, b = 0;
        for (int i = 0; i < n / 2; ++i) {
            a += s.charAt(i) - '0';
        }
        for (int i = n / 2; i < n; ++i) {
            b += s.charAt(i) - '0';
        }
        return a == b ? 1 : 0;
    }
}
```

## Code: Arithmetic Digit Extraction

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Extract digits arithmetically | $O(N \cdot D)$ | $O(1)$ |

```java
class Solution {
    public int countSymmetricIntegers(int low, int high) {
        int ans = 0;
        for (int x = low; x <= high; x++) {
            int d = digits(x);
            if (d % 2 == 1) continue;
            int half = d / 2;
            int left = 0, right = 0;
            int pow = (int)Math.pow(10, half);
            int l = x / pow;
            int r = x % pow;
            while (l > 0) {
                left += l % 10;
                l /= 10;
            }
            while (r > 0) {
                right += r % 10;
                r /= 10;
            }
            if (left == right) ans++;
        }
        return ans;
    }

    private int digits(int x) {
        int c = 0;
        while (x > 0) {
            c++;
            x /= 10;
        }
        return c;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Enumeration | $O(N \cdot D)$ | $O(1)$ | Simple, uses string processing |
| Arithmetic | $O(N \cdot D)$ | $O(1)$ | Avoids string conversion |

## Summary
- Both approaches enumerate the range and check symmetry by digit sums.
