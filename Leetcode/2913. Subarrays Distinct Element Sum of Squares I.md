# 2913. Subarrays Distinct Element Sum of Squares I

## Brute Force with Hashing
```
import java.util.HashSet;
import java.util.List;

class Solution {
    public int sumCounts(List<Integer> nums) {
        int n = nums.size();
        int totalSum = 0;

        for (int i = 0; i < n; i++) {
            HashSet<Integer> distinctElements = new HashSet<>();
            for (int j = i; j < n; j++) {
                distinctElements.add(nums.get(j));
                int distinctCount = distinctElements.size();
                totalSum += distinctCount * distinctCount;
            }
        }

        return totalSum;
    }
}
```

## Brute Force with Frequency Array
```
class Solution {
    public int sumCounts(List<Integer> nums) {
        int n = nums.size();
        int totalSum = 0;
        for (int i = 0; i < n; i++) {
            boolean[] seen = new boolean[101];
            int distinctCount = 0;
            for (int j = i; j < n; j++) {
                int val = nums.get(j);
                if (!seen[val]) {
                    seen[val] = true;
                    distinctCount++;
                }
                totalSum += distinctCount * distinctCount;
            }
        }
        return totalSum;
    }
}
```
