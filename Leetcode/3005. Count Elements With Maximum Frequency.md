
# 3005. Count Elements With Maximum Frequency

## Problem Statement

You are given an array `nums` consisting of positive integers.

Return the total frequencies of elements in `nums` such that those elements all have the maximum frequency.

The frequency of an element is the number of occurrences of that element in the array.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,2,2,3,1,4] | 4 | Elements 1 and 2 have frequency 2 (max), so total is 4 |
| nums = [1,2,3,4,5] | 5 | All elements have frequency 1 (max), so total is 5 |

---

## Constraints

- $1 \leq \text{nums.length} \leq 100$
- $1 \leq \text{nums}[i] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Count frequency for each element | $O(n^2)$ | $O(1)$ |
| Hash Map | Use a map to count frequencies | $O(n)$ | $O(n)$ |
| Frequency Array | Use array for counting (since values are bounded) | $O(n)$ | $O(1)$ |

---

## Code: Hash Map Approach

```java
class Solution {
    public int maxFrequencyElements(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        int maxFreq = 0;
        for (int num : nums) {
            freq.put(num, freq.getOrDefault(num, 0) + 1);
            maxFreq = Math.max(maxFreq, freq.get(num));
        }
        int total = 0;
        for (int f : freq.values()) {
            if (f == maxFreq) {
                total += f;
            }
        }
        return total;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public int maxFrequencyElements(int[] nums) {
        int n = nums.length;
        int maxFreq = 0;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (nums[i] == nums[j]) {
                    count++;
                }
            }
            maxFreq = Math.max(maxFreq, count);
        }
        int total = 0;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (nums[i] == nums[j]) {
                    count++;
                }
            }
            if (count == maxFreq) {
                total++;
            }
        }
        return total;
    }
}
```

### Frequency Array
```java
class Solution {
    public int maxFrequencyElements(int[] nums) {
        int[] freq = new int[101];
        int maxFreq = 0;
        for (int num : nums) {
            freq[num]++;
            if (freq[num] > maxFreq) maxFreq = freq[num];
        }
        int total = 0;
        for (int f : freq) {
            if (f == maxFreq) total += f;
        }
        return total;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Nested loops, slow for large n |
| Hash Map | $O(n)$ | $O(n)$ | Efficient, general purpose |
| Frequency Array | $O(n)$ | $O(1)$ | Efficient for bounded values |

---

## Summary

- Count frequencies using hash map or array.
- Find maximum frequency.
- Sum up frequencies of elements with maximum frequency.
