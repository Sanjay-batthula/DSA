
# 31. Next Permutation

## Problem Description
A permutation of an array of integers is an arrangement of its members into a sequence or linear order.

The next permutation of an array of integers is the next lexicographically greater permutation of its integer. More formally, if all the permutations of the array are sorted in one container according to their lexicographical order, then the next permutation of that array is the permutation that follows it in the sorted container. If such arrangement is not possible, the array must be rearranged as the lowest possible order (i.e., sorted in ascending order).

Given an array of integers nums, find the next permutation of nums.

The replacement must be in place and use only constant extra memory.

## Sample Test Cases
Example 1:  
Input: nums = [1,2,3]  
Output: [1,3,2]

Example 2:  
Input: nums = [3,2,1]  
Output: [1,2,3]

Example 3:  
Input: nums = [1,1,5]  
Output: [1,5,1]

**Constraints:**
- 1 <= nums.length <= 100
- 0 <= nums[i] <= 100

## Brute Force (All Permutations)
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Generate all permutations, sort, find next      |
| **Approach**         | List all, sort, find next in order              |
| **Time Complexity**  | `O(n! * n)`                                     |
| **Space Complexity** | `O(n! * n)`                                     |

```java
import java.util.*;
class Solution {
    public void nextPermutation(int[] nums) {
        List<int[]> list = new ArrayList<>();
        permute(nums, 0, list);
        list.sort((a,b)->{
            for(int i=0;i<a.length;i++){
                if(a[i]!=b[i]) return a[i]-b[i];
            }
            return 0;
        });
        for(int i=0;i<list.size();i++){
            if(equal(list.get(i), nums)) {
                int[] next = list.get((i+1)%list.size());
                for(int k=0;k<nums.length;k++) nums[k]=next[k];
                return;
            }
        }
    }
    void permute(int[] nums, int idx, List<int[]> res) {
        if(idx==nums.length){
            res.add(Arrays.copyOf(nums, nums.length));
            return;
        }
        for(int i=idx;i<nums.length;i++){
            swap(nums,i,idx);
            permute(nums,idx+1,res);
            swap(nums,i,idx);
        }
    }
    boolean equal(int[] a, int[] b){
        for(int i=0;i<a.length;i++) if(a[i]!=b[i]) return false;
        return true;
    }
    void swap(int[] a,int i,int j){
        int t=a[i];
        a[i]=a[j];
        a[j]=t;
    }
}
```

## In-place Lexicographical Next Permutation (Pivot-Swap-Reverse)
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Find pivot, swap with next greater, reverse     |
| **Approach**         | Scan from end, swap, reverse suffix             |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(1)`                                          |

```java
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums.length <= 1) return;
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = nums.length - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, nums.length - 1);
    }
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    private void reverse(int[] nums, int i, int j) {
        while (i < j) swap(nums, i++, j--);
    }
}
```

## Factorial Number System (Rank/Unrank) - Not Recommended

| -------------------- | ----------------------------------------------- |

| **Approach**         | Compute rank, unrank next permutation           |
| **Time Complexity**  | `O(n^2)` or worse                              |
| **Space Complexity** | `O(n)`                                         |

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int[] a = Arrays.copyOf(nums, nums.length);
```

## Custom Bubble-like Sweep
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Find rightmost increasing pair, swap, reverse   |
| **Approach**         | Bubble up next greater, reverse suffix          |
| **Time Complexity**  | `O(n^2)`                                        |
| **Space Complexity** | `O(1)`                                          |

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = -1, j = -1;
        for (int a = 0; a < n; a++) {
            for (int b = a + 1; b < n; b++) {
                if (nums[a] < nums[b]) {
                    i = a;
                    j = b;
                }
            }
        }
        if (i == -1) {
            reverse(nums, 0, n - 1);
            return;
        }
        swap(nums, i, j);
        reverse(nums, i + 1, n - 1);
    }
    void swap(int[] a,int i,int j){
        int t=a[i];a[i]=a[j];a[j]=t;
    }
    void reverse(int[] a,int l,int r){
        while(l<r) swap(a,l++,r--);
    }
}
```

## Using Priority Queue of Suffixes
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Try all swaps, pick lexicographically smallest  |
| **Approach**         | For each i, try swaps, sort suffix, use PQ      |
| **Time Complexity**  | `O(n^3 log n)`                                  |
| **Space Complexity** | `O(n^2)`                                        |

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        for (int i = n - 2; i >= 0; i--) {
            PriorityQueue<int[]> pq = new PriorityQueue<>((a,b)->{
                for(int k=0;k<a.length;k++){
                    if(a[k]!=b[k]) return a[k]-b[k];
                }
                return 0;
            });
            for (int j = i + 1; j < n; j++) {
                if (nums[j] > nums[i]) {
                    int[] copy = nums.clone();
                    int t = copy[i]; copy[i] = copy[j]; copy[j] = t;
                    Arrays.sort(copy, i+1, n);
                    pq.add(copy);
                }
            }
            if (!pq.isEmpty()) {
                int[] best = pq.poll();
                for(int k=0;k<n;k++) nums[k]=best[k];
                return;
            }
        }
        Arrays.sort(nums);
    }
}
```

## Approach Comparison
| Approach         | Time         | Space   | Status    | Notes                |
| ---------------- | ------------ | ------- | --------- | -------------------- |
| Brute Force      | `O(n! * n)`  | `O(n! * n)` | ❌         | Not practical        |
| In-place (Pivot) | `O(n)`       | `O(1)`  | ✅ Optimal | Standard, efficient  |
| Factorial System | `O(n^2)`     | `O(n)`  | ❌         | Overkill, rare       |
| Bubble Sweep     | `O(n^2)`     | `O(1)`  | ❌         | Inefficient          |
| TreeSet          | `O(n! * n)`  | `O(n! * n)` | ❌         | TLE, not practical   |
| PQ of Suffixes   | `O(n^3 log n)` | `O(n^2)` | ❌         | Overkill, slow       |

## Summary

- In-place pivot-swap-reverse is the optimal and standard approach
- Brute force and other methods are not practical for large n
- Key insight: find rightmost ascent, swap, reverse suffix
