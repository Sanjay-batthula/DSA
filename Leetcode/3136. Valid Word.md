
# 3136. Valid Word

## Problem Statement

A word is considered valid if:

- It contains a minimum of 3 characters.
- It contains only digits (0-9), and English letters (uppercase and lowercase).
- It includes at least one vowel.
- It includes at least one consonant.

You are given a string `word`.

Return `true` if `word` is valid, otherwise, return `false`.

Notes:
- 'a', 'e', 'i', 'o', 'u', and their uppercases are vowels.
- A consonant is an English letter that is not a vowel.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| word = "234Adas" | true | Satisfies all conditions |
| word = "b3" | false | Length < 3, no vowel |
| word = "a3$e" | false | Contains '$', no consonant |

---

## Constraints

- $1 \leq \text{word.length} \leq 20$
- $\text{word}$ consists of English uppercase and lowercase letters, digits, '@', '#', and '$'.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Check each character, track vowels/consonants | $O(n)$ | $O(1)$ |
| Hash Set | Use set for vowels, check each character | $O(n)$ | $O(1)$ |
| Regex | Use regex for validation | $O(n)$ | $O(1)$ |

---

## Code: Hash Set Approach

```java
class Solution {
    public boolean isValid(String word) {
        if (word.length() < 3) return false;

        HashSet<Character> vowels = new HashSet<>(Arrays.asList(
            'a','e','i','o','u','A','E','I','O','U'
        ));

        boolean hasVowel = false, hasConsonant = false;

        for (char c : word.toCharArray()) {
            if (!Character.isLetterOrDigit(c)) return false;

            if (Character.isLetter(c)) {
                if (vowels.contains(c)) {
                    hasVowel = true;
                } else {
                    hasConsonant = true;
                }
            }
        }
        return hasVowel && hasConsonant;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public boolean isValid(String word) {
        if (word.length() < 3) return false;
        boolean vowel = false, consonant = false;
        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            if (c >= '0' && c <= '9') continue;
            else if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z')) {
                char lc = Character.toLowerCase(c);
                if (lc == 'a' || lc == 'e' || lc == 'i' || lc == 'o' || lc == 'u') vowel = true;
                else consonant = true;
            } else return false;
        }
        return vowel && consonant;
    }
}
```

### Regex-based Approach
```java
class Solution {
    public boolean isValid(String word) {
        if (word.length() < 3) return false;
        if (!word.matches("[a-zA-Z0-9]+")) return false;
        if (!word.matches(".*[aeiouAEIOU].*")) return false;
        if (!word.matches(".*[a-zA-Z&&[^aeiouAEIOU]].*")) return false;
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(1)$ | Manual checks |
| Hash Set | $O(n)$ | $O(1)$ | Uses set for vowels |
| Regex | $O(n)$ | $O(1)$ | Concise, but less readable |

---

## Summary

- Check length, allowed characters, presence of vowel and consonant.
- Use brute force, hash set, or regex for implementation.
