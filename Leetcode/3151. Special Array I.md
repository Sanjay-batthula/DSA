# 3151. Special Array I

## Linear Traversal / Single Pass Array Check
```
class Solution {
    public boolean isArraySpecial(int[] nums) {
        for (int i = 1; i < nums.length; ++i) {
            if (nums[i] % 2 == nums[i - 1] % 2) {
                return false;
            }
        }
        return true;
    }
}
```

## Bitwise Parity Check
```
class Solution {
    public boolean isArraySpecial(int[] nums) {
        for(int i = 1; i < nums.length; i++){
            if((nums[i] & 1) == (nums[i-1] & 1)){
                return false;
            }
        }
        return true;
    }
}
```
