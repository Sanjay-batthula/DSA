# 326. Power of Three

## Problem Statement

Given an integer n, return true if it is a power of three. Otherwise, return false.

An integer n is a power of three if there exists an integer x such that n == 3^x.

## Sample Test Cases

Example 1:
```
Input: n = 27
Output: true
```
Explanation: 27 = 3^3

Example 2:
```
Input: n = 0
Output: false
```
Explanation: There is no x where 3^x = 0.

Example 3:
```
Input: n = -1
Output: false
```
Explanation: There is no x where 3^x = -1.

---

## 1️⃣ Brute Force (Iterative)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Keep dividing by 3; if you reach 1, it's a power of three.              |
| **Approach**         | Divide n by 3 until n becomes 1 or not divisible by 3.                  |
| **Time Complexity**  | O(log₃ n)                                                               |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfThree(int n) {
        if (n <= 0) return false;
        while (n % 3 == 0) {
            n /= 3;
        }
        return n == 1;
    }
}
```

---

## 2️⃣ Maximum Power Divisibility Approach (O(1))

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | The largest power of 3 in 32-bit int is 3^19 = 1162261467.              |
| **Approach**         | If n divides 3^19, then n is a power of 3.                              |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfThree(int n) {
        return n > 0 && 1162261467 % n == 0;
    }
}
```

---

## 3️⃣ Recursive Brute Force Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use recursion to divide by 3 until 1 or not divisible.                  |
| **Approach**         | Base case: n == 1. Otherwise, recurse on n / 3.                         |
| **Time Complexity**  | O(log₃ n)                                                               |
| **Space Complexity** | O(log₃ n) (recursion stack)                                             |

```
class Solution {
    public boolean isPowerOfThree(int n) {
        if (n <= 0) return false;
        if (n == 1) return true;
        if (n % 3 != 0) return false;
        return isPowerOfThree(n / 3);
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force (Iterative) | O(log₃ n)      | O(1)            | Simple and reliable.                  |
| Max Power Divisibility  | O(1)           | O(1)            | Fastest, but only for 32-bit int.     |
| Recursive               | O(log₃ n)      | O(log₃ n)       | Elegant, but uses stack space.        |

---

## Summary

- Optimal Approach: Max Power Divisibility (O(1) time, O(1) space).
- Iterative brute force is simple and reliable for all valid inputs.
- Recursion is elegant but uses stack space.
