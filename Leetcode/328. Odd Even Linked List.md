# 328. Odd Even Linked List

## Problem Statement

Given the head of a singly linked list, group all nodes at odd positions together followed by all nodes at even positions, and return the reordered list.

The first node is considered odd, the second is even, and so on.

The relative order inside the odd group and the even group must remain the same as in the original list.

You must solve this in O(1) extra space and O(n) time.

## Example

- Input: head = [1,2,3,4,5]
- Output: [1,3,5,2,4]

- Input: head = [2,1,3,5,6,4,7]
- Output: [2,3,6,7,1,5,4]

## Constraints

- The number of nodes in the linked list is in the range [0, 10^4].
- -10^6 <= Node.val <= 10^6

## Intuition

A linked list can be rearranged by splitting it into two lanes:

- odd-positioned nodes: 1st, 3rd, 5th, ...
- even-positioned nodes: 2nd, 4th, 6th, ...

Once we have the two chains, we can connect the odd chain to the head of the even chain.

The key is to do this in-place using only a few pointers, so we avoid extra space.

## Approach: Two-Pointer Rearrangement

### Idea

Maintain three pointers:

- odd: the tail of the odd-positioned chain
- even: the tail of the even-positioned chain
- evenHead: the first node of the even chain

Then repeatedly connect the next odd node after the current odd node, and the next even node after the current even node.

At the end, attach the even chain to the end of the odd chain.

### Algorithm

1. If the list is empty or has only one node, return it immediately.
2. Initialize:
   - odd = head
   - even = head.next
   - evenHead = even
3. While even exists and even.next exists:
   - odd.next = even.next
   - odd = odd.next
   - even.next = odd.next
   - even = even.next
4. After the loop, link the last odd node to the start of the even chain.
5. Return head.

## Java Solution

```java
class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        ListNode odd = head;
        ListNode even = head.next;
        ListNode evenHead = even;

        while (even != null && even.next != null) {
            odd.next = even.next;
            odd = odd.next;
            even.next = odd.next;
            even = even.next;
        }

        odd.next = evenHead;
        return head;
    }
}
```

## Why This Works

Each iteration moves one odd node and one even node into their correct positions while preserving the original relative order inside each group.

Because we only redirect pointers and never create new nodes, the structure is rearranged in-place.

Finally, connecting the tail of the odd chain to the head of the even chain produces the required order:

- odd positions first
- even positions second

## Complexity Analysis

- Time: O(n)
  - Each node is visited a constant number of times.
- Space: O(1)
  - Only a few pointers are used.

## Common Mistakes

- Forgetting to store the head of the even chain before modifying pointers.
- Breaking the list by accidentally linking nodes in the wrong order.
- Not handling the case of empty or single-node lists.

## Summary

This problem is a classic example of in-place linked list restructuring. The solution uses a simple and efficient two-pointer strategy to separate odd and even positions while preserving order within each segment.
