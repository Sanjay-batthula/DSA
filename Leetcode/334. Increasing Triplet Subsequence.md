# 334. Increasing Triplet Subsequence

## Brute Force (Triple Nested Loop) - TLE
```
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[j] > nums[i]) {
                    for (int k = j + 1; k < n; k++) {
                        if (nums[k] > nums[j]) {
                            return true;
                        }
                    }
                }
            }
        }
        return false;
    }
}
```

## Middle Fixing with Linear Scan (Brute Optimized)
```
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int n = nums.length;
        for (int j = 1; j < n - 1; j++) {
            boolean leftSmaller = false;
            boolean rightGreater = false;
            for (int i = 0; i < j; i++) {
                if (nums[i] < nums[j]) {
                    leftSmaller = true;
                    break;
                }
            }
            for (int k = j + 1; k < n; k++) {
                if (nums[k] > nums[j]) {
                    rightGreater = true;
                    break;
                }
            }
            if (leftSmaller && rightGreater) {
                return true;
            }
        }
        return false;
    }
}
```

## Greedy + Two Variables Tracking (Minimum Prefix Tracking)
```
class Solution {
    public boolean increasingTriplet(int[] nums) {
        int first = Integer.MAX_VALUE;
        int second = Integer.MAX_VALUE;
        
        for (int num : nums) {
            if (num <= first) {
                first = num;
            } else if (num <= second) {
                second = num;
            } else {
                return true; 
            }
        }
        return false;
    }
}
```
