# 3350. Adjacent Increasing Subarrays Detection II

## prefix/suffix increasing-length approach
``` 
class Solution {
    public int maxIncreasingSubarrays(List<Integer> nums) {
        int n = nums.size();
        int[] pref = new int[n];
        pref[0] = 1;
        for (int i = 1; i < n; i++) pref[i] = nums.get(i) > nums.get(i - 1) ? pref[i - 1] + 1 : 1;
        int[] start = new int[n];
        start[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) start[i] = nums.get(i + 1) > nums.get(i) ? start[i + 1] + 1 : 1;
        int ans = 0;
        for (int m = 0; m < n - 1; m++) ans = Math.max(ans, Math.min(pref[m], start[m + 1]));
        return ans;
    }
}
```

## Track consecutive increasing run lengths
```
class Solution {
    public int maxIncreasingSubarrays(List<Integer> nums) {
        int prev = 0;
        int curr = 1;
        int ans = 0;
        for (int i = 1; i < nums.size(); i++) {
            if (nums.get(i) > nums.get(i - 1)) {
                curr++;
            } else {
                ans = Math.max(ans, Math.max(curr / 2, Math.min(prev, curr)));
                prev = curr;
                curr = 1;
            }
        }
        ans = Math.max(ans, Math.max(curr / 2, Math.min(prev, curr)));
        return ans;
    }
}
```
