# 338. Counting Bits

## Problem Statement

Given an integer n, return an array ans of length n + 1 such that for each i (0 <= i <= n), ans[i] is the number of 1's in the binary representation of i.

## Sample Test Cases

Example 1:
```
Input: n = 2
Output: [0,1,1]
```
Explanation:
0 --> 0
1 --> 1
2 --> 10

Example 2:
```
Input: n = 5
Output: [0,1,1,2,1,2]
```
Explanation:
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101

---

## 1️⃣ Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Count 1's in binary for each number by dividing by 2.                   |
| **Approach**         | For each i, repeatedly divide by 2 and count remainders.                |
| **Time Complexity**  | O(n log n)                                                              |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public int[] countBits(int n) {
        int[] ans = new int[n + 1];
        for (int i = 0; i <= n; i++) {
            int count = 0;
            int num = i;
            while (num > 0) {
                count += num % 2;
                num = num / 2;
            }
            ans[i] = count;
        }
        return ans;
    }
}
```

---

## 2️⃣ Linear DP Solution

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use previously computed results: ans[i] = ans[i/2] + (i%2).             |
| **Approach**         | Dynamic programming, build up from 0.                                   |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public int[] countBits(int n) {
        int[] ans = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            ans[i] = ans[i / 2] + (i % 2);
        }
        return ans;
    }
}
```

---

## 3️⃣ Built-in Method Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use Java's built-in Integer.bitCount for each number.                   |
| **Approach**         | Call Integer.bitCount(i) for each i.                                    |
| **Time Complexity**  | O(n) (since bitCount is O(1) for 32 bits)                               |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public int[] countBits(int n) {
        int[] ans = new int[n + 1];
        for (int i = 0; i <= n; ++i) {
            ans[i] = Integer.bitCount(i);
        }
        return ans;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n log n)     | O(n)            | Simple, but not optimal.              |
| Linear DP               | O(n)           | O(n)            | Optimal, no built-ins needed.         |
| Built-in Method         | O(n)           | O(n)            | Fastest in practice, uses library.    |

---

## Summary

- Optimal Approach: Linear DP (O(n) time, O(n) space, no built-ins).
- Built-in method is fastest in practice for Java.
- Brute force is educational but not efficient for large n.
