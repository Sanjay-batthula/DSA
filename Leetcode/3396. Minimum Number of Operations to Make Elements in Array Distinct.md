# 3396. Minimum Number of Operations to Make Elements in Array Distinct

## Reverse Traversal with HashSet for First Duplicate Detection
```
class Solution {
    public int minimumOperations(int[] nums) {
        Set<Integer> s = new HashSet<>();
        for (int i = nums.length - 1; i >= 0; --i) {
            if (!s.add(nums[i])) {
                return i / 3 + 1;
            }
        }
        return 0;
    }
}
```

## Progressive Prefix Removal with Distinct Check
```
class Solution {
    public int minimumOperations(int[] nums) {
        int n = nums.length;
        int[] freq = new int[101];
        int duplicates = 0;
        for (int num : nums) {
            if (freq[num] == 1) duplicates++;
            freq[num]++;
        }
        if (duplicates == 0) return 0;
        int operations = 0;
        int index = 0;
        while (index < n) {
            for (int i = 0; i < 3 && index < n; i++, index++) {
                if (freq[nums[index]] == 2) duplicates--;
                freq[nums[index]]--;
            }
            operations++;
            if (duplicates == 0) return operations;
        }
        return operations;
    }
}
```
