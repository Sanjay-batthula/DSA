## Brute Force Approach(Iterative Division)
```
class Solution {
    public boolean isPowerOfFour(int n) {
        if (n <= 0) return false;
        while (n % 4 == 0) {
            n /= 4;
        }
        return n == 1;
    }
}
```
## Bit Manipulation
```
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555) != 0;
    }
}
```

## Math-Based Approach - Wrong answer
```
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && (1073741824 % n == 0) && (n & (n - 1)) == 0;
    }
}
(or)
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && n % 3 == 1;
    }
}
```
