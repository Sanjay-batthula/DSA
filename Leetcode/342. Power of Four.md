# 342. Power of Four

## Problem Statement

Given an integer n, return true if it is a power of four. Otherwise, return false.

An integer n is a power of four if there exists an integer x such that n == 4^x.

## Sample Test Cases

Example 1:
```
Input: n = 16
Output: true
```

Example 2:
```
Input: n = 5
Output: false
```

Example 3:
```
Input: n = 1
Output: true
```

---

## 1️⃣ Brute Force (Iterative Division)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Keep dividing by 4; if you reach 1, it's a power of four.               |
| **Approach**         | Divide n by 4 until n becomes 1 or not divisible by 4.                  |
| **Time Complexity**  | O(log₄ n)                                                               |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfFour(int n) {
        if (n <= 0) return false;
        while (n % 4 == 0) {
            n /= 4;
        }
        return n == 1;
    }
}
```

---

## 2️⃣ Bit Manipulation

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Power of four is a power of two at an even position.                    |
| **Approach**         | n > 0, n is power of two, and only one bit set at even position.        |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && (n & (n - 1)) == 0 && (n & 0x55555555) != 0;
    }
}
```

---

## 3️⃣ Math-Based Approach (Not Recommended)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use divisibility or modulo properties.                                  |
| **Approach**         | Check if n divides 4^15 or n % 3 == 1.                                 |
| **Time Complexity**  | O(1)                                                                    |
| **Space Complexity** | O(1)                                                                    |
| **Note**             | May fail for some edge cases.                                           |

```
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && (1073741824 % n == 0) && (n & (n - 1)) == 0;
    }
}
// or
class Solution {
    public boolean isPowerOfFour(int n) {
        return n > 0 && n % 3 == 1;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(log₄ n)      | O(1)            | Simple and reliable.                  |
| Bit Manipulation        | O(1)           | O(1)            | Fastest and most elegant.             |
| Math-Based              | O(1)           | O(1)            | Not always reliable.                  |

---

## Summary

- Optimal Approach: Bit Manipulation (O(1) time, O(1) space).
- Brute force division is also reliable and easy to understand.
- Math-based approaches may fail for some edge cases.
