## Brute Force Approach (Extra Space)
```
class Solution {
    public void reverseString(char[] s) {
        char[] temp = new char[s.length];
        int j = 0;
        for (int i = s.length - 1; i >= 0; i--) {
            temp[j++] = s[i];
        }
        for (int i = 0; i < s.length; i++) {
            s[i] = temp[i];
        }
    }
}
```

## Two Pointer approach
```
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;
        while (left < right) {
            char temp = s[left];
            s[left++] = s[right];
            s[right--] = temp;
        }
    }
}
```
