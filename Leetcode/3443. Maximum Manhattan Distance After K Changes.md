# 3443. Maximum Manhattan Distance After K Changes

## Greedy Simulation
```java
class Solution {
    private char[] s;
    private int k;

    public int maxDistance(String s, int k) {
        this.s = s.toCharArray();
        this.k = k;
        int a = calc('S', 'E');
        int b = calc('S', 'W');
        int c = calc('N', 'E');
        int d = calc('N', 'W');
        return Math.max(Math.max(a, b), Math.max(c, d));
    }

    private int calc(char a, char b) {
        int ans = 0, mx = 0, cnt = 0;
        for (char c : s) {
            if (c == a || c == b) {
                ++mx;
            } else if (cnt < k) {
                ++mx;
                ++cnt;
            } else {
                --mx;
            }
            ans = Math.max(ans, mx);
        }
        return ans;
    }
}
```

## Prefix Greedy + Mathematical Counting
```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        directions = [
            {"N", "E"},
            {"N", "W"},
            {"S", "E"},
            {"S", "W"}
        ]
        ans = 0
        for good in directions:
            bad = 0
            for i, ch in enumerate(s, 1):
                if ch not in good:
                    bad += 1
                ans = max(ans, i - 2 * max(0, bad - k))
        return ans
```
