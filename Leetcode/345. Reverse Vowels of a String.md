# 345. Reverse Vowels of a String

## Problem Statement

Given a string `s`, reverse only all the vowels in the string and return it.

The vowels are 'a', 'e', 'i', 'o', and 'u', and they can appear in both lower and upper cases, more than once.

## Sample Test Cases

Example 1:
```
Input: s = "IceCreAm"
Output: "AceCreIm"
```
Explanation: The vowels in s are ['I', 'e', 'e', 'A']. On reversing the vowels, s becomes "AceCreIm".

Example 2:
```
Input: s = "leetcode"
Output: "leotcede"
```

---

## 1️⃣ Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Collect all vowels, then replace them in reverse order.                 |
| **Approach**         | Use a list to store vowels, then fill them back in reverse.             |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public String reverseVowels(String s) {
        ArrayList<Character> vowels = new ArrayList<>();
        char[] arr = s.toCharArray();
        for (char c : arr) {
            if (isVowel(c)) vowels.add(c);
        }
        int idx = vowels.size() - 1;
        for (int i = 0; i < arr.length; i++) {
            if (isVowel(arr[i])) {
                arr[i] = vowels.get(idx--);
            }
        }
        return new String(arr);
    }
    private boolean isVowel(char c) {
        return "aeiouAEIOU".indexOf(c) != -1;
    }
}
```

## 2️⃣ HashSet + Two Pointers

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use a set for fast vowel lookup, swap vowels from both ends.            |
| **Approach**         | Two pointers, swap vowels, use HashSet for O(1) lookup.                 |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1) (set size is constant)                                             |

```
class Solution {
    private static final Set<Character> vowels =
        new HashSet<>(Arrays.asList(
            'a','e','i','o','u','A','E','I','O','U'
        ));
    public String reverseVowels(String s) {
        char[] arr = s.toCharArray();
        int l = 0, r = arr.length - 1;
        while (l < r) {
            if (!vowels.contains(arr[l])) l++;
            else if (!vowels.contains(arr[r])) r--;
            else {
                char t = arr[l];
                arr[l] = arr[r];
                arr[r] = t;
                l++; r--;
            }
        }
        return new String(arr);
    }
}
```

## 3️⃣ Two Pointers with Helper

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use two pointers and a helper to check vowels.                          |
| **Approach**         | Move pointers inward, swap vowels, use helper for vowel check.          |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public String reverseVowels(String s) {
        int left = 0;
        int right = s.length() - 1;
        char[] arr = s.toCharArray();
        while (left < right) {
            if (!isVowel(arr[left])) {
                left++;
            } else if (!isVowel(arr[right])) {
                right--;
            } else {
                char temp = arr[left];
                arr[left] = arr[right];
                arr[right] = temp;
                left++;
                right--;
            }
        }
        return new String(arr);
    }
    private boolean isVowel(char c) {
        return "aeiouAEIOU".indexOf(c) != -1;
    }
}
```

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n)           | O(n)            | Simple, but uses extra space.         |
| HashSet + Two Pointers  | O(n)           | O(1)            | Fast lookup, optimal.                 |
| Two Pointers + Helper   | O(n)           | O(1)            | Clean and optimal.                    |

---

## Summary

- Optimal Approach: Two Pointers (O(n) time, O(1) space).
- HashSet version is fast for large alphabets.
- Brute force is simple but uses extra space.
