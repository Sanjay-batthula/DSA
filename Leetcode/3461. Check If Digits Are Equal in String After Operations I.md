
# 3461. Check If Digits Are Equal in String After Operations I

## Problem Statement

You are given a string `s` consisting of digits. Perform the following operation repeatedly until the string has exactly two digits:

- For each pair of consecutive digits in `s`, starting from the first digit, calculate a new digit as the sum of the two digits modulo 10.
- Replace `s` with the sequence of newly calculated digits, maintaining the order in which they are computed.

Return `true` if the final two digits in `s` are the same; otherwise, return `false`.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| s = "3902" | true | After operations, s becomes "11" |
| s = "34789" | false | After operations, s becomes "48" |

---

## Constraints

- $3 \leq \text{s.length} \leq 100$
- $\text{s}$ consists of only digits.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Simulate operations step by step | $O(n^2)$ | $O(n)$ |
| Combinatorial Math | Use binomial coefficients for final digits | $O(n^2)$ | $O(n)$ |
| Dynamic Programming | In-place simulation | $O(n^2)$ | $O(n)$ |
| Recursion | Recursive reduction | $O(n^2)$ | $O(n)$ |

---

## Code: Dynamic Programming Approach

```java
class Solution {
    public boolean hasSameDigits(String s) {
        int n = s.length();
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) arr[i] = s.charAt(i) - '0';
        while (n > 2) {
            for (int i = 0; i < n - 1; i++) {
                arr[i] = (arr[i] + arr[i + 1]) % 10;
            }
            n--;
        }
        return arr[0] == arr[1];
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public boolean hasSameDigits(String s) {
        List<Integer> digits = new ArrayList<>();
        for (char c : s.toCharArray()) {
            digits.add(c - '0');
        }
        while (digits.size() > 2) {
            List<Integer> next = new ArrayList<>();
            for (int i = 0; i < digits.size() - 1; i++) {
                next.add((digits.get(i) + digits.get(i + 1)) % 10);
            }
            digits = next;
        }
        return digits.get(0).equals(digits.get(1));
    }
}
```

### Combinatorial Mathematics
```java
class Solution {
    public boolean hasSameDigits(String s) {
        int n = s.length();
        int[] digits = new int[n];
        for (int i = 0; i < n; i++)
            digits[i] = s.charAt(i) - '0';
        int[] comb = new int[n];
        comb[0] = 1;
        for (int i = 1; i < n - 1; i++) {
            for (int j = i; j > 0; j--) {
                comb[j] = (comb[j] + comb[j - 1]) % 10;
            }
        }
        int left = 0, right = 0;
        for (int i = 0; i < n - 1; i++) {
            left = (left + comb[i] * digits[i]) % 10;
            right = (right + comb[i] * digits[i + 1]) % 10;
        }
        return left == right;
    }
}
```

### Recursion
```java
class Solution {
    public boolean hasSameDigits(String s) {
        if (s.length() == 2) return s.charAt(0) == s.charAt(1);
        StringBuilder next = new StringBuilder();
        for (int i = 0; i < s.length() - 1; i++) {
            int val = (s.charAt(i) - '0' + s.charAt(i + 1) - '0') % 10;
            next.append(val);
        }
        return hasSameDigits(next.toString());
    }
}
```

## Summary

- Simulate the digit reduction process until two digits remain.
- Compare the final two digits for equality.
- Multiple approaches: brute force, combinatorial, DP, recursion.
