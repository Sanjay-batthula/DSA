# 3477. Fruits Into Baskets II

## Greedy First-Fit approach
```
class Solution {
    public int numOfUnplacedFruits(int[] fruits, int[] baskets) {
        boolean[] used = new boolean[baskets.length];
        int count = 0;
        for (int fruit : fruits) {
            boolean placed = false;
            for (int j = 0; j < baskets.length; j++) {
                if (!used[j] && baskets[j] >= fruit) {
                    used[j] = true;
                    placed = true;
                    break;
                }
            }
            if (!placed) count++;
        }
        return count;
    }
}
```

## Greedy with Ordered Map / Multiset
```
import java.util.*;

class Solution {
    public int numOfUnplacedFruits(int[] fruits, int[] baskets) {
        TreeMap<Integer,Integer> map = new TreeMap<>();
        for(int b : baskets){
            map.put(b, map.getOrDefault(b,0)+1);
        }
        int count = 0;
        for(int f : fruits){
            Integer key = map.ceilingKey(f);
            if(key==null){
                count++;
            }else{
                int c = map.get(key);
                if(c==1) map.remove(key);
                else map.put(key,c-1);
            }
        }
        return count;
    }
}
```
