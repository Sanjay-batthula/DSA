
# 3487. Maximum Unique Subarray Sum After Deletion

## Problem Statement

You are given an integer array `nums`.

You are allowed to delete any number of elements from `nums` without making it empty. After performing the deletions, select a subarray of `nums` such that:

- All elements in the subarray are unique.
- The sum of the elements in the subarray is maximized.

Return the maximum sum of such a subarray.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [1,2,3,4,5] | 15 | Select entire array |
| nums = [1,1,0,1,1] | 1 | Delete all but one 1 |
| nums = [1,2,-1,-2,1,0,-1] | 3 | Delete negatives, select [2,1] |

---

## Constraints

- $1 \leq \text{nums.length} \leq 100$
- $-100 \leq \text{nums}[i] \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Greedy Subset Selection | Pick all positive unique elements | $O(n)$ | $O(n)$ |
| Sliding Window | Max sum subarray with unique elements | $O(n)$ | $O(n)$ |
| Frequency Map | Use frequency array for unique positive sum | $O(n)$ | $O(n)$ |

---

## Code: Greedy Subset Selection

```java
class Solution {
    public int maxSum(int[] nums) {
        int mx = Arrays.stream(nums).max().getAsInt();
        if (mx <= 0) {
            return mx;
        }
        boolean[] s = new boolean[201];
        int ans = 0;
        for (int x : nums) {
            if (x < 0 || s[x]) {
                continue;
            }
            ans += x;
            s[x] = true;
        }
        return ans;
    }
}
```

## Other Approaches

### Sliding Window (Wrong Answer)
```java
class Solution {
    public int maxSum(int[] nums) {
        int n = nums.length;
        int l = 0;
        int sum = 0;
        int ans = Integer.MIN_VALUE;
        HashSet<Integer> set = new HashSet<>();
        for (int r = 0; r < n; r++) {
            while (set.contains(nums[r])) {
                set.remove(nums[l]);
                sum -= nums[l];
                l++;
            }
            set.add(nums[r]);
            sum += nums[r];
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```

### Frequency Map + Positive Unique Sum
```java
class Solution {
    public int maxSum(int[] nums) {
        int[] freq = new int[201];
        int mx = -101;
        for (int x : nums) {
            freq[x + 100]++;
            mx = Math.max(mx, x);
        }
        if (mx <= 0) return mx;
        int ans = 0;
        for (int i = 101; i <= 200; i++) {
            if (freq[i] > 0) ans += i - 100;
        }
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Greedy Subset Selection | $O(n)$ | $O(n)$ | Simple, works for positive unique |
| Sliding Window | $O(n)$ | $O(n)$ | Fails for negative values |
| Frequency Map | $O(n)$ | $O(n)$ | Handles negatives, unique sum |

---

## Summary

- Delete elements to maximize unique positive sum.
- Greedy subset selection is optimal for this problem.
