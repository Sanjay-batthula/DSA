# 3487. Maximum Unique Subarray Sum After Deletion

## Greedy subset selection
```
class Solution {
    public int maxSum(int[] nums) {
        int mx = Arrays.stream(nums).max().getAsInt();
        if (mx <= 0) {
            return mx;
        }
        boolean[] s = new boolean[201];
        int ans = 0;
        for (int x : nums) {
            if (x < 0 || s[x]) {
                continue;
            }
            ans += x;
            s[x] = true;
        }
        return ans;
    }
}
```

## Maximum sum subarray with unique elements
```
class Solution {
    public int maxSum(int[] nums) {
        int n = nums.length;
        int l = 0;
        int sum = 0;
        int ans = Integer.MIN_VALUE;
        HashSet<Integer> set = new HashSet<>();

        for (int r = 0; r < n; r++) {
            while (set.contains(nums[r])) {
                set.remove(nums[l]);
                sum -= nums[l];
                l++;
            }
            set.add(nums[r]);
            sum += nums[r];
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```
