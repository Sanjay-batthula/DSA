


# 35. Search Insert Position

## Problem Statement

Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with $O(\log n)$ runtime complexity.

---

## Sample Test Cases

| Input                        | Output |
|------------------------------|--------|
| nums = [1,3,5,6], target = 5 | 2      |
| nums = [1,3,5,6], target = 2 | 1      |
| nums = [1,3,5,6], target = 7 | 4      |

---

## Constraints

- $1 \leq \text{nums.length} \leq 10^4$
- $-10^4 \leq \text{nums}[i] \leq 10^4$
- `nums` contains distinct values sorted in ascending order.
- $-10^4 \leq \text{target} \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Linear scan for insertion point | $O(n)$ | $O(1)$ |
| Binary Search | Iterative binary search for insertion point | $O(\log n)$ | $O(1)$ |
| Built-in | Use Arrays.binarySearch | $O(\log n)$ | $O(1)$ |
| Recursive | Recursive binary search | $O(\log n)$ | $O(\log n)$ |

---

## Code: Iterative Binary Search

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int l = 0, r = nums.length;
        while (l < r) {
            int mid = (l + r) >>> 1;
            if (nums[mid] >= target) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        return l;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] >= target) {
                return i;
            }
        }
        return nums.length;
    }
}
```

### Using Arrays.binarySearch (Built-in Java)
```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int pos = Arrays.binarySearch(nums, target);
        return pos >= 0 ? pos : -(pos + 1);
    }
}
```

### Recursive Binary Search
```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        return fun(nums, target, 0, nums.length - 1);
    }
    int fun(int[] a, int t, int l, int r) {
        if (l > r) return l;
        int m = l + (r - l) / 2;
        if (a[m] == t) return m;
        if (a[m] > t) return fun(a, t, l, m - 1);
        return fun(a, t, m + 1, r);
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(1)$ | Simple, but not optimal |
| Binary Search | $O(\log n)$ | $O(1)$ | Optimal for sorted arrays |
| Built-in | $O(\log n)$ | $O(1)$ | Java's Arrays.binarySearch |
| Recursive | $O(\log n)$ | $O(\log n)$ | Elegant, but uses stack |

---

## Summary

- Use binary search to efficiently find the insertion position for a target in a sorted array.
- Brute force is simple but not efficient for large arrays.
- Java's built-in binary search is concise and reliable.
