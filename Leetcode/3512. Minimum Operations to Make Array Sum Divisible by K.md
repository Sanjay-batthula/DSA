# 3512. Minimum Operations to Make Array Sum Divisible by K

## Greedy + Min Heap on remainders
```
class Solution {
    public int minOperations(int[] nums, int k) {
        int s=0;
        for(int num:nums) s+=num;
        int r=s%k;
        if(r==0) return 0;
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for(int num:nums) pq.add(num %k);
        int ops = 0;
        while(!pq.isEmpty() && r!=0){
            int mod=pq.poll();
            if(mod==0) continue;
            int diff = Math.min(mod,r);
            r-=diff;
            ops+=diff;
        }
        return ops;
    }
}
```

## Global invariant optimization
```
class Solution {
    public int minOperations(int[] nums, int k) {
        int sum = 0;
        for (int num : nums) sum += num;
        return sum % k;
    }
}
```
