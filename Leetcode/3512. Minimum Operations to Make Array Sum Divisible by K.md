# 3512. Minimum Operations to Make Array Sum Divisible by K

## Problem Statement

You are given an integer array $nums$ and an integer $k$. You can perform the following operation any number of times:

Select an index $i$ and replace $nums[i]$ with $nums[i] - 1$.

Return the minimum number of operations required to make the sum of the array divisible by $k$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums = [3,9,7], k = 5 | 4 | Decrement nums[1] by 4 to get sum 15 |
| nums = [4,1,3], k = 4 | 0 | Sum is already divisible by 4 |
| nums = [3,2], k = 6 | 5 | Decrement both to 0 for sum 0 |

---

## Constraints

- $1 \leq nums.length \leq 1000$
- $1 \leq nums[i] \leq 1000$
- $1 \leq k \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Greedy + Heap | Use min-heap on remainders | $O(n \log n)$ | $O(n)$ |
| Math | Use sum % k | $O(n)$ | $O(1)$ |

---

## Code: Greedy + Min Heap on Remainders

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use min-heap on remainders | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int s=0;
        for(int num:nums) s+=num;
        int r=s%k;
        if(r==0) return 0;
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        for(int num:nums) pq.add(num %k);
        int ops = 0;
        while(!pq.isEmpty() && r!=0){
            int mod=pq.poll();
            if(mod==0) continue;
            int diff = Math.min(mod,r);
            r-=diff;
            ops+=diff;
        }
        return ops;
    }
}
```

## Code: Global Invariant Optimization

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use sum % k | $O(n)$ | $O(1)$ |

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int sum = 0;
        for (int num : nums) sum += num;
        return sum % k;
    }
}
```

## Summary
- The minimum operations is simply $sum \% k$ for this problem.
