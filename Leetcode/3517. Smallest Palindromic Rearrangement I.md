# 3517. Smallest Palindromic Rearrangement I

## greedy frequency-counting
```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        from collections import Counter
        c,mid=Counter(s), ''
        half=''.join(k*(v//2)for k,v in sorted (c.items()))
        for k,v in sorted(c.items()):
            if v % 2: mid=k; break
        return half + mid + half[::-1]
        
```

## Greedy + Frequency Array
```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        freq = [0] * 26
        for ch in s:
            freq[ord(ch) - ord('a')] += 1
        left = []
        mid = ""
        for i in range(26):
            left.append(chr(i + ord('a')) * (freq[i] // 2))
            if freq[i] % 2:
                mid = chr(i + ord('a'))
        left = "".join(left)
        return left + mid + left[::-1]
```
