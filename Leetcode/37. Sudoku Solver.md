
# 37. Sudoku Solver

## Problem Statement

Write a program to solve a Sudoku puzzle by filling the empty cells.

A sudoku solution must satisfy all of the following rules:
- Each of the digits 1-9 must occur exactly once in each row.
- Each of the digits 1-9 must occur exactly once in each column.
- Each of the digits 1-9 must occur exactly once in each of the 9 3x3 sub-boxes of the grid.
The '.' character indicates empty cells.

## Constraints

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` is a digit or '.'
- It is guaranteed that the input board has only one solution.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Backtracking | Try all possibilities recursively, filling empty cells | $O(9^{81})$ worst-case | $O(1)$ |
| Brute Force | Try every possible number for every cell | $O(9^{81})$ | $O(1)$ |

---

## Code: Backtracking

```java
class Solution {
    public void solveSudoku(char[][] board) {
        solve(board);
    }

    private boolean solve(char[][] board) {
        for (int row = 0; row < 9; row++) {
            for (int col = 0; col < 9; col++) {
                if (board[row][col] == '.') {
                    for (char num = '1'; num <= '9'; num++) {
                        if (isValid(board, row, col, num)) {
                            board[row][col] = num;
                            if (solve(board)) return true;
                            board[row][col] = '.';
                        }
                    }
                    return false;
                }
            }
        }
        return true;
    }

    private boolean isValid(char[][] board, int row, int col, char c) {
        for (int i = 0; i < 9; i++) {
            if (board[row][i] == c) return false;
            if (board[i][col] == c) return false;
            int subRow = 3 * (row / 3) + i / 3;
            int subCol = 3 * (col / 3) + i % 3;
            if (board[subRow][subCol] == c) return false;
        }
        return true;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public void solveSudoku(char[][] board) {
        brute(board);
    }

    private boolean brute(char[][] board) {
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') {
                    for (char c = '1'; c <= '9'; c++) {
                        if (valid(board, i, j, c)) {
                            board[i][j] = c;
                            if (brute(board)) return true;
                            board[i][j] = '.';
                        }
                    }
                    return false;
                }
            }
        }
        return true;
    }

    private boolean valid(char[][] b, int r, int c, char x) {
        for (int i = 0; i < 9; i++) {
            if (b[r][i] == x) return false;
            if (b[i][c] == x) return false;
        }
        int sr = (r/3)*3, sc = (c/3)*3;
        for (int i = sr; i < sr+3; i++)
            for (int j = sc; j < sc+3; j++)
                if (b[i][j] == x) return false;
        return true;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Backtracking | $O(9^{81})$ | $O(1)$ | Optimal for guaranteed solution |
| Brute Force | $O(9^{81})$ | $O(1)$ | Not practical, but similar to backtracking |

---

## Summary

- Use backtracking to fill empty cells, checking validity for each placement.
- The problem guarantees a unique solution, so backtracking will always succeed.
- Brute force is not practical, but backtracking is efficient for this problem due to constraint guarantees.
