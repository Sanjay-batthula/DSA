# Sudoku Solver 🧩

## Intuition

The Sudoku puzzle is a **constraint satisfaction problem**. Each cell must contain a digit from `1–9`, and every row, column, and `3x3` subgrid must contain unique digits.
Backtracking is a natural choice:

* Place a number in an empty cell.
* Check if it is valid.
* Recursively solve the rest of the board.
* If no valid number can be placed, backtrack.

---

## Approach

1. Traverse the board cell by cell.
2. When an empty cell `'.'` is found, try placing digits `1–9`.
3. Use a helper function `isValid` to check:

   * If the digit already exists in the same row.
   * If the digit already exists in the same column.
   * If the digit already exists in the `3x3` subgrid.
4. If valid, place the number and recursively solve the next cells.
5. If a dead end is reached, reset the cell (`'.'`) and backtrack.
6. Continue until the board is completely filled.

---

## Complexity

* **Time Complexity:**
  Worst case is exponential, since each empty cell has up to 9 possibilities. Rough upper bound:

  $$
  O(9^{m})
  $$

  where `m` = number of empty cells.
  With pruning, it runs efficiently for 9×9 boards.

* **Space Complexity:**

  $$
  O(1)
  $$

  (Only recursion stack; board is modified in-place).

---

## Code

```java
class Solution {
    public void solveSudoku(char[][] board) {
        solve(board);
    }

    private boolean solve(char[][] board) {
        for (int row = 0; row < 9; row++) {
            for (int col = 0; col < 9; col++) {
                if (board[row][col] == '.') {
                    for (char num = '1'; num <= '9'; num++) {
                        if (isValid(board, row, col, num)) {
                            board[row][col] = num;
                            if (solve(board)) return true;
                            board[row][col] = '.';
                        }
                    }
                    return false;
                }
            }
        }
        return true;
    }

    private boolean isValid(char[][] board, int row, int col, char c) {
        for (int i = 0; i < 9; i++) {
            if (board[row][i] == c) return false;
            if (board[i][col] == c) return false;
            int subRow = 3 * (row / 3) + i / 3;
            int subCol = 3 * (col / 3) + i % 3;
            if (board[subRow][subCol] == c) return false;
        }
        return true;
    }
}
```
