## Brute Force-TLE
```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        for (int i = 1; i <= n; i++) {
            if (guess(i) == 0) return i;
        }
        return -1;
    }
}
```


## Recursive Brute Force approach- Runtime Error
```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        return bruteForceGuess(1, n);
    }

    private int bruteForceGuess(int current, int n) {
        if (current > n) return -1;
        if (guess(current) == 0) return current;
        return bruteForceGuess(current + 1, n);
    }
}
```

## Tail recursion-TLE
```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        return helper(1, n);
    }

    private int helper(int current, int n) {
        while (current <= n) {
            if (guess(current) == 0) return current;
            current++;
        }
        return -1;
    }
}
```
