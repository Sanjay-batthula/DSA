# 374. Guess Number Higher or Lower

## Problem Statement

We are playing the Guess Game. The game is as follows:

I pick a number from 1 to n. You have to guess which number I picked (the number I picked stays the same throughout the game).

Every time you guess wrong, I will tell you whether the number I picked is higher or lower than your guess.

You call a pre-defined API int guess(int num), which returns three possible results:
- -1: Your guess is higher than the number I picked (i.e. num > pick).
- 1: Your guess is lower than the number I picked (i.e. num < pick).
- 0: your guess is equal to the number I picked (i.e. num == pick).

Return the number that I picked.

## Sample Test Cases

Example 1:
```
Input: n = 10, pick = 6
Output: 6
```

Example 2:
```
Input: n = 1, pick = 1
Output: 1
```

Example 3:
```
Input: n = 2, pick = 1
Output: 1
```

---

## 1️⃣ Brute Force (TLE)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Try every number from 1 to n.                                           |
| **Approach**         | Linear search from 1 to n.                                              |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        for (int i = 1; i <= n; i++) {
            if (guess(i) == 0) return i;
        }
        return -1;
    }
}
```

---

## 2️⃣ Recursive Brute Force (Runtime Error)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use recursion to try every number.                                      |
| **Approach**         | Recursively check each number from 1 to n.                              |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n) (recursion stack)                                                  |

```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        return bruteForceGuess(1, n);
    }
    private int bruteForceGuess(int current, int n) {
        if (current > n) return -1;
        if (guess(current) == 0) return current;
        return bruteForceGuess(current + 1, n);
    }
}
```

---

## 3️⃣ Binary Search (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use binary search to minimize the number of guesses.                    |
| **Approach**         | Adjust search range based on guess API result.                          |
| **Time Complexity**  | O(log n)                                                                |
| **Space Complexity** | O(1)                                                                    |

```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        int left = 1, right = n;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            int res = guess(mid);
            if (res == 0) return mid;
            else if (res < 0) right = mid - 1;
            else left = mid + 1;
        }
        return -1;
    }
}
```

---

## 4️⃣ Tail Recursion (TLE)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use tail recursion to try every number.                                 |
| **Approach**         | Recursively increment current until found.                              |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n) (recursion stack)                                                  |

```
public class Solution extends GuessGame {
    public int guessNumber(int n) {
        return helper(1, n);
    }
    private int helper(int current, int n) {
        while (current <= n) {
            if (guess(current) == 0) return current;
            current++;
        }
        return -1;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n)           | O(1)            | TLE for large n.                      |
| Recursive Brute Force   | O(n)           | O(n)            | Stack overflow for large n.           |
| Binary Search           | O(log n)       | O(1)            | Optimal and efficient.                |
| Tail Recursion          | O(n)           | O(n)            | TLE and stack overflow for large n.   |

---

## Summary

- Optimal Approach: Binary Search (O(log n) time, O(1) space).
- Brute force and recursion are educational but not practical for large n.
