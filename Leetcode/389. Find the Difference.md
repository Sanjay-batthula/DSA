# 389. Find the Difference

## Problem Statement

You are given two strings `s` and `t`.

String `t` is generated by random shuffling string `s` and then add one more letter at a random position.

Return the letter that was added to `t`.

## Sample Test Cases

Example 1:
```
Input: s = "abcd", t = "abcde"
Output: "e"
```
Explanation: 'e' is the letter that was added.

Example 2:
```
Input: s = "", t = "y"
Output: "y"
```

---

## 1️⃣ Brute Force (Wrong Answer for Duplicates)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Remove each character of `t` from `s`; the leftover is the answer.     |
| **Approach**         | Use StringBuilder to remove matched characters.                         |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |
| **Note**             | Fails if `s` has duplicate characters.                                  |

```
class Solution {
    public char findTheDifference(String s, String t) {
        StringBuilder sb = new StringBuilder(s);
        for (int i = 0; i < t.length(); i++) {
            char c = t.charAt(i);
            int idx = sb.indexOf(String.valueOf(c));
            if (idx == -1) return c;
            sb.deleteCharAt(idx);
        }
        return ' ';
    }
}
```

---

## 2️⃣ XOR Trick (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | XOR cancels out matching characters, leaving the extra one.             |
| **Approach**         | XOR all characters in `s` and `t`; result is the added character.       |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public char findTheDifference(String s, String t) {
        char ans = 0;
        for (char c : s.toCharArray()) ans ^= c;
        for (char c : t.toCharArray()) ans ^= c;
        return ans;
    }
}
```

---

## 3️⃣ ASCII Sum Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | The sum of ASCII values in `t` minus `s` gives the extra character.     |
| **Approach**         | Sum all ASCII values in `s` and `t`, subtract to find the answer.       |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public char findTheDifference(String s, String t) {
        int sumS = 0, sumT = 0;
        for (char c : s.toCharArray()) sumS += c;
        for (char c : t.toCharArray()) sumT += c;
        return (char)(sumT - sumS);
    }
}
```

---

## 4️⃣ Frequency Count Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Count frequency of each character in `s` and `t`, find the one with +1. |
| **Approach**         | Use an array to count and compare frequencies.                          |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1) (since alphabet size is constant)                                  |

```
class Solution {
    public char findTheDifference(String s, String t) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) freq[c - 'a']++;
        for (char c : t.toCharArray()) {
            freq[c - 'a']--;
            if (freq[c - 'a'] < 0) return c;
        }
        return ' ';
    }
}
```

---

## 5️⃣ Sorting-Based Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | After sorting, the first mismatch is the extra character.               |
| **Approach**         | Sort both strings, compare character by character.                      |
| **Time Complexity**  | O(n log n)                                                              |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public char findTheDifference(String s, String t) {
        char[] arrS = s.toCharArray();
        char[] arrT = t.toCharArray();
        Arrays.sort(arrS);
        Arrays.sort(arrT);
        for (int i = 0; i < arrS.length; i++) {
            if (arrS[i] != arrT[i]) return arrT[i];
        }
        return arrT[arrT.length - 1];
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n^2)         | O(n)            | Fails for duplicates.                 |
| XOR Trick               | O(n)           | O(1)            | Optimal and elegant.                  |
| ASCII Sum               | O(n)           | O(1)            | Simple and effective.                 |
| Frequency Count         | O(n)           | O(1)            | Robust for all cases.                 |
| Sorting                 | O(n log n)     | O(n)            | Clean, but slower.                    |

---

## Summary

- Optimal Approach: XOR Trick or Frequency Count (O(n) time, O(1) space).
- ASCII sum is also simple and effective.
- Brute force and sorting are less efficient.
