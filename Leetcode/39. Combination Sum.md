
# 39. Combination Sum

## Problem Statement

Given an array of distinct integers `candidates` and a target integer `target`, find all unique combinations of `candidates` where the chosen numbers sum to `target`. Each number in `candidates` may be used an unlimited number of times.

Return a list of all unique combinations. The same number may be chosen from `candidates` an unlimited number of times. Combinations should be returned in any order.

---

## Sample Test Cases

| Input                        | Output                                  |
|------------------------------|------------------------------------------|
| candidates = [2,3,6,7], target = 7 | [[7],[2,2,3]]                        |
| candidates = [2,3,5], target = 8   | [[2,2,2,2],[2,3,3],[3,5]]            |
| candidates = [2], target = 1       | []                                   |

---

## Constraints

- $1 \leq \text{candidates.length} \leq 30$
- $1 \leq \text{candidates}[i] \leq 200$
- All elements of `candidates` are distinct.
- $1 \leq \text{target} \leq 500$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Backtracking | Recursively build combinations, try each candidate repeatedly | $O(2^t)$ | $O(t)$ |
| DP (not shown) | Dynamic programming to build up combinations | $O(n \cdot t)$ | $O(n \cdot t)$ |

---

## Code: Backtracking

```java
import java.util.*;

class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }

    private void backtrack(int[] candidates, int target, int index, List<Integer> curr, List<List<Integer>> res) {
        if (target == 0) {
            res.add(new ArrayList<>(curr));
            return;
        }
        if (target < 0) return;

        for (int i = index; i < candidates.length; i++) {
            curr.add(candidates[i]);
            backtrack(candidates, target - candidates[i], i, curr, res);
            curr.remove(curr.size() - 1);
        }
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Backtracking | $O(2^t)$ | $O(t)$ | Simple, flexible, exponential |
| DP | $O(n \cdot t)$ | $O(n \cdot t)$ | Not shown, but can optimize for large inputs |

---

## Summary

- Use backtracking to explore all possible combinations, allowing repeated use of each candidate.
- Prune paths where the sum exceeds the target.
- DP can be used for optimization, but backtracking is most common for interview settings.
