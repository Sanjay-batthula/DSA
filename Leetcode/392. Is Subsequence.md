# 392. Is Subsequence

## Problem Statement

Given two strings s and t, return true if s is a subsequence of t, or false otherwise.

A subsequence of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (i.e., "ace" is a subsequence of "abcde" while "aec" is not).

## Sample Test Cases

Example 1:
```
Input: s = "abc", t = "ahbgdc"
Output: true
```

Example 2:
```
Input: s = "axc", t = "ahbgdc"
Output: false
```

---

## 1️⃣ Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | For each character in s, scan t to find it in order.                    |
| **Approach**         | Use a pointer to scan t for each character in s.                        |
| **Time Complexity**  | O(n * m) (n = s.length, m = t.length)                                   |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isSubsequence(String s, String t) {
        int indexT = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            boolean found = false;
            while (indexT < t.length()) {
                if (t.charAt(indexT) == c) {
                    found = true;
                    indexT++;
                    break;
                }
                indexT++;
            }
            if (!found) return false;
        }
        return true;
    }
}
```

---

## 2️⃣ Two-Pointer Approach (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use two pointers to scan both strings in one pass.                      |
| **Approach**         | Move both pointers forward when characters match.                       |
| **Time Complexity**  | O(m) (m = t.length)                                                     |
| **Space Complexity** | O(1)                                                                    |

```
class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0, j = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) i++;
            j++;
        }
        return i == s.length();
    }
}
```

---

## 3️⃣ Recursion

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Recursively check if s is a subsequence of t.                           |
| **Approach**         | Base case: s is empty (true) or t is empty (false).                     |
| **Time Complexity**  | O(n * m) (worst case, due to recursion stack)                           |
| **Space Complexity** | O(n) (recursion stack)                                                  |

```
class Solution {
    public boolean isSubsequence(String s, String t) {
        return helper(s, t, 0, 0);
    }
    private boolean helper(String s, String t, int i, int j) {
        if (i == s.length()) return true;
        if (j == t.length()) return false;
        if (s.charAt(i) == t.charAt(j)) {
            return helper(s, t, i + 1, j + 1);
        } else {
            return helper(s, t, i, j + 1);
        }
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n * m)       | O(1)            | Simple, but not optimal.              |
| Two-Pointer             | O(m)           | O(1)            | Optimal and efficient.                |
| Recursion               | O(n * m)       | O(n)            | Elegant, but uses stack space.        |

---

## Summary

- Optimal Approach: Two-Pointer (O(m) time, O(1) space).
- Brute force and recursion are educational but not practical for large inputs.
