# 394. Decode String

## Problem Statement

Given an encoded string, return its decoded string. A pattern of the form `k[encoded_string]` means that `encoded_string` is repeated exactly `k` times. Encoded patterns may be nested.

The input is guaranteed to be valid. It contains lowercase English letters, digits used only for repeat counts, and square brackets. The decoded output length does not exceed `10^5`.

## Sample Test Cases

### Example 1

```text
Input: s = "3[a]2[bc]"
Output: "aaabcbc"
```

### Example 2

```text
Input: s = "3[a2[c]]"
Output: "accaccacc"
```

### Example 3

```text
Input: s = "2[abc]3[cd]ef"
Output: "abcabccdcdcdef"
```

## Brute Force: Expand Innermost Brackets

| Section | Details |
|---|---|
| **Intuition** | Decode an innermost bracketed section first, since it contains no other encoded sections. |
| **Approach** | Find the next closing bracket and its matching opening bracket, read the repeat count immediately before it, replace that section with its repeated contents, and continue until no opening brackets remain. |
| **Time Complexity** | `O(mD)` in the worst case, where `m` is the encoded input length and `D` is the decoded output length. Repeated scans and string reconstruction can revisit much of the growing string for each bracket pair. |
| **Space Complexity** | `O(D + m)` for the growing string and temporary strings. |

This approach uses repeated whole-string searches and reconstructions, so it can be much slower than processing the input once.

```java
class Solution {
    public String decodeString(String s) {
        while (s.contains("[")) {
            int close = s.indexOf("]");
            int open = s.lastIndexOf("[", close);
            int k = open - 1;
            while (k >= 0 && Character.isDigit(s.charAt(k))) {
                k--;
            }
            int repeat = Integer.parseInt(s.substring(k + 1, open));
            String expanded = s.substring(open + 1, close).repeat(repeat);
            s = s.substring(0, k + 1) + expanded + s.substring(close + 1);
        }
        return s;
    }
}
```

## Stack-Based Iterative Approach ✅

| Section | Details |
|---|---|
| **Intuition** | Each opening bracket starts a nested decoding context. Save the text and repeat count from outside that context until its closing bracket is reached. |
| **Approach** | Accumulate digits into the repeat count. At `[`, push the current text and count, then start a new substring. At `]`, repeat the current substring and append it to the saved text. |
| **Time Complexity** | `O(m + D)`, where `m` is the encoded input length and `D` is the decoded output length. |
| **Space Complexity** | `O(m + D)` including the output and temporary strings; the stack stores nested context. |

```java
class Solution {
    public String decodeString(String s) {
        Stack<String> stack = new Stack<>();
        int number = 0;
        StringBuilder currentString = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (Character.isDigit(c)) {
                number = number * 10 + (c - '0');
            } else if (c == '[') {
                stack.push(currentString.toString());
                stack.push(Integer.toString(number));
                number = 0;
                currentString = new StringBuilder();
            } else if (c == ']') {
                String repeatCountStr = stack.pop();
                String previousString = stack.pop();
                int repeatCount = Integer.parseInt(repeatCountStr);
                StringBuilder repeatedString = new StringBuilder();
                for (int j = 0; j < repeatCount; j++) {
                    repeatedString.append(currentString);
                }
                currentString = new StringBuilder(previousString + repeatedString.toString());
            } else {
                currentString.append(c);
            }
        }

        return currentString.toString();
    }
}
```

## Recursive Approach

| Section | Details |
|---|---|
| **Intuition** | A bracketed substring can be decoded recursively using the same rules as the full input. |
| **Approach** | Share an index into the input. Read literal characters and repeat counts; on `[`, recursively decode the nested substring, append it the requested number of times, and return when `]` is reached. |
| **Time Complexity** | `O(m + D)`, where `m` is the encoded input length and `D` is the decoded output length. |
| **Space Complexity** | `O(m + D)` including recursive call frames and constructed strings. |

```java
class Solution {
    public String decodeString(String s) {
        return decode(s, new int[]{0});
    }

    private String decode(String s, int[] idx) {
        StringBuilder result = new StringBuilder();
        int num = 0;

        while (idx[0] < s.length()) {
            char c = s.charAt(idx[0]);

            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                idx[0]++;
                String sub = decode(s, idx);
                for (int i = 0; i < num; i++) result.append(sub);
                num = 0;
            } else if (c == ']') {
                break;
            } else {
                result.append(c);
            }

            idx[0]++;
        }

        return result.toString();
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|---|---|---|---|
| Expand innermost brackets | `O(mD)` worst case | `O(m + D)` | Repeatedly scans and rebuilds the encoded string. |
| Stack-based iterative | `O(m + D)` | `O(m + D)` including output and temporary strings | Processes the input iteratively and handles nesting with a stack. |
| Recursive | `O(m + D)` | `O(m + D)` including output and recursive state | Uses the call stack to handle nested sections. |

## Summary

- The iterative stack approach decodes each bracketed section when its closing bracket is reached.
- The recursive solution follows the nesting structure directly; both approaches build output proportional to its decoded length.
- Repeatedly replacing innermost sections is easier to follow but can rescan and reconstruct much of the string.
