# 416. Partition Equal Subset Sum

## Problem Statement

Given an integer array `nums`, return `true` if it can be partitioned into two subsets with equal sums; otherwise, return `false`.

The array contains 1 to 200 positive integers, each between 1 and 100.

## Sample Test Cases

### Example 1

```text
Input: nums = [1,5,11,5]
Output: true
```

The array can be partitioned into `[1,5,5]` and `[11]`, each with sum `11`.

### Example 2

```text
Input: nums = [1,2,3,5]
Output: false
```

The total sum is odd, so it cannot be split into two equal integer sums.

## 0/1 Knapsack: Bottom-Up 2D Dynamic Programming

| Section | Details |
|---|---|
| **Intuition** | If the total sum is even, the array can be partitioned equally exactly when some subset sums to half the total. |
| **Approach** | Let `f[i][j]` indicate whether a sum `j` can be formed from the first `i` values. For each value, either skip it or include it if the remaining sum was achievable using earlier values. |
| **Time Complexity** | `O(nT)`, where `n` is the number of values and `T` is half the total sum. |
| **Space Complexity** | `O(nT)` for the two-dimensional table. |

```java
class Solution {
    public boolean canPartition(int[] nums) {
        // int s = Arrays.stream(nums).sum();
        int s = 0;
        for (int x : nums) {
            s += x;
        }
        if (s % 2 == 1) {
            return false;
        }
        int n = nums.length;
        int m = s >> 1;
        boolean[][] f = new boolean[n + 1][m + 1];
        f[0][0] = true;
        for (int i = 1; i <= n; ++i) {
            int x = nums[i - 1];
            for (int j = 0; j <= m; ++j) {
                f[i][j] = f[i - 1][j] || (j >= x && f[i - 1][j - x]);
            }
        }
        return f[n][m];
    }
}
```

## 0/1 Knapsack: Space-Optimized Dynamic Programming ✅

| Section | Details |
|---|---|
| **Intuition** | The same subset-sum states can be stored in one array instead of keeping a row for every input element. |
| **Approach** | Set `dp[0]` to `true`. For each number, update sums from the target down to that number. Descending order ensures the current number is used at most once in this iteration. |
| **Time Complexity** | `O(nT)`, where `n` is the number of values and `T` is half the total sum. |
| **Space Complexity** | `O(T)` for the one-dimensional DP array. |

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (sum % 2 != 0) return false;
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int num : nums) {
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
        }
        return dp[target];
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|---|---|---|---|
| Bottom-up 2D DP | `O(nT)` | `O(nT)` | Stores achievable sums for each prefix of the array. |
| Space-optimized 1D DP | `O(nT)` | `O(T)` | Updates sums in descending order so each value is used at most once. |

Here, `n` is the number of values and `T` is half their total sum.

## Summary

- An odd total sum immediately rules out an equal partition.
- For an even total, the problem becomes checking whether a subset sums to half the total.
- The one-dimensional DP is preferred because descending updates preserve 0/1 usage with less space.
