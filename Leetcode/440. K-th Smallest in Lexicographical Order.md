# 440. K-th Smallest in Lexicographical Order

## Problem Statement

Given integers `n` and `k`, return the `k`th smallest integer in lexicographical order among the numbers from `1` to `n`.

The constraints are `1 <= k <= n <= 10^9`.

## Sample Test Cases

### Example 1

```text
Input: n = 13, k = 2
Output: 10
```

The lexicographical order is `[1,10,11,12,13,2,3,4,5,6,7,8,9]`.

### Example 2

```text
Input: n = 1, k = 1
Output: 1
```

## Prefix-Tree Traversal with Prefix Counting ✅

| Section | Details |
|---|---|
| **Intuition** | Numbers form a prefix tree in lexicographical order. Count how many numbers lie under the current prefix to skip an entire subtree when it contains fewer than the remaining positions. |
| **Approach** | Start at `1` and convert `k` to a zero-based number of steps. For each current prefix, use `countSteps` to count its subtree up to `n`. If that subtree fits within the remaining steps, move to the next sibling and subtract its size; otherwise descend to the first child and consume one step. |
| **Time Complexity** | `O((log n)^2)`; each prefix count examines `O(log n)` digit levels, and the traversal skips subtrees rather than visiting all preceding numbers. |
| **Space Complexity** | `O(1)` auxiliary space. |

```java
class Solution {
    public int findKthNumber(int n, int k) {
        int curr=1;
        k--; 
        while (k > 0) {
            long steps = countSteps(n, curr, curr + 1);
            if (steps <= k) {
                curr++;
                k -= steps;
            } else {
                curr *= 10;
                k--;
            }
        }
        return curr;
    }

    private long countSteps(int n, long n1, long n2) {
        long steps = 0;
        while (n1 <= n) {
            steps += Math.min(n + 1, n2) - n1;
            n1 *= 10;
            n2 *= 10;
        }
        return steps;
    }
}
```

## Summary

- The numbers from `1` to `n` can be viewed as a prefix tree whose preorder is lexicographical order.
- `countSteps` measures a prefix subtree's size, allowing the algorithm to skip it or descend into it.
- Using `long` for subtree boundaries prevents overflow while counting prefixes up to `n`.
