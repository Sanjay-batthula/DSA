# 443. String Compression

## Problem Statement

Compress the input character array in place by replacing each group of consecutive identical characters with the character followed by its count when the count is greater than one. Counts of 10 or more are written as individual digits. Return the length of the compressed prefix; characters after that prefix can be ignored.

The algorithm must use constant extra space. The array length is between 1 and 2000, and its characters may be letters, digits, or symbols.

## Sample Test Cases

### Example 1

```text
Input: chars = ["a","a","b","b","c","c","c"]
Output: 6
Compressed prefix: ["a","2","b","2","c","3"]
```

### Example 2

```text
Input: chars = ["a"]
Output: 1
Compressed prefix: ["a"]
```

### Example 3

```text
Input: chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
Output: 4
Compressed prefix: ["a","b","1","2"]
```

## Two Pointers: Read and Write ✅

| Section | Details |
|---|---|
| **Intuition** | Scan each group in the original array while writing its shorter representation into the array's prefix. |
| **Approach** | Use `read` to count each run of equal characters and `write` to store the run's character. If the count is greater than one, write each decimal digit of the count. Because the output prefix never extends beyond the consumed input, unread characters are preserved while scanning. |
| **Time Complexity** | `O(n)`, including the work to write count digits; each input character is read once. |
| **Space Complexity** | `O(1)` auxiliary space. |

```java
class Solution {
    public int compress(char[] chars) {
        int write = 0;
        int read = 0;
        while (read < chars.length) {
            char currentChar = chars[read];
            int count = 0;
            while (read < chars.length && chars[read] == currentChar) {
                read++;
                count++;
            }
            chars[write++] = currentChar;
            if (count > 1) {
                for (char digit : String.valueOf(count).toCharArray()) {
                    chars[write++] = digit;
                }
            }
        }
        return write;
    }
}
```

## Summary

- Count each consecutive run before writing its compressed form into the same array.
- Write the count only when it is greater than one, using one array character per decimal digit.
- The read/write pointer approach runs in `O(n)` time and uses `O(1)` auxiliary space.
