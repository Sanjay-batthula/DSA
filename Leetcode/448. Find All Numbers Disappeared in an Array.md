# 448. Find All Numbers Disappeared in an Array

## Problem Statement

Given an array nums of n integers where nums[i] is in the range [1, n], return an array of all the integers in the range [1, n] that do not appear in nums.

## Sample Test Cases

Example 1:
```
Input: nums = [4,3,2,7,8,2,3,1]
Output: [5,6]
```

Example 2:
```
Input: nums = [1,1]
Output: [2]
```

---

## 1️⃣ Brute Force (TLE)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | For each number from 1 to n, check if it exists in nums.                |
| **Approach**         | Nested loops to check for each number.                                  |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        List<Integer> res = new ArrayList<>();
        int n = nums.length;
        for (int i = 1; i <= n; i++) {
            boolean found = false;
            for (int num : nums) {
                if (num == i) {
                    found = true;
                    break;
                }
            }
            if (!found) res.add(i);
        }
        return res;
    }
}
```

---

## 2️⃣ In-Place Marking Approach (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Mark indices corresponding to seen numbers as negative.                  |
| **Approach**         | For each num, mark nums[abs(num)-1] negative. Collect indices with positive values.
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(1) (ignoring output list)                                             |

```
class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            int index = Math.abs(nums[i]) - 1;
            if (nums[index] > 0) {
                nums[index] = -nums[index];
            }
        }
        List<Integer> result = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 0) {
                result.add(i + 1);
            }
        }    
        return result;
    }
}
```

---

## 3️⃣ HashSet Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use a set to track all numbers present in nums.                         |
| **Approach**         | Add all nums to a set, then check for missing numbers from 1 to n.       |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int num : nums) set.add(num);
        List<Integer> res = new ArrayList<>();
        for (int i = 1; i <= nums.length; i++) {
            if (!set.contains(i)) res.add(i);
        }
        return res;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n^2)         | O(n)            | TLE for large n.                      |
| In-Place Marking        | O(n)           | O(1)            | Optimal, modifies input array.         |
| HashSet                 | O(n)           | O(n)            | Simple, but uses extra space.          |

---

## Summary

- Optimal Approach: In-Place Marking (O(n) time, O(1) space, modifies input array).
- HashSet is simple but uses extra space.
- Brute force is not practical for large n.
