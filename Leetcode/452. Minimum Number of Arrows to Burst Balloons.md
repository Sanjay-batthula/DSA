# 452. Minimum Number of Arrows to Burst Balloons

## Problem Statement

Balloons are represented by horizontal intervals `points[i] = [xstart, xend]`. A vertical arrow shot at coordinate `x` bursts a balloon when `xstart <= x <= xend`. Return the minimum number of arrows needed to burst all balloons.

There is at least one balloon. Each endpoint is in the range `[-2^31, 2^31 - 1]`, and each interval has `xstart < xend`.

## Sample Test Cases

### Example 1

```text
Input: points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
```

Arrows at `x = 6` and `x = 11` burst all balloons.

### Example 2

```text
Input: points = [[1,2],[3,4],[5,6],[7,8]]
Output: 4
```

### Example 3

```text
Input: points = [[1,2],[2,3],[3,4],[4,5]]
Output: 2
```

Arrows at `x = 2` and `x = 4` burst all balloons; intervals that touch at an endpoint can share an arrow.

## Greedy: Sort by End Coordinate ✅

| Section | Details |
|---|---|
| **Intuition** | Shooting at the end of the earliest-ending balloon bursts it and maximizes the chance that the same arrow also bursts overlapping balloons. |
| **Approach** | Sort intervals by end coordinate. Shoot at the current interval's end when its start lies beyond the last arrow position. Intervals whose start is at or before that position are already burst by the arrow. |
| **Time Complexity** | `O(n log n)` for sorting, followed by an `O(n)` scan. |
| **Space Complexity** | `O(log n)` auxiliary space for sorting in typical Java implementations. Sorting modifies the input array. |

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, Comparator.comparingInt(a -> a[1]));
        int ans = 0;
        long last = -(1L << 60);
        for (var p : points) {
            int a = p[0], b = p[1];
            if (a > last) {
                ++ans;
                last = b;
            }
        }
        return ans;
    }
}
```

## Greedy: Shrink the Common Intersection

| Section | Details |
|---|---|
| **Intuition** | Overlapping balloons can share an arrow if their intervals have a common point. |
| **Approach** | Sort by start coordinate and track the intersection of the current overlapping group. If the next interval starts after the intersection ends, the group needs another arrow; otherwise, shrink the intersection to the overlap with that interval. |
| **Time Complexity** | `O(n log n)` for sorting, followed by an `O(n)` scan. |
| **Space Complexity** | `O(log n)` auxiliary space for sorting in typical Java implementations. Sorting modifies the input array. |

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> Integer.compare(a[0], b[0]));
        int arrows = 1;
        int start = points[0][0];
        int end = points[0][1];
        for (int i = 1; i < points.length; i++) {
            if (points[i][0] <= end) {
                start = Math.max(start, points[i][0]);
                end = Math.min(end, points[i][1]);
            } else {
                arrows++;
                start = points[i][0];
                end = points[i][1];
            }
        }
        return arrows;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|---|---|---|---|
| Sort by end coordinate | `O(n log n)` | `O(log n)` typical sort auxiliary space | Places an arrow at each earliest available interval end. |
| Shrink common intersection | `O(n log n)` | `O(log n)` typical sort auxiliary space | Groups intervals that share a common point, including endpoints. |

## Summary

- Both solutions sort the intervals and greedily group balloons that can be burst by one arrow.
- The end-coordinate approach shoots at the earliest available end; the intersection approach tracks the shared range explicitly.
- Use `<=` for interval overlap so balloons touching at an endpoint can share an arrow.
