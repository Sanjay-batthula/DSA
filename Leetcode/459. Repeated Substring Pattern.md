# 459. Repeated Substring Pattern

## Problem Statement

Given a string `s`, check if it can be constructed by taking a substring of it and appending multiple copies of the substring together.

## Sample Test Cases

Example 1:
```
Input: s = "abab"
Output: true
```
Explanation: It is the substring "ab" twice.

Example 2:
```
Input: s = "aba"
Output: false
```

Example 3:
```
Input: s = "abcabcabcabc"
Output: true
```
Explanation: It is the substring "abc" four times or the substring "abcabc" twice.

---

## 1️⃣ Brute Force

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Try every possible substring length and check if repeating it forms s.   |
| **Approach**         | For each length, build the repeated string and compare.                  |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        for (int len = 1; len <= n / 2; len++) {
            if (n % len == 0) {
                String sub = s.substring(0, len);
                StringBuilder sb = new StringBuilder();
                int times = n / len;
                for (int i = 0; i < times; i++) sb.append(sub);
                if (sb.toString().equals(s)) return true;
            }
        }
        return false;
    }
}
```

---

## 2️⃣ String Doubling/Rotation Trick (Optimal)

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | If s is a repeated substring, it will appear in (s+s)[1:-1].            |
| **Approach**         | Check if s is in (s+s) with first and last char removed.                 |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        String str = s + s;
        return str.substring(1, str.length() - 1).contains(s);
    }
}
```

---

## 3️⃣ KMP Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use KMP prefix table to find repeating pattern.                         |
| **Approach**         | Build lps array, check if pattern length divides string length.          |
| **Time Complexity**  | O(n)                                                                    |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        int[] lps = new int[n];
        int len = 0, i = 1;
        while (i < n) {
            if (s.charAt(i) == s.charAt(len)) {
                lps[i++] = ++len;
            } else {
                if (len > 0) len = lps[len - 1];
                else lps[i++] = 0;
            }
        }
        int l = lps[n - 1];
        return l > 0 && n % (n - l) == 0;
    }
}
```

---

## 4️⃣ Regex Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Use regex to match repeated substrings.                                 |
| **Approach**         | Use pattern (.+)\1+ to check for repetition.                            |
| **Time Complexity**  | O(n^2) (regex engine)                                                   |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        return s.matches("(.+)\\1+");
    }
}
```

---

## 5️⃣ Divide & Check Approach

| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | For each possible length, check if all substrings match.                |
| **Approach**         | Use a helper to check all segments for equality.                        |
| **Time Complexity**  | O(n^2)                                                                  |
| **Space Complexity** | O(n)                                                                    |

```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        for (int len = 1; len <= n / 2; len++) {
            if (n % len == 0) {
                if (check(s, len)) {
                    return true;
                }
            }
        }
        return false;
    }
    private boolean check(String s, int len) {
        String sub = s.substring(0, len);
        for (int i = len; i < s.length(); i += len) {
            if (!s.startsWith(sub, i)) {
                return false; 
            }
        }
        return true;
    }
}
```

---

## Approach Comparison

| Approach                | Time Complexity | Space Complexity | Notes                                 |
| ----------------------- | -------------- | --------------- | ------------------------------------- |
| Brute Force             | O(n^2)         | O(n)            | Simple, but slow for large strings.   |
| String Doubling         | O(n)           | O(n)            | Optimal and elegant.                  |
| KMP                     | O(n)           | O(n)            | Fast, uses prefix table.              |
| Regex                   | O(n^2)         | O(n)            | Simple, but regex engine is slower.   |
| Divide & Check          | O(n^2)         | O(n)            | Clean, but not optimal.               |

---

## Summary

- Optimal Approach: String Doubling/Rotation Trick or KMP (O(n) time, O(n) space).
- Brute force and divide & check are educational but not efficient for large strings.
- Regex is simple but not optimal for performance.
