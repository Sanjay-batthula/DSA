# 494. Target Sum

## Problem Statement

Given an integer array `nums`, place either `+` or `-` before each number and count the expressions that evaluate to `target`.

The array contains 1 to 20 non-negative integers, each at most 1000. Their total sum is at most 1000, and `target` is between `-1000` and `1000`.

## Sample Test Cases

### Example 1

```text
Input: nums = [1,1,1,1,1], target = 3
Output: 5
```

There are five ways to assign signs so that the expression evaluates to `3`.

### Example 2

```text
Input: nums = [1], target = 1
Output: 1
```

## 0/1 Knapsack: Count Subsets (2D Dynamic Programming)

| Section | Details |
|---|---|
| **Intuition** | Let `P` be the sum of numbers assigned `+` and `N` the sum assigned `-`. Then `P - N = target` and `P + N = sum(nums)`, so the negative-sign numbers must sum to `(sum(nums) - target) / 2`. |
| **Approach** | Count subsets that sum to `(sum - target) / 2`. The table `f[i][j]` counts ways to make sum `j` using the first `i` numbers. For each number, add the ways that omit it and, when possible, the ways that include it. |
| **Time Complexity** | `O(nS)`, where `n` is the number of values and `S = (sum(nums) - target) / 2`, when the parity and range checks pass. |
| **Space Complexity** | `O(nS)` for the two-dimensional table. |

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int s = Arrays.stream(nums).sum();
        if (s < target || (s - target) % 2 != 0) {
            return 0;
        }
        int m = nums.length;
        int n = (s - target) / 2;
        int[][] f = new int[m + 1][n + 1];
        f[0][0] = 1;
        for (int i = 1; i <= m; ++i) {
            for (int j = 0; j <= n; ++j) {
                f[i][j] = f[i - 1][j];
                if (j >= nums[i - 1]) {
                    f[i][j] += f[i - 1][j - nums[i - 1]];
                }
            }
        }
        return f[m][n];
    }
}
```

## 0/1 Knapsack: Count Subsets (Space-Optimized 1D DP) ✅

| Section | Details |
|---|---|
| **Intuition** | The same subset-counting recurrence only needs the previous DP state, so it can be stored in one array. |
| **Approach** | Check that `sum - target` is non-negative and even, then let `S = (sum - target) / 2`. For each number, update sums from `S` down to that number so each input value is used at most once. A zero doubles each count, representing its two sign choices. |
| **Time Complexity** | `O(nS)`, where `n` is the number of values and `S = (sum(nums) - target) / 2`, when the parity and range checks pass. |
| **Space Complexity** | `O(S)` for the one-dimensional DP array. |

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) sum += num;
        if ((sum - target) % 2 != 0 || sum < Math.abs(target)) return 0;
        int s = (sum - target) / 2;
        int[] dp = new int[s + 1];
        dp[0] = 1;
        for (int num : nums) {
            for (int j = s; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        return dp[s];
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|---|---|---|---|
| 2D subset-count DP | `O(nS)` | `O(nS)` | Keeps a row of counts for every prefix of `nums`. |
| 1D subset-count DP | `O(nS)` | `O(S)` | Preferred; descending updates preserve 0/1 choices. |

Here, `S = (sum(nums) - target) / 2`; if `sum(nums) - target` is negative or odd, there are no valid expressions.

## Summary

- Transform sign assignment into counting subsets with sum `(sum(nums) - target) / 2`.
- The 1D DP is preferred because it counts the same subsets using less space.
- Descending sum updates prevent reusing a number; zero values correctly double the number of sign assignments.
