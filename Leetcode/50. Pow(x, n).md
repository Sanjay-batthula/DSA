
# 50. Pow(x, n)

## Problem Statement

Implement `pow(x, n)`, which calculates $x^n$ (i.e., $x$ raised to the power $n$).

---

## Sample Test Cases

| Input                  | Output      | Explanation |
|------------------------|------------|-------------|
| x = 2.00000, n = 10    | 1024.00000 | $2^{10}$    |
| x = 2.10000, n = 3     | 9.26100    | $2.1^3$     |
| x = 2.00000, n = -2    | 0.25000    | $2^{-2} = 1/4$ |

---

## Constraints

- $-100.0 < x < 100.0$
- $-2^{31} \leq n \leq 2^{31}-1$
- $n$ is an integer.
- Either $x$ is not zero or $n > 0$.
- $-10^4 \leq x^n \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Multiply $x$ $|n|$ times | $O(|n|)$ | $O(1)$ |
| Binary Exponentiation | Divide-and-conquer, halve $n$ each step | $O(\log |n|)$ | $O(1)$ |
| Recursion | Recursive binary exponentiation | $O(\log |n|)$ | $O(\log |n|)$ |
| Bitwise | Use bitwise operations for fast power | $O(\log |n|)$ | $O(1)$ |

---

## Code: Binary Exponentiation

```java
class Solution {
    public double myPow(double x, int n) {
        return n >= 0 ? qpow(x, n) : 1 / qpow(x, -(long) n);
    }

    private double qpow(double a, long n) {
        double ans = 1;
        for (; n > 0; n >>= 1) {
            if ((n & 1) == 1) {
                ans = ans * a;
            }
            a = a * a;
        }
        return ans;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public double myPow(double x, int n) {
        long k = n;
        if (k < 0) k = -k;
        double ans = 1;
        for (long i = 0; i < k; i++) ans *= x;
        return n >= 0 ? ans : 1 / ans;
    }
}
```

### Recursion
```java
class Solution {
    public double myPow(double x, int n) {
        long k = n;
        return k >= 0 ? solve(x, k) : 1 / solve(x, -k);
    }

    private double solve(double x, long n) {
        if (n == 0) return 1;
        double half = solve(x, n / 2);
        if (n % 2 == 0) return half * half;
        return half * half * x;
    }
}
```

### Bitwise Fast Power
```java
class Solution {
    public double myPow(double x, int n) {
        long p = n;
        if (p < 0) {
            x = 1 / x;
            p = -p;
        }
        double ans = 1;
        while (p > 0) {
            if ((p & 1) == 1) ans *= x;
            x *= x;
            p >>= 1;
        }
        return ans;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(|n|)$ | $O(1)$ | Simple, but slow for large $n$ |
| Binary Exponentiation | $O(\log |n|)$ | $O(1)$ | Optimal, handles negatives |
| Recursion | $O(\log |n|)$ | $O(\log |n|)$ | Elegant, but uses stack |
| Bitwise | $O(\log |n|)$ | $O(1)$ | Fast, branchless |

---

## Summary

- Use binary exponentiation for efficient power calculation.
- Recursion and bitwise methods are alternatives, but binary exponentiation is optimal for interviews.
