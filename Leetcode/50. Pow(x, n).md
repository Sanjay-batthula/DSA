## Brute force
```
class Solution {
    public double myPow(double x, int n) {
        long k = n;
        if (k < 0) k = -k;
        double ans = 1;
        for (long i = 0; i < k; i++) ans *= x;
        return n >= 0 ? ans : 1 / ans;
    }
}
```
## Function call
class Solution {

    }
}

## binary exponentiation
```
class Solution {
    public double myPow(double x, int n) {
        return n >= 0 ? qpow(x, n) : 1 / qpow(x, -(long) n);
    }

    private double qpow(double a, long n) {
        double ans = 1;
        for (; n > 0; n >>= 1) {
            if ((n & 1) == 1) {
                ans = ans * a;
            }
            a = a * a;
        }
        return ans;
    }
}
```
