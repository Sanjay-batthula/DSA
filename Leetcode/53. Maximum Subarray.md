
# 53. Maximum Subarray

## Problem Statement

Given an integer array `nums`, find the subarray with the largest sum, and return its sum.

---

## Sample Test Cases

| Input                        | Output | Explanation |
|------------------------------|--------|-------------|
| nums = [-2,1,-3,4,-1,2,1,-5,4] | 6      | [4,-1,2,1] has sum 6 |
| nums = [1]                     | 1      | [1] has sum 1 |
| nums = [5,4,-1,7,8]            | 23     | [5,4,-1,7,8] has sum 23 |

---

## Constraints

- $1 \leq \text{nums.length} \leq 10^5$
- $-10^4 \leq \text{nums}[i] \leq 10^4$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Try all subarrays, track max sum | $O(n^2)$ | $O(1)$ |
| Kadane's Algorithm | Track current/max sum in one pass | $O(n)$ | $O(1)$ |
| Divide & Conquer | Recursively split, combine results | $O(n \log n)$ | $O(\log n)$ |
| Prefix Sum Trick | Track prefix/min prefix | $O(n)$ | $O(1)$ |
| Dynamic Programming | DP for max sum ending at each index | $O(n)$ | $O(1)$ |

---

## Code: Kadane's Algorithm

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int maxSum = nums[0];
        int currSum = nums[0];
        for (int i = 1; i < nums.length; i++) {
            currSum = Math.max(nums[i], currSum + nums[i]);
            maxSum = Math.max(maxSum, currSum);
        }
        return maxSum;
    }
}
```

## Other Approaches

### Brute Force
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) {
            int sum = 0;
            for (int j = i; j < nums.length; j++) {
                sum += nums[j];
                max = Math.max(max, sum);
            }
        }
        return max;
    }
}
```

### Divide & Conquer
```java
class Solution {
    public int maxSubArray(int[] nums) {
        return divide(nums, 0, nums.length - 1);
    }
    private int divide(int[] a, int l, int r) {
        if (l == r) return a[l];
        int mid = (l + r) / 2;
        int left = divide(a, l, mid);
        int right = divide(a, mid + 1, r);
        int cross = crossSum(a, l, mid, r);
        return Math.max(Math.max(left, right), cross);
    }
    private int crossSum(int[] a, int l, int mid, int r) {
        int leftMax = Integer.MIN_VALUE, sum = 0;
        for (int i = mid; i >= l; i--) {
            sum += a[i];
            leftMax = Math.max(leftMax, sum);
        }
        int rightMax = Integer.MIN_VALUE; sum = 0;
        for (int i = mid + 1; i <= r; i++) {
            sum += a[i];
            rightMax = Math.max(rightMax, sum);
        }
        return leftMax + rightMax;
    }
}
```

### Prefix Sum Removal Trick
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int prefix = 0, minPrefix = 0, max = Integer.MIN_VALUE;
        for (int x : nums) {
            prefix += x;
            max = Math.max(max, prefix - minPrefix);
            minPrefix = Math.min(minPrefix, prefix);
        }
        return max;
    }
}
```

### Dynamic Programming
```java
class Solution {
    public int maxSubArray(int[] nums) {
        int dp = nums[0], max = nums[0];
        for (int i = 1; i < nums.length; i++) {
            dp = Math.max(nums[i], dp + nums[i]);
            max = Math.max(max, dp);
        }
        return max;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(1)$ | Simple, but slow |
| Kadane's | $O(n)$ | $O(1)$ | Optimal, one pass |
| Divide & Conquer | $O(n \log n)$ | $O(\log n)$ | Subtle, good for follow-up |
| Prefix Sum | $O(n)$ | $O(1)$ | Elegant trick |
| DP | $O(n)$ | $O(1)$ | Same as Kadane's |

---

## Summary

- Use Kadane's algorithm for optimal $O(n)$ solution.
- Divide & conquer is a good follow-up for interviews.
- Prefix sum and DP are alternative $O(n)$ approaches.
