# 550. Game Play Analysis IV

## Problem Statement

Return the fraction of players who logged in on the day immediately after their first login, divided by the total number of players. Round the result to two decimal places.

The `Activity` table has one row per `(player_id, event_date)`.

## Sample Test Case

```text
Activity:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-03-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output:
+----------+
| fraction |
+----------+
| 0.33     |
+----------+
```

Only player `1` logged in the day after their first login, so the fraction is `1 / 3`.

## Window Function + Date Comparison ✅

```sql
WITH first_login AS (
    SELECT
        player_id,
        event_date,
        MIN(event_date) OVER (PARTITION BY player_id) AS first_logged
    FROM Activity
)

SELECT ROUND(
    COUNT(DISTINCT player_id) /
    (SELECT COUNT(DISTINCT player_id) FROM Activity),
    2
) AS fraction
FROM first_login
WHERE DATEDIFF(event_date, first_logged) = 1;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | Find players with an activity date exactly one day after their first login, then divide their count by the total player count. |
| **Approach** | The CTE calculates each player's first date with `MIN() OVER (PARTITION BY player_id)`. The `WHERE` clause keeps rows one day after that date. `COUNT(DISTINCT player_id)` counts qualifying players, and the subquery counts all players. `ROUND(..., 2)` formats the fraction to two decimal places. |
| **Key Concepts** | Window function, `PARTITION BY`, `DATEDIFF()`, `COUNT(DISTINCT)`, scalar subquery, `ROUND()` |

## Alternative Approach: Self-Join with Aggregated First Login

```sql
SELECT
    ROUND(
        (
            SELECT COUNT(DISTINCT a.player_id)
            FROM Activity a
            INNER JOIN (
                SELECT player_id, MIN(event_date) AS first_logged
                FROM Activity
                GROUP BY player_id
            ) b
                ON a.player_id = b.player_id
               AND DATEDIFF(a.event_date, b.first_logged) = 1
        ) / (
            SELECT COUNT(DISTINCT player_id)
            FROM Activity
        ),
        2
    ) AS fraction;
```

This query first aggregates each player's first login date, then joins activity rows from the following day.

## Summary

- Compare each player's activity dates with their first login date.
- Count each qualifying player once, then divide by the total number of players and round to two decimal places.
