# 550. Game Play Analysis IV

## Self Join on Aggregated Data
```
select 
round((select count(distinct a.player_id) from Activity a
inner join 
(select player_id, min(event_date) as first_logged 
    from Activity 
    group by player_id) b on datediff(a.event_date, b.first_logged)=1
    and a.player_id = b.player_id)
    /
    (select count(distinct player_id) from Activity),2) as fraction;
```

## Window Function + Date Comparison
```
WITH first_login AS (
    SELECT
        player_id,
        event_date,
        MIN(event_date) OVER (PARTITION BY player_id) AS first_logged
    FROM Activity
)

SELECT ROUND(
    COUNT(DISTINCT player_id) /
    (SELECT COUNT(DISTINCT player_id) FROM Activity),
    2
) AS fraction
FROM first_login
WHERE DATEDIFF(event_date, first_logged) = 1;
```
