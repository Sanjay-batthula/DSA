# 570. Managers with at Least 5 Direct Reports

## Problem Statement

Find the names of employees who manage at least five direct reports. Each employee has a unique `id`; `managerId` is `NULL` when they have no manager.

## Sample Test Case

```text
Employee:
+-----+-------+------------+-----------+
| id  | name  | department | managerId |
+-----+-------+------------+-----------+
| 101 | John  | A          | NULL      |
| 102 | Dan   | A          | 101       |
| 103 | James | A          | 101       |
| 104 | Amy   | A          | 101       |
| 105 | Anne  | A          | 101       |
| 106 | Ron   | B          | 101       |
+-----+-------+------------+-----------+
Output:
+------+
| name |
+------+
| John |
+------+
```

## Group By + Self Join ✅

```sql
SELECT name
FROM Employee
JOIN (
    SELECT managerId AS id, COUNT(1) AS cnt
    FROM Employee
    GROUP BY managerId
    HAVING COUNT(1) >= 5
) AS t USING (id);
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | Count employees for each non-null manager, then look up the manager's name. |
| **Approach** | The subquery groups employees by `managerId` and keeps groups with at least five rows using `HAVING`. It aliases each qualifying `managerId` as `id`, which joins to the manager's row in `Employee`. |
| **Key Concepts** | `GROUP BY`, `COUNT()`, `HAVING`, self-join, `NULL` grouping |

## Alternative Approach: Self-Join + Group By

```sql
SELECT e1.name
FROM Employee e1
JOIN Employee e2
    ON e1.id = e2.managerId
GROUP BY e1.id, e1.name
HAVING COUNT(*) >= 5;
```

This joins each manager to their direct reports and filters managers by the number of joined rows.

## Alternative Approach: Correlated Subquery

```sql
SELECT name
FROM Employee e1
WHERE (
    SELECT COUNT(*)
    FROM Employee e2
    WHERE e2.managerId = e1.id
) >= 5;
```

For each employee, the subquery counts rows whose `managerId` matches that employee's `id`.

## Summary

- Group reports by `managerId` and use `HAVING` to keep counts of at least five.
- Join qualifying manager IDs back to `Employee` to retrieve their names.
- The self-join and correlated-subquery alternatives express the same direct-report count in different ways.
