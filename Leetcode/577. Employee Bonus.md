# 577. Employee Bonus

## Problem Statement

Report each employee's name and bonus when the employee has a bonus below `1000` or has no bonus record. The result may be returned in any order.

`Employee.empId` is unique. `Bonus.empId` is a unique foreign key to `Employee.empId`.

## Sample Test Case

```text
Employee:
+-------+--------+------------+--------+
| empId | name   | supervisor | salary |
+-------+--------+------------+--------+
| 3     | Brad   | NULL       | 4000   |
| 1     | John   | 3          | 1000   |
| 2     | Dan    | 3          | 2000   |
| 4     | Thomas | 3          | 4000   |
+-------+--------+------------+--------+

Bonus:
+-------+-------+
| empId | bonus |
+-------+-------+
| 2     | 500   |
| 4     | 2000  |
+-------+-------+

Output:
+------+-------+
| name | bonus |
+------+-------+
| Brad | NULL  |
| John | NULL  |
| Dan  | 500   |
+------+-------+
```

## Left Join + NULL / Value Filter ✅

```sql
SELECT e.name, b.bonus
FROM Employee e
LEFT JOIN Bonus b
    ON e.empId = b.empId
WHERE b.bonus IS NULL
   OR b.bonus < 1000;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | Keep employees without a matching bonus row, as well as employees whose recorded bonus is below `1000`. |
| **Approach** | `LEFT JOIN` retains every employee. For employees without a bonus record, `b.bonus` is `NULL`; the `WHERE` condition also keeps joined rows with a bonus below `1000`. |
| **Key Concepts** | `LEFT JOIN`, `NULL`, `IS NULL`, `OR` |

## Alternative Approach: `NOT EXISTS`

```sql
SELECT e.name, b.bonus
FROM Employee e
LEFT JOIN Bonus b
    ON e.empId = b.empId
WHERE b.bonus < 1000
   OR NOT EXISTS (
        SELECT 1
        FROM Bonus b2
        WHERE b2.empId = e.empId
   );
```

The correlated subquery checks explicitly whether an employee has no bonus row; the outer `LEFT JOIN` supplies the bonus value for employees who do have one.

## Summary

- Use `LEFT JOIN` so employees without bonus records remain in the result.
- Filter for a missing bonus with `IS NULL` and for a small bonus with `< 1000`.
- `NOT EXISTS` is an alternative way to test that no bonus record exists.
