## Brute force
```
class Solution {
    public int lengthOfLastWord(String s) {
        String[] words = s.split(" ");
        for (int i = words.length - 1; i >= 0; i--) {
            if (!words[i].isEmpty()) {
                return words[i].length();
            }
        }
        return 0;
    }
}

```


## two-pointer
```
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') {
            --i;
        }
        int j = i;
        while (j >= 0 && s.charAt(j) != ' ') {
            --j;
        }
        return i - j;
    }
}
```


# micro-optimization
```
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1, length = 0;
        while (i >= 0) {
            if (s.charAt(i) != ' ') {
                length++;
            } else if (length > 0) {
                break;
            }
            i--;
        }
        return length;
    }
}
```


## Reverse Traversal Using char[]
```
class Solution {
    public int lengthOfLastWord(String s) {
        char[] a = s.toCharArray();
        int i = a.length - 1, len = 0;
        while (i >= 0 && a[i] == ' ') i--;
        while (i >= 0 && a[i] != ' ') {
            len++;
            i--;
        }
        return len;
    }
}
```

## Using String.trim()
```
class Solution {
    public int lengthOfLastWord(String s) {
        s = s.trim();
        int i = s.lastIndexOf(' ');
        return s.length() - i - 1;
    }
}
```

## Using split with regex disabled
```
class Solution {
    public int lengthOfLastWord(String s) {
        String[] w = s.split(" ", -1);
        for (int i = w.length - 1; i >= 0; i--) {
            if (w[i].length() > 0) return w[i].length();
        }
        return 0;
    }
}
```

## Cleanest one-pass tight loop
```
class Solution {
    public int lengthOfLastWord(String s) {
        int n = s.length(), len = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) != ' ') len++;
            else if (len > 0) break;
        }
        return len;
    }
}
```

## Pointer Collapse
```
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') i--;
        int start = i;
        while (i >= 0 && s.charAt(i) != ' ') i--;
        return start - i;
    }
}
```
