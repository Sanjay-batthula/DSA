
# 58. Length of Last Word

## Problem Statement

Given a string $s$ consisting of words and spaces, return the length of the last word in the string.

A word is a maximal substring consisting of non-space characters only.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| s = "Hello World" | 5 | The last word is "World" with length 5. |
| s = "   fly me   to   the moon  " | 4 | The last word is "moon" with length 4. |
| s = "luffy is still joyboy" | 6 | The last word is "joyboy" with length 6. |

---

## Constraints

- $1 \leq s.length \leq 10^4$
- $s$ consists of only English letters and spaces ' '
- There will be at least one word in $s$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Split string and check last word | $O(n)$ | $O(n)$ |
| Two-pointer | Traverse from end, skip spaces | $O(n)$ | $O(1)$ |
| One-pass | Tight loop, count last word | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

```java
class Solution {
    public int lengthOfLastWord(String s) {
        String[] words = s.split(" ");
        for (int i = words.length - 1; i >= 0; i--) {
            if (!words[i].isEmpty()) {
                return words[i].length();
            }
        }
        return 0;
    }
}
```

---

## Code: Two-pointer

```java
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') {
            --i;
        }
        int j = i;
        while (j >= 0 && s.charAt(j) != ' ') {
            --j;
        }
        return i - j;
    }
}
```

---

## Code: One-pass Tight Loop

```java
class Solution {
    public int lengthOfLastWord(String s) {
        int n = s.length(), len = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) != ' ') len++;
            else if (len > 0) break;
        }
        return len;
    }
}
```

## Other Approaches

### Micro-optimization
```java
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1, length = 0;
        while (i >= 0) {
            if (s.charAt(i) != ' ') {
                length++;
            } else if (length > 0) {
                break;
            }
            i--;
        }
        return length;
    }
}
```

### Reverse Traversal Using char[]
```java
class Solution {
    public int lengthOfLastWord(String s) {
        char[] a = s.toCharArray();
        int i = a.length - 1, len = 0;
        while (i >= 0 && a[i] == ' ') i--;
        while (i >= 0 && a[i] != ' ') {
            len++;
            i--;
        }
        return len;
    }
}
```

### Using String.trim()
```java
class Solution {
    public int lengthOfLastWord(String s) {
        s = s.trim();
        int i = s.lastIndexOf(' ');
        return s.length() - i - 1;
    }
}
```

### Using split with regex disabled
```java
class Solution {
    public int lengthOfLastWord(String s) {
        String[] w = s.split(" ", -1);
        for (int i = w.length - 1; i >= 0; i--) {
            if (w[i].length() > 0) return w[i].length();
        }
        return 0;
    }
}
```

### Pointer Collapse
```java
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') i--;
        int start = i;
        while (i >= 0 && s.charAt(i) != ' ') i--;
        return start - i;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(n)$ | Uses split, checks last word |
| Two-pointer | $O(n)$ | $O(1)$ | Traverse from end, skip spaces |
| One-pass | $O(n)$ | $O(1)$ | Tight loop, efficient |

---

## Summary

- Multiple approaches exist: split, two-pointer, one-pass loop.
- Efficient solutions use $O(n)$ time and $O(1)$ space.
- Traversing from the end and skipping spaces is optimal for this problem.
