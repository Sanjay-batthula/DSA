# 594. Longest Harmonious Subsequence

---

## Problem Statement
We define a **harmonious array** as an array where the difference between its maximum value and its minimum value is exactly 1.

Given an integer array `nums`, return the length of its longest harmonious subsequence among all its possible subsequences.

---

## Sample Cases

| Input                        | Output | Explanation                                      |
|------------------------------|--------|--------------------------------------------------|
| nums = [1,3,2,2,5,2,3,7]     | 5      | The subsequence [3,2,2,2,3] is harmonious.        |
| nums = [1,2,3,4]             | 2      | [1,2], [2,3], or [3,4] are harmonious.            |
| nums = [1,1,1,1]             | 0      | No harmonious subsequence exists.                 |

---

## Approaches

### Approach 1: Brute Force
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Try all possible pairs and count valid subsequences. | For each unique number, count elements equal to it and to it+1. | $O(n^2)$ | $O(1)$ |

```java
class Solution {
    public int findLHS(int[] nums) {
        int n = nums.length;
        int maxLen = 0;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (nums[j] == nums[i] || nums[j] == nums[i] + 1) {
                    count++;
                }
            }
            boolean hasNeighbor = false;
            for (int j = 0; j < n; j++) {
                if (nums[j] == nums[i] + 1) {
                    hasNeighbor = true;
                    break;
                }
            }
            if (hasNeighbor) {
                maxLen = Math.max(maxLen, count);
            }
        }
        return maxLen; 
    }
}
```

---

### Approach 2: HashMap Frequency Count
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Count frequencies, then check for pairs with diff 1. | Use a HashMap to count, then check key and key+1. | $O(n)$ | $O(n)$ |

```java
class Solution {
    public int findLHS(int[] nums) {
        int rst = 0;
        Map<Integer, Integer> map = new HashMap<>();
        for (int num : nums) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }
        for (int key : map.keySet()) {
            if (map.containsKey(key + 1)) {
                rst = Math.max(rst, map.get(key) + map.get(key + 1));
            }
        }
        return rst;
    }
}
```

---

### Approach 3: Sorting + Sliding Window
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Sorted array allows windowing for diff 1. | Sort, use two pointers to find valid windows. | $O(n \log n)$ | $O(1)$ |

```java
class Solution {
    public int findLHS(int[] nums) {
        Arrays.sort(nums);
        int left = 0, right = 0, maxLen = 0;
        while (right < nums.length) {
            while (nums[right] - nums[left] > 1) {
                left++;
            }
            if (nums[right] - nums[left] == 1) {
                maxLen = Math.max(maxLen, right - left + 1);
            }
            right++;
        }
        return maxLen;
    }
}
```

---

### Approach 4: TreeMap (Sorted Map)
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| TreeMap keeps keys sorted for easy neighbor lookup. | Count with TreeMap, check each key and key+1. | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public int findLHS(int[] nums) {
        TreeMap<Integer, Integer> map = new TreeMap<>();
        for (int num : nums) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }
        int maxLen = 0;
        for (int key : map.keySet()) {
            if (map.containsKey(key + 1)) {
                maxLen = Math.max(maxLen, map.get(key) + map.get(key + 1));
            }
        }
        return maxLen;
    }
}
```

---

## Approach Comparison

| Approach         | Time Complexity | Space Complexity | Notes                         |
|------------------|----------------|------------------|-------------------------------|
| Brute Force      | $O(n^2)$       | $O(1)$           | Simple, but slow              |
| HashMap          | $O(n)$         | $O(n)$           | Fastest for unsorted input     |
| Sorting+Window   | $O(n \log n)$  | $O(1)$           | Good if sorting is acceptable  |
| TreeMap          | $O(n \log n)$  | $O(n)$           | Useful if order is needed      |

---

## Summary
- The problem asks for the length of the longest harmonious subsequence (max-min=1).
- HashMap approach is optimal for unsorted input.
- Sorting + sliding window is also efficient if sorting is allowed.
- Brute force is not recommended for large inputs.
- TreeMap is useful if you need sorted order or neighbor lookups.
