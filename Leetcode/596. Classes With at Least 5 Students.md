# 596. Classes With at Least 5 Students

## Problem Statement

Find the classes with at least five students. Each `(student, class)` pair in `Courses` is unique.

## Sample Test Case

```text
Courses:
+---------+----------+
| student | class    |
+---------+----------+
| A       | Math     |
| B       | English  |
| C       | Math     |
| D       | Biology  |
| E       | Math     |
| F       | Computer |
| G       | Math     |
| H       | Math     |
| I       | Math     |
+---------+----------+
Output:
+-------+
| class |
+-------+
| Math  |
+-------+
```

`Math` has six students; the other classes have fewer than five.

## Group By + Having ✅

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | Count students in each class and return only classes meeting the minimum. |
| **Approach** | `GROUP BY class` forms one group per class. `HAVING COUNT(student) >= 5` filters those aggregated groups to classes with at least five students. |
| **Key Concepts** | `GROUP BY`, `HAVING`, `COUNT()` |

## Summary

- Group course records by class and count the students in each group.
- Use `HAVING` to filter by an aggregate count.
