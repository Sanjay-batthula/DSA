# 6. Zigzag Conversion

## Problem Description
The string "PAYPALISHIRING" is written in a zigzag pattern on a given number of rows like this: (you may want to display this pattern in a fixed font for better legibility)

```
P   A   H   N
A P L S I I G
Y   I   R
```
And then read line by line: "PAHNAPLSIIGYIR"

Write the code that will take a string and make this conversion given a number of rows:

`string convert(string s, int numRows);`

## Sample Test cases
Example 1:
```
Input: s = "PAYPALISHIRING", numRows = 3
Output: "PAHNAPLSIIGYIR"
```
Example 2:
```
Input: s = "PAYPALISHIRING", numRows = 4
Output: "PINALSIGYAHRPI"
```
Explanation:
```
P     I    N
A   L S  I G
Y A   H R
P     I
```
Example 3:
```
Input: s = "A", numRows = 1
Output: "A"
```

## Brute force(Grid Simulation)
| Section              | Details                                                                                |
| -------------------- | -------------------------------------------------------------------------------------- |
| **Intuition**        | Directly simulate the zigzag pattern in a 2D grid.                                     |
| **Approach**         | Place characters row by row in a matrix following zigzag movement, then read row-wise. |
| **Time Complexity**  | `O(n * numRows)`                                                                       |
| **Space Complexity** | `O(n * numRows)`                                                                       |

```
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || s.length() <= numRows) return s;

        int n = s.length();
        char[][] grid = new char[numRows][n];
        for (int i = 0; i < numRows; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = ' ';
            }
        }

        int row = 0, col = 0;
        boolean goingDown = true;

        for (char c : s.toCharArray()) {
            grid[row][col] = c;
            if (goingDown) {
                if (row == numRows - 1) {
                    goingDown = false;
                    row--;
                    col++;
                } else {
                    row++;
                }
            } else {
                if (row == 0) {
                    goingDown = true;
                    row++;
                } else {
                    row--;
                    col++;
                }
            }
        }

        StringBuilder result = new StringBuilder();
        for (int i = 0; i < numRows; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != ' ') {
                    result.append(grid[i][j]);
                }
            }
        }
        return result.toString();
    }
}
```


## Math Formula Approach
| Section              | Details                                                          |
| -------------------- | ---------------------------------------------------------------- |
| **Intuition**        | Characters repeat in a fixed cycle length in the zigzag pattern. |
| **Approach**         | Use cycle length math to directly pick characters row by row.    |
| **Time Complexity**  | `O(n)`                                                           |
| **Space Complexity** | `O(1)` (excluding output)                                        |
```
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || s.length() <= numRows) return s;

        int n = s.length();
        int cycle = 2 * numRows - 2;
        StringBuilder result = new StringBuilder();

        for (int r = 0; r < numRows; r++) {
            for (int i = r; i < n; i += cycle) {
                result.append(s.charAt(i));
                if (r != 0 && r != numRows - 1 && i + cycle - 2 * r < n) {
                    result.append(s.charAt(i + cycle - 2 * r));
                }
            }
        }
        return result.toString();
    }
}
```


## Simulation Approach
| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Each row can be built independently while simulating direction changes. |
| **Approach**         | Use an array of StringBuilders and simulate up-down traversal.          |
| **Time Complexity**  | `O(n)`                                                                  |
| **Space Complexity** | `O(n)`                                                                  |

```
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1) {
            return s;
        }
        StringBuilder[] g = new StringBuilder[numRows];
        Arrays.setAll(g, k -> new StringBuilder());
        int i = 0, k = -1;
        for (char c : s.toCharArray()) {
            g[i].append(c);
            if (i == 0 || i == numRows - 1) {
                k = -k;
            }
            i += k;
        }
        return String.join("", g);
    }
}
```

## Approach Comparison
| Approach              | Time Complexity | Space Complexity | Notes                           |
| --------------------- | --------------- | ---------------- | ------------------------------- |
| Brute Force (Grid)    | O(n·numRows)    | O(n·numRows)     | Easy to visualize, memory heavy |
| Math Formula          | O(n)            | O(1)             | Most efficient, logic-heavy     |
| Simulation (Builders) | O(n)            | O(n)             | Clean and interview-friendly    |


## Summary

- Math Formula Approach is optimal with linear time and constant extra space.
- Simulation Approach is easiest to explain in interviews.
- Brute force is useful only for understanding the pattern.
