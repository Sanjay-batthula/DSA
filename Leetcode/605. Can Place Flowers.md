# 605. Can Place Flowers

---

## Problem Statement
You have a long flowerbed in which some of the plots are planted, and some are not. However, flowers cannot be planted in adjacent plots.

Given an integer array `flowerbed` containing 0's and 1's, where 0 means empty and 1 means not empty, and an integer `n`, return `true` if `n` new flowers can be planted in the flowerbed without violating the no-adjacent-flowers rule and `false` otherwise.

---

## Sample Cases

| Input                        | Output | Explanation                                      |
|------------------------------|--------|--------------------------------------------------|
| flowerbed = [1,0,0,0,1], n=1 | true   | Plant at index 2: [1,0,1,0,1]                    |
| flowerbed = [1,0,0,0,1], n=2 | false  | Cannot plant 2 flowers without violating the rule |

---

## Approaches

### Approach 1: Brute Force
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Try to plant at every possible spot, checking neighbors. | For each plot, check if both neighbors are empty, plant if possible. | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        int len = flowerbed.length;
        for (int i = 0; i < len; i++) {
            if (flowerbed[i] == 0) {
                int prev = (i == 0) ? 0 : flowerbed[i - 1];
                int next = (i == len - 1) ? 0 : flowerbed[i + 1];
                if (prev == 0 && next == 0) {
                    flowerbed[i] = 1;
                    n--;
                    if (n == 0) return true;
                }
            }
        }
        return n <= 0;
    }
}
```

---

### Approach 2: Greedy Simulation
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Greedily plant at every valid spot, counting as we go. | For each plot, if both neighbors are empty, plant and count. | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        int count = 0;
        for (int i = 0; i < flowerbed.length; i++) {
            if (flowerbed[i] == 0) {
                boolean emptyPrev = (i == 0 || flowerbed[i - 1] == 0);
                boolean emptyNext = (i == flowerbed.length - 1 || flowerbed[i + 1] == 0);
                if (emptyPrev && emptyNext) {
                    flowerbed[i] = 1;
                    count++;
                    if (count >= n) {
                        return true;
                    }
                }
            }
        }
        return count >= n;
    }
}
```

---

### Approach 3: Recursion (Backtracking)
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Try all possible placements recursively. | Use recursion to try planting or skipping each spot. | Exponential (TLE) | $O(n)$ (call stack) |

```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        return backtrack(flowerbed, 0, n);
    }    
    private boolean backtrack(int[] flowerbed, int i, int n) {
        if (n == 0) return true;
        if (i >= flowerbed.length) return false;
        if (flowerbed[i] == 0) {
            boolean emptyPrev = (i == 0 || flowerbed[i - 1] == 0);
            boolean emptyNext = (i == flowerbed.length - 1 || flowerbed[i + 1] == 0);
            if (emptyPrev && emptyNext) {
                flowerbed[i] = 1;
                if (backtrack(flowerbed, i + 2, n - 1)) return true;
                flowerbed[i] = 0;
            }
        }
        return backtrack(flowerbed, i + 1, n);
    }
}
```

---

## Approach Comparison

| Approach         | Time Complexity | Space Complexity | Notes                         |
|------------------|----------------|------------------|-------------------------------|
| Brute Force      | $O(n)$         | $O(1)$           | Simple, modifies input         |
| Greedy           | $O(n)$         | $O(1)$           | Efficient, modifies input      |
| Recursion        | Exponential    | $O(n)$           | Not practical for large input  |

---

## Summary
- The problem asks if you can plant `n` flowers in a flowerbed without adjacent flowers.
- Brute force and greedy approaches are both efficient and similar.
- Recursion is not practical for large inputs due to exponential time.
- All approaches modify the input array; copy it if you need to preserve the original.
