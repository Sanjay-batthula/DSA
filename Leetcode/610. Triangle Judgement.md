## 610. Triangle Judgement

Table: Triangle
```
+-------------+------+
| Column Name | Type |
+-------------+------+
| x           | int  |
| y           | int  |
| z           | int  |
+-------------+------+
```
In SQL, (x, y, z) is the primary key column for this table.  
Each row of this table contains the lengths of three line segments.  
Report for every three line segments whether they can form a triangle.  
Return the result table in any order.  
The result format is in the following example.  

## Sample Test Cases
Example 1:

Input: 
Triangle table:
```
+----+----+----+
| x  | y  | z  |
+----+----+----+
| 13 | 15 | 30 |
| 10 | 20 | 15 |
+----+----+----+
```
Output: 
```
+----+----+----+----------+
| x  | y  | z  | triangle |
+----+----+----+----------+
| 13 | 15 | 30 | No       |
| 10 | 20 | 15 | Yes      |
+----+----+----+----------+
```

## CASE-based row classification approach
| Section       | Details                                                                                                                                                                                                                                                                                  |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | Each row already contains all the information needed to decide whether three line segments can form a triangle. Since the output requires labeling every row as either `"Yes"` or `"No"` rather than filtering rows, we must evaluate a condition per row and classify the result.       |
| **Approach**  | Apply the triangle inequality rule using a `CASE` expression. For each row, check whether the sum of any two sides is greater than the third side. If all three conditions are satisfied, return `"Yes"`; otherwise, return `"No"`. Assign this result to a new column named `triangle`. |

```
SELECT
    x,
    y,
    z,
    CASE
        WHEN x + y > z
         AND x + z > y
         AND y + z > x
        THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```


## IF-based conditional row classification
| Section       | Details                                                                                                                                                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | Each row contains three side lengths, which are sufficient to determine triangle validity. Since every row must be labeled rather than filtered, we directly evaluate the triangle inequality condition for each row and assign a result. |
| **Approach**  | Use MySQL’s `IF()` function to evaluate the triangle inequality rule. If all three conditions are satisfied, return `'Yes'`; otherwise, return `'No'`. The result is added as a derived column named `triangle`.                          |

```
select *, if(x + y > z and x + z > y and y + z > x, 'Yes', 'No') as triangle from triangle
```
