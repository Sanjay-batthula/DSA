# 619. Biggest Single Number

## Problem Statement

A single number appears exactly once in `MyNumbers`. Find the largest single number. Return `NULL` if no number appears exactly once.

The table can contain duplicate values and has no primary key.

## Sample Test Cases

### Example 1

```text
MyNumbers:
+-----+
| num |
+-----+
| 8   |
| 8   |
| 3   |
| 3   |
| 1   |
| 4   |
| 5   |
| 6   |
+-----+
Output:
+-----+
| num |
+-----+
| 6   |
+-----+
```

The single numbers are `1`, `4`, `5`, and `6`; the largest is `6`.

### Example 2

```text
MyNumbers:
+-----+
| num |
+-----+
| 8   |
| 8   |
| 7   |
| 7   |
| 3   |
| 3   |
| 3   |
+-----+
Output:
+------+
| num  |
+------+
| NULL |
+------+
```

No value appears exactly once, so the aggregate returns `NULL`.

## Group By + Having + `MAX()` ✅

```sql
WITH single_number AS (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(num) = 1
)
SELECT MAX(num) AS num
FROM single_number;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | First identify values that occur once, then select the largest among them. |
| **Approach** | The CTE groups rows by `num` and `HAVING COUNT(num) = 1` keeps single numbers. `MAX(num)` returns the largest qualifying value; if the CTE is empty, `MAX()` returns `NULL`. |
| **Key Concepts** | `GROUP BY`, `HAVING`, `COUNT()`, `MAX()`, CTE |

## Summary

- Group by `num` and keep values occurring exactly once.
- Apply `MAX()` to find the largest single number.
- An empty qualifying set naturally produces `NULL` from `MAX()`.
