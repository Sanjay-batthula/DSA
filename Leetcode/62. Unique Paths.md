
# 62. Unique Paths

## Problem Statement

There is a robot on an $m \times n$ grid. The robot is initially located at the top-left corner (i.e., grid[0][0]). The robot tries to move to the bottom-right corner (i.e., grid[m - 1][n - 1]). The robot can only move either down or right at any point in time.

Given the two integers $m$ and $n$, return the number of possible unique paths that the robot can take to reach the bottom-right corner.

The test cases are generated so that the answer will be less than or equal to $2 \times 10^9$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| m = 3, n = 7 | 28 | 28 unique paths from top-left to bottom-right |
| m = 3, n = 2 | 3 | 3 ways: Right → Down → Down, Down → Down → Right, Down → Right → Down |

---

## Constraints

- $1 \leq m, n \leq 100$
- Answer $\leq 2 \times 10^9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Recursion (DFS) | $O(2^{m+n})$ | $O(m+n)$ |
| Dynamic Programming | Tabulation (2D DP) | $O(mn)$ | $O(mn)$ |
| Space Optimized DP | 1D DP | $O(mn)$ | $O(n)$ |
| Combinatorics | Mathematical formula | $O(\min(m, n))$ | $O(1)$ |
| Memoization | Top-down DP | $O(mn)$ | $O(mn)$ |

---

## Code: Brute Force (DFS)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        return dfs(0, 0, m, n);
    }

    int dfs(int i, int j, int m, int n) {
        if(i == m - 1 && j == n - 1) return 1;
        if(i >= m || j >= n) return 0;
        return dfs(i + 1, j, m, n) + dfs(i, j + 1, m, n);
    }
}
```

---

## Code: Dynamic Programming (Tabulation)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        var f = new int[m][n];
        f[0][0] = 1;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i > 0) {
                    f[i][j] += f[i - 1][j];
                }
                if (j > 0) {
                    f[i][j] += f[i][j - 1];
                }
            }
        }
        return f[m - 1][n - 1];
    }
}
```

---

## Code: Space Optimized DP (1D DP)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        dp[0] = 1;
        for(int i = 0; i < m; i++) {
            for(int j = 1; j < n; j++) {
                dp[j] += dp[j - 1];
            }
        }
        return dp[n - 1];
    }
}
```

---

## Code: Combinatorics (Most OP Approach)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        long res = 1;
        int k = Math.min(m - 1, n - 1);
        for(int i = 1; i <= k; i++){
            res = res * (m + n - 2 - (k - i)) / i;
        }
        return (int)res;
    }
}
```

---

## Code: Memoization (Top-Down DP)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        return solve(0, 0, m, n, dp);
    }

    int solve(int i, int j, int m, int n, int[][] dp) {
        if(i == m - 1 && j == n - 1) return 1;
        if(i >= m || j >= n) return 0;
        if(dp[i][j] != 0) return dp[i][j];
        return dp[i][j] = solve(i + 1, j, m, n, dp) + solve(i, j + 1, m, n, dp);
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(2^{m+n})$ | $O(m+n)$ | Exponential, TLE for large $m, n$ |
| DP Tabulation | $O(mn)$ | $O(mn)$ | Standard DP |
| Space Optimized DP | $O(mn)$ | $O(n)$ | 1D DP |
| Combinatorics | $O(\min(m, n))$ | $O(1)$ | Most efficient |
| Memoization | $O(mn)$ | $O(mn)$ | Top-down DP |

---

## Summary

- Multiple approaches: DFS, DP, combinatorics, memoization.
- Combinatorics is most efficient for large grids.
- DP approaches are easy to implement and understand.
