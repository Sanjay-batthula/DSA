# 620. Not Boring Movies

## Problem Statement

Return movies with an odd-numbered `id` and a `description` other than `'boring'`, ordered by `rating` in descending order.

The `Cinema` table has a unique `id`; `rating` is between 0 and 10.

## Sample Test Case

```text
Cinema:
+----+------------+-------------+--------+
| id | movie      | description | rating |
+----+------------+-------------+--------+
| 1  | War        | great 3D    | 8.9    |
| 2  | Science    | fiction     | 8.5    |
| 3  | irish      | boring      | 6.2    |
| 4  | Ice song   | Fantacy     | 8.6    |
| 5  | House card | Interesting | 9.1    |
+----+------------+-------------+--------+
Output:
+----+------------+-------------+--------+
| id | movie      | description | rating |
+----+------------+-------------+--------+
| 5  | House card | Interesting | 9.1    |
| 1  | War        | great 3D    | 8.9    |
+----+------------+-------------+--------+
```

Movies `1`, `3`, and `5` have odd IDs, but movie `3` is excluded because its description is `'boring'`.

## Filter + Sort ✅

```sql
SELECT *
FROM Cinema
WHERE id % 2 <> 0
  AND description <> 'boring'
ORDER BY rating DESC;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | Filter rows by both movie conditions, then place the highest-rated qualifying movie first. |
| **Approach** | `id % 2 <> 0` selects odd IDs. `description <> 'boring'` excludes boring movies. `ORDER BY rating DESC` sorts the remaining rows from highest to lowest rating. |
| **Key Concepts** | Modulo (`%`), `WHERE`, `AND`, `ORDER BY DESC` |

## Summary

- Use modulo to select odd IDs and a comparison to exclude the `'boring'` description.
- Sort the filtered movies by descending rating.
