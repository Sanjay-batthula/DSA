# 626. Exchange Seats

## Problem Statement

Swap the seat IDs of each pair of consecutive students. If the number of students is odd, leave the final student's ID unchanged. Return the result ordered by `id` ascending.

The `Seat.id` sequence starts at 1 and increments continuously.

## Sample Test Case

```text
Seat:
+----+---------+
| id | student |
+----+---------+
| 1  | Abbot   |
| 2  | Doris   |
| 3  | Emerson |
| 4  | Green   |
| 5  | Jeames  |
+----+---------+
Output:
+----+---------+
| id | student |
+----+---------+
| 1  | Doris   |
| 2  | Abbot   |
| 3  | Green   |
| 4  | Emerson |
| 5  | Jeames  |
+----+---------+
```

The final student keeps seat `5` because the number of students is odd.

## Conditional ID Remapping ✅

```sql
SELECT
    CASE
        WHEN id % 2 = 1 AND id <> counts THEN id + 1
        WHEN id % 2 = 1 AND id = counts THEN id
        ELSE id - 1
    END AS id,
    student
FROM Seat,
     (SELECT COUNT(*) AS counts FROM Seat) AS seat_counts
ORDER BY id ASC;
```

## Explanation

| Section | Details |
|---|---|
| **Intuition** | For each original row, calculate the ID of the seat its student should occupy. |
| **Approach** | An odd ID moves to the next ID unless it is the final ID; an even ID moves to the previous ID. The count identifies the last row, which can remain unchanged when the count is odd. |
| **Key Concepts** | `CASE`, modulo (`%`), scalar subquery, `COUNT()`, `ORDER BY` |

## Alternative Approach: Self-Join Adjacent Rows

```sql
SELECT
    s1.id,
    COALESCE(
        CASE
            WHEN s1.id % 2 = 1 THEN s2.student
            ELSE s3.student
        END,
        s1.student
    ) AS student
FROM Seat s1
LEFT JOIN Seat s2
    ON s1.id % 2 = 1
    AND s1.id + 1 = s2.id
LEFT JOIN Seat s3
    ON s1.id % 2 = 0
    AND s1.id - 1 = s3.id
ORDER BY s1.id;
```

The joins look up the adjacent student to swap in. `COALESCE` keeps the original student when no adjacent row exists, including the last student in an odd-length table.

## Alternative Approach: Window Functions

```sql
WITH cte AS (
    SELECT
        id,
        student,
        LEAD(student) OVER (ORDER BY id) AS next_student,
        LAG(student) OVER (ORDER BY id) AS prev_student,
        COUNT(*) OVER () AS cnt
    FROM Seat
)
SELECT
    id,
    CASE
        WHEN id % 2 = 1 AND id <> cnt THEN next_student
        WHEN id % 2 = 0 THEN prev_student
        ELSE student
    END AS student
FROM cte
ORDER BY id;
```

`LEAD()` and `LAG()` fetch the neighboring students; the row count lets the query leave an unpaired final student unchanged.

## Summary

- Remap each student's seat to its adjacent ID, keeping an unpaired final seat unchanged.
- The conditional approach computes new IDs; the self-join and window-function approaches fetch the neighboring student's name.
- The continuous ID sequence makes parity and the total row count sufficient to handle the odd-length case.
