# 643. Maximum Average Subarray I

---

## Problem Statement
You are given an integer array `nums` consisting of $n$ elements, and an integer $k$.

Find a contiguous subarray whose length is equal to $k$ that has the maximum average value and return this value. Any answer with a calculation error less than $10^{-5}$ will be accepted.

---

## Sample Cases

| Input                        | Output    | Explanation                                      |
|------------------------------|-----------|--------------------------------------------------|
| nums = [1,12,-5,-6,50,3], k=4| 12.75000  | (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75           |
| nums = [5], k=1              | 5.00000   | Only one element, so average is 5                |

---

## Approaches

### Approach 1: Brute Force
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Try every possible subarray of length $k$ and compute the average. | For each window, sum elements and track the max average. | $O(nk)$ | $O(1)$ |

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int sum = 0;
        for (int i = 0; i < k; i++) {
            sum += nums[i];
        }
        double maxAvg = (double) sum / k;
        for (int i = 1; i <= nums.length - k; i++) {
            sum = 0;
            for (int j = i; j < i + k; j++) {
                sum += nums[j];
            }
            double avg = (double) sum / k;
            maxAvg = Math.max(maxAvg, avg);
        }
        return maxAvg;
    }
}
```

---

### Approach 2: Sliding Window
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Maintain a running sum of the current window, update as window slides. | Add next element, remove first of previous window. | $O(n)$ | $O(1)$ |

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int sum = 0;
        for (int i = 0; i < k; i++) {
            sum += nums[i];
        }
        double maxAvg = (double) sum / k;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - nums[i - k];
            double avg = (double) sum / k;
            maxAvg = Math.max(maxAvg, avg);
        }
        return maxAvg;
    }
}
```

---

### Approach 3: Prefix Sum Array
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Precompute prefix sums to get window sums in $O(1)$. | Use prefix array to compute sum of any window. | $O(n)$ | $O(n)$ |

```java
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        int n = nums.length;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        double maxAvg = (double)(prefix[k] - prefix[0]) / k;
        for (int i = 1; i <= n - k; i++) {
            double avg = (double)(prefix[i + k] - prefix[i]) / k;
            maxAvg = Math.max(maxAvg, avg);
        }
        return maxAvg;
    }
}
```

---

## Approach Comparison

| Approach         | Time Complexity | Space Complexity | Notes                         |
|------------------|----------------|------------------|-------------------------------|
| Brute Force      | $O(nk)$        | $O(1)$           | Simple, but slow for large $n$ |
| Sliding Window   | $O(n)$         | $O(1)$           | Optimal for this problem       |
| Prefix Sum       | $O(n)$         | $O(n)$           | Useful for many queries        |

---

## Summary
- The problem asks for the maximum average of any contiguous subarray of length $k$.
- Sliding window is the most efficient and practical approach.
- Prefix sum is useful if you need to answer many such queries.
- Brute force is not recommended for large arrays.
