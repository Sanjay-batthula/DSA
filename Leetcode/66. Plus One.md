

# 66. Plus One

## Problem Statement

You are given a large integer represented as an integer array `digits`, where each `digits[i]` is the $i$-th digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading $0$'s.

Increment the large integer by one and return the resulting array of digits.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| digits = [1,2,3] | [1,2,4] | 123 + 1 = 124 |
| digits = [4,3,2,1] | [4,3,2,2] | 4321 + 1 = 4322 |
| digits = [9] | [1,0] | 9 + 1 = 10 |

---

## Constraints

- $1 \leq$ digits.length $\leq 100$
- $0 \leq$ digits[$i$] $\leq 9$
- digits does not contain any leading $0$'s

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Iterate from end, handle carry | $O(n)$ | $O(1)$ |
| Early-Exit | Stop at first non-9 | $O(n)$ | $O(1)$ |
| Explicit Carry | Propagate carry, create new array if needed | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

```java
class Solution {
    public int[] plusOne(int[] digits) {
        int n = digits.length;
        for (int i = n - 1; i >= 0; --i) {
            ++digits[i];
            digits[i] %= 10;
            if (digits[i] != 0) {
                return digits;
            }
        }
        digits = new int[n + 1];
        digits[0] = 1;
        return digits;
    }
}
```

---

## Code: Early-Exit Increment (Optimized Iterative Carry)

```java
class Solution {
    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }
            digits[i] = 0;
        }
        int[] res = new int[digits.length + 1];
        res[0] = 1;
        return res;
    }
}
```

---

## Code: Explicit Carry Propagation

```java
class Solution {
    public int[] plusOne(int[] digits) {
        int carry = 1;
        for (int i = digits.length - 1; i >= 0; i--) {
            int sum = digits[i] + carry;
            digits[i] = sum % 10;
            carry = sum / 10;
            if (carry == 0) return digits;
        }
        int[] res = new int[digits.length + 1];
        res[0] = 1;
        return res;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(1)$ | Handles carry, creates new array if needed |
| Early-Exit | $O(n)$ | $O(1)$ | Stops at first non-9 |
| Explicit Carry | $O(n)$ | $O(1)$ | Propagates carry, efficient |

---

## Summary

- Iterate from the end, handle carry efficiently.
- If all digits are 9, create a new array with leading 1.
- All approaches run in $O(n)$ time and $O(1)$ space.
