
# 67. Add Binary

## Problem Statement

Given two binary strings $a$ and $b$, return their sum as a binary string.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| a = "11", b = "1" | "100" | 11 + 1 = 100 (binary) |
| a = "1010", b = "1011" | "10101" | 1010 + 1011 = 10101 (binary) |

---

## Constraints

- $1 \leq$ a.length, b.length $\leq 10^4$
- $a$ and $b$ consist only of '0' or '1' characters
- Each string does not contain leading zeros except for the zero itself

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Convert to integer, add, convert back | $O(n)$ | $O(n)$ |
| BigInteger | Use BigInteger for large numbers | $O(n)$ | $O(n)$ |
| Carry Approach | Simulate addition with carry | $O(n)$ | $O(n)$ |

---

## Code: Brute Force (TLE)

```java
class Solution {
    public String addBinary(String a, String b) {
        int num1 = Integer.parseInt(a, 2);
        int num2 = Integer.parseInt(b, 2);
        int sum = num1 + num2;
        return Integer.toBinaryString(sum);
    }
}
```

---

## Code: Brute Force (BigInteger)

```java
import java.math.BigInteger;
class Solution {
    public String addBinary(String a, String b) {
        BigInteger num1 = new BigInteger(a, 2);
        BigInteger num2 = new BigInteger(b, 2);
        BigInteger sum = num1.add(num2);
        return sum.toString(2);
    }
}
```

---

## Code: Carry Approach

```java
class Solution {
    public String addBinary(String a, String b) {
        var sb = new StringBuilder();
        int i = a.length() - 1, j = b.length() - 1;
        for (int carry = 0; i >= 0 || j >= 0 || carry > 0; --i, --j) {
            carry += (i >= 0 ? a.charAt(i) - '0' : 0) + (j >= 0 ? b.charAt(j) - '0' : 0);
            sb.append(carry % 2);
            carry /= 2;
        }
        return sb.reverse().toString();
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(n)$ | TLE for large inputs |
| BigInteger | $O(n)$ | $O(n)$ | Handles large numbers |
| Carry Approach | $O(n)$ | $O(n)$ | Efficient, simulates addition |

---

## Summary

- Simulate binary addition with carry for efficiency.
- BigInteger approach handles large inputs easily.
- Brute force may fail for very large strings.
