# 679. 24 Game

## Problem Statement

Given four integers from `1` to `9`, determine whether they can be combined using `+`, `-`, `*`, `/`, and parentheses to make `24`. Division is real division; unary minus and concatenating numbers are not allowed.

## Sample Test Cases

### Example 1

```text
Input: cards = [4,1,8,7]
Output: true
```

One valid expression is `(8 - 4) * (7 - 1) = 24`.

### Example 2

```text
Input: cards = [1,2,1,2]
Output: false
```

## Brute Force: Pairwise Arithmetic Search

| Section | Details |
|---|---|
| **Intuition** | Every valid expression can be built by combining two available values with an operation, then combining the result with the remaining values. |
| **Approach** | Try every ordered pair, replace it with each valid result of `+`, `-`, `*`, or `/`, and recurse until one value remains. Check whether it is within `1e-6` of `24`. |
| **Time Complexity** | `O(1)` for this problem's fixed four cards; the exhaustive search is bounded by the constant-size input. |
| **Space Complexity** | `O(1)` for the fixed four cards, including recursion and temporary lists. |

```java
class Solution {
    public boolean judgePoint24(int[] cards) {
        List<Double> nums = new ArrayList<>();
        for (int c : cards) nums.add((double) c);
        return solve(nums);
    }

    private static boolean solve(List<Double> nums) {
        if (nums.size() == 1) return Math.abs(nums.get(0) - 24) < 1e-6;

        for (int i = 0; i < nums.size(); i++) {
            for (int j = 0; j < nums.size(); j++) {
                if (i == j) continue;
                List<Double> next = new ArrayList<>();
                for (int k = 0; k < nums.size(); k++)
                    if (k != i && k != j) next.add(nums.get(k));

                for (double val : compute(nums.get(i), nums.get(j))) {
                    next.add(val);
                    if (solve(next)) return true;
                    next.remove(next.size() - 1);
                }
            }
        }
        return false;
    }

    private static List<Double> compute(double a, double b) {
        List<Double> res = new ArrayList<>();
        res.add(a + b);
        res.add(a - b);
        res.add(b - a);
        res.add(a * b);
        if (Math.abs(b) > 1e-6) res.add(a / b);
        if (Math.abs(a) > 1e-6) res.add(b / a);
        return res;
    }
}
```

## Recursive Backtracking over Operations ✅

| Section | Details |
|---|---|
| **Intuition** | Recursively reduce the set of numbers by choosing two values and one operation at a time; ordered pairs cover both operand orders for subtraction and division. |
| **Approach** | For every ordered pair, keep the other values, try each operation, and recurse with the computed result. Skip division when the divisor is zero. When one value remains, compare it with `24` using a floating-point tolerance. |
| **Time Complexity** | `O(1)` for the fixed four cards; the search tries a bounded number of ordered pairs and operations. |
| **Space Complexity** | `O(1)` for the fixed four cards, including recursion and temporary lists. |

```java
class Solution {
     private final char[] ops = {'+', '-', '*', '/'};
    public boolean judgePoint24(int[] cards) {
        List<Double> nums = new ArrayList<>();
        for (int num : cards) {
            nums.add((double) num);
        }
        return dfs(nums);
    }

    private boolean dfs(List<Double> nums) {
        int n = nums.size();
        if (n == 1) {
            return Math.abs(nums.get(0) - 24) < 1e-6;
        }
        boolean ok = false;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i != j) {
                    List<Double> nxt = new ArrayList<>();
                    for (int k = 0; k < n; ++k) {
                        if (k != i && k != j) {
                            nxt.add(nums.get(k));
                        }
                    }
                    for (char op : ops) {
                        switch (op) {
                            case '/' -> {
                                if (nums.get(j) == 0) {
                                    continue;
                                }
                                nxt.add(nums.get(i) / nums.get(j));
                            }
                            case '*' -> {
                                nxt.add(nums.get(i) * nums.get(j));
                            }
                            case '+' -> {
                                nxt.add(nums.get(i) + nums.get(j));
                            }
                            case '-' -> {
                                nxt.add(nums.get(i) - nums.get(j));
                            }
                        }
                        ok |= dfs(nxt);
                        if (ok) {
                            return true;
                        }
                        nxt.remove(nxt.size() - 1);
                    }
                }
            }
        }
        return ok;
    }
}
```

## Approach Comparison

| Approach | Time Complexity for Four Cards | Space Complexity for Four Cards | Notes |
|---|---|---|---|
| Pairwise arithmetic search | `O(1)` | `O(1)` | Generates valid results in a helper method; checks both subtraction and division orders. |
| Recursive operation backtracking | `O(1)` | `O(1)` | Tries each operation for ordered pairs; skips zero divisors. |

## Summary

- Repeatedly combine two values with a binary operation until only one value remains.
- Ordered pairs are needed to explore both operand orders for subtraction and division.
- Use a tolerance when comparing floating-point results with `24`, and never divide by zero.
