
# 69. Sqrt(x)

## Problem Statement

Given a non-negative integer $x$, return the square root of $x$ rounded down to the nearest integer. The returned integer should be non-negative as well.

You must not use any built-in exponent function or operator.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| x = 4 | 2 | The square root of 4 is 2 |
| x = 8 | 2 | The square root of 8 is 2.82842..., rounded down to 2 |

---

## Constraints

- $0 \leq x \leq 2^{31} - 1$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Built-in | Use Math.sqrt | $O(1)$ | $O(1)$ |
| Binary Search | Find sqrt by searching | $O(\log x)$ | $O(1)$ |
| Brute Force | Increment until $i^2 > x$ | $O(\sqrt{x})$ | $O(1)$ |
| Recursive | Recursively increment | $O(\sqrt{x})$ | $O(\sqrt{x})$ |

---

## Code: Using Math.sqrt(x)

```java
class Solution {
    public int mySqrt(int x) {
        return (int)Math.sqrt(x);
    }
}
```

---

## Code: Binary Search Approach

```java
class Solution {
    public int mySqrt(int x) {
        int l = 0, r = x;
        while (l < r) {
            int mid = (l + r + 1) >>> 1;
            if (mid > x / mid) {
                r = mid - 1;
            } else {
                l = mid;
            }
        }
        return l;
    }
}
```

---

## Code: Brute Force Approach

```java
class Solution {
    public int mySqrt(int x) {
        int i = 0;
        while ((long)i * i <= x) i++;
        return i - 1;
    }
}
```

---

## Code: Recursive Approach

```java
class Solution {
    public int mySqrt(int x) {
        return helper(0, x);
    }
    private int helper(int i, int x) {
        if ((long)i * i > x) return i - 1;
        return helper(i + 1, x);
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Built-in | $O(1)$ | $O(1)$ | Not allowed by constraints |
| Binary Search | $O(\log x)$ | $O(1)$ | Efficient, recommended |
| Brute Force | $O(\sqrt{x})$ | $O(1)$ | Simple, slow for large $x$ |
| Recursive | $O(\sqrt{x})$ | $O(\sqrt{x})$ | Not efficient |

---

## Summary

- Binary search is the most efficient and recommended approach.
- Brute force and recursion are simple but not optimal for large $x$.
