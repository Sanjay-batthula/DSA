# 7. Reverse Integer

## Problem Description
Given a signed 32-bit integer x, return x with its digits reversed. If reversing x causes the value to go outside the signed 32-bit integer range [-231, 231 - 1], then return 0.

**Assume the environment does not allow you to store 64-bit integers (signed or unsigned).**


## Sample Test cases
Example 1:
```
Input: x = 123
Output: 321
```
Example 2:
```
Input: x = -123
Output: -321
```
Example 3:
```
Input: x = 120
Output: 21
```


## Brute Force (String Based)
| Section              | Details                                                       |
| -------------------- | ------------------------------------------------------------- |
| **Intuition**        | Reverse digits by converting the number to a string.          |
| **Approach**         | Convert to string, reverse it, parse back and check overflow. |
| **Time Complexity**  | `O(n)`                                                        |
| **Space Complexity** | `O(n)`                                                        |

```
class Solution {
    public int reverse(int x) {
        String s = Integer.toString(x);
        boolean neg = s.charAt(0) == '-';
        if (neg) s = s.substring(1);
        StringBuilder sb = new StringBuilder(s);
        sb.reverse();
        long res = Long.parseLong(sb.toString());
        if (neg) res = -res;
        if (res > Integer.MAX_VALUE || res < Integer.MIN_VALUE) return 0;
        return (int) res;
    }
}
```


## Mathematical / Iterative Approach
| Section              | Details                                                                 |
| -------------------- | ----------------------------------------------------------------------- |
| **Intuition**        | Build the reversed number digit by digit using modulo and division.     |
| **Approach**         | Extract last digit, append to result, and check overflow before update. |
| **Time Complexity**  | `O(n)`                                                                  |
| **Space Complexity** | `O(1)`                                                                  |

```
class Solution {
    public int reverse(int x) {
        int ans = 0;
        for (; x != 0; x /= 10) {
            if (ans < Integer.MIN_VALUE / 10 || ans > Integer.MAX_VALUE / 10) {
                return 0;
            }
            ans = ans * 10 + x % 10;
        }
        return ans;
    }
}
```

## Recursive Approach
| Section              | Details                                                        |
| -------------------- | -------------------------------------------------------------- |
| **Intuition**        | Same digit-by-digit reversal but implemented recursively.      |
| **Approach**         | Recursively extract digits and accumulate the reversed number. |
| **Time Complexity**  | `O(n)`                                                         |
| **Space Complexity** | `O(n)` (recursion stack)                                       |

```
class Solution {
    public int reverse(int x) {
        return helper(x, 0);
    }
    private int helper(int x, int ans) {
        if (x == 0) return ans;
        if (ans < Integer.MIN_VALUE / 10 || ans > Integer.MAX_VALUE / 10) return 0;
        return helper(x / 10, ans * 10 + x % 10);
    }
}
```

## Using Stack (Conceptual, not practical)
| Section              | Details                                                               |
| -------------------- | --------------------------------------------------------------------- |
| **Intuition**        | Stack naturally reverses order of digits.                             |
| **Approach**         | Push digits to stack, pop to rebuild reversed number, check overflow. |
| **Time Complexity**  | `O(n)`                                                                |
| **Space Complexity** | `O(n)`                                                                |

```
class Solution {
    public int reverse(int x) {
        boolean neg = x < 0;
        x = Math.abs(x);
        Stack<Integer> st = new Stack<>();
        while (x > 0) {
            st.push(x % 10);
            x /= 10;
        }
        long res = 0;
        long place = 1;
        while (!st.isEmpty()) {
            res += st.pop() * place;
            place *= 10;
        }
        if (neg) res = -res;
        return (res < Integer.MIN_VALUE || res > Integer.MAX_VALUE) ? 0 : (int) res;
    }
}
```

## Approach Comparision
| Approach             | Time Complexity | Space Complexity | Notes                           |
| -------------------- | --------------- | ---------------- | ------------------------------- |
| Brute Force (String) | O(n)            | O(n)             | Simple but violates constraints |
| Mathematical         | O(n)            | O(1)             | Optimal and recommended         |
| Recursive            | O(n)            | O(n)             | Clean but extra stack space     |
| Stack                | O(n)            | O(n)             | Conceptual, not practical       |


## Summary

- Mathematical / Iterative Approach is optimal and constraint-safe.
- Avoid string and stack solutions in interviews.
- Always check overflow before updating the result.
