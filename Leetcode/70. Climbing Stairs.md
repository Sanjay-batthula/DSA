
# 70. Climbing Stairs

## Problem Statement

You are climbing a staircase. It takes $n$ steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| n = 2 | 2 | Ways: [1+1], [2] |
| n = 3 | 3 | Ways: [1+1+1], [1+2], [2+1] |

---

## Constraints

- $1 \leq n \leq 45$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Recursion | $O(2^n)$ | $O(n)$ |
| Fibonacci | Iterative, use previous two values | $O(n)$ | $O(1)$ |
| Dynamic Programming | DP array | $O(n)$ | $O(n)$ |

---

## Code: Brute Force (Recursion) - TLE

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 1) return 1;
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
}
```

---

## Code: Fibonacci Approach

```java
class Solution {
    public int climbStairs(int n) {
        int a = 0, b = 1;
        for (int i = 0; i < n; ++i) {
            int c = a + b;
            a = b;
            b = c;
        }
        return b;
    }
}
```

---

## Code: Dynamic Programming

```java
class Solution {
    public int climbStairs(int n) {
        if (n <= 1) return 1;

        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(2^n)$ | $O(n)$ | Exponential, TLE for large $n$ |
| Fibonacci | $O(n)$ | $O(1)$ | Most efficient |
| Dynamic Programming | $O(n)$ | $O(n)$ | Easy to understand |

---

## Summary

- Fibonacci and DP approaches are efficient and recommended.
- Brute force recursion is simple but not practical for large $n$.
