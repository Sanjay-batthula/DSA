# 700. Search in a Binary Search Tree

---

## Problem Statement
You are given the root of a binary search tree (BST) and an integer `val`.

Find the node in the BST whose value equals `val` and return the subtree rooted with that node. If such a node does not exist, return `null`.

---

## Sample Cases

| Input                        | Output     | Explanation                                      |
|------------------------------|------------|--------------------------------------------------|
| root = [4,2,7,1,3], val = 2  | [2,1,3]    | Node with value 2 found, subtree is [2,1,3]       |
| root = [4,2,7,1,3], val = 5  | []         | No node with value 5, return null                 |

---

## Approaches

### Approach 1: Brute Force (DFS)
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Search every node recursively. | DFS on both left and right subtrees. | $O(n)$ | $O(n)$ (recursion stack) |

```java
public TreeNode searchBST(TreeNode root, int val) {
    if (root == null) return null;
    if (root.val == val) return root;
    TreeNode left = searchBST(root.left, val);
    if (left != null) return left;
    TreeNode right = searchBST(root.right, val);
    if (right != null) return right;
    return null;
}
```

---

### Approach 2: Optimized BST Search (Recursive)
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Use BST property to prune search. | Go left if val < root, right if val > root. | $O(h)$ | $O(h)$ (recursion stack) |

```java
public TreeNode searchBST(TreeNode root, int val) {
    if (root == null || root.val == val) {
        return root;
    }
    return root.val > val ? searchBST(root.left, val) : searchBST(root.right, val);
}
```

---

### Approach 3: Iterative BST Search
| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Avoid recursion by using a loop. | Traverse down the tree iteratively. | $O(h)$ | $O(1)$ |

```java
public TreeNode searchBST(TreeNode root, int val) {
    while (root != null && root.val != val) {
        root = val < root.val ? root.left : root.right;
    }
    return root;
}
```

---

## Approach Comparison

| Approach         | Time Complexity | Space Complexity | Notes                         |
|------------------|----------------|------------------|-------------------------------|
| Brute Force      | $O(n)$         | $O(n)$           | Ignores BST property           |
| BST Recursive    | $O(h)$         | $O(h)$           | Optimal for BST, uses stack    |
| BST Iterative    | $O(h)$         | $O(1)$           | Optimal, no recursion          |

---

## Summary
- The problem asks to find a node with a given value in a BST and return its subtree.
- Use the BST property for efficient search ($O(h)$ time).
- Iterative approach is most space-efficient.
- Brute force is not recommended for BSTs.
