# 75. Sort Colors

## Problem Statement
Sort an array of 0s, 1s, and 2s in-place so that all 0s come first, followed by all 1s, and then all 2s. The solution must avoid using the built-in sort function.

## Sample Test Cases
| Input | Output |
| --- | --- |
| `nums = [2,0,2,1,1,0]` | `[0,0,1,1,2,2]` |
| `nums = [2,0,1]` | `[0,1,2]` |

## Constraints
- `n == nums.length`
- `1 <= n <= 300`
- `nums[i]` is either `0`, `1`, or `2`

## Approaches
| Approach | Pattern | Time Complexity | Space Complexity |
| --- | --- | --- | --- |
| Three-pointer partitioning | Dutch National Flag / Three Pointers | `O(n)` | `O(1)` |

## Code
### Pattern
- Dutch National Flag
- Three Pointers

### Intuition
The array can be partitioned into three regions while scanning once: a prefix of 0s, a middle of 1s, and a suffix of 2s. The key is to keep track of where the next unknown element should be placed.

Using three pointers, we maintain a boundary for the 0-region, a boundary for the current element, and a boundary for the 2-region. As we process each value, we place it into the correct section without needing extra space.

### Algorithm
1. Initialize `low = 0`, `mid = 0`, and `high = nums.length - 1`.
2. While `mid <= high`:
   - If `nums[mid] == 0`, swap with `nums[low]`, then increment `low` and `mid`.
   - If `nums[mid] == 1`, increment `mid`.
   - If `nums[mid] == 2`, swap with `nums[high]`, then decrement `high`.
3. Return when the array is fully partitioned.

### Code
```java
class Solution {
    public void sortColors(int[] nums) {
        int low = 0, mid = 0, high = nums.length - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                int temp = nums[low];
                nums[low] = nums[mid];
                nums[mid] = temp;
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                int temp = nums[mid];
                nums[mid] = nums[high];
                nums[high] = temp;
                high--;
            }
        }
    }
}
```

### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(1)`

## Other Approaches
### Two-Pointer In-Place Partitioning Variant
#### Pattern
- Two Pointers
- In-place Partitioning

#### Intuition
This variant also sorts the array by moving 2s to the right and 0s to the left, but it uses a slightly different pointer structure. It is less direct than the standard three-pointer solution but still works in-place.

#### Algorithm
1. Set `zero = 0` and `second = nums.length - 1`.
2. Scan from left to right while `i <= second`.
3. Swap 2s to the right and 0s to the left as needed.
4. Continue until the array is partitioned.

#### Code
```java
class Solution {
    public void sortColors(int[] nums) {
        int zero = 0;
        int second = nums.length - 1;

        for (int i = zero; i <= second; i++) {
            while (nums[i] == 2 && i < second) {
                swap(nums, i, second--);
            }
            while (nums[i] == 0 && i > zero) {
                swap(nums, i, zero++);
            }
        }
    }

    public void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

#### Complexity
- Time Complexity: `O(n)`
- Space Complexity: `O(1)`

| Three-pointer partitioning | Dutch National Flag | `O(n)` | `O(1)` | Cleanest and most standard | Slightly more careful pointer handling |

## Key Observations
- The values are limited to only three possibilities, which makes partitioning natural.
- The array can be sorted in a single pass without extra memory.
- Swapping elements into the correct region preserves correctness while keeping the scan efficient.

## Common Mistakes
- Forgetting to update the pointers after swapping.
- Incorrectly handling the `mid` pointer when encountering a `2`.
- Assuming the array is sorted after only moving one type of value.

## Related Patterns
- Dutch National Flag
- Two Pointers
- In-place Partitioning

## Summary
- The optimal solution uses a single pass with three pointers to partition the array into 0s, 1s, and 2s.
- The pattern is Dutch National Flag, which is a classic interview problem.
- Time complexity is `O(n)`, and space complexity is `O(1)`.
- Interview takeaway: when values are constrained to a small set, partitioning with pointers is often the cleanest solution.
