# 75. Sort Colors

## Dutch National Flag (DNF) algorithm — two-pointer in-place partitioning variant.
```
class Solution {
    public void sortColors(int[] nums) {
        int zero = 0;
    int second = nums.length - 1;

    for (int i = zero; i <= second; i++) {
      while (nums[i] == 2 && i < second) {
        swap(nums, i, second--);
      }
      while (nums[i] == 0 && i > zero) {
        swap(nums, i, zero++);
      }
    }
  }

  public void swap(int[] nums, int i, int j) {
    int temp = nums[i];
    nums[i] = nums[j];
    nums[j] = temp;
  }
}
```

## Three-pointer Dutch National Flag algorithm
```
class Solution {
    public void sortColors(int[] nums) {
        int low = 0, mid = 0, high = nums.length - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                int temp = nums[low];
                nums[low] = nums[mid];
                nums[mid] = temp;
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                int temp = nums[mid];
                nums[mid] = nums[high];
                nums[high] = temp;
                high--;
            }
        }
    }
}
```
