# 769. Max Chunks To Make Sorted

## Problem Statement

Given a permutation `arr` of the integers from `0` to `n - 1`, split it into the maximum number of contiguous chunks such that sorting each chunk individually and concatenating them produces the fully sorted array.

The array has between 1 and 10 elements, and all values are unique.

## Sample Test Cases

### Example 1

```text
Input: arr = [4,3,2,1,0]
Output: 1
```

The entire array must be sorted as one chunk.

### Example 2

```text
Input: arr = [1,0,2,3,4]
Output: 4
```

One maximum partition is `[1,0]`, `[2]`, `[3]`, `[4]`.

## Prefix Maximum Greedy ✅

| Section | Details |
|---|---|
| **Intuition** | A chunk can end at index `i` when all values seen so far belong to the sorted prefix `0..i`. |
| **Approach** | Track the maximum value in the prefix ending at each index. When that maximum equals the current index, the prefix contains exactly the values `0` through `i`, so it can be sorted independently and forms a chunk boundary. |
| **Time Complexity** | `O(n)`. |
| **Space Complexity** | `O(1)` auxiliary space. |

```java
class Solution {
    public int maxChunksToSorted(int[] arr) {
        int ans = 0, mx = 0;
        for (int i = 0; i < arr.length; ++i) {
            mx = Math.max(mx, arr[i]);
            if (i == mx) {
                ++ans;
            }
        }
        return ans;
    }
}
```

## Summary

- For a permutation of `0..n-1`, a chunk boundary is valid when the prefix maximum equals its final index.
- Each such boundary can be sorted independently without affecting values in other chunks.
- A single pass finds the maximum number of chunks with constant auxiliary space.
