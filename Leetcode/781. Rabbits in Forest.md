# 781. Rabbits in Forest

## Problem Statement

Each rabbit reports how many other rabbits share its color. Given the reported answers, return the minimum possible total number of rabbits in the forest.

There is at least one answer, and each answer is between 0 and 999.

## Sample Test Cases

### Example 1

```text
Input: answers = [1,1,2]
Output: 5
```

The two rabbits answering `1` can form a group of two. A rabbit answering `2` needs a separate group of three, including two rabbits that were not surveyed.

### Example 2

```text
Input: answers = [10,10,10]
Output: 11
```

Each group of rabbits answering `10` must contain 11 rabbits. All three surveyed rabbits can belong to the same group.

## Frequency Counting + Group Formation ✅

| Section | Details |
|---|---|
| **Intuition** | If a rabbit answers `x`, its color group must contain exactly `x + 1` rabbits. Multiple rabbits giving the same answer can share such a group, but any remaining answers require another full group. |
| **Approach** | Count the frequency of each answer `x`. For group size `g = x + 1`, round the frequency up to a whole number of groups and add `ceil(frequency / g) * g` rabbits. |
| **Time Complexity** | `O(n)` expected, where `n` is the number of answers, assuming expected `O(1)` hash-map operations. |
| **Space Complexity** | `O(u)` for the map of `u` distinct answers. |

```java
class Solution {
    public int numRabbits(int[] answers) {
        Map<Integer, Integer> cnt = new HashMap<>();
        for (int x : answers) {
            cnt.merge(x, 1, Integer::sum);
        }
        int ans = 0;
        for (var e : cnt.entrySet()) {
            int group = e.getKey() + 1;
            ans += (e.getValue() + group - 1) / group * group;
        }
        return ans;
    }
}
```

## Summary

- An answer of `x` implies a same-color group size of `x + 1`.
- Round each answer's frequency up to a whole number of groups, since partial groups imply additional unsurveyed rabbits.
- Sum those rounded group sizes to obtain the minimum population.
