# 796. Rotate String

## Problem Statement

Given two strings $s$ and $goal$, return true if and only if $s$ can become $goal$ after some number of shifts on $s$.

A shift on $s$ consists of moving the leftmost character of $s$ to the rightmost position.

For example, if $s = \text{"abcde"}$, then it will be $\text{"bcdea"}$ after one shift.

---

## Sample Test Cases

| Input | Output |
|-------|--------|
| s = "abcde", goal = "cdeab" | true |
| s = "abcde", goal = "abced" | false |

---

## Constraints

- $1 \leq s.length,\ goal.length \leq 100$
- $s$ and $goal$ consist of lowercase English letters.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Try all rotations | $O(n^2)$ | $O(n)$ |
| String Trick | Concatenate and search | $O(n^2)$ | $O(n)$ |
| Queue | Simulate with queue | $O(n^2)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Try all rotations | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public boolean rotateString(String s, String goal) {
        if (s.length() != goal.length()) return false;
        int n = s.length();
        for (int i = 0; i < n; i++) {
            String rotated = s.substring(i) + s.substring(0, i);
            if (rotated.equals(goal)) return true;
        }
        return false;
    }
}
```

## Code: String Concatenation + Substring Search

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Concatenate and search | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public boolean rotateString(String s, String goal) {
        if(s.length()!=goal.length()){
            return false;
        }
        String combined=s+s;
        return combined.contains(goal);
    }
}
```

## Code: Queue Simulation

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Simulate with queue | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public boolean rotateString(String s, String goal) {
        if (s.length() != goal.length()) return false;
        Queue<Character> q = new LinkedList<>();
        for (char c : s.toCharArray()) q.add(c);
        for (int i = 0; i < s.length(); i++) {
            if (buildString(q).equals(goal)) return true;
            q.add(q.poll());
        }
        return false;
    }

    private String buildString(Queue<Character> q) {
        StringBuilder sb = new StringBuilder();
        for (char c : q) sb.append(c);
        return sb.toString();
    }
}
```

## Summary
- All approaches check if $goal$ is a rotation of $s$.
- String concatenation is concise and practical.
- All methods are $O(n^2)$ time for string comparison.
