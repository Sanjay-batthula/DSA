
# 83. Remove Duplicates from Sorted List

## Problem Statement

Given the head of a sorted linked list, delete all duplicates such that each element appears only once. Return the linked list sorted as well.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| head = [1,1,2] | [1,2] | Remove duplicate 1 |
| head = [1,1,2,3,3] | [1,2,3] | Remove duplicate 1 and 3 |

---

## Constraints

- The number of nodes in the list is in the range $[0, 300]$
- $-100 \leq \text{Node.val} \leq 100$
- The list is guaranteed to be sorted in ascending order

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Copy values, rebuild list | $O(n)$ | $O(n)$ |
| Recursion | Recursively remove duplicates | $O(n)$ | $O(n)$ |
| Two-pointer | In-place removal | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) return null;

        List<Integer> vals = new ArrayList<>();
        for (ListNode cur = head; cur != null; cur = cur.next) vals.add(cur.val);

        ListNode dummy = new ListNode(0), cur = dummy;
        cur.next = new ListNode(vals.get(0));
        cur = cur.next;
        for (int i = 1; i < vals.size(); i++) {
            if (!vals.get(i).equals(vals.get(i - 1))) {
                cur.next = new ListNode(vals.get(i));
                cur = cur.next;
            }
        }
        return dummy.next;
    }
}
```

---

## Code: Recursion

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null || head.next == null) return head;
        head.next = deleteDuplicates(head.next);
        return head.val == head.next.val ? head.next : head;
    }
}
```

---

## Code: Two-pointer Approach

```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) return null;

        ListNode slow = head, fast = head.next;
        while (fast != null) {
            if (slow.val != fast.val) {
                slow.next = fast;
                slow = fast;
            }
            fast = fast.next;
        }
        slow.next = null;
        return head;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(n)$ | Rebuilds list |
| Recursion | $O(n)$ | $O(n)$ | Elegant, but uses stack |
| Two-pointer | $O(n)$ | $O(1)$ | In-place, most efficient |

---

## Summary

- Two-pointer approach is most efficient and in-place.
- Recursion is elegant but uses extra stack space.
- Brute force copies values and rebuilds the list.
