
# 860. Lemonade Change

## Problem Statement

At a lemonade stand, each lemonade costs $5. Customers are standing in a queue to buy from you and order one at a time (in the order specified by bills). Each customer will only buy one lemonade and pay with either a $5, $10, or $20 bill. You must provide the correct change to each customer so that the net transaction is that the customer pays $5.

Note that you do not have any change in hand at first.

Given an integer array $bills$ where $bills[i]$ is the bill the $i$th customer pays, return true if you can provide every customer with the correct change, or false otherwise.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| bills = [5,5,5,10,20] | true | All customers get correct change |
| bills = [5,5,10,10,20] | false | Not enough change for last customer |

---

## Constraints

- $1 \leq bills.length \leq 10^5$
- $bills[i]$ is either 5, 10, or 20.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Simulate wallet with list | $O(n^2)$ | $O(n)$ |
| Greedy | Track $5/$10 bills | $O(n)$ | $O(1)$ |
| HashMap | Use map for bills | $O(n)$ | $O(1)$ |
| Priority Queue | Use min-heap (incorrect) | $O(n \log n)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Simulate wallet with list | $O(n^2)$ | $O(n)$ |

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        List<Integer> wallet = new ArrayList<>();
        
        for (int bill : bills) {
            if (bill == 5) {
                wallet.add(5);
            } else if (bill == 10) {
                if (wallet.contains(5)) {
                    wallet.remove(Integer.valueOf(5));
                    wallet.add(10);
                } else {
                    return false;
                }
            } else { // bill == 20
                if (wallet.contains(10) && wallet.contains(5)) {
                    wallet.remove(Integer.valueOf(10));
                    wallet.remove(Integer.valueOf(5));
                } else if (Collections.frequency(wallet, 5) >= 3) {
                    wallet.remove(Integer.valueOf(5));
                    wallet.remove(Integer.valueOf(5));
                    wallet.remove(Integer.valueOf(5));
                } else {
                    return false;
                }
            }
        }
        return true;
    }
}
```

## Code: Greedy Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track $5/$10 bills | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        int five = 0, ten = 0;
        for (int v : bills) {
            switch (v) {
                case 5 -> ++five;
                case 10 -> {
                    ++ten;
                    --five;
                }
                case 20 -> {
                    if (ten > 0) {
                        --ten;
                        --five;
                    } else {
                        five -= 3;
                    }
                }
            }
            if (five < 0) {
                return false;
            }
        }
        return true;
    }
}
```

## Code: HashMap Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use map for bills | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        Map<Integer, Integer> cash = new HashMap<>();
        cash.put(5, 0);
        cash.put(10, 0);
        
        for (int bill : bills) {
            if (bill == 5) {
                cash.put(5, cash.get(5) + 1);
            } else if (bill == 10) {
                if (cash.get(5) <= 0) return false;
                cash.put(5, cash.get(5) - 1);
                cash.put(10, cash.get(10) + 1);
            } else { // 20
                if (cash.get(10) > 0 && cash.get(5) > 0) {
                    cash.put(10, cash.get(10) - 1);
                    cash.put(5, cash.get(5) - 1);
                } else if (cash.get(5) >= 3) {
                    cash.put(5, cash.get(5) - 3);
                } else {
                    return false;
                }
            }
        }
        return true;
    }
}
```

## Code: Priority Queue Approach (Incorrect)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Use min-heap (incorrect) | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        
        for (int bill : bills) {
            pq.add(bill);
            int change = bill - 5;
            List<Integer> temp = new ArrayList<>();
            
            while (change > 0 && !pq.isEmpty()) {
                int smallest = pq.peek();
                if (smallest <= change) {
                    change -= smallest;
                    pq.poll();
                    temp.add(smallest);
                } else break;
            }
            
            if (change > 0) return false;
            pq.addAll(temp);
        }
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n^2)$ | $O(n)$ | Simulate wallet, slow |
| Greedy | $O(n)$ | $O(1)$ | Most efficient, recommended |
| HashMap | $O(n)$ | $O(1)$ | Alternative to greedy |
| Priority Queue | $O(n \log n)$ | $O(n)$ | Incorrect, for illustration |

---

## Summary
- Use greedy counting of $5 and $10 bills for optimal solution.
- Brute force and priority queue approaches are not practical.
- HashMap is an alternative but not needed for only two denominations.
