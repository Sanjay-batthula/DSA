# 872. Leaf-Similar Trees

## Problem Statement

Consider all the leaves of a binary tree, from left to right order, the values of those leaves form a leaf value sequence.

Two binary trees are considered leaf-similar if their leaf value sequence is the same.

Return true if and only if the two given trees with head nodes root1 and root2 are leaf-similar.

---

## Sample Test Cases

| Input | Output |
|-------|--------|
| root1 = [3,5,1,6,2,9,8,null,null,7,4], root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8] | true |
| root1 = [1,2,3], root2 = [1,3,2] | false |

---

## Constraints

- The number of nodes in each tree will be in the range $[1, 200]$.
- Both of the given trees will have values in the range $[0, 200]$.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| DFS | Collect leaf sequence for both trees | $O(N)$ | $O(H)$ |
| Stack/Iterator | Lazy DFS, compare leaves on the fly | $O(N)$ | $O(H)$ |

---

## Code: DFS Traversal with Leaf-Sequence Collection

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Collect leaf sequence for both trees | $O(N)$ | $O(H)$ |

```java
class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        List<Integer> l1 = new ArrayList<>();
        List<Integer> l2 = new ArrayList<>();
        dfs(root1, l1);
        dfs(root2, l2);
        return l1.equals(l2);
    }
    private void dfs(TreeNode root, List<Integer> nums) {
        if (root.left == root.right) {
            nums.add(root.val);
            return;
        }
        if (root.left != null) {
            dfs(root.left, nums);
        }
        if (root.right != null) {
            dfs(root.right, nums);
        }
    }
}
```

## Code: Lazy DFS using Stacks (Leaf Iterator / Two-pointer DFS)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Lazy DFS, compare leaves on the fly | $O(N)$ | $O(H)$ |

```java
import java.util.*;

class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        Deque<TreeNode> s1 = new ArrayDeque<>();
        Deque<TreeNode> s2 = new ArrayDeque<>();
        s1.push(root1);
        s2.push(root2);
        while (!s1.isEmpty() && !s2.isEmpty()) {
            int l1 = nextLeaf(s1);
            int l2 = nextLeaf(s2);
            if (l1 != l2) return false;
        }
        return s1.isEmpty() && s2.isEmpty();
    }
    private int nextLeaf(Deque<TreeNode> stack) {
        while (true) {
            TreeNode node = stack.pop();
            if (node.left == null && node.right == null) {
                return node.val;
            }
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| DFS | $O(N)$ | $O(H)$ | Collects all leaves, then compares |
| Lazy DFS | $O(N)$ | $O(H)$ | Compares leaves as found |

---

## Summary
- Both approaches traverse both trees to collect or compare leaf sequences.
- Lazy DFS can be more space efficient as it doesn't store all leaves at once.
