
# 88. Merge Sorted Array

## Problem Statement

You are given two integer arrays $\text{nums1}$ and $\text{nums2}$, sorted in non-decreasing order, and two integers $m$ and $n$, representing the number of elements in $\text{nums1}$ and $\text{nums2}$ respectively.

Merge $\text{nums1}$ and $\text{nums2}$ into a single array sorted in non-decreasing order.

The final sorted array should not be returned by the function, but instead be stored inside the array $\text{nums1}$. To accommodate this, $\text{nums1}$ has a length of $m + n$, where the first $m$ elements denote the elements that should be merged, and the last $n$ elements are set to $0$ and should be ignored. $\text{nums2}$ has a length of $n$.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3 | [1,2,2,3,5,6] | Merge [1,2,3] and [2,5,6] |
| nums1 = [1], m = 1, nums2 = [], n = 0 | [1] | Merge [1] and [] |
| nums1 = [0], m = 0, nums2 = [1], n = 1 | [1] | Merge [] and [1] |

---

## Constraints

- $\text{nums1.length} = m + n$
- $\text{nums2.length} = n$
- $0 \leq m, n \leq 200$
- $1 \leq m + n \leq 200$
- $-10^9 \leq \text{nums1}[i], \text{nums2}[j] \leq 10^9$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Copy, sort merged array | $O((m+n)\log(m+n))$ | $O(m+n)$ |
| Two-pointer | Merge from end in-place | $O(m+n)$ | $O(1)$ |

---

## Code: Brute Force

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int[] merged=new int[m+n];
        int idx = 0;
        for (int i=0;i<m;i++) {
            merged[idx++]=nums1[i];
        }
        for (int j=0;j<n;j++) {
            merged[idx++]=nums2[j];
        }
        java.util.Arrays.sort(merged);
        for (int k=0;k<m+n;k++) {
            nums1[k] = merged[k];
        }
    }
}
```

---

## Code: Two-pointer Approach

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        //two pointer approach
        int i=m-1;
        int j=n-1;
        int pos=m+n-1;

        while (j>=0) {
            if (i>=0 && nums1[i]>=nums2[j]) {
                nums1[pos]=nums1[i];
                i--;
            }else{
                nums1[pos]=nums2[j];
                j--;
            }
            pos--;
        }
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O((m+n)\log(m+n))$ | $O(m+n)$ | Uses extra array, sorts |
| Two-pointer | $O(m+n)$ | $O(1)$ | In-place, most efficient |

---

## Summary

- Two-pointer approach is most efficient and in-place.
- Brute force copies and sorts, uses extra space.
