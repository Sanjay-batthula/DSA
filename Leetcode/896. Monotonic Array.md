# 896. Monotonic Array

## Problem Statement

An array is monotonic if it is either monotone increasing or monotone decreasing.

An array $nums$ is monotone increasing if for all $i \leq j$, $nums[i] \leq nums[j]$. An array $nums$ is monotone decreasing if for all $i \leq j$, $nums[i] \geq nums[j]$.

Given an integer array $nums$, return true if the given array is monotonic, or false otherwise.

---

## Sample Test Cases

| Input | Output |
|-------|--------|
| nums = [1,2,2,3] | true |
| nums = [6,5,4,4] | true |
| nums = [1,3,2] | false |

---

## Constraints

- $1 \leq nums.length \leq 10^5$
- $-10^5 \leq nums[i] \leq 10^5$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Check both increasing and decreasing | $O(n)$ | $O(1)$ |
| Greedy | Single pass, early exit | $O(n)$ | $O(1)$ |
| Sorting | Compare with sorted arrays | $O(n \log n)$ | $O(n)$ |
| Sign of Differences | Track direction | $O(n)$ | $O(1)$ |
| Two Pointer | Track inc/dec flags | $O(n)$ | $O(1)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Check both increasing and decreasing | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean isMonotonic(int[] nums) {
        boolean increasing = true;
        boolean decreasing = true;
        
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < nums[i - 1]) increasing = false;
            if (nums[i] > nums[i - 1]) decreasing = false;
        }
        
        return increasing || decreasing;
    }
}
```

---

## Code: Greedy / Single-Pass Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Single pass, early exit | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean isMonotonic(int[] nums) {
        boolean asc = false, desc = false;
        for (int i = 1; i < nums.length; ++i) {
            if (nums[i - 1] < nums[i]) {
                asc = true;
            } else if (nums[i - 1] > nums[i]) {
                desc = true;
            }
            if (asc && desc) {
                return false;
            }
        }
        return true;
    }
}
```

## Code: Using Sorting

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Compare with sorted arrays | $O(n \log n)$ | $O(n)$ |

```java
class Solution {
    public boolean isMonotonic(int[] nums) {
        int[] asc = nums.clone();
        int[] desc = nums.clone();
        Arrays.sort(asc);
        Arrays.sort(desc);
        reverse(desc);
        return Arrays.equals(nums, asc) || Arrays.equals(nums, desc);
    }

    private void reverse(int[] arr) {
        int i = 0, j = arr.length - 1;
        while (i < j) {
            int tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
            i++;
            j--;
        }
    }
}
```

## Code: Sign of Differences

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track direction | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean isMonotonic(int[] nums) {
        int direction = 0;
        for (int i = 1; i < nums.length; i++) {
            int diff = nums[i] - nums[i - 1];
            if (diff == 0) continue;
            if (direction == 0) direction = diff > 0 ? 1 : -1;
            else if ((direction > 0 && diff < 0) || (direction < 0 && diff > 0)) return false;
        }
        return true;
    }
}
```

## Code: Two Pointer Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Track inc/dec flags | $O(n)$ | $O(1)$ |

```java
class Solution {
    public boolean isMonotonic(int[] nums) {
        int i = 0, j = 1;
        boolean inc = false, dec = false;
        while (j < nums.length) {
            if (nums[j] > nums[i]) inc = true;
            else if (nums[j] < nums[i]) dec = true;
            if (inc && dec) return false;
            i++;
            j++;
        }
        return true;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(1)$ | Checks both directions |
| Greedy | $O(n)$ | $O(1)$ | Early exit if not monotonic |
| Sorting | $O(n \log n)$ | $O(n)$ | Not optimal |
| Sign of Differences | $O(n)$ | $O(1)$ | Tracks direction |
| Two Pointer | $O(n)$ | $O(1)$ | Similar to greedy |

---

## Summary
- Monotonic arrays are either non-increasing or non-decreasing.
- Greedy and brute force approaches are both $O(n)$ and efficient.
- Sorting is not optimal for this problem.
