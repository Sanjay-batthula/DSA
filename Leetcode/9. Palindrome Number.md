# 9. Palindrome Number
## Problem Description
Given an integer x, return true if x is a palindrome, and false otherwise. An integer is a palindrome when it reads the same backward as forward.

## Sample Test Cases
Example 1:
```
Input: x = 121
Output: true
```
Explanation: 121 reads as 121 from left to right and from right to left.  

Example 2:
```
Input: x = -121
Output: false
```
Explanation: From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome.  

Example 3:
```
Input: x = 10
Output: false
```
Explanation: Reads 01 from right to left. Therefore it is not a palindrome.  

## Brute force (String Reverse)
| Section              | Details                                             |
| -------------------- | --------------------------------------------------- |
| **Intuition**        | A palindrome reads the same forward and backward.   |
| **Approach**         | Convert integer to string, reverse it, and compare. |
| **Time Complexity**  | `O(n)`                                              |
| **Space Complexity** | `O(n)`                                              |

```
class Solution {
    public boolean isPalindrome(int x) {
        String s = String.valueOf(x);
        String rev = new StringBuilder(s).reverse().toString();
        return s.equals(rev);
    }
}
```


## Half Reversal Approach
| Section              | Details                                                  |
| -------------------- | -------------------------------------------------------- |
| **Intuition**        | Only half the digits need to be reversed and compared.   |
| **Approach**         | Reverse last half of digits and compare with first half. |
| **Time Complexity**  | `O(n)`                                                   |
| **Space Complexity** | `O(1)`                                                   |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0 || (x % 10 == 0 && x != 0)) return false;
        int rev = 0;
        while (x > rev) {
            rev = rev * 10 + x % 10;
            x /= 10;
        }
        return x == rev || x == rev / 10;
    }
}
```


## Full Reversal 
| Section              | Details                                              |
| -------------------- | ---------------------------------------------------- |
| **Intuition**        | Reverse the entire number and compare with original. |
| **Approach**         | Use arithmetic operations to reverse digits.         |
| **Time Complexity**  | `O(n)`                                               |
| **Space Complexity** | `O(1)`                                               |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        long rev = 0, n = x;
        while (n != 0) {
            rev = rev * 10 + n % 10;
            n /= 10;
        }
        return rev == x;
    }
}
```


## Half Reversal (Loop Variant)
| Section              | Details                                                      |
| -------------------- | ------------------------------------------------------------ |
| **Intuition**        | Build reversed half dynamically using loop condition.        |
| **Approach**         | Stop when reversed half becomes greater than remaining part. |
| **Time Complexity**  | `O(n)`                                                       |
| **Space Complexity** | `O(1)`                                                       |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0 || (x > 0 && x % 10 == 0)) {
            return false;
        }
        int y = 0;
        for (; y < x; x /= 10) {
            y = y * 10 + x % 10;
        }
        return x == y || x == y / 10;
    }
}
```

## Array Conversion Approach - Runtime Error
| Section              | Details                                              |
| -------------------- | ---------------------------------------------------- |
| **Intuition**        | Compare digits stored in an array from both ends.    |
| **Approach**         | Extract digits into array and compare symmetrically. |
| **Time Complexity**  | `O(n)`                                               |
| **Space Complexity** | `O(n)`                                               |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        int n = (int) Math.log10(x) + 1;
        int[] digits = new int[n];
        for (int i = 0; i < n; i++) {
            digits[i] = x % 10;
            x /= 10;
        }
        for (int i = 0; i < n / 2; i++) {
            if (digits[i] != digits[n - i - 1]) return false;
        }
        return true;
    }
}
```

## Two-Pointer String Approach
| Section              | Details                                               |
| -------------------- | ----------------------------------------------------- |
| **Intuition**        | Palindrome comparison can be done using two pointers. |
| **Approach**         | Compare characters from both ends of string.          |
| **Time Complexity**  | `O(n)`                                                |
| **Space Complexity** | `O(n)`                                                |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        String s = String.valueOf(x);
        int left = 0, right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left++) != s.charAt(right--)) return false;
        }
        return true;
    }
}
```

## Digit Comparison Without Reversal
| Section              | Details                                                         |
| -------------------- | --------------------------------------------------------------- |
| **Intuition**        | Compare most significant and least significant digits directly. |
| **Approach**         | Use divisor to extract digits from both ends.                   |
| **Time Complexity**  | `O(n)`                                                          |
| **Space Complexity** | `O(1)`                                                          |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        int div = 1;
        while (x / div >= 10) div *= 10;
        while (x != 0) {
            int left = x / div;
            int right = x % 10;
            if (left != right) return false;
            x = (x % div) / 10;
            div /= 100;
        }
        return true;
    }
}
```

## Recursive Numeric Check
| Section              | Details                                                    |
| -------------------- | ---------------------------------------------------------- |
| **Intuition**        | Compare digits recursively from outer to inner.            |
| **Approach**         | Use divisor and recursion to shrink number from both ends. |
| **Time Complexity**  | `O(n)`                                                     |
| **Space Complexity** | `O(n)`                                                     |

```
class Solution {
    private int div = 1;
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        while (x / div >= 10) div *= 10;
        return helper(x);
    }
    private boolean helper(int x) {
        if (x == 0) return true;
        int left = x / div;
        int right = x % 10;
        if (left != right) return false;
        x = (x % div) / 10;
        div /= 100;
        return helper(x);
    }
}
```

## Mathematical Mirror Check (Using Logarithms)
| Section              | Details                                         |
| -------------------- | ----------------------------------------------- |
| **Intuition**        | Use digit positions to compare mirrored digits. |
| **Approach**         | Extract digits using powers of 10.              |
| **Time Complexity**  | `O(n)`                                          |
| **Space Complexity** | `O(1)`                                          |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        int digits = (int)Math.log10(x) + 1;
        for (int i = 0; i < digits / 2; i++) {
            int left = (x / (int)Math.pow(10, digits - i - 1)) % 10;
            int right = (x / (int)Math.pow(10, i)) % 10;
            if (left != right) return false;
        }
        return true;
    }
}
```

## Stream / Functional Approach
| Section              | Details                                           |
| -------------------- | ------------------------------------------------- |
| **Intuition**        | Functional comparison of digits using streams.    |
| **Approach**         | Store digits and validate symmetry using streams. |
| **Time Complexity**  | `O(n)`                                            |
| **Space Complexity** | `O(n)`                                            |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        List<Integer> digits = new ArrayList<>();
        int temp = x;
        while (temp != 0) {
            digits.add(temp % 10);
            temp /= 10;
        }
        return IntStream.range(0, digits.size() / 2)
                .allMatch(i -> Objects.equals(digits.get(i), digits.get(digits.size() - i - 1)));
    }
}
```

## Recursive Two-Pointer (String version)
| Section              | Details                                        |
| -------------------- | ---------------------------------------------- |
| **Intuition**        | Two-pointer palindrome logic using recursion.  |
| **Approach**         | Recursively compare characters from both ends. |
| **Time Complexity**  | `O(n)`                                         |
| **Space Complexity** | `O(n)`                                         |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        String s = String.valueOf(x);
        return helper(s, 0, s.length() - 1);
    }
    private boolean helper(String s, int left, int right) {
        if (left >= right) return true;
        return s.charAt(left) == s.charAt(right) && helper(s, left + 1, right - 1);
    }
}
```

## Queue + Stack Comparison
| Section              | Details                                       |
| -------------------- | --------------------------------------------- |
| **Intuition**        | Stack reverses order, queue preserves order.  |
| **Approach**         | Compare elements popped from stack and queue. |
| **Time Complexity**  | `O(n)`                                        |
| **Space Complexity** | `O(n)`                                        |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        String s = String.valueOf(x);
        Stack<Character> stack = new Stack<>();
        Queue<Character> queue = new LinkedList<>();
        for (char c : s.toCharArray()) {
            stack.push(c);
            queue.add(c);
        }
        while (!stack.isEmpty()) {
            if (!stack.pop().equals(queue.poll())) return false;
        }
        return true;
    }
}
```

## Pattern Matching via Regex
| Section              | Details                                             |
| -------------------- | --------------------------------------------------- |
| **Intuition**        | A palindrome equals its reversed string.            |
| **Approach**         | Match original string with its reverse using regex. |
| **Time Complexity**  | `O(n)`                                              |
| **Space Complexity** | `O(n)`                                              |

```
class Solution {
    public boolean isPalindrome(int x) {
        if (x < 0) return false;
        String s = String.valueOf(x);
        return s.matches(new StringBuilder(s).reverse().toString());
    }
}
```

## Approach Comparison
| Approach                        | Time Complexity | Space Complexity | Notes                        |
| ------------------------------- | --------------- | ---------------- | ---------------------------- |
| Half Reversal                   | O(n)            | O(1)             | **Best & interview optimal** |
| Digit Comparison (No Reversal)  | O(n)            | O(1)             | Clean math-based solution    |
| Full Reversal                   | O(n)            | O(1)             | Risk of overflow             |
| String / Array / Stack / Stream | O(n)            | O(n)             | Easy but extra memory        |
| Regex / Functional              | O(n)            | O(n)             | Not recommended              |


## Summary

- Half Reversal Approach is optimal and safest.
- Avoid string-based solutions in interviews.
- Always handle negative numbers and trailing zeros.
