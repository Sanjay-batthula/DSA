# 916. Word Subsets

## Problem Statement

Given string arrays `words1` and `words2`, return all strings in `words1` that contain every string in `words2` as a subset. A string is a subset of another when it contains each letter with at least the same multiplicity.

The arrays each contain 1 to `10^4` strings. Each string contains 1 to 10 lowercase English letters, and strings in `words1` are unique.

## Sample Test Cases

### Example 1

```text
Input: words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["e","o"]
Output: ["facebook","google","leetcode"]
```

### Example 2

```text
Input: words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["lc","eo"]
Output: ["leetcode"]
```

### Example 3

```text
Input: words1 = ["acaac","cccbb","aacbb","caacc","bcbbb"], words2 = ["c","cc","b"]
Output: ["cccbb"]
```

## Maximum Letter Frequencies ✅

| Section | Details |
|---|---|
| **Intuition** | A word in `words1` must satisfy every requirement in `words2`. For each letter, only the greatest count required by any single `words2` word is needed. |
| **Approach** | Count each `words2` word's letters and keep the per-letter maximum. For each `words1` word, count its letters and check that every count meets or exceeds this maximum requirement. |
| **Time Complexity** | `O(L1 + L2 + 26 * (|words1| + |words2|))`, where `L1` and `L2` are the total character counts in the arrays. The fixed 26-letter checks are constant per word. |
| **Space Complexity** | `O(26 + Lmax)` auxiliary space, where `Lmax` is the maximum word length, due to the frequency arrays and `toCharArray()` temporary array. This is constant under the given length limit, excluding the returned list. |

```java
class Solution {
    public List<String> wordSubsets(String[] words1, String[] words2) {
        int[] maxFreq = new int[26];

        for (String b : words2) {
            int[] freq = count(b);
            for (int i = 0; i < 26; i++) {
                maxFreq[i] = Math.max(maxFreq[i], freq[i]);
            }
        }

        List<String> res = new ArrayList<>();
        for (String a : words1) {
            int[] freq = count(a);
            boolean ok = true;
            for (int i = 0; i < 26; i++) {
                if (freq[i] < maxFreq[i]) {
                    ok = false;
                    break;
                }
            }
            if (ok) res.add(a);
        }
        return res;
    }

    private int[] count(String s) {
        int[] freq = new int[26];
        for (char ch : s.toCharArray()) {
            freq[ch - 'a']++;
        }
        return freq;
    }
}
```

## Python Counter Approach

| Section | Details |
|---|---|
| **Intuition** | As in the array-based solution, each letter's required count is the maximum count needed by any word in `words2`. |
| **Approach** | Use `Counter` to count letters and merge each word's counts into a maximum requirement. Include a `words1` word when its counter meets every required count. |
| **Time Complexity** | `O(L1 + L2 + 26 * (|words1| + |words2|))` in the worst case; each string has at most 10 characters and the alphabet has 26 letters. |
| **Space Complexity** | `O(26)` for the frequency requirements and current word counters, excluding the result list. |

```python
class Solution:
    def wordSubsets(self, words1: List[str], words2: List[str]) -> List[str]:
        cnt = Counter()
        for b in words2:
            t = Counter(b)
            for c, v in t.items():
                cnt[c] = max(cnt[c], v)
        ans = []
        for a in words1:
            t = Counter(a)
            if all(v <= t[c] for c, v in cnt.items()):
                ans.append(a)
        return ans
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|---|---|---|---|
| Java frequency arrays | `O(L1 + L2 + 26 * (|words1| + |words2|))` | `O(26 + Lmax)` auxiliary | Uses fixed-size arrays for lowercase letters and a temporary character array when counting each word. |
| Python `Counter` | `O(L1 + L2 + 26 * (|words1| + |words2|))` worst case | `O(26)` auxiliary | Uses counters to express the same maximum-frequency test. |

## Summary

- Combine `words2` into one per-letter requirement by taking the maximum frequency of each letter.
- A `words1` word is universal if its frequency meets every combined requirement.
- Both existing implementations apply the same check using different frequency-counting tools.
