# 933. Number of Recent Calls

## Problem Statement

You have a RecentCounter class which counts the number of recent requests within a certain time frame.

Implement the RecentCounter class:

- RecentCounter() Initializes the counter with zero recent requests.
- int ping(int t) Adds a new request at time t, where t represents some time in milliseconds, and returns the number of requests that has happened in the past 3000 milliseconds (including the new request). Specifically, return the number of requests that have happened in the inclusive range $[t - 3000, t]$.

It is guaranteed that every call to ping uses a strictly larger value of t than the previous call.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| ["RecentCounter", "ping", "ping", "ping", "ping"], [[], [1], [100], [3001], [3002]] | [null, 1, 2, 3, 3] | See below |

Explanation:
RecentCounter recentCounter = new RecentCounter();
recentCounter.ping(1);     // requests = [1], range is [-2999,1], return 1
recentCounter.ping(100);   // requests = [1, 100], range is [-2900,100], return 2
recentCounter.ping(3001);  // requests = [1, 100, 3001], range is [1,3001], return 3
recentCounter.ping(3002);  // requests = [1, 100, 3001, 3002], range is [2,3002], return 3

---

## Constraints

- $1 \leq t \leq 10^9$
- Each test case will call ping with strictly increasing values of t.
- At most $10^4$ calls will be made to ping.

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|----------------|-----------------|
| Brute Force | Scan all requests | $O(n)$ | $O(n)$ |
| Queue | Remove outdated requests | $O(1)$ amortized | $O(n)$ |
| Binary Search | Find left bound in sorted list | $O(\log n)$ | $O(n)$ |

---

## Code: Brute Force

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Scan all requests | $O(n)$ | $O(n)$ |

```java
class RecentCounter {
    List<Integer> requests;

    public RecentCounter() {
        requests = new ArrayList<>();
    }
    
    public int ping(int t) {
        requests.add(t);
        int count = 0;
        for (int time : requests) {
            if (time >= t - 3000 && time <= t) count++;
        }
        return count;
    }
}
```

---

## Code: Optimized (Queue-Based) Approach

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Remove outdated requests | $O(1)$ amortized | $O(n)$ |

```java
import java.util.LinkedList;
import java.util.Queue;

class RecentCounter {
    private Queue<Integer> requests;

    public RecentCounter() {
        requests = new LinkedList<>();
    }

    public int ping(int t) {
        requests.add(t);
        while (requests.peek() < t - 3000) {
            requests.poll();
        }
        return requests.size();
    }
}
```

---

## Code: Binary Search (using ArrayList)

| Approach | Time Complexity | Space Complexity |
|----------|----------------|-----------------|
| Find left bound in sorted list | $O(\log n)$ | $O(n)$ |

```java
class RecentCounter {
    List<Integer> list;
    public RecentCounter() {
        list = new ArrayList<>();
    }
    public int ping(int t) {
        list.add(t);
        int low = 0, high = list.size() - 1;
        while (low < high) {
            int mid = (low + high) / 2;
            if (list.get(mid) < t - 3000) low = mid + 1;
            else high = mid;
        }
        return list.size() - low;
    }
}
```

---

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|----------------|-----------------|-------|
| Brute Force | $O(n)$ | $O(n)$ | Scans all requests |
| Queue | $O(1)$ amortized | $O(n)$ | Most efficient for this problem |
| Binary Search | $O(\log n)$ | $O(n)$ | Needs sorted list, not as practical |

---

## Summary
- Use a queue to efficiently remove outdated requests and count recent calls.
- Brute force is simple but slow for large $n$.
- Binary search is possible but not as practical as queue.
