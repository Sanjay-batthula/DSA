
# 94. Binary Tree Inorder Traversal

## Problem Statement

Given the root of a binary tree, return the inorder traversal of its nodes' values.

---

## Sample Test Cases

| Input | Output | Explanation |
|-------|--------|-------------|
| root = [1,null,2,3] | [1,3,2] | Inorder traversal: left, root, right |
| root = [1,2,3,4,5,null,8,null,null,6,7,9] | [4,2,6,5,7,1,3,9,8] | Inorder traversal |
| root = [] | [] | Empty tree |
| root = [1] | [1] | Single node |

---

## Constraints

- The number of nodes in the tree is in the range $[0, 100]$
- $-100 \leq \text{Node.val} \leq 100$

---

## Approaches

| Intuition | Approach | Time Complexity | Space Complexity |
|-----------|----------|-----------------|-----------------|
| Brute Force | Collect, sort by index | $O(n\log n)$ | $O(n)$ |
| Recursive | Classic inorder traversal | $O(n)$ | $O(n)$ |
| Iterative | Stack-based traversal | $O(n)$ | $O(n)$ |

---

## Code: Brute Force

```java
class Solution {
    int idx = 0;
    public List<Integer> inorderTraversal(TreeNode root) {
        List<int[]> list = new ArrayList<>();
        collect(root, list);
        list.sort((a, b) -> a[0] - b[0]);
        List<Integer> res = new ArrayList<>();
        for (int[] x : list) res.add(x[1]);
        return res;
    }
    void collect(TreeNode root, List<int[]> list){
        if (root == null) return;
        collect(root.left, list);
        list.add(new int[]{idx++, root.val});
        collect(root.right, list);
    }
}
```

## Code: Classic Recursive Inorder Traversal

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res=new ArrayList<>();
        helper(root,res);
        return res;
    }
    public void helper(TreeNode root, List<Integer> res){
        if(root !=null){
            helper(root.left,res);
            res.add(root.val);
            helper(root.right,res);
        }
    }
}
```

## Code: Iterative Inorder Traversal Using a Stack

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> al = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        TreeNode curr = root;
        while (curr != null || !stack.isEmpty()) {
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            curr=stack.pop();
            al.add(curr.val);
            curr=curr.right;
        }
        return al;
    }
}
```

---

## Code: Iterative DFS Inorder with Explicit Stack

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        while(root!=null || !stack.isEmpty()){
            if(root!=null){
                stack.push(root);
                root=root.left;
            }else{
                TreeNode node=stack.pop();
                result.add(node.val);
                root=node.right;
            }
        }
        return result;
    }
}
```

## Approach Comparison

| Approach | Time Complexity | Space Complexity | Notes |
|----------|-----------------|-----------------|-------|
| Brute Force | $O(n\log n)$ | $O(n)$ | Collects and sorts |
| Recursive | $O(n)$ | $O(n)$ | Classic, easy to implement |
| Iterative | $O(n)$ | $O(n)$ | Stack-based, avoids recursion |

---

## Summary

- Recursive and iterative stack-based approaches are efficient and standard.
- Brute force collects and sorts, less optimal.
