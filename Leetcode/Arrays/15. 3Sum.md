# 3Sum Problem

## Intuition
We want to find all unique triplets in the array that sum up to zero.  
A brute-force approach would involve checking all triplets, but that’s too slow (`O(n³)`).  
By sorting the array first and then using a **two-pointer technique**, we can speed things up while avoiding duplicate triplets.

---

## Approach
1. **Sort the array** so we can use the two-pointer technique and handle duplicates easily.
2. Loop through the array with index `i`:
   - Skip duplicate values for `i` to avoid repeated triplets.
   - Set two pointers:
     - `j` starts at `i + 1`
     - `k` starts at `n - 1`
   - Calculate the sum `nums[i] + nums[j] + nums[k]`.
     - If the sum is less than `0`, move `j` right (increase sum).
     - If the sum is greater than `0`, move `k` left (decrease sum).
     - If the sum is `0`, store the triplet and move both pointers, skipping duplicates.
3. Continue until all valid triplets are found.

---

## Complexity
- **Time Complexity:**  
  `O(n²)` — Sorting takes `O(n log n)` and the two-pointer search for each element takes `O(n)`.

- **Space Complexity:**  
  `O(1)` — Ignoring the output list, we only use a few extra variables.

---

## Code
```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n - 2 && nums[i] <= 0; ++i) {
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }
            int j = i + 1, k = n - 1;
            while (j < k) {
                int x = nums[i] + nums[j] + nums[k];
                if (x < 0) {
                    ++j;
                } else if (x > 0) {
                    --k;
                } else {
                    ans.add(List.of(nums[i], nums[j++], nums[k--]));
                    while (j < k && nums[j] == nums[j - 1]) {
                        ++j;
                    }
                    while (j < k && nums[k] == nums[k + 1]) {
                        --k;
                    }
                }
            }
        }
        return ans;
    }
}
```
