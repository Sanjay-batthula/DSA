# Intuition
The problem asks for generating the next lexicographically greater permutation of a sequence of numbers.  
If no such permutation exists (i.e., the array is in descending order), we must rearrange it to the lowest possible order (ascending).

Key insight:  
- We can find a pivot point from the right where the sequence stops increasing, swap it with the next larger number to the right, and then reverse the remaining tail.



# Approach
1. **Find the pivot**:  
   Traverse from the right until you find the first index `i` such that `nums[i] < nums[i+1]`.  
   This is the point where the ascending order breaks when moving from right to left.
   
2. **Find the next larger element**:  
   If such `i` exists, traverse again from the right to find the first element greater than `nums[i]` and swap them.

3. **Reverse the suffix**:  
   Reverse the subarray from `i+1` to the end to get the smallest possible order for that suffix.

4. **Special case**:  
   If no `i` is found (the array is entirely non-increasing), reverse the whole array to get the smallest permutation.



# Complexity
- Time complexity:
- **Time complexity:** \(O(n)\) —  
  Each step involves a linear scan or reversal over part of the array.
  
- **Space complexity:** \(O(1)\) —  
  The rearrangement is done in-place with constant extra space.

# Code
```java []
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums.length <= 1) return;
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = nums.length - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, nums.length - 1);
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    private void reverse(int[] nums, int i, int j) {
        while (i < j) swap(nums, i++, j--);
    }
}
```
