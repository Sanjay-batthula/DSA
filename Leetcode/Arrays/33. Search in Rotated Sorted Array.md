# Intuition
The problem asks to search for a target value in a rotated sorted array. My first thought is to use a modified binary search, since the array is sorted but rotated, which means there are two sorted subarrays.

# Approach
We use binary search to efficiently find the target. At each step, we check if the middle element is in the left sorted portion or the right sorted portion. Depending on where the target could be, we adjust our search boundaries (start and end). The loop continues until start equals end, and we check if the target is found.

# Complexity
Time complexity:
$$O(\log n)$$
Binary search divides the search space in half each time.

Space complexity:
$$O(1)$$
Only a constant amount of extra space is used.

# Code
```java []
class Solution {
    public int search(int[] nums, int target) {
        int n = nums.length;
        int start = 0, end = n - 1;
        while (start < end) {
            int mid = (start + end) / 2;
            if (nums[0] <= nums[mid]) {
                if (nums[0] <= target && target <= nums[mid]) {
                    end = mid;
                } else {
                    start = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[n - 1]) {
                    start = mid + 1;
                } else {
                    end = mid;
                }
            }
        }
        return nums[start] == target ? start : -1;
    }
}
```
