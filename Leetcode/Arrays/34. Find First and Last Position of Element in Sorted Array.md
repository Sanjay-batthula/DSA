# Intuition
The problem asks to find the **first** and **last** positions of a given `target` in a sorted array.  
A direct scan would take \(O(n)\), but since the array is sorted, binary search can find boundaries in \(O(\log n)\).
Key observation:  
- The **first occurrence** of `target` can be found by binary searching for `target` itself.  
- The **last occurrence** can be found by binary searching for the first index where the value is **greater than** `target` (i.e., `target + 1`) and subtracting one.

- - -

# Approach
1. **Binary search for the left boundary**:
   - Use `findFirst(nums, target)` to find the first index where `nums[i] >= target`.
   
2. **Binary search for the right boundary**:
   - Use `findFirst(nums, target + 1)` to find the first index where `nums[i] >= target + 1`.
   - Subtract one to get the last position of `target`.

3. **Check if target exists**:
   - If `leftIndex == rightIndex`, target is not present → return `[-1, -1]`.

4. **Return result**:
   - Return `[leftIndex, rightIndex - 1]` as the range.

# Complexity
- **Time complexity:** \(O(\log n)\) —  
  Each boundary is found with a binary search.
  
- **Space complexity:** \(O(1)\) —  
  Uses only constant extra space.


# Code
```java []
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int leftIndex = findFirst(nums, target);
        int rightIndex = findFirst(nums, target + 1);
        if (leftIndex == rightIndex) {
            return new int[] {-1, -1};
        } else {
            return new int[] {leftIndex, rightIndex - 1};
        }
    }

    private int findFirst(int[] nums, int x) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = (left + right) >>> 1;
            if (nums[mid] >= x) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
}
```
