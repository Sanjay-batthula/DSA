# 1. Two Sum 

## 🚀 Intuition
You’re given an array of integers and a target value. The goal is to find **two numbers** in the array that add up to the target.  
Using a **hash map** lets us store numbers we’ve seen so far and check if the complement (target - current number) exists — all in constant time.

---

## 🧠 Approach
1. Initialize an empty hash map.
2. Loop through each number in the array:
   - Let `x` be the current number.
   - Calculate `y = target - x`.
   - Check if `y` exists in the map:
     - If yes, return indices of `y` and `x`.
     - If not, store `x` in the map with its index.
3. Since the problem guarantees a solution, a return is guaranteed during the loop.

---

## ⏱️ Complexity

- **Time Complexity:**  
  $$O(n)$$ — Looping through the array once.

- **Space Complexity:**  
  $$O(n)$$ — In the worst case, all elements stored in the map.

---

## Brute force approach
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        
        for(int i=0;i<nums.length;i++){
            for(int j=i+1;j<nums.length;j++){
                if(nums[i]+nums[j]==target){
                    return new int[]{i,j};
                }
            }
        }
        return new int[]{};
    }
}
```

## HashMap approach
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> d = new HashMap<>();
        for (int i = 0;; ++i) {
            int x = nums[i];
            int y = target - x;
            if (d.containsKey(y)) {
                return new int[] {d.get(y), i};
            }
            d.put(x, i);
        }
    }
}
```

## Two-pass HashMap
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) map.put(nums[i], i);
        for (int i = 0; i < nums.length; i++) {
            int y = target - nums[i];
            if (map.containsKey(y) && map.get(y) != i) return new int[]{i, map.get(y)};
        }
        return new int[]{};
    }
}
```

## Two-pointer Approach (after sorting)
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int[][] arr = new int[nums.length][2];
        for (int i = 0; i < nums.length; i++) arr[i] = new int[]{nums[i], i};
        Arrays.sort(arr, Comparator.comparingInt(a -> a[0]));
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int sum = arr[left][0] + arr[right][0];
            if (sum == target) return new int[]{arr[left][1], arr[right][1]};
            else if (sum < target) left++;
            else right--;
        }
        return new int[]{};
    }
}
```

## Binary Search (for sorted arrays) - Wrong Answer
```
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            int idx = Arrays.binarySearch(nums, i + 1, nums.length, complement);
            if (idx > i) return new int[]{i, idx};
        }
        return new int[]{};
    }
}
```
