### Four Sum Problem

# Intuition
We need to find all unique quadruplets in the array that sum up to a given target.
A brute-force approach would check all quadruplets in O(n⁴) time, but that’s inefficient.
By sorting the array and fixing two numbers, then using the two-pointer technique for the remaining two numbers, we can reduce it to O(n³) while also avoiding duplicates efficiently.

# Approach
Sort the array to make duplicate handling and two-pointer logic easier.

Iterate with the first index i from 0 to n - 4:

Skip duplicates for i to avoid repeating quadruplets.

Iterate with the second index j from i + 1 to n - 3:

Skip duplicates for j as well.

Use two pointers:

k = j + 1 (left pointer)

l = n - 1 (right pointer)

Compute the sum as long (to avoid integer overflow) → sum = nums[i] + nums[j] + nums[k] + nums[l].

If sum == target, store the quadruplet and skip duplicates for k and l.

If sum < target, move k++ to increase the sum.

If sum > target, move l-- to decrease the sum.

Return the list of all found quadruplets.

# Complexity
- Time complexity:
O(n³) — Sorting takes O(n log n), and we have a nested loop with two pointers.

- Space complexity:
O(1) extra space (ignoring the result storage).

# Code
```java []
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < n; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int k = j + 1, l = n - 1;

                while (k < l) {
                    long sum = (long) nums[i] + nums[j] + nums[k] + nums[l];

                    if (sum == target) {
                        ans.add(Arrays.asList(nums[i], nums[j], nums[k], nums[l]));

                        while (k < l && nums[k] == nums[k + 1]) k++;
                        while (k < l && nums[l] == nums[l - 1]) l--;

                        k++;
                        l--;
                    } else if (sum < target) {
                        k++;
                    } else {
                        l--;
                    }
                }
            }
        }
        return ans;
    }
}
```
