### Remove Duplicates from Sorted Array Problem
# Intuition
Since the array is already sorted, any duplicates will appear next to each other.
We can remove duplicates in-place by overwriting them with the next unique element as we traverse.

# Approach
- Maintain an index k to store the position of the next unique element.
- Traverse through each number x in nums:
- - If k == 0 (first element) or x != nums[k - 1] (different from last unique),
assign nums[k] = x and increment k.
- At the end, k will be the length of the array without duplicates, and the first k elements will be unique.

# Complexity
- Time complexity:
O(n) — We only iterate through the array once.

- Space complexity:
O(1) — No extra data structures, in-place update.

# Code
```java []
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 0;
        for (int x : nums) {
            if (k == 0 || x != nums[k - 1]) {
                nums[k++] = x;
            }
        }
        return k;
    }
}
```
