## Brute Force - TLE
```
class Solution {
    public boolean isUgly(int n) {
        if (n <= 0) return false;
        for (int i = 2; i <= n; i++) {
            while (n % i == 0) {
                n /= i;
                if (i != 2 && i != 3 && i != 5) {
                    return false;
                }
            }
        }
        return true;
    }
}
```


## prime factorization approach
```
class Solution {
    public boolean isUgly(int n) {
        if (n <= 0) return false;
        for (int factor : new int[]{2, 3, 5}) {
            while (n % factor == 0) {
                n /= factor;
            }
        }
        return n == 1;
    }
}
```
