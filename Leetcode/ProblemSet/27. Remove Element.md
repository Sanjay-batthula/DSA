### Remove Element Problem
# Intuition
We need to remove all occurrences of a given value val from the array, in-place, without using extra space.
Since the order of elements can be changed but isn’t required to, we can simply overwrite unwanted elements with the next valid ones as we go.

# Approach
- Maintain an index k to track the position where the next valid element should be placed.

- Loop through each element x in nums:

-  - If x is not equal to val, assign it to nums[k] and increment k.

- After the loop, k will be the new length of the array without any val.

- The first k elements in nums are the updated array.

# Complexity
- Time complexity:
O(n) — Single pass through the array.

- Space complexity:
O(1) — Done in-place with only a few extra variables.

# Code
```java []
class Solution {
    public int removeElement(int[] nums, int val) {
        int k = 0;
        for (int x : nums) {
            if (x != val) {
                nums[k++] = x;
            }
        }
        return k;
    }
}
```
