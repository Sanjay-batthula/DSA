## Brute Force
```
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        int[] temp = new int[n];
        int k = 0;
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) temp[k++] = nums[i];
        }
        while (k < n) temp[k++] = 0;
        for (int i = 0; i < n; i++) nums[i] = temp[i];
    }
}
```


## in-place shifting approach
```
class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] == 0) {
                for (int j = i; j < n - 1; j++) {
                    nums[j] = nums[j + 1];
                }
                nums[n - 1] = 0;
                i--; 
                n--; 
            }
        }
    }
}

```

## two-pointer approach
```
class Solution {
    public void moveZeroes(int[] nums) {
        int i = 0;
        for (int j = 0; j < nums.length; j++) {
            if (nums[j] != 0) {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
                i++;
            }
        }
    }
}
```
