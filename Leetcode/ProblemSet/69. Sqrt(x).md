## Using Math.sqrt(x)
```
class Solution {
    public int mySqrt(int x) {
        return (int)Math.sqrt(x);
    }
}

```


## Binary Search Approach
```
class Solution {
    public int mySqrt(int x) {
        int l = 0, r = x;
        while (l < r) {
            int mid = (l + r + 1) >>> 1;
            if (mid > x / mid) {
                r = mid - 1;
            } else {
                l = mid;
            }
        }
        return l;
    }
}
```
## Brute Force Approach
```
class Solution {
    public int mySqrt(int x) {
        int i = 0;
        while ((long)i * i <= x) i++;
        return i - 1;
    }
}
```

## Recursive Approach
```
class Solution {
    public int mySqrt(int x) {
        return helper(0, x);
    }
    private int helper(int i, int x) {
        if ((long)i * i > x) return i - 1;
        return helper(i + 1, x);
    }
}
```
