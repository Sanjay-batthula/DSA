## Brute Force
```
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int[] merged=new int[m+n];
        int idx = 0;
        for (int i=0;i<m;i++) {
            merged[idx++]=nums1[i];
        }
        for (int j=0;j<n;j++) {
            merged[idx++]=nums2[j];
        }
        java.util.Arrays.sort(merged);
        for (int k=0;k<m+n;k++) {
            nums1[k] = merged[k];
        }
    }
}
```


## two-pointer approach
```
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        //two pointer approach
        int i=m-1;
        int j=n-1;
        int pos=m+n-1;

        while (j>=0) {
            if (i>=0 && nums1[i]>=nums2[j]) {
                nums1[pos]=nums1[i];
                i--;
            }else{
                nums1[pos]=nums2[j];
                j--;
            }
            pos--;
        }
    }
}
```
