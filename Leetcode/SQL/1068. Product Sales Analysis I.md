## 1068. Product Sales Analysis I

## JOIN-based product enrichment
| Section       | Details                                                                                                                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | Each sale record contains a `product_id`, but the corresponding `product_name` exists only in the `Product` table. Since every sale must be reported, we enrich each sale row with its product name. |
| **Approach**  | Use the `Sales` table as the base and perform a `LEFT JOIN` with the `Product` table on `product_id`. This attaches `product_name` when available while preserving all sales rows.                   |

```
SELECT p.product_name, s.year, s.price
FROM Sales s LEFT JOIN Product p ON
    s.product_id = p.product_id
```
