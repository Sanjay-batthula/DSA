## 1211. Queries Quality and Percentage

## Group-by aggregation with conditional counting
```
SELECT
    query_name,
    ROUND(AVG(rating / position), 2) AS quality,
    ROUND(100 * SUM(rating < 3) / COUNT(*), 2) AS poor_query_percentage
FROM Queries
GROUP BY query_name;
```

## Group-by conditional aggregation with ratio averaging
```
SELECT 
    query_name,
    ROUND(AVG(1.0 * rating / position), 2) AS quality,
    ROUND(AVG(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100, 2) AS poor_query_percentage
FROM 
    Queries
GROUP BY 
    query_name;
```
