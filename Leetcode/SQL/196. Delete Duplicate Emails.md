# 196. Delete Duplicate Emails
Table: Person
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
```
id is the primary key (column with unique values) for this table.
Each row of this table contains an email. The emails will not contain uppercase letters.

## Problem Description
Write a solution to delete all duplicate emails, keeping only one unique email with the smallest id.  
For SQL users, please note that you are supposed to write a DELETE statement and not a SELECT one.
For Pandas users, please note that you are supposed to modify Person in place.  
After running your script, the answer shown is the Person table. The driver will first compile and run your piece of code and then show the Person table. The final order of the Person table does not matter.  

The result format is in the following example.

## Self Join Delete approach
| Section       | Details                                                                                                                                                                     |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | If two rows have the **same email**, only the row with the **smallest id should survive**. Any row with a **greater id for the same email is garbage**.                     |
| **Approach**  | Join the table with itself on `email`. For each duplicate pair, delete the row where `id` is **greater than the matching row’s id**. This directly targets only duplicates. |

```
DELETE p1
FROM Person p1
JOIN Person p2
ON p1.email = p2.email AND p1.id > p2.id;
```

## Group-by Minimum ID Deletion (Derived Table)
| Section       | Details                                                                                                                                                                            |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | For each email, only the **minimum id is valid**. Any row whose id is **not one of these minimum ids must be deleted**.                                                            |
| **Approach**  | First compute `MIN(id)` per email using `GROUP BY`. Then delete all rows whose `id` is **not in that survivor list**. A derived table is used to avoid MySQL’s delete restriction. |

```
DELETE
FROM Person
WHERE id NOT IN (
    SELECT id
    FROM (
        SELECT MIN(id) AS id
        FROM Person
        GROUP BY email
    ) t
);
```
