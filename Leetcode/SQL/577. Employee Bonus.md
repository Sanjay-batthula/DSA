## NOT EXISTS approach
```
SELECT e.name, b.bonus
FROM Employee e
LEFT JOIN Bonus b ON e.empId = b.empId
WHERE b.bonus < 1000
   OR NOT EXISTS (
        SELECT 1
        FROM Bonus b2
        WHERE b2.empId = e.empId
   );
```

## LEFT OUTER JOIN with conditional filtering
```
select name, bonus
from employee
left join bonus on employee.empid=bonus.empid
where bonus is null or bonus<1000
```
