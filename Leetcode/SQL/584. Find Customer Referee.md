# 584. Find Customer Referee

Table: Customer
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| name        | varchar |
| referee_id  | int     |
+-------------+---------+
```
In SQL, id is the primary key column for this table.
Each row of this table indicates the id of a customer, their name, and the id of the customer who referred them.


## Problem Description
Find the names of the customer that are either:
- referred by any customer with id != 2.
- not referred by any customer.
Return the result table in any order.

The result format is in the following example.
## Sample Test Cases
Example 1:

Input: 
Customer table:
```
+----+------+------------+

+----+------+------------+

```

```
+------+
| name |
+------+
| Will |

| Bill |
| Zack |
+------+
```

## Approach 1: Conditional filtering with explicit NULL handling (Preferred)
| Section             | Details                                                                                                        |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Intuition**       | Customers with `referee_id = 2` must be excluded; customers with `NULL` referrers must be included explicitly. |
| **Approach**        | Use a direct conditional predicate combining value exclusion and explicit `NULL` inclusion.                    |
                                                                                    


### Query
```
select name
from customer
where referee_id != 2 or referee_id is NULL
```
