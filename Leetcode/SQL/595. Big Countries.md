## 595. Big Countries

Table: World
```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| name        | varchar |
| continent   | varchar |
| area        | int     |
| population  | int     |
| gdp         | bigint  |
+-------------+---------+
```

name is the primary key (column with unique values) for this table.
Each row of this table gives information about the name of a country, the continent to which it belongs, its area, the population, and its GDP value.
 
## Problem Description
A country is big if:
- it has an area of at least three million (i.e., 3000000 km2), or
- it has a population of at least twenty-five million (i.e., 25000000).
Write a solution to find the name, population, and area of the big countries.
Return the result table in any order.  
The result format is in the following example.

## Boolean Indexing in Pandas
| Section       | Details                                                                                                                                                                                |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Intuition** | A country qualifies as big if **either** its area is very large **or** its population is very high. We only care about countries meeting at least one of these thresholds.             |
| **Approach**  | Apply a single **OR-based filter** to select rows where `area ≥ 3000000` **or** `population ≥ 25000000`, then **project** only the required columns: `name`, `population`, and `area`. |

```
import pandas as pd
def big_countries(world: pd.DataFrame) -> pd.DataFrame:
    return world[(world["area"] >= 3000000) | (world["population"] >= 25000000)][["name", "population", "area"]]
```

## Selection + Projection
| Section       | Details                                                                                                                                                                              |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Intuition** | A country should be included if it satisfies **at least one** of the two “big country” conditions: large area or large population. Rows not meeting either condition are irrelevant. |
| **Approach**  | Use a **WHERE clause with an OR predicate** to filter rows based on the size conditions, then **select only the required columns** (`name`, `population`, `area`) using projection.  |

```
SELECT name, population, area
FROM World
WHERE area >= 3000000
   OR population >= 25000000;
```
