# ⚡ Check if a Number is a Power of Another Number

## 🧾 Problem Statement

Given two positive numbers `x` and `y`, determine if `y` is a **power of** `x`.

That means: check if there exists some integer `k ≥ 0` such that:

```
x^k = y
```

---

## ✨ Examples

### Input

```
x = 10, y = 1
```

### Output

```
True
```

Explanation: `10^0 = 1`

---

### Input

```
x = 10, y = 1000
```

### Output

```
True
```

Explanation: `10^3 = 1000`

---

### Input

```
x = 10, y = 1001
```

### Output

```
False
```

---

## 📌 Constraints

* `1 <= x, y <= 10^12`
* Both `x` and `y` are positive integers

---

## 💡 Logic

1. If `x == 1`, then the **only valid power** is `y == 1`.
2. Otherwise, check whether repeated multiplication of `x` can reach `y`.
3. Optimized approaches use **binary search** or **logarithms** to speed things up.

---

## 🧠 Approaches

### 🔹 Naive Approach – Repeated Multiplication

* Start with `pow = 1`
* Keep multiplying by `x` until `pow >= y`
* If `pow == y`, return `true`, else return `false`

**Code:**

```java
public class Main {
    public static boolean isPower(int x, long y) {
        if (x == 1) return (y == 1);

        long pow = 1;
        while (pow < y) {
            pow *= x;
        }

        return (pow == y);
    }

    public static void main(String[] args) {
        System.out.println(isPower(10, 1));   // true
        System.out.println(isPower(1, 20));   // false
        System.out.println(isPower(2, 128));  // true
        System.out.println(isPower(2, 30));   // false
    }
}
```

**Time Complexity:** `O(log_y x)`
**Space Complexity:** `O(1)`

---

### 🔹 Better Approach – Exponentiation + Binary Search

* Try to grow powers of `x` quickly (using repeated squaring).
* If we overshoot `y`, use binary search between ranges to check.

**Code:**

```java
public class PowerCheck {
    public static boolean isPower(int x, long y) {
        if (x == 1) return (y == 1);
        if (y == 1) return true;

        long pow = x;
        while (pow < y) {
            pow *= pow;
        }

        if (pow == y) return true;

        long low = x, high = pow;
        while (low <= high) {
            long mid = low + (high - low) / 2;
            long result = (long) Math.pow(x, (int)(Math.log(mid) / Math.log(x)));

            if (result == y) return true;
            if (result < y) low = mid + 1;
            else high = mid - 1;
        }
        return false;
    }

    public static void main(String[] args) {
        System.out.println(isPower(10, 1));   // true
        System.out.println(isPower(1, 20));   // false
        System.out.println(isPower(2, 128));  // true
        System.out.println(isPower(2, 30));   // false
    }
}
```

**Time Complexity:** `O(log log y)`
**Space Complexity:** `O(1)`

---

### 🔹 Expected Approach – Logarithmic Method

* Use:

  ```
  k = log(y) / log(x)
  ```
* If `k` is an integer, then `y` is a power of `x`.

**Code:**

```java
import java.lang.Math;

public class Main {
    public static boolean isPower(int x, int y) {
        double res1 = Math.log(y) / Math.log(x);
        return res1 == Math.floor(res1);
    }

    public static void main(String[] args) {
        System.out.println(isPower(2, 128));  // true
    }
}
```

**Time Complexity:** `O(1)`
**Space Complexity:** `O(1)`

---

## ⏱️ Complexity Comparison

| Approach      | Time         | Space |
| ------------- | ------------ | ----- |
| Naive Loop    | O(log\_y x)  | O(1)  |
| Binary Search | O(log log y) | O(1)  |
| Logarithmic   | O(1)         | O(1)  |

---

## 📝 Notes

* If `x = 1`, only `y = 1` is valid.
* Logarithmic approach is **fastest** but may suffer from floating-point precision issues for very large numbers.
* Binary search method avoids floating-point errors but is more complex.
