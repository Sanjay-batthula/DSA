
# 📏 Distance Between Two Points

## 🧾 Problem Statement

You are given two points `(x1, y1)` and `(x2, y2)` in a 2D plane.
Your task is to calculate the **distance between these two points**.

The formula is derived from the **Pythagorean theorem**:

$$
Distance = \sqrt{(x2 - x1)^2 + (y2 - y1)^2}
$$

---

## ✨ Examples

### Input

```
x1 = 3, y1 = 4
x2 = 7, y2 = 7
```

### Output

```
5
```

---

### Input

```
x1 = 3, y1 = 4
x2 = 4, y2 = 3
```

### Output

```
1.41421
```

---

## 📌 Constraints

* Coordinates are integers: `-10^5 <= x1, y1, x2, y2 <= 10^5`

---

## 💡 Logic

1. Compute the difference in x-coordinates: `dx = x2 - x1`
2. Compute the difference in y-coordinates: `dy = y2 - y1`
3. Use Pythagoras:

   ```
   distance = sqrt(dx^2 + dy^2)
   ```
4. Round the result if necessary.

---

## 🧑‍💻 Java Code

```java
// Java program to calculate distance between two points
class GFG {
    // Function to calculate distance
    static double distance(int x1, int y1, int x2, int y2) {
        return Math.sqrt(Math.pow(x2 - x1, 2)
                       + Math.pow(y2 - y1, 2) * 1.0);
    }

    // Driver code
    public static void main(String[] args) {
        System.out.println(
            Math.round(distance(3, 4, 4, 3) * 100000.0) / 100000.0
        );
    }
}
```

---

## ⏱️ Time and Space Complexity

* **Time Complexity:** `O(1)` → Just arithmetic + sqrt operation
* **Space Complexity:** `O(1)` → No extra memory used

---

## 📝 Notes

* Formula is symmetric → distance is the same regardless of order of points.
* Works for **integer and floating-point** coordinates.
* Commonly used in **geometry, graphics, AI, and competitive programming**.
