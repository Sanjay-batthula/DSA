# ✅ Check Whether a Triangle is Valid

## Intuition

A triangle is valid if the **sum of any two sides is greater than the third side**.
So, for sides `a`, `b`, `c`, the conditions are:

* `a + b > c`
* `a + c > b`
* `b + c > a`

If all hold true → the triangle is **Valid**, else **Invalid**.

---

## Approach

1. Take three side lengths `a`, `b`, `c`.
2. Check the three conditions above.
3. If they hold, print `"Valid"`. Otherwise, print `"Invalid"`.

---

## Complexity

* **Time Complexity:**

  $$
  O(1)
  $$

  (just three checks).

* **Space Complexity:**

  $$
  O(1)
  $$

  (no extra space used).

---

## Code

```java
public class TriangleCheck {
    public static void main(String[] args) {
        int a = 7, b = 10, c = 5;

        if (a + b > c && a + c > b && b + c > a) {
            System.out.println("Valid");
        } else {
            System.out.println("Invalid");
        }
    }
}
```

---

## Example

**Input:**

```
a = 7, b = 10, c = 5
```

**Output:**

```
Valid
```
