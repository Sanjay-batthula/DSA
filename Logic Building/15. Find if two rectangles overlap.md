
# 🟦 Rectangle Overlap

## 🧾 Problem Statement

You are given two **axis-aligned rectangles** in a 2D plane.  
Each rectangle is represented by two points:

- **Top-left corner (l)**
- **Bottom-right corner (r)**

Your task is to determine if the two rectangles **overlap**.

---

## ✨ Examples

### Input
```

l1 = (0, 10), r1 = (10, 0)
l2 = (5, 5), r2 = (15, 0)

```

### Output
```

Rectangles Overlap

```

---

### Input
```

l1 = (0, 10), r1 = (10, 0)
l2 = (-10, 5), r2 = (-1, 0)

```

### Output
```

Rectangles Don't Overlap

````

---

## 📌 Constraints

* Coordinates are integers: `-10^5 <= x, y <= 10^5`
* Rectangles are **parallel to the coordinate axes**.

---

## 💡 Logic

Two rectangles **do not overlap** if **either** of these is true:

1. One rectangle is **completely to the left** of the other.  
   `l1.x > r2.x || l2.x > r1.x`

2. One rectangle is **completely above** the other.  
   `r1.y > l2.y || r2.y > l1.y`

If neither condition is satisfied → **they overlap** ✅

---

## 🧑‍💻 Java Code

```java
public class RectangleOverlap {

    static class Point {
        int x, y;
        Point(int x, int y) {
            this.x = x;
            this.y = y;
        }
    }

    static boolean doOverlap(Point l1, Point r1, Point l2, Point r2) {
        if (l1.x > r2.x || l2.x > r1.x) return false;
        if (r1.y > l2.y || r2.y > l1.y) return false;
        return true;
    }

    public static void main(String[] args) {
        Point l1 = new Point(0, 10);
        Point r1 = new Point(10, 0);
        Point l2 = new Point(5, 5);
        Point r2 = new Point(15, 0);

        if (doOverlap(l1, r1, l2, r2))
            System.out.println("Rectangles Overlap");
        else
            System.out.println("Rectangles Don't Overlap");
    }
}
````

---

## ⏱️ Time and Space Complexity

* **Time Complexity:** `O(1)` → Only comparisons
* **Space Complexity:** `O(1)` → No extra memory

---

## 📝 Notes

* Works only when rectangles are aligned to axes.
* For rotated rectangles, geometry calculations are more complex.
* This check is widely used in **graphics, collision detection, and computational geometry**.
