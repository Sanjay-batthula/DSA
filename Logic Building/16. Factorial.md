
# ✨ Factorial of a Number

## 🧾 Problem Statement

Given an integer `n (n ≥ 0)`, compute the **factorial** of `n`.

The factorial of `n` is defined as:

$$
n! = 1 \times 2 \times 3 \times \dots \times n
$$

Special cases:
- `0! = 1`
- `1! = 1`

---

## ✨ Examples

### Input
```

n = 5

```

### Output
```

120

```

---

### Input
```

n = 4

```

### Output
```

24

```

---

### Input
```

n = 0

```

### Output
```

1

```

---

## 📌 Constraints
* `0 <= n <= 20` (beyond this, factorial grows extremely large unless handled with BigInteger).

---

## 💡 Logic

1. **Iterative Approach**  
   Multiply numbers from `1` to `n`.

   Example for `n = 4`:  
```

res = 1
res = res \* 2 → 2
res = res \* 3 → 6
res = res \* 4 → 24

```

2. **Recursive Approach**  
Using the relation:
```

n! = n \* (n - 1)!
factorial(0) = 1
factorial(1) = 1

````

---

## 🧑‍💻 Iterative Java Code

```java
class GFG {
 static int factorial(int n) {
     int res = 1;
     for (int i = 2; i <= n; i++) {
         res *= i;
     }
     return res;
 }

 public static void main(String[] args) {
     int num = 5;
     System.out.println("Factorial of " + num + " is " + factorial(num));
 }
}
````

---

## 🧑‍💻 Recursive Java Code

```java
class GFG {
    static int factorial(int n) {
        if (n == 0 || n == 1) return 1;
        return n * factorial(n - 1);
    }

    public static void main(String[] args) {
        int num = 5;
        System.out.println("Factorial of " + num + " is " + factorial(num));
    }
}
```

---

## ⏱️ Time and Space Complexity

* **Iterative Approach:**

  * Time Complexity → `O(n)`
  * Space Complexity → `O(1)`

* **Recursive Approach:**

  * Time Complexity → `O(n)`
  * Space Complexity → `O(n)` (recursion stack)

---

## 📝 Notes

* Iterative is more **efficient** (no extra stack overhead).
* Recursive is **cleaner & elegant** but less memory efficient.
* Factorials grow **super fast** → use `BigInteger` in Java or Python’s `int` for large values.
* Applications: **permutations, combinations, probability, series expansions, statistics**.
* Related problems: **count trailing zeroes in factorial, factorial of large numbers**.
