# 🎲 Pair Cube Count – Medium

## 🧾 Problem Statement

Given an integer `n`, count all ordered pairs `(a, b)` such that:

$$
a^3 + b^3 = n
$$

⚡ Note: `(a, b)` and `(b, a)` are considered **two different pairs**.

---

## 📥 Input

* A single integer `n`

---

## 📤 Output

* The number of valid ordered pairs `(a, b)`

---

## ✨ Examples

### Example 1

**Input:**

```
n = 9
```

**Output:**

```
2
```

**Explanation:**

* `1³ + 2³ = 9`
* `2³ + 1³ = 9`

---

### Example 2

**Input:**

```
n = 28
```

**Output:**

```
2
```

**Explanation:**

* `1³ + 3³ = 28`
* `3³ + 1³ = 28`

---

## 📌 Constraints

* `1 ≤ n ≤ 10^9`

---

## 💡 Logic

1. A brute-force method tries all possible `a` and `b` up to `n`, which is **O(n²)** — not efficient.
2. A smarter way:

   * Iterate `a` from `1` to `cuberoot(n)`
   * Compute `n - a³`
   * Check if it’s a perfect cube → then `(a, b)` is valid.

---

## 🧠 Approaches

### 🔴 Naive Approach (O(n²))

Use **nested loops** to check all pairs `(a, b)`.

```java
public class GfG {
    static int countPairs(int n) {
        int count = 0;
        for (int a = 1; a <= n; a++) {
            for (int b = 0; b <= n; b++) {
                if (a * a * a + b * b * b == n) {
                    count++;
                }
            }
        }
        return count;
    }

    public static void main(String[] args) {
        int n = 9;
        System.out.println(countPairs(n));
    }
}
```

---

### 🟢 Optimized Approach (O(n^(1/3)))

Only loop `a` up to `cuberoot(n)`.

```java
class GfG {
    static int countPairs(int n) {
        int count = 0;

        for (int a = 1; a <= Math.cbrt(n); a++) {
            int cubeA = a * a * a;
            int diff = n - cubeA;

            int b = (int) Math.cbrt(diff);
            if (b * b * b == diff) {
                count++;
            }
        }
        return count;
    }

    public static void main(String[] args) {
        int n = 28;
        System.out.println(countPairs(n));
    }
}
```

---

## ⏱️ Time and Space Complexity

* **Naive:** `O(n²)` time, `O(1)` space
* **Optimized:** `O(n^(1/3))` time, `O(1)` space

---

## 🔑 Notes

* `(a, b)` and `(b, a)` are **different**, so both are counted.
* Works efficiently even for large `n` up to `10^9`.
