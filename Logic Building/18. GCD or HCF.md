# 🤝 GCD (Greatest Common Divisor) / HCF of Two Numbers – Easy

## 🧾 Problem Statement

Given two positive integers `a` and `b`, the task is to find their **GCD** (Greatest Common Divisor) or **HCF** (Highest Common Factor).

The **GCD** of two numbers is the largest number that divides both of them.

---

## 📥 Input

* Two positive integers `a`, `b`

---

## 📤 Output

* A single integer → the GCD of `a` and `b`

---

## ✨ Examples

### Example 1

**Input:**

```
a = 20, b = 28
```

**Output:**

```
4
```

**Explanation:**
Factors of 20 → `{1, 2, 4, 5, 10, 20}`
Factors of 28 → `{1, 2, 4, 7, 14, 28}`
Common factors → `{1, 2, 4}` → GCD = `4`

---

### Example 2

**Input:**

```
a = 60, b = 36
```

**Output:**

```
12
```

**Explanation:**
`GCD(60, 36) = 12`

---

## 📌 Constraints

* `1 ≤ a, b ≤ 10^9`

---

## 🧠 Approaches

### 🔴 Approach 1: Using Loop (O(min(a, b)))

Brute force: check factors of smaller number.

```java
class GFG {
    static int gcd(int a, int b) {
        int result = Math.min(a, b);
        while (result > 0) {
            if (a % result == 0 && b % result == 0)
                break;
            result--;
        }
        return result;
    }

    public static void main(String[] args) {
        int a = 20, b = 28;
        System.out.println(gcd(a, b));
    }
}
```

---

### 🟡 Approach 2: Euclidean Algorithm (Subtraction)

Keep subtracting smaller from larger until both are equal.

```java
class GfG {
    static int gcd(int a, int b) {
        if (a == 0) return b;
        if (b == 0) return a;
        if (a == b) return a;

        if (a > b)
            return gcd(a - b, b);
        return gcd(a, b - a);
    }

    public static void main(String[] args) {
        int a = 20, b = 28;
        System.out.println(gcd(a, b));
    }
}
```

---

### 🟢 Approach 3: Optimized Euclidean (Modulo)

Instead of subtraction, use modulo.

```java
class GfG {
    static int gcd(int a, int b) {
        return (b == 0) ? a : gcd(b, a % b);
    }

    public static void main(String[] args) {
        int a = 20, b = 28;
        System.out.println(gcd(a, b));
    }
}
```

✅ Time Complexity: `O(log(min(a, b)))`
✅ Space Complexity: `O(log(min(a, b)))`

---

### 🟣 Approach 4: Built-in Function (BigInteger)

Use Java’s built-in `gcd()`.

```java
import java.math.BigInteger;

class GfG {
    public static void main(String[] args) {
        int a = 20, b = 28;
        int gcd = BigInteger.valueOf(a).gcd(BigInteger.valueOf(b)).intValue();
        System.out.println(gcd);
    }
}
```

---

## ⏱️ Time & Space Complexity Summary

| Approach                | Time Complexity   | Space Complexity  |
| ----------------------- | ----------------- | ----------------- |
| Loop                    | O(min(a, b))      | O(1)              |
| Euclidean (Subtraction) | O(min(a, b))      | O(min(a, b))      |
| Euclidean (Modulo)      | O(log(min(a, b))) | O(log(min(a, b))) |
| Built-in                | O(log(min(a, b))) | O(1)              |

---

## 🔑 Notes

* Euclidean Algorithm (Modulo) is the **most efficient**.
* Built-in `BigInteger.gcd()` is super handy for large numbers.
* GCD is the backbone for problems like **LCM, coprime checks, number theory, fractions simplification**.
