# 🔍 Closest Number Divisible by m – Medium

## 🧾 Problem Statement

Given two integers `n` and `m` (`m != 0`), find the number closest to `n` that is divisible by `m`.  
If there are two such numbers equally close, choose the one with the **maximum absolute value**.

---

## 📥 Input

- Two integers `n` and `m`

---

## 📤 Output

- A single integer: the closest number to `n` that is divisible by `m`

---

## 📌 Examples

### Example 1
**Input**  
n = 13
m = 4

**Output**  
12

**Explanation:** 12 is the closest to 13 and divisible by 4.

---

### Example 2
**Input**  
n = -15
m = 6

**Output**  
-18

**Explanation:** Both -12 and -18 are equally close to -15, but -18 has the larger absolute value.

---

## 💡 Logic

- Find the number `q = n / m` (integer division).
- Compute the nearest multiples:  
  - `n1 = m * q`  
  - `n2 = m * (q + 1)`  
- Compare which is closer to `n`.
- If both distances are equal, choose the one with the greater absolute value.

---

## 🧠 My Approach

1. Calculate `q = n // m` (integer division).
2. Compute:
   - `n1 = m * q` (lower multiple)
   - `n2 = m * (q + 1)` (higher multiple)
3. Compare `abs(n - n1)` and `abs(n - n2)`.
4. If equal, return the number with the **larger absolute value**.
5. Else, return the closer one.

---

## ⏱️ Time and Space Complexity

- **Time Complexity:** O(1) — only constant-time operations  
- **Space Complexity:** O(1)

---

## 👨‍💻 Java Code

```java
import java.util.Scanner;

public class ClosestDivisible {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();

        int q = n / m;
        int n1 = m * q;
        int n2 = (m * (n < 0 ? q - 1 : q + 1));

        if (Math.abs(n - n1) < Math.abs(n - n2)) {
            System.out.println(n1);
        } else if (Math.abs(n - n1) > Math.abs(n - n2)) {
            System.out.println(n2);
        } else {
            System.out.println(Math.abs(n1) > Math.abs(n2) ? n1 : n2);
        }
    }
}
```
