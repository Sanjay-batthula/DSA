# 🎲 Opposite Face of a Dice – Easy

## 🧾 Problem Statement

You are given a standard cubic dice with faces numbered from 1 to 6.  
Given a number `n` on one face, find the number on the **opposite face**.

In a normal dice:
- 1 ↔ 6  
- 2 ↔ 5  
- 3 ↔ 4  

---

## 📥 Input

- An integer `n` (1 ≤ n ≤ 6) representing the number on the given face.

---

## 📤 Output

- An integer representing the number on the opposite face of the dice.

---

## 📌 Examples

### Example 1
**Input**  
2

**Output**  
5

**Explanation:** 2 is opposite to 5 on a standard dice.

---

### Example 2
**Input**  
6

**Output**  
1

**Explanation:** 6 is opposite to 1 on a standard dice.

---

## 💡 Logic

- In a standard dice, the sum of numbers on opposite faces is always **7**.
- So, the opposite face number is simply `7 - n`.

---

## 🧠 My Approach

1. Read the integer `n`.
2. Calculate `opposite = 7 - n`.
3. Output `opposite`.

---

## ⏱️ Time and Space Complexity

- **Time Complexity:** O(1) – constant operations.  
- **Space Complexity:** O(1) – no extra storage used.

---

## 👨‍💻 Java Code

```java
import java.util.Scanner;

public class OppositeFaceDice {
    public static int oppositeFace(int n) {
        return 7 - n;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(oppositeFace(n));
    }
}
```
