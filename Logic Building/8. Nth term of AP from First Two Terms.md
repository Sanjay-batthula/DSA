# 💪 Arithmetic Progression – Find Nth Term

## 🧾 Problem Statement

Given two integers `a1` (the first term) and `a2` (the second term) of an **Arithmetic Progression (AP)**, along with an integer `n`, find the `n`th term of the sequence.

In an AP, the difference between consecutive terms is constant.

---

## 📥 Input

* Three integers:

  * `a1` → first term
  * `a2` → second term
  * `n` → the term position to find

---

## 📤 Output

* Print the value of the `n`th term.

---

## ✨ Examples

### Input

```
a1 = 2, a2 = 3, n = 4
```

### Output

```
5
```

### Input

```
a1 = 1, a2 = 3, n = 10
```

### Output

```
19
```

---

## 📌 Constraints

* `-10^5 <= a1, a2 <= 10^5`
* `1 <= n <= 10^5`

---

## 💡 Logic

1. Compute the common difference:

   ```
   d = a2 - a1
   ```
2. Formula for the nth term:

   ```
   tN = a1 + (n - 1) * d
   ```
3. Return `tN`.

---

## 🧠 Approaches

### 🔹 Naive Approach (Loop)

* Start with `a1`.
* Keep adding the common difference `d` until reaching the nth term.
* Time Complexity → `O(n)`

### 🔹 Optimized Approach (Formula)

* Use direct formula:

  ```
  tN = a1 + (n - 1) * (a2 - a1)
  ```
* Time Complexity → `O(1)`

---

## 🧑‍💻 Java Code

### Naive Approach

```java
public class Main {
    public static int nthTermOfAP(int a1, int a2, int n) {
        int nthTerm = a1, d = a2 - a1;
        for (int i = 1; i < n; i++) {
            nthTerm += d;
        }
        return nthTerm;
    }

    public static void main(String[] args) {
        int a1 = 2, a2 = 3, n = 4;
        System.out.println(nthTermOfAP(a1, a2, n));
    }
}
```

### Optimized Formula Approach

```java
public class Main {
    public static int nthTermOfAP(int a1, int a2, int n) {
        return a1 + (n - 1) * (a2 - a1);
    }

    public static void main(String[] args) {
        int a1 = 2, a2 = 3, n = 4;
        System.out.println(nthTermOfAP(a1, a2, n));
    }
}
```

---

## ⏱️ Time and Space Complexity

* **Naive Approach:**

  * Time → `O(n)`
  * Space → `O(1)`

* **Formula Approach:**

  * Time → `O(1)`
  * Space → `O(1)`

---

## 📝 Notes

* Formula-based approach is **always preferred** since it’s constant-time.
* Works for both positive and negative differences in the sequence.
* Useful in competitive programming when `n` is very large.
