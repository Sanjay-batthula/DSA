## 📌 About This Repository

This repository documents my work across **Data Structures, Algorithms, and SQL**, covering algorithmic problem-solving, programming fundamentals, database querying, and optimisation techniques.

The focus goes beyond producing correct outputs. It emphasises understanding the underlying concepts, evaluating different approaches, and developing solutions that are efficient, readable, and maintainable.

Solutions are implemented using **Java, Python, and SQL**, combining algorithmic thinking with practical programming and data manipulation skills.

The repository serves as a structured technical reference for problem-solving techniques, algorithmic patterns, and query optimisation.

---

## 🧠 Core Focus Areas

- **Problem-Solving:** Breaking down complex challenges into manageable components and developing logical solutions.
- **Data Structures & Algorithms:** Understanding fundamental concepts, algorithmic patterns, and efficient implementations.
- **Multiple Approaches:** Exploring brute-force, intermediate, and optimised solutions where applicable.
- **Complexity Analysis:** Evaluating time and space complexity using Big O notation.
- **SQL & Database Queries:** Working with relational data, joins, aggregations, subqueries, and analytical queries.
- **Optimisation:** Improving algorithmic efficiency, query structure, and code readability.
- **Pattern Recognition:** Identifying reusable techniques across different computational problems.

## ⚙️ Problem-Solving Methodology

### 01. Understand
Analyse the problem statement, constraints, expected output, and potential edge cases.

### 02. Develop
Identify relevant concepts and formulate an initial solution using logical reasoning.

### 03. Explore
Evaluate alternative algorithms, data structures, or SQL query strategies.

### 04. Optimise
Analyse computational complexity, reduce unnecessary operations, and improve overall efficiency.

### 05. Implement & Validate
Develop solutions using Java, Python, or SQL, test their correctness, and refine them where necessary.
